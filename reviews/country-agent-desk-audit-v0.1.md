# 국가별 전문가 에이전트 범위·누락·중지권 감사 v0.1

## 감사 목적

`agents/countries/`가 국가 이름만 나열한 조직도가 아니라 실제 조사 라우팅·문화 무결성·설정 생성 중지를 수행할 수 있는지 점검한다.

## 종합 판정

**조건부 통과.**

- 한국·태국·베트남은 지역 파일럿 연구가 존재한다.
- 중국·일본·몽골·동남아 다수는 내부 분해와 금지선이 있는 구조화 라우팅 데스크다.
- 중앙아시아·남아시아·러시아 극동·홍콩·마카오의 개별 파일은 현재 설정 전문가가 아니라 보류 표식이다.
- 모든 국가를 지금 상세화하는 대신 실제 등장 필요 순서에 따라 연구하도록 운영해야 한다.
- AI 데스크는 현지 문화 전문가나 감수자를 대체하지 않는다.

# 감사 항목별 판정

## 1. 각 국가 파일에 필요한 이유와 내부 권역이 있는가

### 통과

다음 상세 데스크는 국가 내부 차이·클리셰·금지 작업을 어느 정도 명시한다.

- 한국
- 중국
- 일본
- 몽골
- 한반도 북부·접경
- 대만
- 태국
- 베트남
- 라오스
- 캄보디아
- 미얀마
- 말레이시아
- 싱가포르
- 인도네시아
- 필리핀
- 브루나이
- 동티모르

### 미통과·보류

다음 개별 데스크는 현재 표식 수준이므로 구체 설정을 생성할 수 없다.

- 홍콩·마카오
- 카자흐스탄·키르기스스탄·우즈베키스탄·타지키스탄·투르크메니스탄
- 인도·파키스탄·방글라데시·네팔·부탄·스리랑카·몰디브·아프가니스탄
- 러시아 극동·시베리아 접경

### 보정

`agents/countries/STATUS.md`에서 준비도와 허용·금지 작업을 명시했다. 보류 파일은 실제 전문가 완성이 아니라 누락 방지용 라우팅 표식으로 취급한다.

## 2. 현존 종교·소수집단·분쟁의 중지 조건이 있는가

### 판정

기존 권역·상세 데스크에는 일부 존재했으나 전체 파일에 일관되지 않았다.

### 보정

공통 중지 조건을 상태 인덱스와 `templates/country-desk.md`에 추가했다.

중지 대상:

- 현존 종교·신성 의례의 직접 전용
- 소수민족·원주민 전승을 대표 술법·생물로 변환
- 전쟁·분단·학살·난민·인권 피해의 판타지화
- 현재 영토·국경 분쟁의 숨은 세계 진짜 원인화
- 공동체 자기서술과 현지 감수 없이 고위험 설정 생성

## 3. 국가 데스크와 권역 리드의 역할이 중복되는가

### 판정

역할 구분을 명시하면 통과.

### 권역 리드의 역할

- 산맥·강·해류·계절풍·교역·이주 등 초국가 연결
- 국가 간 비교와 공통 조사 질문
- 한 국가 자료로 권역 전체를 설명하는 오류 검사
- 회랑·국제 질서·번역 충돌 분석

### 국가 데스크의 역할

- 국가 내부 지역·언어·법·도시·현대생활 분해
- 자기명칭·공공기관·학술·공동체 자료 확인
- 국가별 정치·역사·종교 민감도와 중지권
- 작품에서 등장할 구체 지역 파일럿 범위 설정

두 역할은 상하 관계가 아니라 교차 검증 관계다.

## 4. 특수 범위가 분리되어 있는가

### 한반도 북부·접경

별도 파일이 있으며 한국 학교의 잃어버린 비밀 지역으로 소비하지 못하게 한다. 공개 자료·안보·인권·주민 자기서술 한계 때문에 고위험 `structured-routing`으로 유지한다.

### 대만

별도 데스크가 존재한다. 중국·일본·남양권의 중간 장식으로 취급하지 않으며 내부 지역·언어·원주민 공동체 연구가 필요하다.

### 홍콩·마카오

별도 표식은 있으나 하나의 통합 상세 데스크로는 부족하다. 향후 실제 등장 시 홍콩과 마카오를 각각 도시사·법·언어·식민·현대생활 기준으로 분리한다.

### 중국 내부 민감 지역

티베트·신장·내몽골 등을 중국의 특수 마법 권역으로 자동 생성하지 않는다. 별도 지역·언어·민족·종교·정치 조사와 감수가 필요하다.

### 미얀마·아프가니스탄 등 분쟁 지역

현대 분쟁과 피해를 판타지 세력전으로 변환하지 않는다. 안전한 자료·자기서술·감수 경로가 없으면 설정 생성을 중지한다.

## 5. 현지 감수자를 AI가 대체하지 않는가

### 판정

통과.

운영 규칙:

- AI 데스크는 조사 범위와 위험을 정리하는 라우터다.
- 출처 카드와 공공·학술 자료만으로 문화 정본을 만들 수 없다.
- 현존 종교·소수집단·신성 의례·분쟁·정체성 고위험 항목은 현지 인간 감수가 필요하다.
- 감수자가 없으면 `candidate` 이상의 승격과 구체 창작 전용을 중지한다.

## 6. 등장 순서 전에 대량 설정을 만들지 않는가

### 판정

기존 국가 파일 수가 많아 자동 확장 위험이 있었으나 상태 분류로 보정했다.

운영 제한:

- 세계 지도에는 존재해도 상세 설정을 만들지 않는다.
- 본편 5권에서 필요한 지역만 파일럿으로 승격한다.
- 3권 본격 해외 지역은 한 곳으로 제한한다.
- 다른 국가는 교환학생·기관명·도감 항목을 만들기 전에도 실제 연구 필요성을 검토한다.
- 보류 데스크는 설정 생성이 아니라 향후 누락 방지와 연구 계획만 담당한다.

# 누락·과잉 분할 감사

## 누락된 광역 범위

현재 상세 국가 데스크가 없는 주요 범위:

- 서아시아 각국
- 캅카스
- 유럽 내부 지역
- 북아프리카
- 아메리카·오세아니아
- 러시아 서부와 북극권 전체

현재 작품의 동양 중심·범아시아 우선 범위에서는 즉시 생성할 필요가 없다. `western-contact-desks.md`는 교류 질문만 담당하며 이 지역들을 대표하지 않는다.

## 과잉 분할 위험

- 모든 현대 국가마다 즉시 학교·술법·기관을 만드는 것
- 실제 등장하지 않는 국가를 동일 깊이로 조사하는 것
- 국가 데스크 수를 세계관의 완성도로 오해하는 것

대응:

- 준비도 상태와 등장 순서 기반 연구
- 권역 리드와 국가 데스크의 이중 라우팅
- 보류 데스크의 설정 생성 금지

# 국가별 술법 배정 금지 재검사

다음 자동 배정은 모두 실패로 판정한다.

- 한국=부적·무속
- 중국=무공·선법
- 일본=음양술·결계
- 몽골=샤먼·말·별
- 태국=정령술
- 베트남=용·삼계술
- 인도=차크라·요가
- 인도네시아=섬·화산 정령

지역 인물은 다른 지역의 기술을 배우거나 현대 장비·공통 안전 절차를 사용할 수 있다. 술법은 국적이 아니라 교육·관계·환경·전승·개인 선택과 연결한다.
