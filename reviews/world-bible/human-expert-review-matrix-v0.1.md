# 세계 설정집 인간·전문가 검토 매트릭스 v0.1

## 1. 상태 정의

| 상태 | 의미 |
|---|---|
| auto-candidate | 내부 설계·테스트에 사용 가능 |
| author-gate | 작가 의도 선택 전 canon 금지 |
| expert-gate | 전문 검토 전 현실 세부·canon 금지 |
| local-gate | 현지 언어·생활·당사자 감수 전 구체화 금지 |
| reader-gate | 실제 독자 반응 전 문체·공개 밀도·상품화 확정 금지 |
| legal-gate | 법적 표현·계약·권한·상표 확정 금지 |
| protected-private | 검토와 무관하게 일반 공개 제한 |
| publish-gate | 판형·삽화·분권·가격·유통 확정 금지 |

# 3. 청소년·성인 독자 검토

## 대상 그룹

- 10~12세: 핵심 미스터리·용어·긴장·학교 매력
- 13~15세: 관계·권리·제도 갈등·완독 리듬
- 성인: 기관 현실성·설명 밀도·감정 복합성
- 보호자·교사 독자: 미성년 안전·가족·학교 신뢰

| 자료 | 질문 | 통과 기준 | 실패 시 |
|---|---|---|---|
| 첫 부제작 1~3장 | 첫 가치와 이상을 이해하는가 | 핵심 질문을 자기 말로 설명 | 도입 용어·기준선 조정 |
| 7장/8장 분권 경계 | 1권 보상과 2권 재가동이 있는가 | 절단 판매가 아닌 중간 전환 | 단권 통합 |
| 13~14장 클라이맥스 | 현장에 없는 하진의 긴장이 전달되는가 | 권한 이양이 수동적으로 보이지 않음 | 행동·관계 표현 수술 |
| 학교 설정 샘플 | 학교가 가고 싶은 곳인가 | 안전 절차만이 아니라 생활 매력 기억 | 수업·친구·놀이 강화 |
| 도감 샘플 6개 | 수집하고 싶지만 소유하고 싶기만 하지는 않는가 | 관계·정정·상태 보상 이해 | 외형/행동/권리 균형 수정 |
| 지도 샘플 4개 | 보호 폐쇄·비공개도 보상으로 느끼는가 | 전체 개방 욕구만 남지 않음 | 범례·이유·생활 결과 강화 |
| 7부제 요약 | 작품별 차이를 구분하는가 | 6개 후속 사건을 서로 바꾸지 않음 | 사건 엔진 차별화 |
