# 제1부 제5장 역할별 검수 v0.1

## 판정

통과. 제5장 씬 비트와 정본 규칙에 부합한다.

## 시점·서술거리

- 윤서후 중심 3인칭 제한 시점 유지.
- 타인의 내면을 단정하지 않고 표정·행동으로만 제시.

## 문장·리듬

- 접근 금지선 장면은 짧은 문장과 관찰 중심으로 긴장 유지.
- 빈자리새 등장 후 리듬이 빨라지며 설명 과잉 없이 기능 전달.

## 인물 음성

- 나린: 안전·공개 범위를 먼저 정함.
- 도겸: 공간과 순서를 기술적으로 구분.
- 모아: 생태 반응을 해석하고 주인공의 오판을 수정.
- 오현정·배기준: 학생을 무력화하지 않으면서 중지 권한 행사.

## 정보 공개

- 새 핵심 개념은 이동 순서 복제와 빈자리새 두 가지로 제한.
- ‘이름이 있다는 것=선택받음’이라는 오판을 즉시 뒤집음.

## 선택과 비용

- 서후는 표식 접근 욕구를 억제하고 관찰만 수행.
- 학교 보고와 보호자 공유를 수용하여 활동 자유 감소 가능성을 감수.

## 독창성

- 특정 학교 판타지 작품의 선택 장치·혈통·예언 구조와 대응하지 않음.
- 갈등은 작품 고유의 관찰권·접근권·생태 거부 규칙에서 발생.

## 연속성

- 제4장의 서후 이름 표식을 직접 계승.
- 제6장의 가족 내부 약칭과 과거 통학 기록 조사로 자연스럽게 연결.

## 후속 주의

- 금속 조각이 서후 가방에 들어온 경로를 즉시 전능한 의지로 설명하지 말 것.
- 윤미정이 정보를 숨기는 단순 비밀 보호자처럼 보이지 않도록, 기억의 불완전성과 당시 안전 판단을 함께 제시할 것.
