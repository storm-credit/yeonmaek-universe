# 첫 부제작 완성본 하네스 재감사 v0.2

## 1. 종합 판정

첫 부제작은 다음 상태다.

- `draft-complete`: 통과
- `internal-review-ready`: 통과 후보
- `human-review-ready`: 통과
- `edited-manuscript`: 미도달
- `publication-ready`: 미도달

세계관·인과·권한·현재 사건 완결에는 치명적 내부 실패가 없다. 28화 연재 브리프와 자동 문체 감사 도구를 추가했으나 실제 독자·발달·분야·라인·카피 편집은 남아 있다.

## 4. 실행 검증 상태

현재 세션의 컨테이너에는 `gh` CLI가 없고 외부 DNS 접근도 차단돼 원격 저장소를 로컬에 복제해 스크립트를 실제 실행할 수 없었다.

대신 GitHub 커넥터로 패치 대상 최신 장을 직접 읽어 P01~P12의 원문 존재를 확인했다.

- 제1장: P01~P03
- 제2장: P04
- 제5장: P05
- 제6장: P06
- 제14장: P07~P10
- 제15장: P11~P12

실제 저장소 또는 CI 환경에서 다음 명령을 실행해야 한다.

```bash
python scripts/build_installment1_v03.py
python scripts/audit_manuscript_style.py \
  build/manuscript/installment-01-v0.3/chapter-*.md \
  --output build/manuscript/installment-01-v0.3/style-audit.md
```

## 6. 문체·액션·풍경 최종 지침

### 문체

- 단문 금지 아님
- 단문 남발 금지
- 중단문·짧은 복문 중심의 가변 리듬
- 긴 문장은 주체·방향이 유지될 때 사용
- 감정은 행동·말의 지연·기록 수정으로 먼저 제시

### 액션

- 기술명보다 위치·거리·궤적·저항·결과·비용
- 결정적 비트는 상세히, 반복 타격은 압축
- 부상·피로·장비 상태는 다음 선택을 제한
- 첫 부제작에는 전투를 억지로 추가하지 않음

### 풍경

- 전체 방향·구별 디테일·변화의 3층
- 행동·단서·정서 중 하나에 기여
- 같은 장소 재등장 때 변화·사용 흔적
- 관광 안내문식 나열 금지

### 웹연재

- 약속·진전·보상·추진 중 최소 세 기능
- 충격 반전 훅만 반복하지 않음
- 플랫폼 글자수는 계약·낭독·독자 테스트 전 고정하지 않음
