# 첫 부제작 반복어·대사 기능 감사 v0.1

## 방법 제한

GitHub 코드 검색이 직전 생성 원고를 아직 색인하지 않아 정확한 자동 빈도 계산은 수행하지 못했다. 최신 장 파일을 문맥 단위로 직접 비교했다. 정량 빈도는 로컬 원고 묶음 또는 출판 편집 도구가 준비되면 다시 측정한다.

## 핵심 반복어

### `모르다 / 미확인 / 확정하지 않다`

작품 주제상 필요한 어휘지만 후반 회의 장에서 논증 대사로 반복될 위험이 있었다.

수정:
- 10장: 네 기록을 실제 책상 위에 놓는 행동으로 대체
- 12장: 여섯 질문을 세 질문으로 축소하고 모형 조작으로 역할을 표현
- 13장: `가능성` 반복 대신 하진이 기존 메모를 직접 지우는 행동 사용
- 14장: 절차 설명보다 개체별 멈춤·재접근·이동 차이를 전면화

현재 판정: `PASS-WITH-THEME-WORDS`.

### `대답하지 않았다 / 말문이 막혔다`

하진이 정보를 숨기거나 자기 오신념과 부딪힐 때 반복될 수 있다.

유지 가능한 경우:
- 가족에게 정보 누락이 드러나는 장면
- 자기 기록과 반대 증거를 처음 만나는 장면

교정 원칙:
- 침묵 대신 화면을 끄기, 문장을 지우기, 손을 멈추기, 기록 순서를 바꾸기 등 사건 관련 행동으로 변주
- 같은 장에서 두 번 이상 사용하지 않음

현재 판정: `PASS`, 출판 교정에서 정량 재검사.

### `기록`

핵심 소재이므로 단순 동의어 치환하지 않는다. 다만 기능을 구분한다.

- 생활 흔적
- 사진 원본
- 지도 상태
- 센서값
- 임시 분류
- 동의·철회 이력
- 관찰 메모
- 최종 정정본

같은 문단 안에서 기능이 다른 기록을 모두 `기록`으로만 부르면 구체 명칭으로 바꾼다.

| 인물 | 대사 기능 | 반복 방지 규칙 | 판정 |
|---|---|---|---|
| 하진 | 질문·검증·통제 욕망 | 모든 대사를 질문으로 끝내지 않음, 직접 수정 행동 병행 | PASS |
| 유나 | 생활 맥락·자료 권리·친밀한 반문 | 하진의 농담 상대나 확인 도구로 축소 금지 | PASS |

| 하람 | 신고·절차·검증 | 규칙 문구 낭독보다 실제 유익과 수정 경험 제시 | PASS |
