첫 부제작은 `초고 완료`와 `인간 검토용 리뷰본` 단계다.

- 세계관·인과·권한·현재 사건 완결: 통과
- 문체 기준과 국소 반복어 수술: 통과 후보

- 실제 독자·발달편집·라인편집·카피편집: 대기

## 3. 문체 판정

현재 voice anchor의 핵심 방향은 적절하다.

- 근접 3인칭·과거형
- 중단문·짧은 복문 중심
- 같은 길이 단문 연속 금지
- 감정 행동화
- 비유 장면당 핵심 1개
- 생활 기록과 감각 우선

새 하네스 적용 시 `단문금지`는 채택하지 않는다.

수정 원칙:
- 충격·판단·전환 단문은 유지
- 설명과 이동까지 모두 한 줄로 끊는 과분절은 통합
- 긴 문장은 주체·방향이 명확할 때 사용

## 4. 액션·전투 판정

첫 부제작은 전투물이 아니므로 전투 디테일을 억지로 추가하지 않는다.

대신 다음을 액션으로 본다.
- 통로에서 순서 변화 확인
- 여울띠의 경로 거부
- 학생 철수
- 복수 경로 준비
- 개체별 시험과 독립 이동

이 장면들은 기술명보다 공간 기준점·진동·거리·정지·재접근·새 위치를 보여 줘야 한다. 기존 13·14장 v0.2 수술 방향과 일치한다.

## 5. 풍경 판정

잘 작동:
- 철길 아래 통로의 등·시멘트 자국·배수 덮개
- 시간과 진동이 공간 단서로 기능
- 같은 통학로가 폐쇄·비·공사·경로 시험에 따라 달라짐

주의:
- 모든 장소가 기록 장치처럼만 보이지 않도록 집·학교·상가·비 오는 길의 생활 흔적을 낭독 테스트에서 확인
- 풍경을 늘리기 위해 새 지역·관광 묘사를 추가하지 않음

## 6. 웹연재 판정

200화 지도는 1부제를 28화로 배정한다. 그러나 28화의 상세 공개 브리프는 아직 없다.

원고 전환 시 필요한 작업:
1. 30장면 카드를 28화로 매핑
2. 각 화 약속·진전·보상·추진 표시
3. 훅 유형 8종 회계
4. 이전 화 요약·빈 이동 화 제거
5. 1~3화, 무료 구간 말미, 1권 경계의 독자 테스트

15장 단행본 구조가 통과했다는 이유로 28화 웹연재 리듬도 자동 통과한 것으로 보지 않는다.
