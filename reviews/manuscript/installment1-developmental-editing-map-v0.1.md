# 첫 부제작 발달편집 지도 v0.1

## 원칙

전체 재작성 대신 수정이 필요한 위치·목적·검증 질문만 제시한다. 사건·설정·인물 선택·결말은 변경하지 않는다.

## 우선순위 A — 실제 독자 반응 전에도 확인할 항목

### 1~3장: 장르 약속과 신고 지연

- 위치: 1장 첫 20%, 2장 지도 대조, 3장 신고 창
- 위험: 기록 불일치가 숫자 퍼즐처럼만 보일 수 있음
- 확인: 통학 생활과 감각적 이상이 함께 보이는가
- 수정 상한: 시각·소리·동선의 구체성 보강, 새 현상 추가 금지

### 4~5장: 학교 진입과 여울띠 첫 등장

- 위치: 안전 계약 설명, 도겸 소개, 임시 분류 화면
- 위험: 새 고유명사와 역할 설명이 몰릴 수 있음
- 확인: 독자가 사람 이름·기관·여울띠를 동시에 구분하는가
- 수정 상한: 설명 대사 통합, 첫 행동을 이름보다 앞세움

### 6~7장: 첫 해결의 반전과 권한 상실

- 위치: 폐쇄 성공 뒤 유나 사진, 강변 추적, 철수 위반
- 위험: 하진이 같은 실수를 반복하는 것으로만 보일 수 있음
- 확인: ‘정확히 알고 싶다’는 장점이 비용으로 바뀌는 과정이 보이는가
- 수정 상한: 선택 직전의 대안 인식과 시간 압박 명료화

### 8~10장: 두 시간 제한과 자료권

- 위치: 강우 통제, 유나 공유 범위, 네 증거류 수렴
- 위험: 비·공사·자료권·시설 책임이 한꺼번에 설명될 수 있음
- 확인: 독자가 현재 가장 급한 문제가 무엇인지 장마다 답할 수 있는가
- 수정 상한: 장별 목표 문장과 행동 결과를 선명하게 함

### 11~12장: 감정 저점과 성인 전문성

- 위치: 기록 제출·화면 차단·복수 경로 준비
- 위험: 11장이 정적인 처벌 장면, 12장이 회의 장면으로 느껴질 수 있음
- 확인: 권한을 내려놓는 선택과 어른들의 실제 행동이 보이는가
- 수정 상한: 손·화면·장비·동선 행동 강화, 새 사고 금지

### 13~14장: 거부와 선택의 클라이맥스

- 위치: 첫 경로 거부, 사후 영상, 개체별 재접근
- 위험: 하진이 현장에 없어서 즉시성이 약할 수 있음
- 확인: 기다림의 비용과 영상 속 이동 차이가 긴장을 만드는가
- 수정 상한: 시간 감각·관계 반응·개체별 움직임 강화, 현장 지휘 복귀 금지

### 15장: 생활 완결과 장기 질문

- 위치: 통학 변화, 동의·철회 조건, 도감·지도 정정, 삭제 ID
- 위험: 정리 목록처럼 보이거나 삭제 ID가 현재 결말을 압도
- 확인: 독자가 ‘무엇이 달라졌는지’를 생활 장면으로 느끼는가
- 수정 상한: 생활 장면 우선, 삭제 ID 10% 이하 유지

## 우선순위 B — 인간 독자 반응이 있을 때만 수정

- 인물 이름 혼동
- 학교·센터·시설팀 구분 실패
- 여울띠 펫 오해
- 7장 분권 경계 불만
- 13~14장 긴장 부족
- 15장 미완결 인식

## 우선순위 C — 라인·카피 단계

- 같은 종결어미 연속
- 짧은 한 줄 문단 남발
- `기록`, `모르다`, `확정`, `가능성` 반복
- 숫자·시각·용어 표기 통일
- 인물별 대사 길이와 말의 속도

## 금지

- 하진에게 새 능력 부여
- 여울띠가 인간 언어로 이유 설명
- 악당 추가
- 시설 공사 취소로 간단 해결
- 하진의 철수 위반·권한 상실 삭제
- 유나·지현의 자료·동의 권한 축소
- 장기 ID를 현재 사건 해결 열쇠로 확대

## 현재 판정

내부 발달편집 지도는 준비됐지만 실제 수정 우선순위는 인간 응답 뒤 확정한다.
