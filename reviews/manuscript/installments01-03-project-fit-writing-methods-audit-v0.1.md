# 1~3부제 프로젝트 맞춤 집필법 소급 감사 v0.1

## 목적

이미 작성된 1~3부제 초고를 전면 재작성하지 않고, 새로 명문화한 프로젝트 맞춤 집필법이 실제 원고 구조에 존재하는지 확인한다. 인간 독자 응답 전에는 문제 위치와 교체 범위만 기록한다.

## 국소 감사 우선 구간

### 1부제

- 10·12·13장: 제도·기록 설명 뒤 하진의 즉각적 감각·감정 반응이 짧은 구간을 표시한다.
- 13~14장: 기록·영상 매개 장면에서 공간 기준점과 대기 시간의 체감이 유지되는지 낭독 점검한다.
- 15장: 생활 귀환과 관계 비용이 정답 설명 뒤 부록처럼 느껴지지 않는지 확인한다.

### 2부제

- 5~8장: 보호 계획 성공 구간에서 축제·훈련·팀 보상이 충분히 선행하는지 확인한다.
- 9~11장: 하진의 전술적 이용이 규정 위반이 아니라 관계 이용이라는 차이를 대화보다 행동 결과로 읽히게 하는지 확인한다.
- 13~15장: 경기 공간·봉화·멈춤종의 위치를 독자가 놓치지 않는지 액션 지도를 대조한다.
- 16장: 제도 회수와 관계 미회복을 분리해 감정이 행정 정리 뒤 묻히지 않는지 확인한다.

### 3부제

- 1~4장: 판본 네 종류가 설명 목록이 아니라 생활 시간표·걷기·측정 행동으로 구분되는지 확인한다.
- 8~11장: 성공한 호환표가 단독 근거로 굳는 과정에서 같은 설명을 반복하지 않는지 점검한다.
- 13~14장: 표식 재배치의 공간 방향·순서·현지 책임자의 결정권을 명료하게 유지한다.
- 15장: 해외 호환 표식이 현재 지역 결말보다 더 크게 강조되지 않도록 상한을 지킨다.

## 수정 원칙

- 사건·설정·결말 추가 금지
- 전체 장 재작성 금지
- 위치·문제·교체 범위·목적을 먼저 제시
- 인간 독자에게 반복해서 지적된 문제만 실제 문장 교체 후보로 승격
- 단문을 일괄 늘리거나 줄이지 않음

## 판정

1~3부제는 새 프로젝트 맞춤 집필법과 구조적으로 호환된다. 치명적 재설계 필요는 없다. 남은 것은 문장·장면 단위 국소 감사와 인간 낭독·독자 반응이다.
