# 제1부 1장 원고 검수 v0.1

대상: `manuscript/part1/chapter01-late-return-v0.1.md`

## 총괄 판정

집필 시스템의 첫 적용 원고로서 통과 가능하다. 일상 목적, 이상 징후, 인물 관계, 제한 시점, 장 끝 단서가 모두 기능한다.

## 역할별 검사

### 시점·서술거리

- 윤서후 중심 3인칭 제한 시점 유지.
- 나린이 보는 출구는 대사와 관찰을 통해서만 전달됨.
- 장 내 시점 이탈 없음.

판정: 통과.

### 문장 리듬

- 평상 장면은 중간 길이 문장 중심.
- 골목 진입 후 짧은 문장과 반복음을 사용해 긴장 상승.
- 장 끝은 설명보다 흙과 은빛 풀의 방향으로 마감.

판정: 통과.

### 감각 묘사

- 학원차 경고음, 실외기 바람, 물소리, 젖은 흙 냄새가 기능적으로 사용됨.
- 시각적 화려함보다 규칙의 어긋남이 중심.

판정: 통과.

### 대사·인물 음성

- 서후: 시간·경로·안전 중심.
- 나린: 생활 현실과 관계 경계 중심.
- 윤미정: 걱정과 확인 중심.

판정: 통과.

### 유머·생활감

- 귀가 시간 계산, 오리 인형, ‘대비를 숫자로 하는 것’ 대사가 초반 생활감을 제공.
- 긴장 이후 유머를 과도하게 삽입하지 않음.

판정: 통과.

### 미스터리·정보 공개

한 장에서 공개한 핵심 규칙:

1. 같은 길에서 서로 다른 출구를 볼 수 있음.
2. 체감 시간과 현실 시간이 어긋날 수 있음.

추가 단서는 흙과 은빛 풀이지만 규칙으로 설명하지 않음.

판정: 통과.

### 장면 긴장

- 지름길 선택의 사소한 목적에서 시작.
- 출구 불일치와 시간 손실로 위험 상승.
- 집에 돌아온 뒤에도 이상이 남음.

판정: 통과.

### 청소년 안전

- 위험을 영웅적 모험으로 미화하지 않음.
- 귀가 지연과 보호자 연락 실패가 실제 비용으로 작동.
- 다음 장에서 재진입보다 관찰·보고가 우선되어야 함.

판정: 통과.

### 세계관·연속성

- 제1장 씬 비트의 네 단계 모두 반영.
- 장 끝 흙 단서가 제2장 조사로 연결 가능.
- 은빛 풀은 신규 정본이 아니라 방향 반응을 보여주는 비명명 현상으로 취급. 이후 설정집 항목과 충돌 여부를 제2장 작성 전에 확인할 것.

판정: 조건부 통과.

### 독창성·모사 방지

- 특정 작품의 학교 입학, 초대장, 기숙사, 선택받은 혈통, 대표 마법 도구 구조 없음.
- 경이는 통학로·귀가 약속·시간 손실·서로 다른 출구라는 프로젝트 고유 규칙에서 발생.
- 특정 작가의 문장 구조나 번역체 모사 징후 없음.

판정: 통과.

## 수정 권고

현재 즉시 수정이 필요한 치명적 문제는 없다.

다음 장 작성 전 확인:

1. 흙의 출처를 하천 둔치 단서와 연결한다.
2. 은빛 풀을 독립 생물로 확대하지 말고 경로 방향 반응의 보조 단서로 제한한다.
3. 서후가 스스로 재진입하려는 충동보다 기록·대조를 먼저 선택하게 한다.
4. 나린이 단순 동행자가 아니라 보호자 연락과 생활 비용을 주도하도록 유지한다.
