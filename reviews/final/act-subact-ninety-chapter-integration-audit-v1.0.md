# Act·Subact·90장 통합 감사 v1.0

## 감사 대상

- 5부
- 15 Act
- 45 Subact
- 90장
- 90장 씬 비트
- 인물 성장축
- 장기 복선 10개

## 구조 판정

- 각 부는 3 Act다.
- 각 Act는 3 Subact다.
- 각 Subact는 원칙적으로 2개 장을 담당한다.
- 총합은 5부 × 3 Act × 3 Subact × 2장 = 90장이다.
- 기존 Sequence는 기능 참고 자료로 유지하되, 집필·검수의 공식 단위는 Subact로 변경한다.

## Subact 필수 항목 검사

45개 모두 다음 항목을 갖는다.

- 시작 상태
- 주도 인물
- 중심 갈등
- 핵심 사건
- 중간 반전
- 비용
- 관계 변화
- 복선
- 종료 전환
- 대응 장

판정: 통과.

## 부별 성장 연결

### 제1부 관찰

- 같은 길이 사람마다 다르게 작동함을 발견한다.
- 단일 귀환선을 강요한 성공과 비용을 경험한다.
- 여러 귀환 조건과 닫힐 권리를 수용한다.

판정: 관찰 성장과 연결됨.

### 제2부 중지

- 안전 담당이면서 성과 욕망에 흔들린다.
- 규칙상 가능한 위험과 실제 책임의 차이를 경험한다.
- 개인 중지가 아니라 다중 중지권을 설계한다.

판정: 중지 성장과 연결됨.

### 제3부 보조

- 외부 표준으로 현지 문제를 빠르게 해결한다.
- 자기명칭·지역 지식·현지 결정권을 훼손한다.
- 주도권을 내려놓고 도구·철수·비교 자료만 지원한다.

판정: 보조 성장과 연결됨.

### 제4부 수행

- 공개와 보호의 비용을 직접 감당한다.
- 단일 합의와 완전 공개를 포기한다.
- 단계별 공개·제한 열람·철회·사후 복구 체계를 수행한다.

판정: 수행 성장과 연결됨.

### 제5부 조율

- 서후의 전문성이 중앙 병목으로 변한다.
- 도구·정보·교육·중지권을 분산한다.
- 자신이 빠져도 작동하는 빈자리를 만든다.

판정: 조율 성장과 최종 결말에 연결됨.

## 반복 기능 감사

반복 위험:

- 매 부마다 ‘기관이 잘못했다’로 단순화될 가능성
- 서후가 먼저 오판하고 나린이 현실을 지적하는 패턴 반복
- 중간 성공 뒤 비용 발생 구조의 기계적 반복

보정 규칙:

- 제1부 갈등 중심은 개인별 귀환 조건이다.
- 제2부는 경기·성과·중지권이다.
- 제3부는 지역 이름·권한·외부인의 역할이다.
- 제4부는 공개·사생활·사후 책임이다.
- 제5부는 중앙 병목·교육·권한 분산이다.
- 나린만 교정 역할을 독점하지 않는다. 이솔·모아·도겸·재원·교사·가족도 각 부에서 서후의 오판을 수정한다.
- 중간 성공의 비용은 각각 생태 밀림, 주민 이동 봉쇄, 지역 지식 삭제, 생활권 노출, 중앙 병목으로 다르게 유지한다.

판정: 조건부 통과. 집필 검수 시 반복 패턴을 재확인한다.

## 복선 감사

- 사람마다 다른 귀환선: 제1부 제시, 제5부 최종 회수.
- 반납 기록: 제1부 제시, 제5부 도구 분산·만료 권한으로 확장.
- 공개 범위 표식: 제1부 단서, 제4부 핵심 제도, 제5부 분산 공개 체계로 회수.
- 경기 중지 신호: 제2부 핵심, 제5부 지역별 중지권으로 확장.
- 지역별 다른 이름: 제3부 핵심, 제5부 번역 가능한 신호 설계에 연결.
- 빈칸의 의미: 제1·2부 양식, 제4부 기록, 제5부 서후의 빈자리로 의미 확장.
- 귀환 집착: 제1부 약점, 제5부 병목으로 최종 회수.
- 기관별 다른 장부: 제2부 제시, 제4부 공개 갈등에서 회수.
- 현장 지식의 기록 거부: 제3부 핵심, 제5부 현지 권한으로 회수.
- 빈자리새: 제1부 제시, 제5부 조율자의 빈자리 상징으로 회수.

판정: 통과.

## 권한·안전 감사

- 학생이 단독 구조대가 되지 않는다.
- 학생은 관찰·중지 신호·기록·보조 역할을 맡는다.
- 교사·보호자·현장 담당·기관의 책임이 삭제되지 않는다.
- 제5부에서도 학생에게 무제한 권한을 주지 않고 기능 축소·만료·지역 위임을 사용한다.

판정: 통과.

## 공식 구조

앞으로 공식 이야기 계층은 다음과 같다.

`시리즈 → 5부 → 15 Act → 45 Subact → 90장 → 장별 씬 비트 → 원고`

기존 Sequence 문서는 폐기하지 않지만, Subact의 상위 초안·기능 원장으로 취급한다.

## 최종 판정

Act·Subact 구조는 내용과 형식 모두 정식화되었다.

다만 이 판정은 90장 원고 완성을 뜻하지 않는다. 현재 원고 진행은 별도 진행표를 따른다.
