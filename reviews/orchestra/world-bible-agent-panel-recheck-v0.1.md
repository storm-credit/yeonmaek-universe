# 2. 세계 평의회 재점검

## A01 — 세계 구조

### 통과

- 현실과 심층을 별도 우주가 아닌 같은 지리·물질·시간의 복수 위상으로 정의함.
- 장소·상태·관계 정족수가 지역·생태·기관 확장에 재사용 가능함.
- 단일 비밀제국·단일 세계정부·한국 중심 기원을 피함.
- 국제 조정망의 권한 상한이 명확함.

### 조건부

- `부담 보존`이 모든 사건의 언어가 되어 지역·장르 차이를 평평하게 만들 위험.
- 해외 지역의 고유한 생활 기술과 사건 미학은 아직 provisional.

### 판정

`PASS / regional differentiation pending`

## A02 — 현실-이면 접점

### 통과

- 스마트폰·사진·센서·교통·시설 기록이 완전히 지워지지 않음.
- 비밀 유지가 기억 삭제가 아니라 분산 지식·접근 제한·기록 불일치로 작동함.
- 현실 구조·의료·시설·수사 권한이 유지됨.

### 공백

- 언론·플랫폼·AI 영상 분석·보험사·온라인 커뮤니티가 사건 규모별로 어떻게 반응하는지 단계별 사례가 부족함.
- 부제작 5 이전까지 사회가 얼마나 알고 있는지 대중 인지 곡선을 더 구체화해야 함.

### 판정

`CONDITIONAL — exposure escalation ledger needed`

## A03 — 힘·비용·복구

### 통과

- 공통 마나·무한 출력 대신 결합 조율과 부담 보존을 사용함.
- 실패·오용·중지·복구가 구체 사례로 정리됨.
- 학생 성장 기준이 출력보다 관측·중지·인계·복구임.

### 중대 매력 위험

- 현재 힘 체계는 윤리·안전·절차에는 강하지만, 독자가 상상하고 따라 하고 싶어 하는 `감각적 행위`가 약함.
- 기술 10개의 손동작·도구 반응·공간 변화·훈련 실패의 시각적 차별이 부족함.
- 너무 안전교육처럼 보이면 판타지의 경이와 놀이가 약해질 수 있음.

### 판정

`STRUCTURAL PASS / WONDER DESIGN CONDITIONAL`

## A04·P05 — 생태·생물·권리

### 통과

- 생물 12종이 외형·행동·생태 기능·권리·사건·재등장과 연결됨.
- 포획·희귀도·전투력·영구 계약을 피함.
- 여울띠·모서리잠·온기고리·물갈피 등은 서로 사건 기능이 다름.

### 조건부

- 생활사·먹이망·번식·개체 차이보다 사건 기능이 앞서는 항목이 있음.
- 일부는 `부담을 분산하는 생물` 변주로 느껴질 수 있음.
- 실루엣·움직임·재질·소리·크기 비교판이 없어서 수집 욕구를 검증할 수 없음.

### 판정

`CONTENT PASS / ECOLOGY+VISUAL REVIEW PENDING`

## A05 — 학교·기관·경기

### 통과

- 인가 학교·별도 센터·현실 기관·재단 권한이 분리됨.
- 학적·일반 교과·통학·기숙·방학·철수·의료·보험·진로가 존재함.
- 학교가 악 조직이나 비밀 설명소로만 작동하지 않음.
- 길문전은 쿼디치 복제 방지 규칙과 안전 설계가 있음.

### 중대 매력 위험

운영 바이블은 매우 상세하지만 아이가 학교에 가고 싶어지는 정서적 얼굴이 약함.

부족한 항목:

- 입학 첫날의 경이와 통과 의식
- 매년 기다리는 축제·시장·야간 행사
- 급식·도서관·온실·기숙·동아리의 대표적 즐거움
- 교사들의 수업 방식과 유머
- 친구들이 사건 없이 노는 반복 장면
- 학교만의 소리·냄새·계절 변화·상징 공간

### 판정

`OPERATIONS PASS / SCHOOL LOVE DESIGN REQUIRED`

## N00·N02·N17 — 7부제 구조

### 통과

- 2/3/2 대형막이 발견→기준 확장→권한 재구성으로 비가역적으로 움직임.
- 부제작 3·5·6의 삭제 필요성이 설명됨.
- 한국 홈베이스와 해외 확장·귀환이 연결됨.
- 부제작마다 독립 사건·감정 결말이 있음.

### 중대 반복 위험

일곱 작품의 중심 질문이 모두 `권한·기록·동의·공동관리` 언어로 수렴한다.

구조적 주제는 강하지만 독자 체감 장르는 더 다르게 배분해야 한다.

- 1: 도시 미스터리·첫 경이
- 2: 학교 스포츠·친구·경쟁
- 3: 국내 여행·수계 탐사
- 4: 해외 재난 스릴러·번역 미스터리
- 5: 공개 추적극·도시 사회 미스터리
- 6: 대규모 구조·권력 선택
- 7: 분산 최종 임무·졸업

이 장르 체감 차이가 상세 장면 설계에서 확보되지 않으면 같은 논쟁을 반복하는 시리즈가 됨.

### 판정

`ARCHITECTURE PASS / GENRE VARIETY GATE REQUIRED`

### 판정

## 중대

1. PM과 검토 provenance가 과거 산출물에서 불명확함 — 이번 이슈에서 보강 중.
2. 실제 독자·전문가·현지 감수 없이 `완성`이라는 표현을 쓰면 오해를 만듦.
3. 학교 운영은 강하지만 학교에 가고 싶은 경이·놀이·정서적 매력이 약함.
4. 7부제의 윤리·제도 질문이 반복돼 장르적 다양성을 압도할 위험.
5. 힘·생물·유물이 절차와 권리 설명 장치로만 보일 위험.
6. 주인공 이름·정체성 마이그레이션 미완료.

## 보통

1. 생물 12종의 먹이망·생활사 상호관계 부족.
2. 대표 경기의 관전 재미와 30초 설명 테스트 미완료.
3. 영웅 기록이 모두 복합적이어서 단순한 동경·감탄의 입구가 약함.
4. 해외 지역 에이전트 다수가 placeholder이며 실제 등장 지역만 사용해야 함.
5. 시각 설계가 텍스트 뒤에 밀려 수집욕구를 아직 검증하지 못함.

# 6. A14 준비도 판정

## 세계관·설정집

`conditional-ready`

내부 설계와 첫 원고 검증에는 사용할 수 있다. 단, `canon-complete`나 `publication-ready`라고 부르지 않는다.

## 7부제 설계도

`conditional-ready`

작가 게이트 #79와 주인공 마이그레이션 #94가 필요하다. 부제작 2부터는 장르 다양성·학교 매력·수집 시각성 게이트를 먼저 수행한다.

## 다음 단계 차단

다음 전에는 부제작 2 원고를 쓰지 않는다.

1. #94 이름 마이그레이션 완료
2. #79 작가 기본값·주인공 성별/가족 관계 선택
3. 학교 사랑·경이·일상 4안
4. 길문전 관전·안전·30초 설명 게이트
5. 생물·유물·회랑 시각 언어 4안
6. 부제작 2 공정 단서·장면 구조 게이트
7. 명시적 원고 승인

# 7. 최종 결론

> 필요한 에이전트 역할은 대부분 존재했고 실제 설정 산출물도 내부 candidate로 충분히 상세하다. 그러나 이전에는 독립 에이전트 실행·검토 서명이 추적되지 않았고, 인간 검토와 실제 독자 테스트는 아직 없다. 이번 보강 뒤 세계관·설정집·설계도는 `conditional-ready`이며, 재미·경이·시각적 수집성·주인공 개인성·지역 인간 검토를 완료하기 전에는 정본이나 출판 완료로 선언하지 않는다.
