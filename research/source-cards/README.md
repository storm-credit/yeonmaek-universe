# 문화 출처 카드 등록부

이 디렉터리는 실제 문화·전승·공동체 자료를 세계관 설정으로 바로 변환하기 위한 자료창고가 아니다.

목적은 다음 세 가지다.

1. 출처가 실제로 확인하는 범위를 제한한다.
2. 창작에 사용할 수 있는 구조적 기능과 사용할 수 없는 신성·고유 표현을 분리한다.
3. 후속 지역 조사와 현지 감수가 필요한 지점을 기록한다.

## 핵심 원칙

- UNESCO 등재는 창작 사용 허가나 문화 전체의 대표성 인증이 아니다.
- 공식 자료 한 건은 입구일 뿐 완전한 문화 설명이 아니다.
- 실제 신·영·조상·성지·의례·공연·문양을 생물, 주문, 직업, 경기로 직접 전환하지 않는다.
- 국가 전체를 한 전승으로 대표하지 않는다.
- `실제 사실`, `기능 추상화`, `복합 변형`, `완전 창작`을 분리한다.
- 현존 공동체의 자기 설명과 현대 생활을 반드시 후속 조사한다.

## 출처 등급

| 등급 | 범위 | 용도 |
|---|---|---|
| A | 정부·국제기구·공식 박물관·원문 학술자료 | 사실 기준선과 공식 설명 확인 |
| B | 대학·전문 연구기관·동료평가 논문·전문 단행본 | 맥락, 논쟁, 지역 차이 보완 |
| C | 신뢰 가능한 언론·전문가 해설·공연단·지역단체 자료 | 현재 변화와 자기 서술 보완 |
| D | 관광 블로그·위키·무출처 영상·AI 요약 | 검색어 발굴만 가능, 근거 사용 금지 |

A등급 자료도 단독으로 정본 근거가 될 수 없다.

## 민감도

| 민감도 | 기준 | 요구사항 |
|---|---|---|
| 낮음 | 자연환경·일반 생활 기술 중심 | 기본 출처 검증 |
| 중간 | 지역 정체성·예술·역사적 전승 포함 | 복수 출처와 자기 서술 |
| 높음 | 현존 종교·신성 존재·의례·소수집단·성지 포함 | 직접 전용 금지, 현지 감수 게이트 |

## 창작 변형 거리

| 거리 | 의미 |
|---|---|
| near | 사실 기반 재현. 세계관 핵심 창작에서는 원칙적으로 사용하지 않음 |
| medium | 명칭·외형은 변경하지만 구조적 유사성이 큼. 문화 검토 필수 |
| far | 기능적 원리만 추상화하고 명칭·의식·형태·서사는 새로 설계 |
| very-far | 민감한 자료. 공동체·자연·제도의 관계 같은 상위 질문만 참고 |
| prohibited | 작품 장치로 사용하지 않고 연구 경계 설정에만 활용 |

## 카드 작성 절차

1. 구체적인 지역·시대·현상을 정한다.
2. A등급 출처로 사실 기준선을 잡는다.
3. B등급 자료로 내부 차이와 논쟁을 확인한다.
4. 공동체·수행자·지역기관의 자기 서술을 찾는다.
5. 출처가 말하지 않는 것을 명시한다.
6. 직접 전용 금지 항목을 먼저 적는다.
7. 사용할 수 있는 기능 추상화를 최소화한다.
8. 창작 변형 거리를 지정한다.
9. 문화 무결성 검토를 받는다.
10. 세계관 문서에서는 카드의 사실과 창작 변형을 별도 표기한다.

## 중지 조건

다음 중 하나라도 발생하면 설정 생성을 중단한다.

- 하나의 의례나 신앙으로 국가 전체를 설명함
- 실제 신성 존재를 종·스킬·보스로 변환함
- 의상·동작·문양만 가져와 이국성을 연출함
- 공식 등재를 문화 사용 허가처럼 해석함
- 공동체의 현재 생활과 자기 설명을 조사하지 않음
- 분쟁·식민지·빈곤·환경 위기를 판타지 배경 장식으로 소비함

## 정본 승격 조건

출처 카드가 존재한다고 해당 문화 기반 설정이 정본이 되는 것은 아니다.

정본 승격에는 다음이 필요하다.

- A/B급 출처 복수
- 지역 내부 다양성 기록
- 실제 사실과 창작 변형의 분리
- 문화 무결성 에이전트 검토
- 필요 시 현지 감수
- 다른 세계관 모듈에 미치는 영향 검토
- 작가 승인
