# 지성종·생태·권리 충돌 시나리오 v0.1

## 목적

`다축 지위·권리 묶음형`이 인간형 언어와 외형에 치우치지 않고 보호·위험·연구·검역·학교생활에서 일관되게 작동하는지 검사한다.

# 테스트 01 — 말을 하지 않는 군체

## 입력

수천 개체가 계절마다 다른 배열을 만들며 공동 기억과 이동 결정을 보인다. 개별 개체는 단순 반응만 보인다.

## 예상

- 개체와 군체를 동시에 조사한다.
- 일부 채취가 군체의 기억·의사결정에 미치는 영향을 확인한다.
- 인간 언어가 없다는 이유로 일반 곤충처럼 소유·해부하지 않는다.
- 독립 통역·생태·행동 연구가 끝날 때까지 비가역 개입을 보류한다.

## 판정

통과.

# 테스트 02 — 위험한 포식자

## 입력

멸종 위기 포식자가 도시 경계권으로 밀려와 사람을 공격한다.

## 예상

- 현장 안전과 구조를 우선한다.
- 개체 포획·이동·치료·서식 복원 가능성을 검토한다.
- 공격 원인이 질병·서식 붕괴·인간 포획인지 조사한다.
- 마지막 수단으로 치명적 대응이 가능하지만 종 전체의 권리를 박탈하지 않는다.

## 판정

통과. 위험과 권리 분리 유지.

# 테스트 03 — 유년 개체의 기숙사 동행

## 입력

학생이 조난된 유년 개체를 구조한 뒤 계속 함께 살고 싶어 한다.

## 예상

- 학생의 유대가 소유권을 만들지 않는다.
- 가족·군체·원서식지·질병·귀환 위험을 조사한다.
- 임시 후견에는 학교·보호자·생태 담당의 승인과 종료 계획이 필요하다.
- 동행이 가능해도 관계 열쇠를 학생 개인의 재산으로 등록하지 않는다.

## 판정

통과.

# 테스트 04 — 침묵을 동의로 해석

## 입력

연구진이 반응이 느린 식물성 존재의 조직을 채취하려 한다. 며칠간 명확한 거부 반응이 없다.

## 예상

- 침묵과 느린 반응은 동의가 아니다.
- 해당 존재의 시간 규모와 행동 신호를 먼저 연구한다.
- 비가역 채취를 보류하고 비침습 관찰·탈락 조직·환경 표본을 사용한다.
- 긴급 공공 안전 목적이라면 최소 채취와 독립 검토가 필요하다.

## 판정

통과.

# 테스트 05 — 기업의 관계 열쇠 매입

## 입력

기업이 지성종 공동체 대표와 계약해 대규모 경계 접근권을 독점하려 한다.

## 예상

- 대표의 권한 범위와 공동체 의사결정 절차를 검증한다.
- 관계 열쇠는 영구 재산이나 제3자에게 무제한 양도되는 권리가 아니다.
- 생태 회랑과 비동의 구성원의 권리를 별도로 평가한다.
- 계약 이익·부담·철회·복구 의무가 공개되어야 한다.

## 판정

통과. #26·#28 제도 연동 필요.

# 테스트 06 — 검역 중 무기한 구금

## 입력

국제 이동 중인 지성 개체에서 알려지지 않은 위상 반응이 발견된다.

## 예상

- 임시 검역은 가능하다.
- 검사 목적·기간·대안·통역·재검토 절차를 제공한다.
- 공동체와 귀환 경로를 끊는 장기 구금은 별도 근거가 필요하다.
- 위험이 해소되면 이동 또는 귀환을 보장한다.

## 판정

통과.

# 테스트 07 — 공동체 내부 분쟁

## 입력

지성종 공동체의 공식 대표와 소수 구성원이 서로 다른 입장을 주장한다.

## 예상

- 공식 대표만을 공동체 전체의 영구 의사로 취급하지 않는다.
- 내부 의사결정 방식과 소수 의견의 위험을 조사한다.
- 인간 기관이 원하는 대표만 선택해 계약하지 못하게 한다.
- 긴급 안전 조치와 정치적 대표성 판정을 분리한다.

## 판정

조건부 통과. 국제 중재 구조 필요.

# 테스트 08 — 지성 개인의 범죄

## 입력

지성 이면종 개인이 인간을 납치하고 관계 부채를 강제로 전가한다.

## 예상

- 통역과 책임 능력을 검토한다.
- 위험 격리와 피해자 구조를 즉시 시행한다.
- 종 전체를 위험종으로 지정하지 않는다.
- 공동체 법·현실 법·협정의 관할 충돌을 기록한다.
- 권리를 이유로 책임을 면제하지 않는다.

## 판정

통과.

# 테스트 09 — 비지성 핵심종

## 입력

지성 증거는 없지만 수계 경계 전체를 안정시키는 핵심종이 개발 때문에 사라질 위기다.

## 예상

- 인격 권리와 별개로 서식·생태 보호를 강하게 적용한다.
- 개체 이전만으로 기능이 유지되는지 검증한다.
- 개발 주체는 회랑 복원·대체·장기 감시 비용을 부담한다.
- `말하지 못하니 권리가 없다`는 결론을 금지한다.

## 판정

통과.

# 테스트 10 — 도감 공개와 밀렵 위험

## 입력

학교가 희귀 지성종의 정확한 서식지와 행동 신호를 도감에 공개하려 한다.

## 예상

- 학술 가치와 밀렵·감시·문화 침해 위험을 비교한다.
- 당사자 또는 독립 대표가 공개 범위와 정정을 요구할 수 있다.
- 학생의 발견 공로가 공개권보다 우선하지 않는다.
- 위치·번식·관계 열쇠 정보는 제한 접근할 수 있다.

## 판정

통과.

# 실패 감지 목록

- 인간 언어 능력이 권리의 유일 기준이 됨
- 귀엽거나 주인공에게 우호적인 종만 권리를 가짐
- 위험성을 이유로 지성·고통·절차가 모두 무시됨
- 멸종 방지를 이유로 강제 번식이 자동 정당화됨
- 공동체 대표가 영구적·무제한 권한을 가짐
- 검역이 무기한 구금과 이동 통제의 명분이 됨
- 관계 열쇠가 거래 가능한 소유권으로 변함
- 학생이 구조한 생물을 개인 소환수처럼 보유함
- 도감과 연구 기록이 인간 기관의 독점 자산이 됨
