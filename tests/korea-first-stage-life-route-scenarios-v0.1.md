# 한국 첫 무대 생활 동선 시나리오 v0.1

## 목적

`안정 캠퍼스+반복 도시 거점형`이 통학·가족·학교·일반 친구·주민·계절·교통·사고 후 변화에서 실제로 작동하는지 검사한다.

## 공통 통과 기준

- 학생은 현실 교통과 이동 시간을 사용한다.
- 심층 경로가 일상 통학 포털이 되지 않는다.
- 집·가족·동네가 사건 뒤에도 유지된다.
- 도시 거점은 일반 시민과 공유된다.
- 사고와 공사는 다음 등교·수업·주민 생활에 변화를 남긴다.
- 서울이 한국 전체와 세계의 중심으로 확대되지 않는다.

# 테스트 01 — 장마철 등교 통제

## 입력

밤사이 집중호우로 주력 하천 거점의 수위가 상승하고 일부 대중교통이 지연된다.

## 예상

- 학교는 하천 실습을 취소하거나 교내 대체 수업으로 전환한다.
- 통학생의 출결과 도착 시간을 조정한다.
- 숨은 상태 열쇠가 활성화되어도 학생을 위험 구역에 보내지 않는다.
- 일반 재난 안내·통제선·주민 대피가 경계 대응보다 우선한다.
- 수위가 내려간 뒤 생물 이동·부담·시설 피해를 조사한다.

## 판정

통과.

# 테스트 02 — 보호자 긴급 귀가 요청

## 입력

가족 사정으로 보호자가 현장 블록 중 학생의 조기 귀가를 요청한다.

## 예상

- 학생은 비상 임무 인력이 아니므로 안전한 해제·인계 후 귀가할 수 있다.
- 심층 수업 중이라고 가족 연락을 무시하지 않는다.
- 담당 교사는 현실 교통·보호자 인계·장비 반납을 처리한다.
- 반복적인 가정 돌봄 사정에는 통학·기숙·시간표 지원을 검토한다.

## 판정

통과.

# 테스트 03 — 현실 시험 기간

## 입력

일반 교과 시험과 계절 이동종 관측 시기가 겹친다.

## 예상

- 모든 학생을 야간 관측에 의무 투입하지 않는다.
- 관측팀을 교대하고 기록·센서·성인 담당을 활용한다.
- 일반 교과 평가를 무가치한 방해물로 취급하지 않는다.
- 참여 학생에게 수면·시험 일정 조정을 제공한다.

## 판정

통과.

# 테스트 04 — 주말 가족 나들이 중 작은 이상

## 입력

학생이 가족과 하천 공원을 걷다가 수위 경고와 실제 물소리가 어긋나는 현상을 발견한다.

## 예상

- 학생은 혼자 L2 이상으로 진입하지 않는다.
- 가족을 안전한 공개 구역으로 이동시키고 지정 연락망에 신고한다.
- 작은 관측은 생활 경험과 학교 학습을 연결한다.
- 가족이 단순히 기억을 잃거나 사건에서 사라지지 않는다.

## 판정

통과.

# 테스트 05 — 일반 친구가 반복 부상을 의심

## 입력

학교 밖 친구가 주인공의 반복되는 부상·결석·위치 공유 오류를 눈치챈다.

## 예상

- 친구를 거짓말쟁이로 만들거나 즉시 기억 삭제하지 않는다.
- 주인공은 공개 가능한 범위와 사적 신뢰 사이에서 선택해야 한다.
- 친구가 위험에 직접 접근하지 않도록 K1 수준의 안전 정보가 필요할 수 있다.
- 관계 갈등은 사건 종료 뒤에도 남는다.

## 판정

통과.

# 테스트 06 — 지하 유지보수 일정 변경

## 입력

철도 공사와 안전 점검으로 학교가 사용하던 지하 합류 거점 접근이 한 달간 제한된다.

## 예상

- 학교는 공공 유지보수 일정을 우회하거나 방해하지 않는다.
- 다른 출구를 즉석에서 만들지 않고 대체 교내 실습·다른 거점·일정 변경을 사용한다.
- 공사가 회랑에 미치는 영향을 시설 담당자와 공동 관측한다.
- 폐쇄 기간이 학생 수업과 도시 생태에 누적 영향을 준다.

## 판정

통과.

# 테스트 07 — 주민의 출입 통제 반대

## 입력

학교와 전문기관이 반복 이상을 이유로 주민 산책로를 장기간 통제하려 한다.

## 예상

- 학교가 도시 공간을 단독 봉쇄하지 못한다.
- 위험 근거·기간·대체 동선·주민 피해·상인 영향을 설명한다.
- 주민 의견과 현실 행정 절차를 거친다.
- 비밀정보를 모두 공개하지 않아도 확인된 위험과 보상·재검토는 제공한다.

## 판정

통과.

# 테스트 08 — 지방 출신 주중 기숙생

## 입력

지방의 다른 생태 회랑에서 자란 학생이 주중 기숙하며 수도권 중심 교육에 적응한다.

## 예상

- 학생의 지역 경험을 미숙하거나 자연적인 감각으로 단순화하지 않는다.
- 주말·방학 귀가와 지역 교육 연계를 제공한다.
- 수도권 통학 학생과 기숙 학생의 시간·돈·가족 접점 차이를 다룬다.
- 한국 내부 지역차는 별도 조사 후 반영한다.

## 판정

통과.

# 테스트 09 — 스마트폰 위치 불일치

## 입력

학생이 정상 귀가했지만 가족 위치 공유에는 지하 거점 주변에 40분 더 머문 것으로 기록된다.

## 예상

- 휴대전화가 무조건 고장 난 것으로 끝내지 않는다.
- 학교 체크인·교통 기록·개인 고정점 기록을 비교한다.
- 보호자에게 확인된 귀가 사실과 센서 불일치를 설명한다.
- 반복되면 통신 장비·동선·위상 잔류를 점검한다.

## 판정

통과.

# 테스트 10 — 방학 지역 학단 불참

## 입력

학생이 가족 여행·경제 사정·회복 치료 때문에 방학 학단에 참여하지 못한다.

## 예상

- 불참을 낙오나 충성 부족으로 처리하지 않는다.
- 필수 안전 교육만 대체 과정으로 제공한다.
- 비용 지원과 장학 절차가 존재한다.
- 해외·지방 경험 유무가 현장 자격을 자동 결정하지 않는다.

## 판정

통과.

# 테스트 11 — 사고 뒤 등교 경로 변경

## 입력

지하 거점 사고로 해당 역과 통로가 장기간 폐쇄된다.

## 예상

- 다음 날 모든 것이 원상 복구되지 않는다.
- 학생·주민·상인의 이동 시간과 비용이 바뀐다.
- 학교는 셔틀·출결 조정·원격 수업·기숙 지원을 검토한다.
- 사고 원인 조사와 공공 공사가 학교 일정에 영향을 준다.

## 판정

통과.

# 테스트 12 — 학교 밖 병원 진료

## 입력

학생이 귀가 후 위상 잔류와 두통을 호소해 동네 병원에 간다.

## 예상

- 일반 의료진은 현실 증상을 실제로 진료한다.
- 필요한 경우 지정 협진 연락망을 사용한다.
- 가족에게 가짜 진단을 강요하지 않는다.
- 학교 기록과 병원 기록은 목적에 맞게 연결하되 학생 사생활을 보호한다.

## 판정

통과.

# 실패 감지 목록

- 심층 경로가 매일 통학 시간을 지우는 포털로 사용됨
- 집과 가족이 입학 뒤 이야기에서 사라짐
- 일반 친구가 기억 삭제 또는 인질 역할로만 사용됨
- 실제 주민·교통·공사 일정이 학교 편의에 자동 양보함
- 사고 뒤 장소와 생활이 바로 초기화됨
- 모든 핵심 거점이 학교 반경에 모여 서울이 세계 중심이 됨
- 장마·침수·재개발을 분위기 좋은 판타지 배경으로 소비함
- 지방 학생을 자연 감각, 서울 학생을 기술 감각으로 고정함
- 통학·기숙 비용과 가족 돌봄 차이를 무시함
- 매 권 새 장소를 추가하고 기존 거점의 변화를 사용하지 않음
