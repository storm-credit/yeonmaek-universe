# 장기 성장형 메인 사가 시나리오 테스트 v0.1

## 목적

5·7·9부제·가변형이 실제로 같은 주인공의 성장, 한국 홈베이스, 독립 완결, 수집 리듬과 복선 회수를 감당하는지 시험한다.

## 판정

- `PASS`: 구조 수정 없이 통과
- `CONDITIONAL`: 명시된 안전장치가 있어야 통과
- `FAIL`: 현재 작가 의도와 양립하기 어려움

# T01 — 초반 소속감 축적

## 상황

첫 부제작은 세계 발견과 통학 회랑 사건을 해결해야 한다. 두 번째 부제작은 학교생활·경기·동행종 관계·보호와 소유 갈등을 다뤄야 한다.

## 질문

독자가 학교와 친구를 충분히 좋아하기 전에 국제·제도 갈등으로 넘어가지 않는가?

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | CONDITIONAL | 두 작품으로 가능하지만 세 번째부터 해외 확장 시 국내 세계가 얕아질 수 있음 |
| 7부제 | PASS | 세 번째 부제작에 한국 내부 다양성과 학교 밖 질서를 둘 수 있음 |
| 9부제 | PASS | 충분하지만 초반 3부제가 유사 학교 사건으로 반복될 위험 |
| 가변형 | CONDITIONAL | 초기 두 작품은 가능하나 세 번째 기능이 미확정 |

# T02 — 동일 주인공의 체감 성장

## 상황

주인공은 처음에는 더 잘 보고 혼자 해결하려 하고, 이후 팀·절차·권한의 피해를 배우며 마지막에 독점 해결자 자리를 거부해야 한다.

## 판정 기준

- 욕망 변화가 최소 세 단계인가?
- 능력 상승보다 책임과 관계 변화가 먼저 보이는가?
- 마지막 선택이 초반과 다른 사람의 선택처럼 느껴지는가?

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | CONDITIONAL | 성장 단계 압축 가능하지만 3~4부제에 권한·국제·기록 변화가 몰림 |
| 7부제 | PASS | 2/3/2 대형막에서 욕망·책임·관계 변화를 단계화 가능 |
| 9부제 | PASS | 가장 풍부하나 중간 성장 정체 구간 위험 |
| 가변형 | CONDITIONAL | 부제작 수 변경 시 성장 단계가 흔들릴 수 있음 |

# T03 — 한국 홈베이스 지속성

## 상황

해외 공동 사건 뒤 한국으로 귀환한다. 가족은 해외 사건의 진실을 전부 알지 못하고, 학교와 재단은 통제를 강화하며, 현실 친구는 주인공의 생활 변화와 기록 불일치를 감지한다.

## 통과 조건

각 부제작에서 다음 다섯 홈베이스 앵커 중 최소 셋이 사건 인과에 영향을 준다.

1. 가족
2. 학교
3. 현실 친구·주민
4. 통학·도시 동선
5. 한국 기관·지역 공동체

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | CONDITIONAL | 해외와 귀환 후폭풍을 별도 작품으로 분리할 공간이 부족함 |
| 7부제 | PASS | 4부제 해외 전환, 5부제 한국 귀환·후폭풍 분리 가능 |
| 9부제 | CONDITIONAL | 해외 4~6부제가 길어지면 한국 홈베이스가 명목화될 위험 |
| 가변형 | CONDITIONAL | 귀환 작품을 축소하지 않는 운영 규칙 필요 |

# T04 — 부제작 독립 완결

## 상황

각 부제작은 다음 작품이 없어도 그 작품의 현장 사건과 핵심 감정 질문을 끝내야 한다.

## 실패 예

- 범인을 알기 직전에 종료
- 구조 대상의 생사·이동권을 후속편으로 미룸
- 대회·조사·협정 결과를 다음 작품에서만 공개
- 설정집을 읽어야 결말 이해 가능

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | PASS | 작품 기능이 선명하고 압축에 유리 |
| 7부제 | PASS | 각 작품 기능을 분리할 충분한 공간 |
| 9부제 | CONDITIONAL | 연결용 다리 작품이 생길 위험 |
| 가변형 | PASS | 대형막 단위 중지 안전성을 전제로 함 |

# T05 — 중앙 전환점

## 상황

중간 작품에서 한국식 도감과 현지 기록의 충돌, 국제 협정의 불공정, 주인공의 독점 접근 가능성이 동시에 드러난다. 사건 뒤 이전 학교생활로 완전히 돌아갈 수 없어야 한다.

## 비가역 변화 후보

- 학교·재단에 외부 조사 개시
- 지성 공동체의 협력 중단
- 주인공 접근권 제한 또는 관리 대상화
- 민간 기록의 비가역 확산
- 주요 멘토 관계의 신뢰 붕괴

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | CONDITIONAL | 3부제가 중앙 전환과 해외 입문을 동시에 감당해야 함 |
| 7부제 | PASS | 4부제를 중앙 전환점으로 두고 5부제에 후폭풍 배치 가능 |
| 9부제 | PASS | 5부제 전환 또는 4~6부제 연속 전환 가능하나 느슨해질 위험 |
| 가변형 | CONDITIONAL | 중앙 위치가 가변이라 장기 복선 배치가 어려움 |

# T06 — 다섯 핵심 수집축

## 상황

동행종, 도감, 회랑 지도, 유물, 영웅 기록을 모두 세계관 핵심으로 쓰되 매 작품 카탈로그처럼 반복하지 않는다.

## 테스트 배치

- 각 부제작 중심축 1개
- 보조축 1개
- 장기 미확인 항목 1개 이하
- 이전 중심축 재맥락화 최소 1회

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | CONDITIONAL | 다섯 축을 한 번씩 중심화하면 재방문과 재맥락화 여유가 부족 |
| 7부제 | PASS | 다섯 축 중심화+두 작품의 결합·회수 가능 |
| 9부제 | PASS | 여유는 충분하나 항목 증식 통제가 필수 |
| 가변형 | CONDITIONAL | 축별 공개 약속이 부제작 수 변경과 충돌 가능 |

# T07 — 복선 부채

## 상황

핵심 비밀은 잘못 분류된 도감과 분산 부담 기록이다. 독자는 공정한 단서를 받아야 하며, 최종권 직전 설명 폭탄을 피해야 한다.

## 예산

- 사가급 핵심 질문 3개 이하
- 대형막 질문 1~2개씩
- 부제작 장기 미회수 단서 1개 이하
- 같은 단서의 의미 변경은 최대 2회

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | PASS | 부채 통제 가장 쉬움 |
| 7부제 | PASS | 예산 규칙을 지키면 공정한 반복·재해석 가능 |
| 9부제 | CONDITIONAL | 질문·인물·판본 증식 위험이 큼 |
| 가변형 | CONDITIONAL | 삭제·통합 시 단서 위치 재조정 필요 |

# T12 — 최종 선택의 준비

## 상황

최종적으로 주인공은 모든 경로와 기록의 독점 통제자가 되어 빠르게 구할 수 있는 선택과, 느리고 갈등이 많은 공동관리 사이에서 후자를 택한다.

## 필요한 선행 경험

1. 학교가 보호로 실제 이익을 주는 경험
2. 보호가 소유와 부담 전가로 바뀌는 경험
3. 다른 지역의 자기 기준과 당사자성을 보는 경험
4. 공개가 피해와 권리를 동시에 만드는 경험
5. 중앙 통제가 실제로 효율적인 경험
6. 독점권을 포기할 개인적 관계와 대가

| 안 | 결과 | 근거 |
|---|---|---|
| 5부제 | CONDITIONAL | 여섯 경험 중 일부가 한 작품에 결합돼 설득력 약화 가능 |
| 7부제 | PASS | 각 경험을 작품별 중심 또는 재맥락화로 배치 가능 |
| 9부제 | PASS | 충분하지만 반복 논증 위험 |
| 가변형 | CONDITIONAL | 중간 작품 삭제 시 선행 경험 누락 가능 |
