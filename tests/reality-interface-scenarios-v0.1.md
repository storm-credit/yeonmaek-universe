# 현실 연결 4관점 시험 v0.1

각 사례는 동일 사건을 `일반인 / 훈련자 / 센서 / 기관` 관점에서 검증한다. 네 관점이 임의로 바뀌지 않아야 한다.

## Case 1 — 막차 뒤 지하철 이동종

### 상황

막차가 끝난 뒤 터널 유지보수 구간에 L2 겹침이 열리고 중형 이동종 한 개체가 선로를 따라 이동한다. 작업자 두 명과 학생 탐사대가 목격한다.

### 일반인

- 작업자는 대형 유기견 또는 공사 장비의 그림자로 인식한다.
- 울음은 레일 진동과 환풍기 소음으로 기억한다.
- 가까이 접근해 냄새와 발자국을 확인하면 정상화가 약해져 `설명되지 않는 동물`로 기억할 수 있다.

### 훈련자

- 실루엣, 이동 방향, 흔적을 구분한다.
- 터널 자체가 L2라는 사실과 더 깊은 입구를 별도로 인식한다.
- 종을 완전히 식별하지 못하면 `미확인 이동종`으로 기록한다.

### 센서

- 전방 CCTV: 형태가 프레임마다 다르게 늘어남
- 열화상: 생물보다 선로 주변이 먼저 뜨거워짐
- 진동 센서: 실제 체중보다 큰 하중 기록
- 작업자 보디캠: 그림자는 있으나 몸통의 프레임이 누락

### 기관

- 지하철 운영기관은 시설물 낙하와 야생동물 침입 가능성으로 1차 통제
- 현실 협력실이 영상·센서 불일치를 인계받음
- 보호원이 이동 경로를 열어 개체를 유도
- 기록은 삭제하지 않고 제한 등급으로 보존

### 실패 조건

- 작업자 부상이나 운행 차질이 있으면 단순 은폐 불가
- SNS 업로드가 여러 각도에서 동시에 발생하면 부분 설명 필요

## Case 2 — 재개발 구역의 경계 붕괴

### 상황

철거 공사로 오래된 복개 수로와 산지 경로의 연결이 끊기며 L3 구역 일부가 현실 표면에 겹친다. 주민들이 반복적으로 같은 골목으로 되돌아온다.

### 일반인

- 공사 가림막과 임시 동선 때문에 길을 잃었다고 생각
- 일부 주민은 철거 전 골목이 다시 나타났다고 증언
- 오랜 거주자는 새 건물 사이에서 과거 집의 내부를 잠시 봄

### 훈련자

- 공간이 과거를 재생하는 것이 아니라 끊어진 경계가 가장 안정적이었던 구조를 반복한다는 가설 제시
- 주민의 기억과 공간 현상을 구분해 기록

### 센서

- GPS가 동일한 80m 경로를 반복 표시
- 드론 영상은 빈 공터를 보여 주지만 지상 카메라는 벽을 기록
- 공사 장비의 총 이동거리가 실제 작업량보다 큼

### 기관

- 시공사·구청·소방이 지반 불안정과 유해물질 문제로 현장 폐쇄
- 학교가 아니라 보호원과 현실 협력실이 대응 주체
- 주민 이주, 보상, 공사 변경이 필요
- 숨은 생태 이동로를 새로 만드는 비용과 책임을 협상

### 실패 조건

- 개발 중단 비용을 누가 부담하는지 설명하지 못하면 기관 설정 실패
- 주민 기억을 지워 해결하면 시스템 원칙 위반

## Case 3 — 조수 문을 촬영한 관광객

### 상황

남해의 섬 사이에서 특정 조수 높이에 L2~L3 항로가 열린다. 관광객 수십 명이 스마트폰으로 같은 순간을 촬영한다.

### 일반인

- 육안으로는 안개 속에 섬 또는 대형 선박이 나타난 것으로 봄
- 영상 재생 시 사람마다 다른 물체로 해석할 수 있음
- 여러 사람이 같은 이상한 방향 전환을 기억해 단순 개인 착각으로 끝나지 않음

### 훈련자

- 조수, 바람, 새의 이동이 항로 조건을 만들었다고 확인
- 외부인이 깊은 항로로 진입하지 않도록 현실 선박 동선을 조정

### 센서

- 스마트폰 영상마다 수평선과 물체 크기가 다름
- 선박 AIS에는 대상이 없음
- 레이더는 하나의 큰 물체가 아니라 여러 작은 반사로 기록
- 위치 메타데이터는 촬영 시각보다 수 분 앞섬

### 기관

- 해경·기상·관광 당국은 국지 안개와 항법 오류로 1차 발표
- 공개 영상을 모두 삭제하지 않음
- 반복 발생 시 관광 제한과 해양 보호구역 지정 검토
- 국제 항로와 연결되면 조정원이 개입

### 실패 조건

- 수백 명이 명확한 동일 영상을 확보하면 지각 정상화만으로 설명 불가
- 제한 공개 또는 현실적 자연현상과 혼합된 설명 필요

## Case 4 — 공항 환승 구역의 외국 학생

### 상황

외국 학단에서 파견된 학생이 현실 항공편으로 입국한다. 동행 생물의 흔적이 수하물 검사와 공항 센서에 포착되며, 학생은 한국의 출입 표식을 잘못 해석한다.

### 일반인

- 세관 직원은 살아 있는 검역 대상 또는 불법 반입 물질 가능성을 의심
- 승객은 수하물 지연과 보안 검색으로 인식

### 훈련자

- 출신 지역의 호환성 카드를 확인
- 한국 표식이 상대 전통에서 금지 신호로 읽힐 수 있음을 발견
- 강제 통과가 아니라 공동 번역과 새로운 출입 조건을 구성

### 센서

- X-ray에서 수하물 내부 부피가 외부보다 크게 표시
- 무게 센서와 열 감지 결과 불일치
- 여권·탑승 기록은 정상

### 기관

- 학교 국제 과정은 현실 비자·보험·학적을 사전에 처리
- 검역 담당과 현실 협력실이 생물 동행 여부를 별도 승인
- 조정원은 지역별 표식 번역 오류를 사고 보고서로 남김

### 실패 조건

- 국제 이동을 마법 통로 하나로 우회하면 현대 현실 연결 목표 실패
- 외국 학생이 한국식 체계를 무조건 따라야 하면 문화 호환 원칙 위반

## 공통 판정

현재 중첩 현실 모델은 네 사례에서 작동할 수 있다. 다만 다음 규칙을 추가 확정해야 한다.

1. L2와 L3에서 영상 왜곡의 상한
2. 지각 정상화가 약해지는 조건
3. 기관의 제한 공개 기준
4. 현실 피해 보상 주체
5. 국제 검역과 동행 생물의 권리
6. 일반 목격자가 반복 노출로 훈련자 수준에 접근하는 과정
