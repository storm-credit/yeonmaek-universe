# 부제작 5 인간 독자·분야 검토 패키지 v0.1

## 독자군

- 10~12세: 1~4장, 7~12장, 14~17장
- 13~15세: 전체 17장
- 성인·보호자: 1·5·8·11·14·16·17장
- 개인정보·미성년 기록 검토자
- 언론·플랫폼 정정·비식별 검토자
- 교통 운영·주민 안내·보상 검토자

## 핵심 질문

1. 예방 폐쇄가 왜 실제로 안전했는지 설명할 수 있는가?
2. 폐쇄 뒤 부담이 어디로 이동했는지 이해하는가?
3. 잔기록판이 삭제 내용을 복원하거나 범인을 찾는 도구가 아님을 이해하는가?
4. 정당한 보호 삭제와 책임·지원 연결 삭제를 구분할 수 있는가?
5. 9장의 공개가 실제 문제를 고쳤다고 느끼는가?
6. 10장의 위치 추정 피해가 갑작스럽지 않은가?
7. 유나가 공동 작업을 중단할 충분한 이유가 있는가?
8. 주민 피해를 알리면서 신상과 생태 위치를 지킬 수 있다는 구조를 이해하는가?
9. 15장에서 누가 교통 재개를 결정했는지 구분하는가?
10. 17장에서 두 개의 기록이 실패가 아닌 결말로 느껴지는가?

## 분야 검토

- 미성년 사진·메타데이터·학교 기록의 공개·재사용·철회 범위
- 플랫폼 정정 링크·비식별 자료·원본 보존의 현실성
- 독립 조사와 학교 내부 기록 정정 관계
- 교통 폐쇄·제한 재개·대체 동선·주민 안내·보상 절차
- 온라인 이용자를 단일 악의적 집단으로 일반화하지 않는지

## 중지 기준

- 독자 2명 이상이 공개=무조건 선 또는 비공개=무조건 악으로 읽음
- 독자 2명 이상이 잔기록판을 범인 탐지 도구로 오독
- 유나의 철회가 단순 갈등 장치로 느껴진다는 반응 반복
- 교통·개인정보·플랫폼 검토자가 위험한 오해 가능성을 지적
- 14~16장이 행정 정리만으로 느껴진다는 반응 반복
