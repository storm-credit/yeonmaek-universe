# 부제작 4 인간 독자·현지 검토 마스터 패키지 v0.1

## 독자군

- 10~12세: 1~4장, 7~8장, 13~16장
- 13~15세: 전체 16장
- 성인·보호자: 1·6·10·13·16장 중심과 전체 결말
- 현지 언어·문화 검토자: 합성 지역 표현, 이름·말투·통역 권한
- 시설·재난 검토자: 수문 운영·대피·검역·학생 권한 상한

## 핵심 질문

1. 4장까지 국제 최소 코드가 왜 유용한지 설명할 수 있는가?
2. 문답결의 행동을 적대나 오염으로 확정하지 않았다고 느끼는가?
3. 린이 대표 범위를 쓰지 않는 이유가 단순 고집이 아니라 권한 문제로 읽히는가?
4. 7~8장에서 운영 창과 검역 이송의 두 시계를 구분할 수 있는가?
5. 9장에서 `먼저 보이는 기록`이 권력이라는 점을 이해하는가?
6. 11장의 수정 성공이 실제 성과로 느껴지는가?
7. 12장의 하진 오류가 갑작스럽지 않고 성공의 연장으로 느껴지는가?
8. 13장의 토큰 이양이 책임 회피가 아니라 권한 분리로 읽히는가?
9. 15장에서 누가 수문을 결정하고 누가 지원했는지 구분할 수 있는가?
10. 16장에서 현재 사건이 끝났다고 느끼며, 서명 흔적은 다음 질문 하나로만 남는가?

## 현지·문화 검토

- 실제 태국어처럼 보이게 만든 가짜 표현이 없는가
- 현지 학생이 한국팀 안내자·교훈 제공자에 머물지 않는가
- 합성 수계 도시가 방콕의 취약 생활권을 판타지 문제로 대체하지 않는가
- 실제 종교·왕실·의례·문양을 장식으로 소비하지 않는가
- 식사·이동·학교 교류 등 생활 장면이 관광 목록이 되지 않는가

## 시설·안전 검토

- 학생은 수문 조작·대피 지휘·검역 판정·의료 판단을 하지 않는가
- 현지 수문 책임자와 국제 검역 책임자의 권한이 현실적으로 분리되는가
- 단계 운영·부분 격리·대체 동선의 개념이 과도한 기술 확정 없이 이해 가능한가
- 해외 미성년 철수·보험·의료·자료 접근 조건이 충분히 표시되는가

## 중지 기준

다음 반응이 반복되면 원고를 전면 재작성하지 않고 문제 위치를 국소 표시한다.

- 10~15세 2명 이상이 검역 시계와 운영 시계를 혼동
- 독자 2명 이상이 하진이 수문을 지휘했다고 오독
- 현지 검토자가 한국팀 중심 대리 해결 또는 문화 평면화를 지적
- 시설 검토자가 학생 권한·운영 절차를 위험하게 오해할 수 있다고 판정
- 13~15장이 행정 회의로만 느껴진다는 반응 반복

실제 응답은 아직 0건이며 인간 검토 완료로 표시하지 않는다.
