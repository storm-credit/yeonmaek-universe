# 대표 경기 단순화 시험 v0.1

## 시험 목표

대표 경기는 세계관을 잘 반영하는 것보다 먼저 관중이 승패를 즉시 이해해야 한다. 현재 결합안의 `길표+씨앗+문` 요소가 과도한지 비교한다.

## Variant A — 씨앗 운반형

> 세 길표를 연결해 문을 열고 씨앗을 통과시키면 승리.

### 장점

- 운반자를 중심으로 스타 플레이 가능
- 씨앗의 위치로 경기 진행을 추적하기 쉬움
- 럭비·릴레이와 유사한 운동성

### 약점

- 길표 연결과 씨앗 운반이라는 두 단계 규칙
- 씨앗이 왜 필요한지 세계관적 이유 요구
- 공처럼 보이면 기존 스포츠와 비교될 수 있음

### 30초 설명 결과

통과. 다만 `길표`, `씨앗`, `문` 세 용어를 기억해야 한다.

## Variant B — 봉화 점화형

> 세 길표를 연결해 중앙 봉화를 먼저 밝히면 승리.

### 장점

- 승리 장면이 명확하고 시각적
- 운반 물체가 없어 규칙이 단순
- 팀 전체의 연결 완성이 중요

### 약점

- 이동 스타의 역할이 약해질 수 있음
- 마지막 행동이 버튼 누르기처럼 보일 위험
- 공수 전환이 느릴 수 있음

### 30초 설명 결과

가장 명확함. 운동성을 별도 규칙으로 강화해야 한다.

## Variant C — 문 통과 릴레이형

> 세 길표를 연결해 마지막 문을 열고 팀원 세 명이 차례로 통과하면 승리.

### 장점

- 사람의 이동 자체가 목표
- 팀원 여러 명의 활약이 필요
- 마지막 추격전이 자연스러움

### 약점

- 이미 통과한 선수가 경기에서 빠지는지 복잡
- 문 앞 몸싸움과 안전 규칙 필요
- 길 연결보다 단순 경주로 기울 수 있음

### 30초 설명 결과

명확하지만 포지션·교대 규칙이 증가한다.

## Variant D — 영역 연결 점수형

> 제한 시간 동안 길표를 연결해 더 넓고 안정적인 길망을 만든 팀이 승리.

### 장점

- 경기 내내 점수 변화
- 한 번의 우연한 결승으로 승부가 결정되지 않음
- 전략 다양성

### 약점

- 관중이 안정도와 면적 계산을 이해하기 어려움
- 즉각적인 클라이맥스 부족
- 전자 스포츠나 보드게임처럼 보일 수 있음

### 30초 설명 결과

규칙은 이해되지만 판타지 스포츠의 상징적 결승 장면이 약함.

## 권장 순위

1. Variant B 봉화 점화형
2. Variant A 씨앗 운반형
3. Variant C 문 통과 릴레이형
4. Variant D 영역 연결 점수형

## B안 보완 규칙

봉화형의 운동성을 살리기 위해 `불씨`를 선수 한 명이 운반하는 중간안을 검토한다.

> 세 길표를 연결하면 불씨가 활성화되고, 선수가 불씨를 중앙 봉화에 옮기면 승리.

이 경우 다시 길표+불씨+봉화의 세 요소가 되므로 A안과 본질적으로 같아진다.

따라서 다음 두 모델만 최종 비교한다.

### B1 순수 봉화형

- 세 길표 연결 즉시 중앙 봉화 점화
- 단순하고 전략 중심

### B2 활성자 도달형

- 세 길표 연결 후 팀의 `활성자` 한 명이 중앙 봉화에 접촉
- 별도 물체 없이 이동 스타와 최종 추격을 보존

## 2D 시뮬레이션 기준

종이 위에 다음만 표시해 20회 모의 진행한다.

- 팀별 시작점 2개
- 중립 길표 5개
- 중앙 봉화 1개
- 선수 말 각 6개
- 연결선 토큰
- 차단 토큰

### 한 턴의 행동 후보

- 한 구간 이동
- 길표 활성화
- 연결선 설치·복구
- 상대 연결선 차단
- 팀원 지원

실제 작품은 턴제가 아니지만, 2D 시험은 다음을 확인한다.

- 선두 팀이 누구인지 보이는가
- 역전 경로가 존재하는가
- 한 역할이 모든 전략을 지배하는가
- 중앙 봉화 주변에만 선수가 몰리는가
- 길표 5개가 너무 많거나 적은가

## 잠정 제안

`B2 활성자 도달형`을 다음 설계 대상으로 둔다.

> 두 팀이 다섯 길표 가운데 세 개를 연결해 자기 길을 완성한다. 길이 완성되면 팀의 활성자가 중앙 봉화에 먼저 닿아 점화하는 팀이 이긴다.

### 아직 남는 문제

- 활성자가 고정 포지션인지 경기 중 바뀌는지
- 상대 활성자를 어떤 방식으로 막을 수 있는지
- 길표를 빼앗는 규칙
- 연결선이 끊겼을 때 봉화 접근 자격이 사라지는지
- 시간 종료 시 판정
- 다득점 세트제인지 단판 완주형인지
