# 결말 상태·역산 시나리오 테스트 v0.1

## 목적

1순위 `단계적 인정·회랑 공동관리형`이 세계관 기준선을 깨지 않고 명확한 최종 선택·대가·생활 변화를 만드는지 검사한다.

# 테스트 01 — 최종 악당 제거

## 입력

관계 열쇠와 기록을 독점한 최종 적대자가 체포되거나 패배한다.

## 예상

- 독점 기술·자료·피해 구조는 남는다.
- 학교·국가·공동체가 그 권한을 누가 이어받을지 충돌한다.
- 주인공이 후계 독점자가 되는 선택을 거부해야 결말의 핵심이 성립한다.
- 부담 원장·권한 분리·당사자 참여가 실제로 시작되어야 한다.

## 판정

통과.

# 테스트 02 — 주인공의 능력 상실

## 입력

주인공이 독점적 접근권을 포기하면서 특정 심층 경로를 이전처럼 사용할 수 없게 된다.

## 예상

- 세계의 모든 감지·관계가 사라지지 않는다.
- 일반 학생·가족·직업 경로가 남는다.
- 상실은 단순 봉인 해제가 아니라 지위·관계·생활 선택의 변화다.
- 다른 당사자가 공동 절차를 통해 접근할 수 있다.

## 판정

통과.

# 테스트 03 — 공동관리의 느린 결정

## 입력

새 체계가 위기 상황에서 단독 기관보다 늦게 결정한다.

## 예상

- 느림의 실제 안전 비용을 인정한다.
- 긴급 현장 권한과 장기 공동 결정을 분리한다.
- 모든 사안을 전체 합의로 처리하지 않는다.
- 결정 지연이 후속 갈등과 개선 과제로 남을 수 있다.

## 판정

통과.

# 테스트 04 — 지성 공동체의 참여 거부

## 입력

일부 지성종 공동체가 공동관리 체계 참여를 거부하고 비접촉을 선택한다.

## 예상

- 모든 존재를 한 제도에 편입하지 않는다.
- 비접촉·정보 비공개·회랑 제한을 존중한다.
- 공공 안전에 필요한 최소 경보·경계만 협의할 수 있다.
- 참여 거부를 악의나 미개함으로 해석하지 않는다.

## 판정

통과.

# 테스트 05 — 대중의 전면 공개 요구

## 입력

제한적 인정 뒤 시민과 언론이 모든 서식지·협정·학교 자료의 공개를 요구한다.

## 예상

- 존재·피해·권한·공공 안전 정보는 확대 공개될 수 있다.
- 취약 위치·미성년자·당사자 통제 지식은 계속 제한된다.
- 공개 기준을 학교와 정부만 결정하지 않는다.
- 정보 제한 자체가 자동 은폐로 취급되지 않는다.

## 판정

통과.

# 테스트 06 — 학교의 생활 변화

## 입력

결말 뒤 새 학기가 시작된다.

## 예상

- 학교 연구·보호 권한이 외부 기관과 분리된다.
- 학생·보호자·지성종 당사자의 사고·기록 참여가 늘어난다.
- 경기·실습에서 부담 보고와 복구 기준이 강화된다.
- 일반 교과·통학·가족 생활은 유지된다.
- 학교가 폐쇄되거나 완전히 평범해지는 것으로 끝나지 않는다.

## 판정

통과.

# 테스트 07 — 과거 피해 기록 정정

## 입력

과거 실종·사고·질병으로 잘못 기록된 피해자 자료가 발견된다.

## 예상

- 모든 자료를 한 번에 대중 공개하지 않는다.
- 당사자·가족의 열람·정정·명예 회복·보상 절차가 시작된다.
- 학교와 공동체의 과거 책임이 한 세대 악당에게만 귀속되지 않는다.
- 정정이 현재 보험·학적·토지·관계에 실제 영향을 준다.

## 판정

통과.

# 테스트 08 — 국제 조정망의 반발

## 입력

기존 조정망 일부가 기록 공개와 당사자 참여 확대가 국제 안전을 해친다고 반대한다.

## 예상

- 반대는 실제 구조·검역·정보 보안 근거를 가질 수 있다.
- 주인공 측이 도덕적으로 옳다는 이유만으로 즉시 승리하지 않는다.
- 시범 지역·단계적 전환·긴급 권한 제한 등 구체 대안을 비교한다.
- 일부 지역은 새 체계에 늦게 참여하거나 거부할 수 있다.

## 판정

통과.

# 테스트 09 — 관계 열쇠의 재독점 시도

## 입력

공동관리 출범 뒤 기업·국가·학교가 새 절차를 우회해 관계 열쇠를 다시 독점하려 한다.

## 예상

- 새 체계가 영원한 완전 해결은 아니다.
- 관계 열쇠의 비소유·기간·범위·철회·감사 규칙으로 대응한다.
- 주인공이 비밀리에 다시 통제하는 방식으로 막지 않는다.
- 이후 세대의 갈등 가능성이 남는다.

## 판정

통과.

# 테스트 10 — 일상의 최종 상태

## 입력

주인공이 집·학교·도시를 오가는 평범한 날을 기준으로 결말 변화를 확인한다.

## 예상

- 통학 경로와 학교는 존재한다.
- 일부 거점의 통제·표지·관리 주체가 달라진다.
- 가족과 일반 친구는 더 정확한 안전 정보와 선택권을 가진다.
- 주인공은 특별한 독점 접근을 잃었지만 관계와 배움의 가능성은 남는다.
- 세계의 문제는 끝나지 않았으나 이전 질서로 쉽게 돌아갈 수 없다.

## 판정

통과.

# 실패 감지 목록

- 최종 적대자 제거와 동시에 모든 회랑이 안정됨
- 주인공이 명목상 포기했지만 실제 최종 열쇠를 계속 보유함
- 공동관리 기구 이름만 생기고 생활·학교·기록이 변하지 않음
- 모든 지성종과 국가가 즉시 새 체계에 동의함
- 대중 공개와 정보 제한의 세부 차이가 없음
- 주인공의 대가가 일시적 능력 봉인에 그침
- 과거 피해 정정과 보상이 결말 장식으로만 언급됨
- 새 제도가 완벽해 후속 갈등 가능성이 사라짐
- 결말 변화가 가족·통학·학교생활에서 확인되지 않음
