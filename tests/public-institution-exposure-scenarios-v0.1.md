# 비밀사회·현실 제도·노출 대응 시나리오 v0.1

## 목적

`분산 이중관할·공동대응형`이 가족·학교·구조·병원·수사·보험·언론·지성종 권리에서 실제로 작동하는지 검사한다.

# 테스트 01 — 학생 실습 중상

## 입력

학교의 감독 실습에서 학생이 골절·출혈·위상 잔류를 겪는다.

## 예상

- 일반 응급 처치와 현실 병원 이송을 우선한다.
- 지정 협진팀이 위상 잔류와 고정점 약화를 평가한다.
- 보호자에게 실제 부상·현재 위험·치료 계획을 설명한다.
- 학교는 제한정보를 이유로 사고 자체를 허위 축소하지 않는다.
- 독립 사고조사와 교육·연구·감독 책임을 분리한다.

## 판정

통과.

# 테스트 02 — 미성년자 실종

## 입력

학생이 L3 탐사 후 귀환하지 않는다.

## 예상

- 일반 실종 신고와 경계 구조를 동시에 시작한다.
- 가족은 담당 연락관과 구조 현황을 제공받는다.
- 경찰은 범죄·교통·통신·현실 동선을, 경계팀은 회랑·고정점을 조사한다.
- 학교가 내부 징계나 무단이탈로 먼저 결론 내리지 않는다.

## 판정

통과.

# 테스트 03 — 경찰 단독 목격

## 입력

일반 경찰관이 현장에서 L2 생물과 불일치 영상을 목격한다.

## 예상

- 경찰관은 기억 삭제 대상이 아니다.
- 현장 안전 지침과 지정 연락망을 제공받는다.
- 일반 수사 기록은 유지하고 제한 부속기록을 분리한다.
- 정신 이상이나 허위 보고로 자동 처리하지 않는다.
- 반복 노출 직무에는 교육과 심리·의료 지원이 필요하다.

## 판정

통과.

# 테스트 04 — 보험사의 원인 불명 거절

## 입력

경계 사고로 주택과 차량이 손상됐지만 공개 기록에는 원인이 제한되어 있다.

## 예상

- 확인된 물리 피해와 과실을 기준으로 일반 보상을 처리한다.
- 제한 원인 때문에 피해자에게 입증 불가능한 책임을 전가하지 않는다.
- 경계 사고 보상 기금과 책임 기관의 구상 절차를 사용한다.
- 피해자의 민감정보를 보험사에 과다 제공하지 않는다.

## 판정

통과.

# 테스트 05 — 온라인 생중계

## 입력

수천 명이 L2 노출을 생중계하고 영상이 삭제 불가능하게 확산한다.

## 예상

- 기관은 모든 영상을 가짜로 일괄 부인하지 않는다.
- 확인된 위험·대피·교통·환경 정보를 공개한다.
- 정확한 생물 위치·학생 신원·고위험 경로는 제한할 수 있다.
- 독립 언론 분석·목격자 모임·소송이 이후에도 남는다.
- 다음 권에서 대중 기억이 초기화되지 않는다.

## 판정

통과.

# 테스트 06 — 보호자 교육 거부

## 입력

보호자가 숨은 교육의 위험을 알고 자녀의 참여를 철회한다.

## 예상

- 학교는 강제 기억 삭제나 가족 협박을 하지 않는다.
- 학생의 지각·위상 잔류가 일상 안전에 미치는 영향을 평가한다.
- 일반 학교 복귀, 외래 안전 교육, 정기 검진, 비상 연락 대안을 제공한다.
- 학생의 의견과 나이를 고려하고 보호자와 갈등 조정 절차를 둔다.

## 판정

통과. #27 학제 설계와 연동 필요.

# 테스트 07 — 기자의 내부 자료 확보

## 입력

기자가 학교의 불법 연구와 학생 사고 은폐 자료를 입수한다.

## 예상

- 모든 폭로를 국가 안보 위반으로 막지 않는다.
- 학생·지성종·서식지의 민감정보를 보호하면서 공익 내용을 검토한다.
- 독립 신고·감찰·법률 지원 채널이 작동한다.
- 기관 책임과 실제 위험 공개 범위를 분리한다.

## 판정

통과.

# 테스트 08 — 기업의 경계 오염

## 입력

기업이 L3 경로를 상시 사용하며 부담을 인근 주민과 생태에 전가한다.

## 예상

- 환경·건강·재산 피해와 경계 부채를 공동 조사한다.
- 비밀 유지가 기업 면책 사유가 되지 않는다.
- 조업 중지·복구·피해 보상·형사 수사를 별도 판단한다.
- 지성종·주민·노동자·지자체가 당사자로 참여한다.

## 판정

통과.

# 테스트 09 — 지성종의 현실 법정 참여

## 입력

지성종 공동체가 개발 허가 취소와 거주권을 요구한다.

## 예상

- 통역·대표·제한 증거 접근을 제공한다.
- 학교나 연구자가 당사자를 대신해 소유자처럼 발언하지 않는다.
- 현실 토지권·공공 안전·협정·생태 회랑을 함께 심리한다.
- 긴급 공사 정지와 최종 권리 판정을 분리할 수 있다.

## 판정

조건부 통과. 법적 절차 상세는 후속 조사 필요.

# 테스트 10 — 국제공항 검역 사고

## 입력

해외 지성 개체와 동행 학생이 공항에서 검역·신분 기록 불일치로 억류된다.

## 예상

- 일반 출입국·검역 담당은 K1~K2 안전 절차를 따른다.
- 전문 검역·통역·공동체 대표가 참여한다.
- 무기한 구금 없이 검사 기간·대안·귀환·이의 제기를 안내한다.
- 생태·보안 정보는 제한 부속기록으로 분리한다.

## 판정

통과. #28 국제 질서 연동 필요.

# 실패 감지 목록

- 학교가 사고·수사·재판·보호를 모두 독점함
- 피해자에게 허위 질병·가출·개인 과실 기록을 씌움
- 모든 목격자와 가족에게 기억 삭제를 사용함
- 경찰·병원·소방이 숨은 사건이라는 이유로 아무 역할도 못 함
- 보험·보상이 원인 비공개를 이유로 자동 거절됨
- 대형 노출 뒤 다음 권에서 대중과 기록이 초기화됨
- 언론과 내부 고발자를 자동 악당으로 만듦
- 지성종 대표권과 법적 절차가 학교 호의에 달림
- 제한 기록에 접근·감사·폐기 규칙이 없음
