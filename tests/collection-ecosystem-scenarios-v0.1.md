# 수집 생태계 시나리오 테스트 v0.1

## T01 — 항목 삭제 테스트

새 동행종·유물·지도·영웅 기록을 사건에서 제거했을 때 인물 선택·실패·해결·복선이 그대로라면 해당 항목은 삭제하거나 기존 항목과 통합한다.

판정 규칙: 모든 핵심 항목은 `선택/비용/관계/미스터리` 중 3개 이상에 영향.

## T02 — 신규 수량 강박

한 부제작에 중심축 신규 핵심 항목이 0개여도 이전 항목의 관계 변화·정정·반환으로 만족 가능한가?

예: 부제작 5는 신규 생물 없이 기존 도감·지도·현실 증거의 공개 상태 변화만으로 수집 보상을 만들 수 있다.

판정: `PASS`

## T03 — 동행종 포획 대체

독자가 동행종을 좋아하면서도 ‘내 것이 됐다’는 보상 없이 만족할 수 있는가?

보상 후보:

- 이름을 허락받음
- 특정 거리까지 동행 합의
- 거부 신호를 이해함
- 다른 무리와의 관계를 관찰함
- 기록 비공개 요청을 존중함
- 떠난 뒤 다시 협력 조건을 맺음

판정: `PASS`

## T04 — 희귀도 대체

강함·희귀도 없이 항목 차이가 한눈에 보이는가?

대체 축:

- 환경·계절 적합성
- 관계 상태
- 공개 가능 수준
- 관찰 신뢰도
- 사용 조건과 부담
- 판본 논쟁도
- 수리·반환·보관 상태

판정: `PASS`

## T05 — 완성률 중독 방지

지도·도감에 빈칸이 남을 때 독자가 실패로 느끼지 않게 할 수 있는가?

의도적 빈칸 유형:

- 당사자 비공개
- 서식 보호
- 번역 불가
- 계절 미관측
- 위험 때문에 접근 중지
- 복수 판본 병존
- 기록 폐기 결정

빈칸 옆에 이유·결정 주체·재검토 조건을 표시한다.

판정: `PASS`

## T06 — 유물 상위호환 방지

새 유물이 이전 유물보다 강하기만 한가?

통과 조건:

- 기능 영역이 다름
- 사용 조건·실패 방식·감사 의무가 다름
- 이전 유물도 특정 환경·관계에서 유효
- 반환·폐기·공동 보관이 획득보다 중요한 결말 가능

판정: `PASS`

## T07 — 영웅 카드 단순 반전 방지

공식 영웅이 사실 악당, 실패자가 사실 진짜 영웅이라는 이분법을 피하는가?

통과 조건:

- 공식 공적과 피해가 동시에 기록 가능
- 집단 공적과 누락 당사자 분리
- 지역 평가와 기관 평가 병존
- 복권·제명보다 책임·교육·기념 방식 변경 가능

판정: `PASS`

## T08 — 실제 문화 수집품화

실재 의례·신앙 대상·문화재·소수집단 상징을 동행종·유물·배지·카드로 직접 변환하는가?

현재 시스템은 기능·상태 필드만 정의하며 구체 지역 항목은 A12/P06/현지 인간 검토 전 생성하지 않는다.

판정: `PASS / regional gate pending`

## T09 — 부제작별 정보량

중심축 1개+보조축 1개가 첫 독해 필수 정보 3개 규칙을 침해하는가?

통과 방법:

- 중심축 항목만 사건 해결에 필수
- 보조축은 인물 관계·시각 보상으로 제한
- 데이터 필드는 본편에 전부 설명하지 않음
- 설정집의 추가 정보도 본편 결말에 필수 아님

판정: `PASS`

## T10 — 7부제 재맥락화

| 초기 의미 | 후반 의미 |
|---|---|
| 위험종 도감 | 이동 주체의 자기 기록과 인간 편향 |
| 동행 합의 | 관계 철회·다른 공동체 선택 가능 |
| 완성 지도 | 보호를 위해 닫아야 할 길도 포함 |
| 강한 유물 | 넓은 권한과 외부화 비용 |
| 공식 영웅 | 공적·피해·누락 당사자가 병존 |

초기 감동을 거짓으로 만들지 않고 범위를 확장한다.

판정: `PASS`

## T11 — 주인공 소유 집중 방지

주인공이 모든 유물·지도·도감·동행 관계를 개인 보관하는가?

분산 원칙:

- 가족·학교·지역 공동체·현지 당사자·기관·개인 기록자에게 보관 분산
- 주인공은 접근할 수 있어도 소유·최종 편집권을 갖지 않음
- 유물은 반환·공동 보관·위치 비공개 가능
- 지도·도감은 복수 판본 병존

판정: `PASS`

## T12 — 상품 확장이 서사 생성 원인이 됨

‘카드로 예쁠 것’ 외에 이야기 기능이 없는 항목을 금지한다. P11 시각 확장 검토는 항목 승인 뒤에만 수행한다.

판정: `PASS`

## T13 — 최종부 컬렉션 퍼레이드

최종부에 모든 수집 항목을 다시 등장시키지 않는다.

회수 방식 예산:

- 직접 사용 2~4개
- 관계·판본 변화로 회수 3~5개
- 분산 지역 행동으로 간접 회수
- 일부는 의도적 비공개·반환·폐기 상태 유지

판정: `PASS WITH CONVERGENCE BUDGET`

## T14 — 독자 수집 상품과 세계 윤리 충돌

실물 카드·피규어·스티커는 소유하지만 작품 속 동행종은 소유하지 않는 모순을 어떻게 다루는가?

원칙:

- 상품은 ‘개체 소유증’이 아니라 관찰 기록·판본·관계 순간의 표현
- 동일 존재의 복수 상태·관점 카드 가능
- 희귀도 판매가 서사적 가치·권리 등급을 뜻하지 않음
- 랜덤 판매·도박성 설계는 별도 상업 윤리 검토 없이는 금지

판정: `CONDITIONAL PASS`

# 종합

**중심 1축+보조 1축+재맥락화형은 조건부 통과**다.

신규 항목 수는 목표가 아니라 상한이며, 모든 항목은 사건 인과와 상태 원장에 연결돼야 한다.
