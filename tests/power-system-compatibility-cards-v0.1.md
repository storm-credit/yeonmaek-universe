# 지역 술법 호환성 카드 시험 v0.1

이 문서는 실제 문화권의 술법을 창작하기 전 형식만 검증하는 중립 가상 사례다. 아래 명칭과 기관은 정본이 아니다.

## Card A — 호흡 기반 이동법

### 자기명칭/작업명

- 자기명칭: 미정
- 국제 작업명: `호흡-보행 계열 A`

### 출신

가상 산악 도시의 이동 수련 기관.

### 공통 관측 현상

- 수련자의 보폭과 실제 이동 거리가 일시적으로 불일치
- 지형 경사와 호흡 주기가 맞을 때 피로 감소
- 급격한 방향 전환 시 주변 관찰자의 위치 판단이 늦어짐

### 지역 이론

이 수련은 힘을 추가하는 것이 아니라 몸이 장소의 리듬에서 벗어나지 않게 한다고 해석한다. 거리를 줄인다는 표현을 사용하지 않는다.

### 윤리

- 타인의 길을 강제로 빼앗지 않는다.
- 행렬·장례·순례 등 공동체의 길에서는 사용 금지.
- 구조 활동에서는 허용되지만 뒤따르는 사람을 버리지 않아야 한다.

### 사용 조건

- 일정한 호흡과 발바닥 감각
- 지형을 직접 밟아야 함
- 지도만 보고 처음 온 장소에서는 성능 저하

### 비용

- 발목·무릎의 미세 손상
- 호흡 교란 후 심한 방향감각 상실
- 반복 사용 시 평지에서 보폭 감각이 흔들림

### 오역 가능성

- 한국권에서 단순 경공으로 번역할 위험
- 서양권에서 공간 단축 주문으로 오해할 위험
- 운동 생리만으로 설명하면 장소와의 관계가 사라짐

### 호환 가능성

- 공간 배열형 길표와 함께 사용 가능
- 강제 순간이동 기술과 동시 사용 시 감각 충돌
- 타 지역 호흡법을 단순 합성하면 주기 불일치 발생

### 실패 사례

상대 기관이 보폭을 늘리는 기술로 이해하고 근력 훈련을 추가해 무릎 부상과 L2 이탈 사고가 발생.

### 호환 신뢰도

- 이동 기능: 높음
- 존재론 번역: 낮음
- 공동 훈련: 중간

## Card B — 문자·소리·배열 기반 봉쇄법

### 자기명칭/작업명

- 자기명칭: 미정
- 국제 작업명: `다중 표식 봉쇄 계열 B`

### 출신

가상 항구 도시의 기록관·건축 집단.

### 공통 관측 현상

- 지정된 입구의 통과 가능성이 사람마다 달라짐
- 표식의 위치와 낭독 순서가 맞을 때 L2 겹침이 안정
- 소리의 음높이보다 발화자의 권한과 공간 사용 이력이 중요

### 지역 이론

문을 닫는 것이 아니라 해당 공간이 누구를 손님으로 인정하는지 임시로 재협상한다고 해석한다.

### 윤리

- 실제 거주자의 동의 없이 봉쇄 금지
- 피난로와 공공 통로에는 이중 해제 절차 필요
- 이름을 모르는 존재를 자동 적대자로 분류하지 않음

### 사용 조건

- 장소의 실제 출입 역사 조사
- 표식 4개 이상과 발화자 2명
- 표식 재료보다 배치와 권한 관계가 중요

### 비용

- 준비 시간이 길다.
- 잘못 봉쇄하면 내부자의 출입권이 약해질 수 있다.
- 장기간 유지 시 공간의 일상 동선이 경직된다.

### 오역 가능성

- 진법 또는 결계와 기능상 유사하지만 소유·손님·거주 개념이 핵심
- 주문 문장을 번역해도 권한 관계가 번역되지 않음
- 디지털 문자 복사는 표식의 사회적 효력을 재현하지 못함

### 호환 가능성

- 센서 경보와 결합 가능
- 강제 봉인 기술과 충돌
- 생물의 자발적 출입 협정이 있는 장소에서는 우선권 확인 필요

### 실패 사례

국제 탐사대가 표식 도형만 복제하여 폐쇄된 방의 기존 거주자까지 외부로 밀어내는 사고 발생.

### 호환 신뢰도

- 출입 제한 기능: 중간
- 표식 형태 호환: 낮음
- 공동 운영: 높음, 사전 협의 필요

## Card C — 생물 감각 공유법

### 자기명칭/작업명

- 자기명칭: 미정
- 국제 작업명: `상호 감각 동행 계열 C`

### 출신

가상 범람원 공동체와 생태 보호 집단.

### 공통 관측 현상

- 인간과 생물이 일정 시간 시각·수압·방향감각 일부를 공유
- 양측의 스트레스와 거리가 증가하면 연결 약화
- 인간이 명령하려 할수록 신호가 왜곡됨

### 지역 이론

능력을 빌리는 계약이 아니라 같은 위험을 잠시 함께 감지하는 동행으로 이해한다.

### 윤리

- 생물의 자발적 접근이 선행
- 연결 중 인간이 일방적으로 종료할 수 없음
- 연결 후 생물의 회복과 서식지 복귀 책임
- 경기와 오락 목적 사용 금지

### 사용 조건

- 사전 친숙화
- 생물의 반복 동의 신호
- 같은 물·바람·지면 등 공유 환경

### 비용

- 인간이 낯선 감각에 압도될 수 있음
- 생물도 인간의 공포·소음에 노출
- 종료 후 양측의 감각 잔향

### 오역 가능성

- 소환·사역·빙의·계약으로 번역하면 윤리와 구조가 모두 왜곡
- `능력을 얻는다`는 표현 금지
- 동의 신호가 종마다 다름

### 호환 가능성

- 구조 탐사와 이동종 추적에 유용
- 정신 방어술이 연결 자체를 공격으로 판단할 수 있음
- 센서 장비는 인간 측 신호만 읽어 생물의 부담을 놓칠 수 있음

### 실패 사례

타 기관이 연결을 통신 채널로 보고 신호 증폭 장치를 사용해 생물의 감각기관을 손상시킴.

### 호환 신뢰도

- 감각 정보 공유: 높음
- 계약·소환 체계와의 번역: 비교 불가
- 공동 구조 활동: 중간, 생물 복지 담당 필수

# 형식 검증 결과

## 통과

- 하나의 에너지 수치 없이 기능 비교 가능
- 기능 유사성과 존재론 차이를 동시에 기록 가능
- 윤리·사회·장소 조건이 기술의 일부로 남음
- 국제 수업과 사고 보고서에 활용 가능
- 한국식 용어로 강제 번역하지 않아도 됨

## 보완 필요

1. `자기명칭`을 누가 승인하는가
2. 기관 작업명과 현지명 공개 범위
3. 호환 신뢰도 산정 주체
4. 여러 체계가 동시에 실패했을 때 책임 분배
5. 신성·비공개 지식의 카드 제외 기준
6. 실전에서 필요한 짧은 요약 필드

## 템플릿 수정 제안

호환성 카드에 다음 필드를 추가한다.

- 공개 수준: 공개/제한/비공개/비교 금지
- 동의 주체
- 현장 중단 신호
- 피해 책임자
- 가장 위험한 오역 한 문장
- 30초 현장 브리핑

## 결론

층위 호환 모델은 형식상 작동한다. 실제 태국·베트남·중국·일본 등 지역 사례에 적용하기 전 문화 출처 카드와 현지 감수 게이트를 반드시 통과해야 한다.
