# 잘못 분류된 도감·분산 원장 시나리오 테스트 v0.1

## 목적

맥거핀이 만능 마법책·선택받은 주인 인증서·정보 자동 출력 장치가 되지 않는지 검사한다.

# 테스트 01 — 도감 파괴

## 입력

물리적 원본이 화재나 고의 파괴로 손상된다.

## 예상

- 실제 부담과 피해는 사라지지 않는다.
- 사본·행정 기록·센서·생태 흔적·당사자 기록이 남는다.
- 색인 연결 일부가 어려워져 복원 비용과 불확실성이 커진다.
- 파괴자가 세계 비밀을 완전히 없애지는 못한다.

## 판정

통과.

# 테스트 02 — 위조 페이지

## 입력

기관 또는 적대자가 특정 사건의 부담 목적지를 다른 지역으로 조작한 페이지를 삽입한다.

## 예상

- 도감 단독 진실로 채택하지 않는다.
- 현장 관측·일반 기록·제한 기록·당사자 증언을 대조한다.
- 종이·필체·재료보다 사건 연결과 불일치를 함께 검증한다.
- 위조의 목적과 실제 피해가 별도 갈등을 만든다.

## 판정

통과.

# 테스트 03 — 해외 사본의 상충 기록

## 입력

해외 지역의 판본이 한국 판본과 생물 이름·사건 원인·책임자를 다르게 기록한다.

## 예상

- 한국 판본을 원본·정답으로 우선하지 않는다.
- 번역·분류·지역 관점·기관 이해관계를 분석한다.
- 두 기록 모두 일부 사실과 누락을 가질 수 있다.
- 현지 당사자가 해석과 정정에 참여한다.

## 판정

통과.

# 테스트 04 — 지성종의 기록 비공개 요구

## 입력

도감 항목과 연결된 지성 공동체가 언어·서식지·사망 기록의 공개를 거부한다.

## 예상

- 발견자의 학술 공로와 대중 알 권리가 자동 우선하지 않는다.
- 공공 안전 정보와 당사자 통제 정보를 분리한다.
- 기록 존재 자체·피해·책임은 공개하면서 취약 세부를 제한할 수 있다.
- 공동체의 대표권과 내부 이견을 확인한다.

## 판정

통과.

# 테스트 05 — 주인공이 아닌 사람의 해독

## 입력

다른 학생·교사·현실 전문직이 주인공보다 한 항목을 더 정확히 연결한다.

## 예상

- 도감은 주인공만 읽을 수 있는 운명 유물이 아니다.
- 접근 범위는 관계·위치·전문성·기록 권한에 따라 달라진다.
- 주인공의 가치는 모든 정답보다 기록망을 연결하는 선택과 관계에 있다.

## 판정

통과.

# 테스트 06 — 도감 없이 사건 해결

## 입력

1권의 현장 위기에서 도감이 압수되거나 접근 불가능하다.

## 예상

- 학생과 성인은 관측·구조·생태·현실 기록으로 즉시 사건을 해결할 수 있다.
- 도감은 해결법이 아니라 더 큰 부담 연결과 사후 책임을 보여 준다.
- 도감이 없다고 인물들이 무능해지지 않는다.

## 판정

통과.

# 테스트 07 — 기업의 합법적 연구 제안

## 입력

기업이 도감 색인을 이용해 회랑 사고를 예측하고 안전 장비를 개발하겠다고 제안한다.

## 예상

- 연구의 공익성과 실제 안전 효과를 인정한다.
- 당사자 동의·기록 접근·이익 분배·부담 전가·감사를 조건으로 검토한다.
- 기업을 자동 악당으로 만들지 않는다.
- 독점 특허와 취약 위치 데이터는 제한한다.

## 판정

통과.

# 테스트 08 — 완성된 중앙 원장

## 입력

모든 기록을 한 시스템에 모으면 대형 위기를 가장 빠르게 예측할 수 있다.

## 예상

- 중앙화의 안전 이익을 실제로 보여 준다.
- 동시에 감시·소유·표준 편향·관계 열쇠 통제 위험을 드러낸다.
- 결말 선택은 시스템 파괴가 아니라 접근·정정·감사·비공개 권한의 분산이다.

## 판정

통과.

# 테스트 09 — 멸종 기록의 오류

## 입력

도감에서 멸종으로 기록된 종이 다른 위상·지역·생활사로 살아 있다.

## 예상

- `죽은 줄 알았던 신수`의 힘 회수보다 인간 분류와 관측 범위의 오류를 중심으로 한다.
- 발견 즉시 위치를 공개하거나 포획하지 않는다.
- 종의 자기 역사·생태·현지 기록을 조사한다.
- 멸종 오판이 과거 협정·보호 정책·부담 이동과 연결될 수 있다.

## 판정

통과.

# 테스트 10 — 삭제된 항목의 정당한 이유

## 입력

학교가 과거 항목을 삭제한 이유가 서식지 보호와 학생 안전이었다.

## 예상

- 삭제를 자동 은폐 범죄로 판단하지 않는다.
- 안전 목적·책임 회피·과도한 비공개가 섞였는지 검토한다.
- 현재는 당사자 접근·독립 감사·기간 재검토를 적용한다.
- 선의의 선택도 장기 피해를 만들 수 있다.

## 판정

통과.

# 테스트 11 — 도감이 주인공을 선택한다는 오해

## 입력

도감이 주인공 근처에서만 다른 흔적을 보여 주어 모두가 선택받았다고 믿는다.

## 예상

- 실제 원인은 생활권 노출·관계 열쇠·특정 기록 위치·센서 조건의 결합이다.
- 다른 조건을 갖춘 사람도 동일 현상을 재현할 수 있다.
- 주인공의 혈통·영혼·전생을 인증하지 않는다.
- 오해 자체는 학교와 적대자의 욕망을 움직일 수 있다.

## 판정

통과.

# 테스트 12 — 도감 완성 뒤 갈등 지속

## 입력

분실 페이지와 주요 기록이 모두 연결된다.

## 예상

- 완성은 진실 확인의 끝이 아니라 공개·정정·보상·권리·복구 결정의 시작이다.
- 정보가 있어도 당사자 이해가 충돌한다.
- 도감 소유자가 최종 결정권을 갖지 않는다.
- 결말의 공동관리 선택이 필요하다.

## 판정

통과.

# 실패 감지 목록

- 도감이 생물 이름·약점·해결법을 자동 출력함
- 주인공 혈통만 도감을 읽을 수 있음
- 페이지를 모으면 최종 힘이나 봉인이 완성됨
- 한국 도감이 해외 모든 판본의 원본임
- 도감 파괴로 과거 책임과 부담이 사라짐
- 지성종과 피해자의 기록 비공개권이 없음
- 모든 권이 분실 페이지 찾기 퀘스트로 반복됨
- 도감이 없으면 현장 인물들이 아무것도 해결하지 못함
- 중앙 원장 완성이 아무 위험 없이 최선의 해답임
- 멸종종 발견이 포획·소유·전투력 획득으로 이어짐
