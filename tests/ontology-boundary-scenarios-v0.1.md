# 존재론·경계 시나리오 테스트 v0.1

## 목적

다층 생태 위상형 후보가 일상·재난·기술·범죄·국제 이동에서 같은 규칙으로 작동하는지 검사한다. 장면이나 대사는 쓰지 않는다.

## 통과 기준

- 물질이 복제되지 않는다.
- 과거로 돌아갈 수 없다.
- 목적지와 실제 연결 경로가 존재한다.
- 진입과 귀환에 열쇠와 고정점이 필요하다.
- 현실 피해와 기록이 사라지지 않는다.
- 센서는 무조건 고장 나지 않고 불완전한 증거를 남긴다.

# 테스트 01 — 우발적 동반 진입

## 입력

표식이 있는 학생과 아무것도 모르는 보호자가 같은 지하 통로를 통과한다. 장소·상태 열쇠는 활성화되어 있고 학생만 관계 열쇠를 가진다.

## 예상

- 학생은 L3 경로에 안정적으로 진입한다.
- 보호자는 L1~L2 수준으로 일부 끌려가거나 경로 반복을 경험할 수 있다.
- 두 사람이 손을 잡거나 구조 관계가 강하면 학생의 관계 열쇠가 보호자를 임시로 포함할 수 있다.
- 보호자가 표면에 복제되어 남지 않는다.
- CCTV에는 두 사람의 위치와 시간이 서로 맞지 않는 구간이 남는다.

## 판정

통과. 관계 열쇠의 임시 공유 조건은 #24와 #26에서 제한해야 한다.

# 테스트 02 — 입구 철거

## 입력

재개발 공사로 장기간 유지된 장소 열쇠가 완전히 철거된다.

## 예상

- 기존 입구는 폐쇄된다.
- 심층 생태가 즉시 소멸하지 않는다.
- 가장 가까운 수계·산지·지하 회랑으로 이동 압력이 전이된다.
- 이면종 출현, 배수 이상, 지반·센서 이상이 주변으로 이동할 수 있다.
- 개발 허가, 환경 책임, 주민 피해가 남는다.

## 판정

통과. 경계 보호를 토지 소유권만으로 처리할 수 없다는 결론을 #26과 #30에 전달한다.

# 테스트 03 — 심층 사망

## 입력

사람이 L4에서 사망하고 원래 입구는 폐쇄된다.

## 예상

- 사망은 되돌아가지 않는다.
- 시신 또는 물질 흔적은 L4에 남는다.
- 현실에서는 실종·사망 추정·보험·가족 문제가 발생한다.
- 회수에는 같은 회랑의 다른 출구와 관계 승인이 필요하다.
- 기억 삭제로 기록을 정리하지 않는다.

## 판정

통과. 시신의 위상 안정성과 법적 사망 시점은 #26에서 정한다.

# 테스트 04 — 대규모 생중계

## 입력

수천 명이 있는 축제에서 L2 겹침이 발생하고 여러 방송사·휴대전화가 촬영한다.

## 예상

- 영상이 모두 사라지지 않는다.
- 카메라 위치·센서·촬영자의 결합 상태에 따라 형체와 동선이 다르게 기록된다.
- 현실 피해와 현장 통제는 공개된다.
- 서로 모순되는 영상 때문에 단일 설명은 어려우나 은폐가 완전하지 않다.
- 반복 노출로 일부 대중이 불일치 패턴을 학습할 수 있다.

## 판정

통과. 장기적으로 제한 공개 논쟁이 발생해야 하며 시리즈 초기화 금지.

# 테스트 05 — 강제 산업화

## 입력

기업이 기상 장비·굴착·센서·대형 진법으로 L3 경로를 상시 개방하려 한다.

## 예상

- 장소·상태 열쇠는 기술로 상당 부분 제어할 수 있다.
- 관계 열쇠가 없으면 경로 불안정·생태 반발·회수 실패가 누적된다.
- 일부 비지성 생태에서는 관계 열쇠를 서식 조건 충족으로 대체할 가능성이 있다.
- 상업화가 불가능한 것이 아니라 비싸고 위험하며 권리 갈등을 낳는다.

## 판정

부분 통과. 관계 열쇠가 편의적 거부권이 되지 않도록 #25와 #30에서 객관적 징후를 정해야 한다.

# 테스트 06 — 해외 지름길

## 입력

학생이 서울의 지하 통로에서 방콕 학교로 직접 가려 한다.

## 예상

- 실제 연결된 수계·항로·중간 거점이 없다면 실패한다.
- 장거리 위상 경로는 하나의 문이 아니라 여러 회랑의 연속이다.
- 여권·검역·기관 승인과 별개로 생태 회랑의 상태 조건도 필요하다.
- 항상 비행기보다 빠르지 않다.

## 판정

통과. 국제 경로 지도는 #28과 P04가 관리한다.

# 테스트 07 — 구급대 진입

## 입력

일반 구급대가 L2에 걸친 부상자를 구조하려 한다.

## 예상

- L0~L2 물리 피해는 일반 의료로 일부 처리 가능하다.
- 구급대의 구조 관계가 임시 관계 열쇠로 작동할 수 있지만 자동은 아니다.
- 정식 경계 구조 요원이 위상 안정과 귀환 고정점을 지원한다.
- 의료 기록에는 원인을 알 수 없는 손상과 시간·위치 불일치가 남는다.

## 판정

통과. 구조 행위의 관계 열쇠 인정 기준이 필요하다.

# 테스트 08 — 범죄자의 고정점 파괴

## 입력

범죄자가 진입자의 귀환을 막기 위해 원래 입구와 개인 표식을 파괴한다.

## 예상

- 즉시 영구 고립되는 것은 아니다.
- 같은 회랑의 보조 출구, 동행자 관계, 기관의 구조 고정점을 사용할 수 있다.
- 모든 대체 고정점이 끊기면 장기 조난이 가능하다.
- 임의 장소로 탈출하거나 과거 진입 전으로 돌아갈 수 없다.

## 판정

통과. 고정점의 우선순위와 중복 등록 한도는 #24에서 정한다.

# 테스트 09 — 토지 소유권 충돌

## 입력

현실 토지 소유자가 자신의 건물 아래 L4 사회의 출입을 금지한다.

## 예상

- 현실 토지 권리만으로 L4의 존재와 이동권이 자동 소멸하지 않는다.
- 표면 공사와 안전 권한은 현실 법이 갖지만 심층 거주권·회랑권은 별도 협정 대상이다.
- 한쪽의 절대 우선이 아니라 중재·보상·이전·보호구역 지정 문제가 발생한다.

## 판정

통과. 지성종 법적 지위가 #25에서 정해져야 완성된다.

# 테스트 10 — 서로 다른 문화의 공동 탐사

## 입력

한국·베트남·몽골 탐사자가 같은 L3 경로를 각기 다른 용어와 기법으로 해석한다.

## 예상

- 물질·인과·경로 보존 법칙은 동일하게 적용된다.
- 각 전통은 장소·상태·관계 열쇠 중 서로 다른 신호를 더 정밀하게 읽을 수 있다.
- 어느 한 전통만 객관적 진실이고 다른 전통은 미신인 구조를 금지한다.
- 번역 실패와 윤리 차이가 사건을 만들 수 있다.

## 판정

통과. 지역별 기술 상세는 국가 데스크 조사 후 설계한다.

# 실패 감지 목록

다음 중 하나라도 발생하면 존재론 후보를 다시 연다.

- 인물이나 물건이 설명 없이 두 위상에 동시에 원본으로 존재함
- 포털이 필요한 장소로 임의 연결됨
- 심층 시간이 과거 수정 수단으로 사용됨
- 관계 열쇠가 작가가 원하는 사람만 통과시키는 변명이 됨
- 카메라·통신이 매번 편의적으로 고장 남
- 개발로 입구를 닫으면 생태·권리 문제가 모두 해결됨
- 지역 전승이 공통 과학의 미숙한 표현으로 취급됨
