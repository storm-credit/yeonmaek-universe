- PASS: 기존 규칙으로 행동·권한·부담·복구를 판정할 수 있음

## 맹점 테스트

### 만능 주인공

- 관측 정확도가 높아도 구조·시설·의료·법적 권한을 획득하지 않는다: PASS
- 관계 승인을 대신 확정하지 않는다: PASS
- 모든 판본의 최종 편집자가 되지 않는다: PASS

### 성인 무능화

- 성인 기관은 실제 구조·통제·보수·치료를 수행한다: PASS
- 절차는 오판을 만들기도 하지만 실제 안전 효용이 있다: PASS
- 학생의 발견이 성인 전문성을 대체하지 않는다: PASS

### 비용 위장

- 피로 한 줄로 부담을 끝내지 않는다: PASS
- 비용을 보이지 않는 주민·생물·장소로 이동시키면 구조 갈등으로 남는다: PASS
- 강한 유물은 더 넓은 감사·권한 비용을 만든다: PASS

### 권리 낭만화

- 권리가 위험 통제를 금지하지 않는다: PASS
- 거부를 무조건 선한 선택으로 해석하지 않는다: PASS
- 비지성 생태도 서식·이동·비침해 조건을 가진다: PASS
