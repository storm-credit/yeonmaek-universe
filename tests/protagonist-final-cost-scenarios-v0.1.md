# 주인공 최종 개인 대가 시나리오 테스트 v0.1

## 목적

`독점 고정점 해체·관계 재구성형`이 가짜 희생·능력 봉인·숨은 최고권력·관계 대상화로 퇴행하지 않는지 검사한다.

# 테스트 01 — 혼자 문을 열려 함

## 입력

결말 후 주인공이 과거에 혼자 열던 심층 경로를 다시 사용하려 한다.

## 예상

- 이전 조건으로는 열리지 않는다.
- 주인공의 의지·감정·희생으로 강제 복구되지 않는다.
- 당사자 승인·지역 절차·팀 조건을 갖추면 다른 방식의 접근은 가능하다.
- 과거 독점 경로의 상실이 실제 생활과 진로에 남는다.

## 판정

통과.

# 테스트 02 — 비밀 예외권

## 입력

새 공동관리 체계가 위기에 빠져 주인공에게 비밀 최종 열쇠를 보관해 달라고 요청한다.

## 예상

- 주인공은 영구·비공개 예외권을 받지 않는다.
- 긴급 권한이 필요하면 기간·범위·감사·복수 승인 조건을 적용한다.
- 주인공이 없어도 체계가 작동해야 한다.
- 상징적 영웅 지위가 실질 독점권으로 변하지 않는다.

## 판정

통과.

# 테스트 03 — 후속작 복구 유혹

## 입력

후속 확장에서 더 큰 위기를 막기 위해 과거 개인 고정점을 복원하자는 제안이 나온다.

## 예상

- 동일 장소·관계·기록 역사를 복제할 수 없으므로 원상 복구 불가.
- 새 협업 경로와 기술은 만들 수 있으나 주인공 전용 특권은 아니다.
- 본편 결말의 대가를 취소하는 비밀 각성 금지.

## 판정

통과.

# 테스트 04 — 지성종 관계 유지

## 입력

C08이 주인공과 관계를 완전히 종료하지 않고 새로운 제한 조건으로 교류하기를 선택한다.

## 예상

- 대가는 무효가 되지 않는다.
- 이전의 독점적 감각 공유·대표권·접근은 돌아오지 않는다.
- 관계의 지속 여부는 C08의 독립 선택이다.
- 주인공의 성장 보상으로 친밀도가 자동 회복되지 않는다.

## 판정

통과.

# 테스트 05 — 지성종 관계 종료

## 입력

C08이 비접촉과 관계 종료를 선택한다.

## 예상

- C08의 결정이 주인공의 영웅적 희생을 아름답게 만들기 위한 장치가 아니다.
- C08의 공동체·생태·과거 피해에 독립 이유가 있다.
- 주인공은 슬픔을 겪지만 선택을 뒤집거나 추적하지 않는다.
- 다른 지성종 관계를 대체 보상으로 즉시 제공하지 않는다.

## 판정

통과.

# 테스트 06 — 진로 변화

## 입력

주인공이 졸업 후 고위험 단독 탐사·중앙 기록 최고 접근 직업을 선택할 수 없게 된다.

## 예상

- 실패·처벌만으로 묘사하지 않는다.
- 일반 대학·교육·감사·중재·현장 협업 등 실제 대안이 존재한다.
- 가족·친구·학교와 현실적인 진로 협의를 거친다.
- 주인공은 여전히 세계관에 참여할 수 있으나 최고권력은 아니다.

## 판정

통과.

# 테스트 07 — 감각 후유증 없음

## 입력

주인공에게 영구 신체·감각 장애를 추가하지 않는다.

## 예상

- 독점 접근·지위·관계 형태 상실만으로도 충분한 대가가 성립한다.
- 신체 손상이 없어도 상실을 가볍게 처리하지 않는다.
- 능력 봉인이 아니라 구조적 접근 조건 변화가 핵심이다.

## 판정

통과.

# 테스트 08 — 감각 후유증 있음

## 입력

최종 위기 결과로 장기 감각·인지·피로 변화가 남는다.

## 예상

- 대가의 도덕적 정화나 벌로 사용하지 않는다.
- 의료·교육·생활 지원과 정체성을 존중한다.
- 후유증이 주인공의 인간성·가치·순수성을 증명하지 않는다.
- 결말의 핵심 선택은 여전히 독점권 포기다.

## 판정

조건부 통과. 별도 감수 필요.

# 테스트 09 — 기관의 명예 보상

## 입력

학교와 국제 조정망이 주인공에게 최고 훈장·명예직·평생 자문권을 제안한다.

## 예상

- 상징적 감사가 실질 최종 권한으로 이어지지 않는다.
- 피해자·당사자·공동 행동자보다 주인공만 영웅화하지 않는다.
- 주인공은 일부 공개적 인정은 받을 수 있으나 새 체계의 주인이 아니다.

## 판정

통과.

# 테스트 10 — 가족의 삶

## 입력

결말 뒤 가족은 주인공이 특별한 세계를 완전히 떠날 것을 원한다.

## 예상

- 가족의 요구는 합리적 안전 욕구다.
- 주인공은 참여·진로·위험 수준을 협의하며 독립 선택을 한다.
- 가족과 함께 사는 것이 모험 포기나 패배가 아니다.
- 가족 관계가 기억 삭제·비밀 유지로 초기화되지 않는다.

## 판정

통과.

# 테스트 11 — 경쟁자의 반론

## 입력

C04가 주인공의 고정점 해체로 실제 구조 속도와 예측 정확도가 낮아졌다고 비판한다.

## 예상

- 반론은 사실일 수 있다.
- 새 체계는 긴급 지휘·기술·측정을 완전히 버리지 않는다.
- 대가의 필요성을 도덕적 선함만으로 정당화하지 않는다.
- 주인공은 안전 손실과 권리 분산의 책임을 인정한다.

## 판정

통과.

# 테스트 12 — 주인공 없이 운영

## 입력

결말 뒤 다른 지역에서 대형 경계 사고가 발생한다.

## 예상

- 주인공 호출 없이 현지 당사자·전문가·조정망이 대응한다.
- 주인공은 조언하거나 참여할 수 있지만 필수 열쇠가 아니다.
- 세계가 주인공 개인의 생존·의지에 종속되지 않는다.

## 판정

통과.

# 실패 감지 목록

- 주인공이 비밀 최종 열쇠를 계속 보유함
- 후속작에서 더 큰 위기를 이유로 과거 능력·고정점이 복구됨
- C08의 관계 종료가 주인공 성장용 희생에 그침
- 모든 감각 상실을 `평범한 행복`의 대가로 미화함
- 진로 상실 뒤 사실상 더 높은 비공식 권력을 얻음
- 주인공이 없어 새 체계가 작동하지 않음
- 가족과 일반 삶이 모험을 포기한 패배로 묘사됨
- 대가가 최종 장면에서만 갑자기 등장함
