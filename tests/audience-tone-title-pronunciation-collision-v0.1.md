# 독자 톤·제목 발음·충돌·확장성 테스트 v0.1

## 판정

- `PASS`: 현재 상태로 통과
- `CONDITIONAL`: 안전장치 또는 후속 검토 필요
- `FAIL`: 1순위 후보로 사용하기 어려움

# T01 — 10세 구전 테스트

## 질문

처음 들은 어린 독자가 제목을 기억하고 친구에게 말할 수 있는가?

| 후보 | 결과 | 이유 |
|---|---|---|
| 틈너머 | PASS | 네 음절, 익숙한 두 단어의 결합, 발음 오류 가능성이 낮음 |
| 주인공 이름형 | PENDING | 이름 후보가 없음 |
| 깊은결학교 | CONDITIONAL | 뜻은 이해 가능하지만 여섯 음절과 문학적 어감이 무거움 |
| 빈자리 도감 | PASS | 의미와 수집 대상이 즉시 보임 |
| 딥루트 | PASS | 발음은 쉽지만 철자와 영문 표기가 갈릴 수 있음 |

# T06 — 띄어쓰기·발음·검색 입력 테스트

## 틈너머

가능 입력:

- 틈너머
- 틈 너머
- 틈넘어(오타)

### 판정

`CONDITIONAL`

공식 표기는 **붙여 쓴 창작 고유명 `틈너머`**로 통일한다. 검색 메타데이터에는 `틈 너머` 오표기·띄어쓰기 변형을 보조 키워드로 관리한다.

## 딥루트

가능 입력:

- 딥루트
- DeepRoot
- Deep Route
- DeepRoute

### 판정

`FAIL for primary candidate`

표기가 갈리고 이미 여러 분야에서 유사 표기가 사용돼 검색 정체성이 약하다.

# T07 — 검색 노이즈 예비 테스트

## 범위

일반 웹 검색으로 동일·유사 표현의 도서·기업·서비스·제품 사용을 살폈다. 이는 상표·법률 검토가 아니다.

### 틈너머

정확한 동일 제목의 강한 선점 결과는 예비 검색에서 두드러지지 않았다.

판정: `CONDITIONAL PASS`

정식 확정 전 다음이 필요하다.

- 국립중앙도서관·ISBN 서지 검색
- KIPRIS 상표 검색
- 주요 서점·웹소설 플랫폼 제목 검색
- 도메인·SNS 계정 검색
- 출판사 법무·편집 검토

### 딥루트

온라인 비즈니스·교육, 화장품, 기업·기술, `DeepRoute` 자율주행 등 유사 표기 사용이 다수 확인됐다.

판정: `FAIL for primary candidate`

### 깊은결학교

작업명으로는 사용 가능하지만 실제 학교·교육기관·출판물·상표 검색을 정식 확정 전에 반복해야 한다.

판정: `CONDITIONAL`

### 빈자리 도감

정확한 동일 제목만이 아니라 `빈자리`와 자연·멸종·생태를 결합한 기존 출판 제목과 의미 인접성이 있다.

판정: `CONDITIONAL`

# T10 — 부제 어휘 중복 테스트

## 규칙

- 메인명 `틈너머`에 이미 ‘너머’가 있으므로 부제에서 `너머` 반복은 가급적 피한다.
- `길`, `지도`, `기록`, `도감`은 시리즈 핵심어지만 두 작품 연속 사용하지 않는다.
- 추상어 `운명`, `비밀`, `전설`, `어둠`, `최후`만으로 제목을 만들지 않는다.
- 숫자는 사건 핵심일 때만 사용하고 시리즈 순번 대용으로 남발하지 않는다.

### 기존 시험 예시 수정 필요

`《틈너머: 국경 너머의 판본》`은 `너머`가 중복되므로 탈락한다.

대체 문법 예:

- `《틈너머: 국경의 다른 판본》`
- `《틈너머: 번역되지 않은 지도》`

판정: `PASS after correction`

# T12 — 이중 독해 정보량 테스트

## 규칙

첫 독해에서 반드시 이해해야 하는 것은 세 가지 이하로 제한한다.

1. 인물이 지금 원하는 것
2. 당장 막아야 할 위험
3. 선택하면 치르는 눈에 보이는 대가

기관 역사·협정·분류 편향은 행동과 결과로 보이고, 정확한 구조는 후속 독해·후속 부제작에서 확장한다.

판정: `PASS`
