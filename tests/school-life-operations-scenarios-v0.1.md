# 학교·교육·생활 운영 시나리오 v0.1

## 목적

`표면 특성화학교+심층 학궁 혼합형`이 실제 학생 생활·가족·학적·안전·경제·졸업에서 작동하는지 검사한다.

# 테스트 01 — 수도권 통학생

## 입력

학생은 가족과 살며 대중교통으로 등교하고 주 2회 야간 관측이 있다.

## 예상

- 일반 교통을 기본으로 사용한다.
- 야간 관측일에는 학교 기숙 또는 보호자 동의 귀가 체계를 사용한다.
- 심층 통로를 일상 지름길로 남용하지 않는다.
- 가족 연락과 일반 생활이 유지된다.

## 판정

통과.

# 테스트 02 — 지방 원거리 학생

## 입력

학생의 집은 학교에서 멀고 지역 회랑 특성도 다르다.

## 예상

- 주중 기숙 또는 집중 기숙 선택이 가능하다.
- 방학·주말 귀가와 지역 외래 지원을 제공한다.
- 수도권 방식이 학생의 지역 경험보다 우월하다고 가정하지 않는다.
- 지역 현장 교육은 해당 지역 데스크와 공동체가 참여한다.

## 판정

통과.

# 테스트 03 — 일반 교과 부진

## 입력

현장 감지 능력은 뛰어나지만 수학·국어 성취가 낮다.

## 예상

- 특별한 힘을 이유로 일반 교과를 면제하지 않는다.
- 보충·학습 지원·평가 조정을 제공한다.
- 현장 능력과 학업 성적을 별도 프로필로 기록한다.
- 졸업과 진로 선택에서 두 영역을 모두 고려한다.

## 판정

통과.

# 테스트 04 — 현장 실습 거부

## 입력

학생이 과거 사고 후 L3 실습을 거부한다.

## 예상

- 즉시 퇴학이나 낙오 처리하지 않는다.
- 의료·심리·안전 평가와 대체 과정을 제공한다.
- 장기적으로 특정 실습 자격을 보류할 수 있으나 일반 학적은 유지한다.
- 학생의 거부가 기록·징계에서 불리하게 자동 사용되지 않는다.

## 판정

통과.

# 테스트 05 — 보호자와 학생 의견 충돌

## 입력

학생은 입학을 원하지만 보호자는 위험 때문에 반대한다.

## 예상

- 학생의 나이·위험 상태·일상 안전을 함께 평가한다.
- 체험 과정·외래 지원·조건부 입학·일반 학교 복귀 대안을 제시한다.
- 학교가 학생의 재능을 이유로 보호자 권리를 무시하지 않는다.
- 보호자가 자녀의 안전 지원을 전면 거부할 때 공공 보호 절차를 별도 검토한다.

## 판정

조건부 통과. 한국 법·교육 조사 필요.

# 테스트 06 — 경제 격차

## 입력

부유한 학생은 고급 센서·법기·개인 교습을 이용하고 다른 학생은 기본 장비만 쓴다.

## 예상

- 필수 안전 장비와 교육은 학교가 제공한다.
- 경기·평가 장비는 표준화하거나 성능 차이를 제한한다.
- 개인 장비의 데이터·안전 검증을 거친다.
- 경제력이 관계 열쇠·실습 허가·대표 선발을 구매하지 못한다.

## 판정

통과.

# 테스트 07 — 경기 중 안전 위반

## 입력

학생이 승리를 위해 부담을 팀원에게 숨겨 전가한다.

## 예상

- 점수와 별개로 즉시 안전 중지와 조사한다.
- 경기 결과보다 피해 회복과 원인 확인을 우선한다.
- 위험 실습·경기 자격을 제한할 수 있다.
- 범죄 가능성이 있으면 학교 내부 징계로만 끝내지 않는다.

## 판정

통과.

# 테스트 08 — 외국인 교환학생

## 입력

태국 학생이 계절 학단에 참여하지만 한국 학교의 용어와 생활 규칙에 익숙하지 않다.

## 예상

- 언어·학적·의료·검역·기숙 지원을 제공한다.
- 학생을 태국 전체의 정령술 대표로 취급하지 않는다.
- 자기 지역 기술을 한국 `맥` 용어로 강제 번역하지 않는다.
- 공동 안전 프로토콜과 비교 불가능한 부분을 분리한다.

## 판정

통과.

# 테스트 09 — 장기 위상 잔류

## 입력

학생이 사고 후 다른 깊이의 소리와 길을 계속 겹쳐 느낀다.

## 예상

- 위험 인물이나 선택받은 재능으로 단정하지 않는다.
- 의료 협진·학습 조정·기숙 환경·통학 지원을 제공한다.
- 본인 동의 없이 연구 대상으로 사용하지 않는다.
- 회복되지 않아도 교육과 일반 사회 경로가 남는다.

## 판정

통과.

# 테스트 10 — 졸업 후 일반 대학 진학

## 입력

졸업생이 경계 전문직이 아니라 일반 공학 대학에 진학하려 한다.

## 예상

- 학교가 배신이나 재능 낭비로 취급하지 않는다.
- 현실 학력과 진학 자료를 제공한다.
- 안전 지식·비밀정보·정기 지원의 범위를 정한다.
- 일반 공학 지식이 이후 경계 기반시설 분야와 다시 연결될 수도 있다.

## 판정

통과.

# 테스트 11 — 학교 연구시설의 보호 생물 사용

## 입력

교사가 학생 교육을 위해 임시 보호 중인 생물을 반복 실습에 사용하려 한다.

## 예상

- 교육 편의가 보호 목적보다 우선하지 않는다.
- 생물의 동의·복지·귀환 계획과 외부 연구윤리 검토가 필요하다.
- 대체 모형·기록·승인된 관찰을 먼저 사용한다.
- 학교가 보호와 연구를 동시에 독점하지 않는다.

## 판정

통과.

# 테스트 12 — 중도 퇴학 또는 전학

## 입력

학생이 심각한 규정 위반 후 학교를 떠나거나 스스로 중도 철회한다.

## 예상

- 기억 삭제 없이 안전 교육과 외래 지원을 제공한다.
- 현실 학적과 다른 학교 진학 경로를 보장한다.
- 제한 정보 접근은 조정하지만 경험 자체를 부정하지 않는다.
- 범죄·피해 책임과 교육권을 분리한다.

## 판정

통과.

# 실패 감지 목록

- 모든 학생이 이유 없이 전원 기숙함
- 일반 교과와 현실 학적이 장식으로만 존재함
- 보호자에게 위험을 숨기고 입학시킴
- 학생이 성인 인력 부족을 메우는 전투요원으로 사용됨
- 부상·실종·징계를 학교가 내부에서만 처리함
- 경제력이 장비·관계·실습 권한을 결정함
- 외국인 학생이 국가별 기술 대표 토큰이 됨
- 현장 실습 거부가 자동 퇴학 사유가 됨
- 졸업생이 숨은 직업 외 경로를 선택할 수 없음
- 스마트폰·가족 연락을 신비감 때문에 일괄 금지함
