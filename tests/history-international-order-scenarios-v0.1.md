# 역사·국제 질서·협정 시나리오 v0.1

## 목적

`다중 협정망·후발 조정체형`이 국가·지역 공동체·지성종·생태 회랑·국제 학교 교류에서 실제로 작동하는지 검사한다.

# 테스트 01 — 오래된 협정과 현대 법 충돌

## 입력

지역 공동체의 오래된 비접근 협정 구역에 공공 기반시설이 필요하다.

## 예상

- 오래된 협정이 자동 절대권은 아니다.
- 공공 필요·대안 경로·지성종·생태·주민 피해를 함께 검토한다.
- 긴급 조치와 영구 변경을 분리한다.
- 과거 협정의 대표성과 강제성도 재검토한다.

## 판정

통과.

# 테스트 02 — 국가의 일방 회랑 폐쇄

## 입력

국가가 보안과 검역을 이유로 국경 내 이동 회랑을 영구 폐쇄한다.

## 예상

- 긴급 임시 폐쇄는 가능하다.
- 회랑 협의층과 다른 국가·공동체·이동종에 영향 평가를 통지한다.
- 기간·재검토·대체 이동·생태 복구가 필요하다.
- 영토 주권만으로 국제 회랑의 모든 권리를 소멸시키지 못한다.

## 판정

통과.

# 테스트 03 — 국제 조정체 명령 거부

## 입력

국가가 국제 조정체의 조사·중재 권고를 거부한다.

## 예상

- 조정체는 세계정부처럼 군사 강제하지 못한다.
- 정보 공유 제한, 공동 구조 지원 중단, 협정 분쟁 절차, 다른 당사자 보호 조치를 사용할 수 있다.
- 국가 법과 국제 협정의 실제 구속 범위는 사안별로 다르다.
- 거부 자체가 자동 악행은 아니며 보안·대표성·과거 불신 이유가 있을 수 있다.

## 판정

통과.

# 테스트 04 — 국제 학생 사고

## 입력

한국 학생이 해외 학단에서 지역 관계 규칙을 위반해 지성종과 충돌한다.

## 예상

- 학생 개인·한국 학교·현지 학교·통역·교육 표준의 책임을 나눈다.
- 한국식 규칙을 현지에 강요하지 않는다.
- 학생 보호와 현지 당사자 피해 회복을 함께 처리한다.
- 사고를 국가 간 자존심 대결로만 축소하지 않는다.

## 판정

통과.

# 테스트 05 — 밀수된 생체 기술

## 입력

A지역 공동체의 조직과 기록을 이용한 장비가 B국가 기업에서 판매된다.

## 예상

- 원재료 채취·동의·기록권·특허·이익·검역·귀환을 추적한다.
- 국제 조정체는 정보·수사·당사자 연결을 지원한다.
- 국가 법원의 재산·범죄 절차와 공동체 권리를 병행한다.
- 장비 몰수만으로 피해가 끝나지 않고 데이터 삭제·보상·복구가 남는다.

## 판정

통과.

# 테스트 06 — 회랑 붕괴 피난민

## 입력

심층 공동체가 거점 붕괴로 다른 국가 회랑에 장기 체류한다.

## 예상

- 검역·안전·현지 생태 수용력을 평가한다.
- 단순 외래종 또는 불법 입국자로만 분류하지 않는다.
- 임시 보호·자치·교육·귀환·정착 대안을 협의한다.
- 현지 공동체와 주민 피해·불안을 무시하지 않는다.

## 판정

통과.

# 테스트 07 — 상류 시설의 하류 부담

## 입력

상류 국가의 대형 진·시설이 자국 위험을 낮추지만 하류에 위상 부채를 보낸다.

## 예상

- 공통 측정과 독립 감정을 시행한다.
- 시설 중지·개선·부담 분담·피해 보상을 협의한다.
- 상류 국가의 안전 필요와 하류 피해를 동시에 인정한다.
- 고의 은폐가 있으면 국제 수사·제재 후보가 된다.

## 판정

통과.

# 테스트 08 — 오래된 불공정 협정

## 입력

지성종 공동체가 수백 년간 인간 도시의 경계를 안정시키는 대신 이동과 기록 권리를 포기한 협정의 폐기를 요구한다.

## 예상

- 오래된 합의라는 이유로 유지하지 않는다.
- 체결 당시 대표성·강제·대가·현재 피해를 재검토한다.
- 즉시 폐기로 도시 안전이 무너지면 임시 대체와 단계적 전환을 협의한다.
- 피해 보상과 과거 기록 공개가 필요할 수 있다.

## 판정

통과.

# 테스트 09 — 서양권과 공동 탐사

## 입력

서양권 기관이 범아시아 회랑의 센서 연구와 공동 탐사를 제안한다.

## 예상

- 아시아 조정망이 모든 비서양 지역을 대표하지 않는다.
- 기술·기록·생물·관계 정보의 접근과 이익을 협상한다.
- 존재론 차이를 하나의 마법 과학으로 통합하지 않는다.
- 지역 당사자와 국가가 참여한다.

## 판정

통과.

# 테스트 10 — 비밀 협정 공개 요구

## 입력

대형 노출 후 시민과 언론이 국제 비밀 협정과 과거 피해 기록 공개를 요구한다.

## 예상

- 모든 자료를 국가 안보로 영구 봉인하지 않는다.
- 현재 생물·미성년자·고위험 경로 보호와 과거 책임 공개를 분리한다.
- 단계적 공개·독립 조사·피해자 열람·기록 정정을 검토한다.
- 공개 여부가 국제 조정망의 정당성과 존속 문제로 이어진다.

## 판정

통과.

# 실패 감지 목록

- 아시아 전체가 하나의 고대 문명에서 갈라졌다고 확정함
- 국제 조정체가 국가·공동체 위에 절대 명령권을 가짐
- 오래된 협정이 무조건 지혜롭고 정당함
- 현대 국가가 무조건 탐욕스럽고 전승 공동체가 무조건 선함
- 실제 전쟁·식민지·재난의 진짜 원인을 숨은 세계로 대체함
- 한국 학교가 국제 본부·최강·원조가 됨
- 국경과 법을 무의미한 인간 착각으로만 취급함
- 국제 분쟁이 문화별 능력 대결로 해결됨
- 회랑 붕괴 피난민을 외래종 문제로만 다룸
- 비밀 협정 공개와 과거 보상이 결말까지 아무 영향도 주지 않음
