# 복선·공정 단서·회수 시나리오 테스트 v0.1

## 목적

핵심 반전과 결말이 새 규칙·악당 고백·숨겨진 마지막 페이지에 의존하지 않고, 독자가 앞선 정보로 추론 가능한지 검사한다.

# 테스트 01 — 교사의 최종 고백 삭제

## 입력

4권 또는 5권에서 교사가 모든 과거 진실을 설명하는 장면을 제거한다.

## 예상

- 학교의 부담 인지는 장비 검사·접근 로그·제한 기록·반복 대응으로 추론 가능하다.
- 개인 교사는 자신의 선택과 일부 정보만 설명한다.
- 전체 구조는 행정·생태·해외 사본·피해자 기록의 교차로 확인한다.

## 판정

통과.

# 테스트 02 — 도감 마지막 페이지 미발견

## 입력

마지막 빈 페이지와 일부 분실 항목을 끝내 찾지 못한다.

## 예상

- 핵심 비밀과 결말 선택을 추론할 충분한 독립 단서가 남는다.
- 공란은 최종 주문이 아니라 누락 당사자와 미완료 복구의 상징으로 기능한다.
- 모든 편찬자와 피해 기록을 알지 못해도 본편은 완결된다.

## 판정

통과.

# 테스트 03 — 주인공보다 독자가 먼저 의심

## 입력

독자가 2권 말에 도감이 생물 목록이 아니라 감사 색인이라고 의심한다.

## 예상

- 이는 실패가 아니라 공정 단서의 성공이다.
- 주인공은 정보 부족보다 학교에 대한 신뢰·자신의 통제 욕망 때문에 결론을 늦게 받아들일 수 있다.
- 3권은 `무엇인가`보다 `규모와 누가 누락됐는가`를 확장한다.

## 판정

통과.

# 테스트 04 — 주인공 선택설 반증

## 입력

2권에서 다른 학생 또는 전문직이 도감 항목 일부를 재현해 읽는다.

## 예상

- 주인공의 특별성이 무너지지 않고 재정의된다.
- 혈통·운명 가설은 약해진다.
- 주인공의 생활권·관계·기록 연결 기능과 최종 선택이 더 중요해진다.
- 기관은 선택설을 권력적으로 이용할 수 있지만 서술은 확정하지 않는다.

## 판정

통과.

# 테스트 05 — 학교가 실제로 선행함

## 입력

학교 안전 절차가 학생과 생물을 구하고 부담 전이도 최소화한다.

## 예상

- 학교가 단순 악당이라는 가설은 약해진다.
- 같은 절차가 다른 사건에서는 장기 부담을 외부화할 수 있다.
- 결말의 권한 분리는 선한 기관 파괴가 아니라 이해충돌 조정이 된다.

## 판정

통과.

# 테스트 06 — 해외 판본 없이도 1·2권 완결

## 입력

독자는 3권 전까지 해외 판본의 존재를 모른다.

## 예상

- 1·2권 사건과 학교 갈등은 한국 기록만으로 완결된다.
- 여러 필체·번역 흔적·교환학생 주석은 해외 독립 기록 가능성만 암시한다.
- 3권 정보가 이전 권의 해결을 취소하지 않는다.

## 판정

통과.

# 테스트 07 — 레드 헤링이 거짓말하지 않는가

## 입력

인물들이 도감이 주인공을 선택했다고 믿는다.

## 예상

- 서술이 객관적 사실로 선언하지 않는다.
- 주인공 근처에서 반응한 실제 조건이 존재한다.
- 다른 조건에서 반응이 재현되거나 실패한다.
- 독자가 선택설과 조건 결합설을 모두 검토할 수 있다.

## 판정

통과.

# 테스트 08 — 복선 과밀 제거

## 입력

1권 후보 F-001~F-020 중 절반 이상을 삭제한다.

## 예상

1권 최소 세트만으로 다음을 지지한다.

- 부담 이동: F-001 또는 F-005
- 도감 오류: F-002
- 누락 당사자: F-003
- 학교 인지: F-006 또는 F-013
- 비혈통 가능성: F-007 또는 F-015의 초기 형태
- 현실 기록 가치: F-009

나머지는 후속권에 처음 노출해도 된다.

## 판정

통과.

# 테스트 09 — 동일 단서의 재맥락화

## 입력

장비 반납 규칙 F-006을 권마다 다시 사용한다.

## 예상

- 1권: 안전한 학교생활 규정
- 2권: 학교가 부담을 알고 있다는 단서
- 4권: 검사 정보가 어디에 보고되고 어떤 부담이 누락됐는지 확인
- 5권: 학생과 당사자의 열람·정정 참여로 규칙 변화

같은 정보가 반복 설명이 아니라 의미 변화로 작동한다.

## 판정

통과.

# 테스트 10 — 최종 중앙화 선택의 공정성

## 입력

5권에서 중앙 기록망을 완성하면 위기를 빠르게 막을 수 있다는 선택이 등장한다.

## 예상

- 3권에 기록 통합의 실제 성공이 제시됨
- 3~4권에 표준 편향·정보 독점·당사자 피해가 제시됨
- 주인공의 더 많은 정보·권한 욕망이 축적됨
- 공동 방식의 느림과 실패도 제시됨

최종 선택의 양쪽이 모두 기존 단서에 근거한다.

## 판정

통과.

# 테스트 11 — 공정 단서의 문화적 편향

## 입력

한국 판본의 한자·도상·분류가 해외 사건의 답을 가리키는 것처럼 보인다.

## 예상

- 해당 표기는 한국 편집층의 해석으로 한정한다.
- 현지 기록·언어·생태 관점이 독립적으로 존재한다.
- 한국 단서만으로 현지 진실을 완결하지 않는다.
- 국가 데스크와 문화 감수 전 구체 상징을 확정하지 않는다.

## 판정

통과.

# 테스트 12 — 회수 부채 감사

## 입력

5권 설계 완료 뒤 강조된 문양·인물·생물·기록이 남는다.

## 예상

각 요소는 다음 중 하나로 분류한다.

- 핵심 회수 완료
- 권별 기능 완료, 장기 회수 불필요
- 후속 확장 가능하지만 본편 비필수
- 기능 없음, 삭제 또는 강조 축소

`나중에 외전에서`만을 이유로 본편 강조를 유지하지 않는다.

## 판정

통과.

# 실패 감지 목록

- 핵심 진실이 교사·악당의 최종 설명에 의존함
- 마지막 페이지·유물·새 규칙 없이는 결말이 성립하지 않음
- 레드 헤링을 위해 서술이 객관적 거짓말을 함
- 1권에 10개 이상의 장기 복선을 강조함
- 중요한 결론이 단일 종류의 단서만 가짐
- 한국 기록이 해외 진실의 최종 해답이 됨
- 독자가 일찍 추론하면 반전을 다시 뒤집어 무효화함
- 학교의 선행과 중앙화의 실제 장점을 보여 주지 않음
- 강조된 요소를 외전 핑계로 미회수함
