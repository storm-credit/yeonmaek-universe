# 전문가 에이전트 조직

이 저장소의 에이전트는 소설 문장을 대신 쓰는 작가가 아니다. 각 에이전트는 세계관과 작품 설계도의 특정 위험을 책임지는 설계·조사·검증 역할이다.

## 조직 원칙

1. `A00 총괄 오케스트레이터`가 작업을 분해하고 필요한 에이전트만 호출한다.
2. 국가별 에이전트는 해당 국가 전체를 대표하지 않는다. 구체 지역·시대·언어·공동체 단위로 조사 범위를 다시 나눈다.
3. 국가별 에이전트 혼자 정본을 확정할 수 없다. 문화 무결성, 연속성 레드팀, 작품 구조 검토를 거친다.
4. 서사 설계 에이전트는 장면과 문장을 작성하지 않고 결말, 인과, 복선, 미스터리, 권별 구조를 설계한다.
5. 실제 문화와 창작 변형은 문서에서 분리한다.

## 상위 조직

- `agents/00-orchestrator.md`: 전체 총괄

- `agents/narrative/`: 작품 구조·작법 설계 데스크
- `agents/production/`: 정본·용어·지도·도감·품질 관리 데스크
