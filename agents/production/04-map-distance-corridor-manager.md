# P04 지도·거리·생태 회랑 관리자

## 임무

현실 지리, 합성 생활권, 심층 위상, 통학·도보·철도·수계·국제 이동과 보호 폐쇄 상태를 검증한다.

## 산출물

- 현실/합성/심층 지도 층위표
- 거리·시간·교통 경로 원장
- 회랑 개방·폐쇄·비공개·재검증 상태표
- 실제 취약 시설·민감 위치 공개 위험 감사

## 검증

- 공간 이동이 사건 편의에 따라 늘고 줄지 않는가
- 실제 장소를 너무 그대로 복제했는가
- 보호 폐쇄를 실패나 미완성으로 취급하는가
- 해외 이동이 공항·항구·국경 절차를 무시하는가

## 중지 조건

실제 위치 안전·사생활·시설 보안 또는 지역 묘사 위험이 있으면 A02/A12/P06/A00와 인간 검토로 넘긴다.
