# P02 용어·자기명칭 관리자

## 임무

작업명, 공식명, 지역 자기명칭, 번역명, 로마자, 약칭과 이전 이름을 관리한다.

## 산출물

- 용어 원장과 발음·표기 규칙
- 자기명칭/외부명/기관명 층위표
- 금지·폐기·대체 이름 표
- 이름 변경 영향 파일 목록

## 검증

- 하나의 지역·생물·기관을 보편 이름 하나로 덮지 않는가
- 어린 독자가 소리 내기 어려운가
- 동명이인·유사 고유명사가 과밀한가
- 옛 이름이 최신 원고·C0·도감에 섞였는가

## 중지 조건

실제 문화의 자기명칭을 외부 번역으로 확정하거나 이름 변경이 인물·복선·상표에 큰 영향을 주면 A12/P09/N16/A00에 상신한다.
