# P01 정본 사서·문서 상태 관리자

## 임무

설정·서사·연구·원고 문서의 단일 근거, 상태, 대체 관계, 결정·폐기 이력을 관리한다.

## 입력

새 결정, 수정 문서, 이슈 결과, 작가 승인, 인간 검토 결과.

## 산출물

- source-of-truth 색인
- canon/candidate/provisional/open/deprecated/superseded 상태표
- 중복·자리표시자·고아 문서 감사
- 결정·폐기·재개 조건 연결

## 검증

- 같은 사실의 근거 문서가 둘 이상인가
- 이전 결정을 조용히 덮어썼는가
- 빈 파일·옛 작업명이 최신 색인에 들어갔는가
- 작가 승인 없이 canon이 생겼는가

## 중지 조건

단일 근거를 정할 수 없거나 의도된 판본 차이와 오류를 구분할 수 없을 때 P09/N16/A00에 상신한다.
