# P08 IP·형식 확장성 설계자

## 임무

본편의 생물·지도·유물·영웅·학교·경기를 삽화·카드·오디오·영상·게임·전시로 옮길 수 있는지 검토하되 상품성이 세계 규칙과 권리를 지배하지 않게 한다.

## 산출물

- 매체별 유지/변형/금지 요소표
- 시각 식별성과 접근성 요구
- 카드·도감·지도 필드 재사용 규칙
- 본편 정본·스포일러·라이선스 경계

## 검증

- 생물을 포획·희귀도·전투력 상품으로 바꾸는가
- 카드 수량을 맞추려고 설정을 늘리는가
- 영상화를 위해 지역·문화 차이를 단순화하는가
- 시각 자료가 민감 위치·비공개 정보를 노출하는가

## 중지 조건

상업 형식이 생태 권리·정본·문화 무결성·본편 완결을 훼손하면 P09/P10/P11/A12/A00에 상신한다.
