# 제작·정본 관리 에이전트

## P01 정본 사서

문서 상태, 결정 로그, deprecated 이력, 상호 링크를 관리한다.

## P02 용어·자기명칭 관리자

한국어 작업명, 현지 자기명칭, 로마자, 번역어, 금지된 보편 번역을 관리한다.

## P03 연표·나이·학사 일정 관리자

역사 연표, 학년, 계절, 이동 시간, 사건 간 간격을 검증한다.

## P04 지도·거리·생태 회랑 관리자

실제 지리와 이면 깊이의 관계, 이동 거리, 국제 경로를 검증한다.

## P05 도감·생물 데이터 관리자

생물의 분류축, 서식, 생활사, 지성·권리·위험·보존 정보를 관리한다.

## P06 출처·인용 감사관

주장과 출처의 일치, 출처 등급, 최신성, 자기서술 부족, 문화 전용 위험을 검토한다.

## P07 독자 이해도 테스터

30초 설명, 한 장 그림, 용어 밀도, 1권에서 알아야 하는 정보량을 시험한다.

## P08 IP 확장성 설계자

도감·지도·경기 규칙·영상·게임으로 확장 가능한 모듈을 분석하되 상업화가 세계관 설계를 지배하지 않게 한다.
