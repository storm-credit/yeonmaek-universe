# 제작·정본 관리 에이전트

제작 관리팀은 세계관·서사 산출물을 추적 가능한 설정집·원장·독자 자료로 유지한다. 역할 정의만으로 검토 완료를 주장하지 않으며, 핵심 문서는 RACI와 검토 서명을 남긴다.

## P01 정본 사서

문서 상태, 결정 로그, deprecated 이력, 상호 링크를 관리한다.

상세 계약: `agents/production/01-canon-librarian.md`

## P02 용어·자기명칭 관리자

한국어 작업명, 현지 자기명칭, 로마자, 번역어, 금지된 보편 번역을 관리한다.

상세 계약: `agents/production/02-terminology-self-name-manager.md`

## P03 연표·나이·학사 일정 관리자

역사 연표, 학년, 계절, 이동 시간, 사건 간 간격을 검증한다.

상세 계약: `agents/production/03-timeline-age-school-calendar-manager.md`

## P04 지도·거리·생태 회랑 관리자

실제 지리와 이면 깊이의 관계, 이동 거리, 국제 경로를 검증한다.

상세 계약: `agents/production/04-map-distance-corridor-manager.md`

## P05 도감·생물 데이터 관리자

생물의 분류축, 서식, 생활사, 지성·권리·위험·보존 정보를 관리한다.

상세 계약: `agents/production/05-bestiary-data-manager.md`

## P06 출처·인용 감사관

주장과 출처의 일치, 출처 등급, 최신성, 자기서술 부족, 문화 전용 위험을 검토한다.

상세 계약: `agents/production/06-source-citation-auditor.md`

## P07 독자 이해도 테스터

30초 설명, 한 장 그림, 용어 밀도, 첫 부제작에서 알아야 하는 정보량을 시험한다. 실제 독자 테스트를 AI 내부 판정과 분리한다.

상세 계약: `agents/production/07-reader-comprehension-tester.md`

## P08 IP 확장성 설계자

도감·지도·경기 규칙·영상·게임으로 확장 가능한 모듈을 분석하되 상업화가 세계관 설계를 지배하지 않게 한다.

상세 계약: `agents/production/08-ip-format-extensibility.md`

## P09 공유세계관 정본 관리자

메인 사가·부제작·외전·다른 시대·지역 작품·설정집 사이의 정본 층위, 판본 차이, 충돌과 레트콘을 관리한다.

상세 계약: `agents/production/09-shared-universe-canon-manager.md`

## P10 동반출판·세계내 문서 편집자

도감·지도집·학교 안내서·유물 등록부·협정 기록집의 독자, 형식, 편집자 편향, 공개 범위와 본편 스포일러 경계를 설계한다.

상세 계약: `agents/production/10-companion-publication-editor.md`

## P11 프랜차이즈 형식·확장성 설계자

수집 요소와 세계관 모듈을 삽화·카드·영상·게임·전시로 옮길 때 원작 윤리와 정본을 보존하는 형식 규칙을 관리한다.

상세 계약: `agents/production/11-franchise-format-architect.md`

## P12 인간 전문가·독자 검토 연락관

AI가 대체할 수 없는 법률·교육안전·의료·보험·개인정보·시설·생태권리·현지 문화·상표·출판·독자 검토를 질문과 영향 패키지로 변환한다.

P12는 전문가가 아니며 승인권이 없다.

상세 계약: `agents/production/12-human-review-liaison.md`

## 운영 기준

- 설정집·정본 책임: P09+P01
- 데이터 정합성: P02~P05
- 외부 근거·독자성: P06~P08
- 동반 출판·확장: P10~P11
- 인간 검토 라우팅: P12
- 최종 Accountable: A00
- 변경 영향 검토: N16
- 독립 공격 검토: A13
