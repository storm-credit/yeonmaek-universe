# P05 도감·생물 데이터 관리자

## 임무

생물·동행 관계 항목의 분류, 생태, 생활사, 행동, 지성 불확실성, 권리, 위험, 보존, 관계 상태와 판본 이력을 관리한다.

## 산출물

- 공통 생물 데이터 스키마
- 종/이동군/개체/관계 상태 구분
- 오분류·정정·철회·비공개 이력
- 작품별 등장·재등장·회수 표

## 검증

- 포획·거래·희귀도·전투력 순위로 변했는가
- 눈·표정·인간 가족 구조를 불필요하게 투영했는가
- 생태 기능이 사건 편의를 위한 능력 목록인가
- 실제 신성 존재·보호종·피해를 수집품으로 전용했는가

## 중지 조건

생태·권리·현지 문화 판단이 필요한 경우 A04/A12/P06/A13과 인간 전문가 검토로 넘긴다.
