# 국가·지역별 전문가 데스크

국가명은 조사 라우팅을 위한 행정적 입구일 뿐, 하나의 균질한 문화 단위라는 뜻이 아니다. 모든 데스크는 첫 작업에서 내부 권역을 다시 나눈다.

## 우선권

- 1단계: 한국, 중국, 일본, 몽골, 태국, 베트남
- 2단계: 라오스, 캄보디아, 미얀마, 말레이시아, 인도네시아, 필리핀, 싱가포르
- 3단계: 브루나이, 동티모르, 대만, 북한·접경, 중앙아시아 5개국, 남아시아·히말라야
- 서양권은 아시아 세계와의 접촉 설계가 필요할 때 별도 호출

각 파일은 담당 범위, 필요한 이유, 핵심 질문, 금지, 산출물, 협업 대상을 명시한다.
