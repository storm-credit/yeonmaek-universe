# 국가·지역 전문가 데스크 준비도와 라우팅

## 목적

국가 파일이 존재한다는 이유만으로 AI가 해당 문화의 전문가인 것처럼 설정을 생성하지 못하게 한다.

국가명은 조사 요청을 보내는 **라우팅 키**일 뿐 문화·마법·민족의 단일 단위가 아니다. 모든 데스크는 국가 내부 지역·언어·역사·현대 생활·접경 교류로 다시 분해한다.

# 준비도 상태

## `pilot-active`

공식·학술·지역 자료를 사용한 파일럿 조사 문서가 있으며, 구체 지역 단위의 비교 설계를 시작할 수 있다.

허용:

- 연구 질문과 지역 4안
- 출처 카드와 문화 금지선
- 현실 지리·도시·기반시설 비교
- 세계관 공통 규칙과의 호환성 시험

금지:

- 국가 전체의 대표 술법·학교·종족 확정
- 현존 종교·의례의 직접 판타지 전용
- 현지 감수 없이 `canon` 승격

## `structured-routing`

국가 내부 분해·위험·금지사항·필요 조사 항목이 정의되어 있으나, 작품 설정에 사용할 충분한 지역 자료가 없다.

허용:

- 조사 범위 선정
- 지역 파일럿 후보 비교
- 출처 수집 계획
- 다른 권역과의 접점 질문

금지:

- 구체 학교·술법·생물·기관 생성
- 해당 국가 대표 캐릭터·문화 속성 생성
- 국가 전체를 하나의 존재론으로 설명

## `holding`

파일은 존재하지만 작업 중 누락을 막기 위한 보류 표식이다. 구체 설정을 생성할 준비가 되어 있지 않다.

허용:

- 필요한 전문가·출처·민감도 목록 작성
- 등장 필요성 평가
- 연구 이슈 생성

금지:

- 문화·역사·종교 기반 창작 설정
- 학교·문파·생물·술법·인물 배경 생성
- 다른 국가 자료로 빈칸 추정

## `contact-only`

본편 중심 권역이 아니라 교류·비교·국제 제도 접점을 연구하는 데스크다. 해당 지역 전체를 대표하거나 상세 설정을 생성하지 않는다.

### 러시아 극동·시베리아 접경

- 극동 도시·시베리아·북극·원주민 공동체·중앙정부 관계에 대한 연구가 부족하다.
- 원주민 전승과 샤머니즘을 생물·주술 소재로 직접 만들지 않는다.
- 현재 국제정세와 접근 가능한 자료의 한계를 명시한다.

## 접촉 전용

### 서양·서아시아 접촉 데스크

현재 파일은 다음 기능만 담당한다.

- 국제 조정망과의 제도 비교
- 교역·이주·항로·학술·산업·식민 접촉 질문
- 서양 마법을 하나의 체계로 단순화하지 않는 경고
- 향후 지역별 데스크가 필요한 범위 식별

유럽·서아시아·북아프리카·아메리카를 하나의 `서양` 설정으로 생성하지 않는다.

# 특수 범위 처리

## 중국 내부 민감 지역

티베트·신장·내몽골·홍콩·마카오 등은 `중국의 특수 마법 지역`처럼 소비하지 않는다. 언어·민족·종교·정치·자기명칭을 별도 조사하고, 자료와 감수가 부족하면 설정을 중지한다.

## 한반도 북부와 접경

북한 주민·탈북민·접경 공동체·군사 지역을 신비한 봉인 지역이나 잊힌 전승 보관소로 사용하지 않는다. 공개자료의 한계와 현재 인권·안보 문제를 숨은 세계 모험으로 덮지 않는다.

## 미얀마·아프가니스탄·분쟁 지역

현재 분쟁과 피해를 판타지 세력전으로 변환하지 않는다. 안전한 자기서술·학술 자료·감수 없이 현대 배경 설정을 만들지 않는다.

# 모든 국가 데스크의 필수 호출 패널

구체 국가·지역 설정은 최소 다음이 함께 검토한다.

1. 해당 국가 데스크
2. 해당 권역 리드 A07~A11
3. A12 문화 무결성
4. P06 출처 감사
5. A13 연속성·레드팀
6. 설정 유형에 따른 세계·시스템 전문가
7. 가능한 경우 현지 인간 감수자

AI 국가 데스크는 현지 감수자를 대체하지 않는다.

# 국가 데스크의 중지권

다음 중 하나면 설정 생성을 중지하고 조사 이슈로 전환한다.

- 국가 내부 지역·언어·집단을 구분할 자료가 없음
- 공식 자료만 있고 공동체 자기서술이 없음
- 현존 종교·신성 의례·소수집단 전승을 직접 사용해야 아이디어가 성립함
- 현재 전쟁·분쟁·인권 피해를 판타지화할 위험이 큼
- 해당 국가를 대표할 술법·성격·생물 하나를 요구함
- 관광·신화·애니메이션 자료에만 의존함
- 번역어와 자기명칭을 확인할 수 없음
- 현지 감수가 필요한 고위험 항목인데 감수 경로가 없음

# 등장 순서 원칙

- 세계 지도에는 존재해도 모든 데스크를 지금 상세화하지 않는다.
- 본편 5권의 구체 필요가 생긴 지역부터 조사한다.
- 3권의 본격 해외 지역은 한 곳으로 제한한다.
- 등장하지 않는 국가의 학교·술법·생물·역사를 대량 생성하지 않는다.
- 후속 확장 후보는 `holding` 상태로 보존한다.

# 다음 조치

1. 3권 해외 지역 후보 4안을 결말·맥거핀·문화 조사 가능성으로 비교
2. 선정 지역만 `pilot-active`로 승격하는 조사 이슈 생성
3. 중앙아시아·남아시아 보류 데스크는 실제 등장 필요 전까지 상세 설정 금지
4. 국가별 데스크 표준 템플릿을 사용해 누락 필드를 검사
