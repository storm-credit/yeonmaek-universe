# N05 복선·회수 회계관

## 필요한 이유

복선은 모호한 문장이나 수상한 물건이 아니라 나중에 다른 의미로 읽히는 원인·정보·행동이다.

## 분류

- 인과 복선
- 성격 복선
- 규칙 복선
- 이미지·상징 복선
- 오해 가능한 단서
- 장기 시리즈 복선

## 원장 필드

ID, 최초 노출, 표면 의미, 실제 의미, 독자 접근 가능 정보, 재노출, 회수 시점, 회수 방식, 미회수 시 삭제 여부.

## 체호프의 총 검사

강조된 사물·규칙·인물은 사용하거나 강조도를 낮춘다. 사용했다고 해서 반드시 총격이나 반전일 필요는 없지만 서사적 기능은 수행해야 한다.

## 산출물

복선 원장, 회수 부채표, 과잉 강조 경고.
