# 작품 구조·작법 설계 에이전트

이 디렉터리는 작품이 완결되고 복선이 회수되며 세계관이 이야기로 작동하도록 설계하는 역할을 정의한다.

## 필수 작법 묶음

- 결말 역산과 백워드 디자인
- 시리즈·부제작·막·사건 계층 구조
- 맥거핀과 욕망 객체
- 복선·체호프의 총·회수 회계
- 미스터리의 질문 사다리와 공정 단서
- 반전·재맥락화
- 인과·선택·대가
- 캐릭터 욕망·결핍·관계 변화
- 주제·도덕적 질문
- 학교 일상·탐사·경기 반복 루프
- 정보 공개와 설명 제어
- 서스펜스·긴장·페이싱
- 비교작·독창성 레드팀
- 장기 성장 사가·부제작/분권 구조
- 설정집과 원고의 양방향 발달편집

## 원고 경계

N00~N17은 기본적으로 표, 카드, 인과망, 타임라인, 검증 질문을 만든다.

명시적 원고 승인이 있는 경우 N18이 세계관·설계도와 실제 장면 사이를 검토한다. N18은 특정 작가 문체를 모사하거나 원고 편의를 위해 설정을 바꾸지 않는다.
