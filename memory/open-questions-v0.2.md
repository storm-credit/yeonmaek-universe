# 열린 질문 원장 v0.2

## 사용 규칙

질문은 `resolved / partial / active / human-review / later`로 구분한다.

- `resolved`: 현재 candidate 기준선에서 답이 있음. canon 확정과는 다름.
- `partial`: 구조는 있으나 상세 사례·수치·항목이 부족함.
- `active`: 다음 자동 설계를 실제로 막음.
- `human-review`: 자동 설계는 가능하지만 canon 승격에 전문가 검토 필요.
- `later`: 현재 사건·사가 선택에 기여하지 않아 보류.

# 3. 활성 질문 — 자동 설계에서 답해야 함

1. 위상 상호작용의 실패를 독자가 한눈에 구분할 수 있는 5~7개 유형은 무엇인가?
2. 학생이 6년 동안 실제로 배우는 공통 기초 과목과 선택 전문 과정은 무엇인가?
3. 학교·센터·재단·외부기관이 함께 활동할 때 비용과 책임을 누가 어떤 비율·절차로 부담하는가?
4. 첫 작품의 여울띠 외에 장기 사가의 대표 얼굴이 될 생물·유물·영웅은 무엇인가?
5. 유물의 강함이 아니라 선택을 어렵게 만드는 공통 설계 필드는 무엇인가?
6. 학교 영웅 기록이 부제작 2에서 어떤 현재 갈등을 만든 뒤 후반에 어떻게 재평가되는가?
7. 부제작 3의 지역 판본은 중앙 지도와 정확히 무엇이 다른가?
8. 부제작 4의 기록 호환 실패는 현지 권리·검역·구조에 어떤 서로 다른 위험을 만드는가?
9. 부제작 5에서 공개와 보호가 동시에 옳고 동시에 해로운 구체 상황은 무엇인가?
10. 부제작 6에서 독점 통제가 분산 체계보다 실제로 더 많은 생명을 구하는 이유는 무엇인가?
11. 부제작 7에서 주인공이 권한을 포기한 뒤에도 책임을 회피하지 않는 역할은 무엇인가?
12. 첫 부제작 원고가 후속 설정을 불필요하게 선점하거나 막는 문장은 어디인가?

# 4. 작가 판단 필요

아래는 자동으로 candidate를 만들 수 있지만 최종 선택은 작가 의도에 크게 영향을 준다.

- 주인공의 성별·외형·구체 가족 구성
- 학교 생활에서 독자가 가장 사랑해야 할 핵심: 친구/수업/탐사/경기/생물 관계의 우선순위
- 장기 사가를 대표하는 수집 얼굴: 생물/유물/영웅/지도 중 무엇을 전면 브랜드로 둘지
- 부제작 2에서 학교 공동체의 즐거움과 보호·소유 갈등의 비중
- 최종 결말의 감정 잔향: 아쉬운 졸업/새로운 책임/관계 회복/의도적 거리 중 우선
- `겹길`, 학교·재단·도감·경기·생물 작업명의 최종 후보 선택

작가 질문은 C0 candidate가 충분히 작성된 뒤 4안과 영향 비교로 한 번에 제시한다.
