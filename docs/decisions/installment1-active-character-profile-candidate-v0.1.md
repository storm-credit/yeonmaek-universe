## 작업 이름 상태

모든 이름은 `working candidate`다. 최종 이름·성별·구체 가족 직업은 작가 승인과 소리내기·검색·기능 스왑 테스트 전 canon으로 올리지 않는다.

## 등장·조합 규칙

- 도입 전면: P1·P4·P5
- 학교 진입: P1·P2 또는 P3·P6
- 초기 오판: P1·P2
- 거부 패턴 확인: P1·P3·P7
- 구조·철수: P6+외부 전문팀
- 기록·참여 조건 결말: P1·P4·P5·P6, P7의 독립 결과

P1·P2·P3가 모든 단계에 함께 있지 않는다.

## 기능 가드레일

- P2의 절차는 실제로 생명을 지키는 옳은 선택도 만든다.
- P3는 생물 마음을 읽거나 독점 번역하지 않는다.
- P4는 증거 제공을 거부·제한할 독립 판단을 가진다.
- P5는 모험 반대자가 아니라 학적·의료·정보·귀가의 공동 결정자다.
- P6은 세계 비밀을 알지 못하고 실제 구조·의료·교통 지휘를 독점하지 않는다.
- P7은 주인공의 소유·팀원·마스코트가 아니다.

## 아직 확정하지 않는 것

- 주인공 성별과 외형
- 모든 이름의 최종 표기
- P5와 다른 보호자의 구체 직업·가족 구성
- 경제 수준·주거 형태의 세부
- 장애·질병·종교·출신 지역 등 정체성 세부
- 장기 이탈·전학·연애·죽음 경로
