# 시각 수집 언어 candidate 결정 v0.1

## 결정

전체 수집 인터페이스는 **현장기록·정정형**을 1순위 candidate로 둔다.

대상별 형태 문법은 분리한다.

- 생물: 반투명 겹막·간격·접힘·진동
- 회랑: 지층선·끊긴 경로·보호된 공백
- 유물·장비: 구조신호·모듈·사용 흔적
- 도감·지도책: 관찰 스케치·판본 탭·정정 이력

## 선택 이유

1. `완성품을 소유한다`가 아니라 `관찰과 정정의 과정이 쌓인다`는 작품 주제를 시각화한다.
2. 생물·유물·영웅·회랑을 한 가지 귀여운 화풍으로 평평하게 만들지 않는다.
3. 카드·단행본·지도책·모바일 화면으로 확장하기 쉽다.
4. 잘못된 기록과 보호 비공개 상태도 수집 보상으로 만들 수 있다.

## 고정 규칙

- 카드 번호는 희귀도나 전투력 순서가 아니다.
- 삭제·정정 전 기록을 완전히 지우지 않는다.
- 위치 비공개는 미완성 오류가 아니라 정당한 상태로 표시한다.
- 생물의 감정은 인간식 얼굴 표정으로 확정하지 않는다.
- 실제 문화 문양과 신성 상징을 장식 자산으로 사용하지 않는다.
- 흑백·색각·작은 화면 대체 규칙을 동시에 만든다.

## 대표 시안 패키지

인간 시각 전문가에게 다음 네 판을 요청한다.

1. 대표 생물 6종 흑백 실루엣
2. 유물 8종 손 크기 형태
3. 회랑 상태 6종 지도 기호
4. 도감 카드 단행본·모바일·흑백 버전

각 판은 하나의 완성 일러스트가 아니라 서로 다른 4개 방향을 비교해야 한다.
