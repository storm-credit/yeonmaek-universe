# 복선·미스터리·회수 원장 후보 결정 기록 v0.1

## 결정

5권 시리즈의 장기 미스터리를 다음 질문 사다리로 관리한다.

1. 왜 현실 기록과 현장 경험이 다른가
2. 왜 도감 항목이 삭제·재분류됐는가
3. 왜 해외 판본과 한국 판본이 충돌하는가
4. 기존 질서는 무엇을 유지하고 무엇을 숨겼는가
5. 주인공과 도감의 특별한 관계는 무엇인가
6. 중앙화와 독점 통제가 정말 세계를 구하는가

## 핵심 규칙

- 중요한 결론은 최소 세 종류의 독립 단서로 지지
- 교사·악당의 최종 고백에 의존하지 않음
- 5권에 새 세계 규칙·최종 페이지·예언 추가 금지
- 레드 헤링은 인물의 합리적 가설이며 서술이 거짓말하지 않음
- 1권 장기 복선은 5~7개로 축소
- 논리 회수와 관계·생활 회수를 별도 관리
- 강조된 요소는 기능을 수행하거나 강조를 낮춤
- 미회수 핵심을 외전으로 넘기지 않음

## 필수 회수

- 도감의 실제 기능
- 주인공 접근 원인
- 멸종 분류의 의미
- 학교·국제 조정망의 부담 인지 범위
- 누락 당사자와 서명의 구조
- 중앙화의 실제 장점과 위험
- 주인공의 독점권 포기

## 재검토 조건

- 1권에 장기 복선이 8개 이상 강조될 때
- 4권이 기록 설명과 복선 해설만으로 구성될 때
- 해외 문화 상징이 암호 퍼즐로 사용될 때
- 독자가 일찍 추론한 답을 억지 반전으로 무효화할 때
- 5권 해결에 새 규칙이 필요할 때
- 논리 회수 뒤 인물 관계 변화가 없을 때
