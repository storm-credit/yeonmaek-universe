# 첫 부제작 초고 준비도 결정 v0.1

## 결정

첫 부제작은 `first-draft-complete`로 판정한다.

- 최신 원고: 1장 v0.2, 2~15장 v0.1
- 15장 전체 작성 완료
- 현재 사건·감정·생활·관계·제도 결말 완료
- 장기 미확인: 삭제 항목 ID 1개
- 전체 회귀: PASS 26 / CONDITIONAL 4 / FAIL 0

## 아직 완료가 아닌 것

- 출판 원고
- 최종 제목·인물명·생물명
- 정확한 문자 수·원고지·판형
- 물리적 분권 확정
- 2차 문장 압축과 반복어 교정
- 외부 10~15세 독자 테스트

## 다음 게이트

1. 물리적 분권 구조
2. 조건부 4항목 수정
3. v0.2 통합 초고 감사

초고 작성으로 candidate 설정을 canon으로 승격하지 않는다.
