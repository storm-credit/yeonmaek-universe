# 부제작 5 원고 단계 승인 v0.1

## 승인 범위

작가의 `이어서진행` 지시를 부제작 5 원고 단계 승인으로 기록한다.

- 17장 초고
- 34개 장면 카드 원고화
- 111~139화 연재 원장
- F01~F22 단서·오독·회수 추적
- 하진·유나 공동 중심 구조
- 개인정보·미성년·교통·언론·플랫폼·보상 관련 인간 검토 패키지

## 제한

- 실제 법률·플랫폼 정책·언론 절차·교통 보상 절차는 인간 검토 전 working approximation이다.
- 온라인 사용자를 단일 악의적 군중으로 묘사하지 않는다.
- 하진이나 유나가 조사·교통 재개·보상·법적 판정을 대신하지 않는다.
- 공개의 효용과 비공개의 효용을 모두 실제로 보여 준다.
- 유나의 원본·재사용·익명·철회 권한은 하진의 공익 판단보다 우선한다.
