## 원고 규칙

- 특정 작품·작가 문체 모사 금지
- 단문 금지가 아니라 단문 남발 금지
- 학교의 즐거움과 생활 보상을 갈등보다 먼저 충분히 제시
- 길문전은 30초 설명 가능성을 유지
- 온기고리·모서리잠의 마음을 인간 언어로 확정하지 않음
- 보호 계획은 실제로 학생과 시설에 도움이 됨
- 하진의 오류는 규칙 위반이 아니라 관계 철회를 안전·전술 데이터로 소비하는 선택
- 학생은 경기 중지 신호를 낼 수 있지만 시설·의료·생태 구조를 지휘하지 않음
- 실제 교육·시설·보험·안전 세부는 인간 검토 전 working candidate

## 완료 상태 용어

- 초고 작성 완료는 `draft-complete`
- 내부 검토 뒤 `internal-review-ready`
- 인간 검토 전에는 `edited-manuscript` 또는 `publication-ready`로 부르지 않음
