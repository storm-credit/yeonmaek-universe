# 장기 성장형 메인 사가 작가 의도 기록 v0.1

## 확정된 의도

본편은 한국을 홈베이스로 삼고 동일 주인공이 여러 **부제작**에 걸쳐 성장하는 장기 성장형 메인 사가다.

`부제작`은 하나의 고유 제목·중심 사건·미스터리·감정적 결말을 가진 독립 장편 단위다. 출판 과정에서 한 부제작이 여러 물리적 책으로 나뉠 수 있으나, 분권 수는 서사 단위가 아니다.

## 구조 원칙

- 여러 부제작이 하나의 대형막을 이룬다.
- 메인 사가는 복수의 대형막으로 구성된다.
- 한국의 학교·가족·현실 친구·도시 생활은 끝까지 홈베이스로 남는다.
- 해외 확장은 주인공의 성장과 세계 질문을 확장하지만 국가 수집 여행이 되지 않는다.
- 각 부제작은 자체 사건을 완결하며 후속 출간 실패 시에도 독자 만족을 보존한다.
- 전체 메인 사가의 최종 질문과 주인공 성장만 마지막 부제작에서 완결한다.

## 기존 5권 후보 처리

기존 `5권 핵심 완결형`은 메인 사가의 확정 구조가 아니다. 해당 문서에서 설계된 발견·보호·국경·기록·공동관리 기능은 폐기하지 않고 **부제작 기능 후보 풀**로 재분류한다.

정확한 부제작 수, 대형막 수, 시간 경과, 분권 수는 4안 비교 뒤 candidate로 결정한다.

## 독자 약속

- 핵심 연령 10~15세, 성인까지 확장되는 크로스오버
- 초반의 경이·학교·수집 재미와 후반의 책임·권력·상실을 함께 성장시킴
- 동행종·도감·지도·유물·영웅 기록이 장기 미스터리와 인물 선택에 연결됨
- 수집 요소는 생명 소유·가챠·무한 파워업으로 다루지 않음

## 영향 대상

- 시리즈 길이·결말·복선·캐릭터 성장 문서
- 1권/2권처럼 표기된 기존 권별 설계
- 해외 지역 배치
- 수집 시스템과 동반 출판선
- 메인 제목 및 부제 명명 체계

N16은 기존 문서를 조용히 덮어쓰지 않고 `재사용`, `재배치`, `deprecated candidate`로 구분해 변경 원장을 작성한다.
