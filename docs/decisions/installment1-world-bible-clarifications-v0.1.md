# 첫 부제작 역검증 설정 명료화 v0.1

## 결정 1 — O-05 기록 불일치

`기록 불일치`는 물리적 시간여행이나 사건 순서 역전을 뜻하지 않는다.

- 현실의 총 경과 시간·물질·부상·시설 결과는 O-03에 따라 보존된다.
- 심층 상호작용 구간에서는 감각·사진·메모·센서가 관찰 범위와 동기화 조건에 따라 서로 다른 순서·경과를 남길 수 있다.
- 원고는 등장인물이 시간 이상을 의심하게 할 수 있으나 객관 서술로 `사라진 시간`을 확정하지 않는다.
- 해결 과정은 기록 범위·순서·조건을 대조하는 방향으로 진행한다.

## 결정 2 — BIO-001 공식 군집명

여울띠의 공식 C0 기본 표현은 `이동군`이다.

- `가족군`은 제7장의 학생 임시 가설로만 허용한다.
- 인간 가족·부모·자녀·성별·번식 구조를 확정하지 않는다.
- 도감·결과표·기관 기록은 `현재 관측 이동군`을 사용한다.
- 관계를 설명할 때는 간격·동시 이동·재접근·거리 두기 같은 관찰 행동만 기록한다.

## 결정 3 — 기관 행위 주체

- 시설 구조 설치·보수·공정 변경: 시설 책임팀
- 사람 동선·통제: 교통 책임팀
- 학생 관찰·중지·철수: 현장교육센터
- 구조·의료: 현실 외부 전문기관
- 경로의 시험·거부·선택: 여울띠 이동군

짧은 원고 문장에서도 센터가 시설공사와 교통을 직접 지휘하는 것처럼 표현하지 않는다.

## 영향

- 세계관 구조 변경 없음
- 첫 부제작 사건·인물·결말 변경 없음
- 원고 교체 문장 12곳
- 도감 샘플과 향후 공식 기록에 적용
- 부제작 2~7의 기록·군집·기관 표현에 재사용

## 후퇴

독자 테스트에서 `이동군`이 지나치게 행정적이라면 대화에서는 `무리`를 사용하되, 공식 기록은 `현재 관측 이동군`으로 유지한다.
