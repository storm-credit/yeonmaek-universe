# 대표 경기 작업 규칙 후보 결정 v0.1

## 결정

대표 경기의 1순위 작업 규칙은 `세 길 연결·중앙 봉화형`으로 둔다.

현재 `길문전`은 설명용 작업명이며 최종 경기명이 아니다.

## 30초 규칙

> 두 팀이 다섯 길표 가운데 세 개를 이어 자기 팀 길을 만든다. 길이 이어진 동안 아무 선수나 중앙 봉화에 먼저 닿아 점화하면 이긴다. 상대는 사람을 때리지 않고 길을 끊거나 이동을 늦춘다.

## 승리 조건

`자기 시작진과 연결된 길표 3개 이상을 유지한 상태에서 중앙 봉화를 먼저 점화한다.`

다른 점수·진행도·숨은 판정으로 승자를 정하지 않는다.

## 경기 구성

- 코트 선수: 팀당 5명
- 교대 선수: 팀당 2명
- 길표: 중립 5개
- 중앙 목표: 봉화 1개
- 정규 시간: 12분 단판 후보
- 리그전 시간 종료: 무승부
- 토너먼트: 같은 승리 조건의 제한 연장전

## 경기 기능 4개

- 탐로
- 결선
- 차단
- 점화

이는 고정 포지션이 아니라 경기 중 바뀌는 기능이다. 선수는 최소 두 기능을 수행한다.

## 금지

- 고정 점화자·특수 선수
- 직접 타격·정신 침해
- 살아 있는 생물의 경기 사용
- 관계 열쇠 탈취·위조
- 허가되지 않은 부담 전가
- 표준 장비로 수행할 수 없는 필수 기능
- 국가별 고정 전술
- 매 권 예선·결승 반복

## 관중 정보

실시간 기본 표시는 5개로 제한한다.

1. 활성 길표
2. 현재 연결선
3. 봉화 접근 열림/닫힘
4. 선수 부담 정상/경고/교대 필요
5. 경기장 안정 정상/주의/중지

## 안전

다음 상황은 자동 중지한다.

- 선수 부담 한계 초과
- 경기장 안정 중지 단계
- 관중·시설 구역과 비정상 연결
- 위치 기록과 실제 인원 불일치
- 허가되지 않은 생물·관계 열쇠·장비 개입

재개 판단은 안전 심판·의료·시설 책임자가 맡는다.

## 장비·후원 원칙

- 필수 안전 장비와 길표 결합기는 표준품 제공
- 개인 장비 기능·부담 계수 공개
- 후원사는 안전 측정·심판 시스템을 독점하지 못함
- 선수뿐 아니라 장비·경기장·교대 구역의 총부담을 기록
- 고의 부담 은폐는 몰수패와 장비 승인 정지 가능

## 환경 변화

- 경기 전 공개
- 한 경기 3개 이하
- 고정 시간 또는 길표 활성 조건으로 작동
- 실제 생물·신성 의례·신성 장소를 사용하지 않음
- 개최지 환경은 안전하게 추상화

## 권별 배치

### 1권

수업·관전·기초 훈련으로 규칙 일부만 소개한다. 1권 사건의 해결을 경기 기술로 대체하지 않는다.

### 2권

대표 경기 중심권으로 사용한다.

- 학교 관계와 라이벌
- 장비·후원 격차
- 부담 은폐와 보고
- 규칙의 형식적 공정성
- 보호와 이용의 경계

경기 결승만으로 권을 끝내지 않고 경기에서 드러난 문제가 별도 현장 사건과 연결된다.

### 3권

친선 훈련 또는 국제 공통 규칙 충돌 사례로 제한한다. 해외 지역을 대회 개최지와 국가 전술로 축소하지 않는다.

### 4~5권

경기 자체보다 장비 기록·부담 보고·규칙 개정의 결과를 회수한다.

## 재검토 조건

- 30초 설명 후 독자가 승리 조건을 재현하지 못함
- 중앙 봉화 교착이 반복
- 무승부 비율이 지나치게 높음
- 점화자가 사실상 특수 포지션으로 고정
- 장비 격차가 승부를 결정
- 부담 규칙이 경기 외 설명으로만 존재
- 국제 경기에서 국가별 능력 고정관념 발생
- 2권 전체가 대회 서사에 잠식

## 후속 작업

- 2D 경기장 모의 진행
- 길표 간 거리와 중앙 접근 구역 설계
- 청소년부 출력·부담 한계
- 심판·의료·시설 독립 권한
- 최종 경기명·유니폼·리그 구조
