# 부제작 6 원고 단계 승인 v0.1

작가의 연속 진행 지시를 부제작 6 원고 단계 승인으로 기록한다.

## 승인 범위

- 18장 초고
- 36개 장면 카드 원고화
- 140~169화 연재 원장
- F01~F24 심기·진전·회수 추적
- 중앙 조율망의 두 차례 실제 성공과 세 번째 역할 분해 대응

## 제한

- 실제 기반시설 수치·재난 절차·긴급 권한은 전문가 검토 전 working approximation이다.
- 하진은 시설·의료·구조 실행을 지휘하지 않는다.
- 중앙망은 악한 체계가 아니라 실제 피해를 줄이는 합리적 선택으로 쓴다.
- 분산 대안은 무비용 정답이 아니며 속도 저하와 일부 서비스 중지를 감수한다.
- 수용처·생태·지역 거부·감사 권한을 화면 밖 비용으로만 소비하지 않는다.
