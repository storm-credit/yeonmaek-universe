## 승격 규칙

`candidate`를 `provisional` 또는 `canon`으로 승격하려면 다음이 필요하다.

- 작가 방향 승인
- 연속성·독창성·문화 무결성 검토
- 앞선 세계관 기준선과의 충돌 없음
- 1권 사건과 인물 설계에서 실제 작동 확인
- 복선·대가·생활 변화의 회수 가능성
