# 지역·기관·세력 통합 기준선 v0.1

## 통합 구조

- 홈 생활권은 독자의 일상 기준점이다.
- 인접 수계권과 산자락 구도심권은 초기 탐사 확장축이다.
- 하구·항만 연결권은 장거리·국제 확장축이다.
- 신도시·옛길 경계권은 개발과 이동권 갈등을 담당한다.

기관은 기능별로 나눈다.

- 교육기관: 배우고 회복하는 곳
- 공공 조정기관: 임시 안전조치와 관할 협의
- 기록기관: 판본·분류·공개 수준 관리
- 보호·복구기관: 생물·장소·경로 회복
- 민간·협동기관: 도구·운송·서비스
- 주민 공동체: 생활 지식과 지역 결정권
- 독립 중재기관: 이의·재심·권한 만료

세력은 기관 이름이 아니라 선택 기준이다.

- 공개 / 보호
- 연결 / 폐쇄
- 표준화 / 지역 자율
- 성장 / 돌봄

## 기본 사건 생성식

`지역의 생활 문제 + 경로·생태 변화 + 둘 이상의 기관 권한 충돌 + 세력 가치축 + 학생이 감당할 수 있는 선택`

## 예시 기능

- 하천 공사로 통과로가 끊겼을 때 연결 복구와 생태 보호가 충돌한다.
- 오래된 계단길 공개가 주민 안전과 기록 공개 요구를 동시에 건드린다.
- 학생 경기에서 발견한 새 경로의 기록 소유권을 학교·주민·기록관이 다르게 주장한다.
- 해외 교환 지역에서 공통 안전표준과 현지 자기명칭이 충돌한다.

## 장기 설계 장점

- 매 사건마다 악당을 새로 만들지 않아도 갈등이 발생한다.
- 같은 지역을 다시 방문해도 다른 권한·가치 문제가 생긴다.
- 학생의 성장은 강함보다 판단과 책임 범위의 확대로 측정된다.
- 세계 확장이 국가별 속성 수집으로 변질되지 않는다.

## 미확정

- 실제 도시명과 기관명
- 기관 수와 규모
- 세력 대표 인물
- 작품 수와 갈등 배치
- 최종 정치·제도적 결론
