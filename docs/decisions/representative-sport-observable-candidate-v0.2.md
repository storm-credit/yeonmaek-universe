# 길문전 관전·안전 candidate 결정 v0.2

## 결정

대표 경기의 1순위는 계속 `세 길 연결·중앙 봉화형`으로 둔다.

## 핵심 규칙

> 다섯 길표 중 세 개를 자기 시작진과 이어 중앙 길을 연 뒤, 아무 선수나 봉화를 먼저 켜면 이긴다.

- 팀당 코트 선수 5명·교대 2명
- 정규 시간 12분 후보
- 숨은 점수 없음
- 점화 전담자 없음
- 직접 타격·장비 탈취·생물 이용 금지
- 길표 독점 20초 뒤 중립 펄스
- 봉화 접근은 연결 3개 이상을 유지할 때만 열림

## 관전 화면

1. 길표 상태
2. 현재 연결선
3. 봉화 열림/닫힘
4. 선수 부담 정상/경고/교대
5. 경기장 안정 정상/주의/중지

색 외에도 선·도형·빗금으로 구분한다.

## 선택 이유

- 회전 봉화형보다 운과 설명 부담이 작음
- 왕복 운반형처럼 특수 운반자가 고정되지 않음
- 누적 점수형보다 승리 순간이 명확함
- 경로·협업·교대·중지를 경기 안에서 보여 줄 수 있음
- 부제작 2의 보호·소유·철회 문제와 직접 연결됨

## 안전

선수 부담 초과, 위치 기록 불일치, 시설 안정 중지, 관중·비상동선 연결, 허가되지 않은 생물·장비 개입, 의료·시설 중지, 멈춤종 사용 시 자동 중지한다.

재개는 필요한 성인 안전·의료·시설 책임 확인 뒤 가능하다.

## 부제작 2 사용 상한

- 완전한 경기 최대 2회
- 부분 훈련·관전 3~4회
- 경기 결승만으로 작품을 끝내지 않음
- 중지 뒤 시설·생태·학교 규칙 결과를 별도 회수
