# 첫 부제작 v0.2 준비도 결정 v0.1

## 결정

첫 부제작 최신 통합 원고를 **`v0.2 integrated draft / author-and-reader-review-ready`**로 판정한다.

## 완료

- 15장 초고
- 1장 초반 장르 약속 보강
- 10·12장 제도 설명 압축
- 13·14장 클라이맥스 행동·감정 밀도 보강
- 반복어·대사 기능 감사
- 7장/8장 2물리권 후보
- 내부 회귀 PASS 28 / FAIL 0

## 남은 인간 게이트

- 실제 10~15세 독자 완독·낭독 테스트
- 성인 확장 독자의 제도 장면 피로도 테스트
- 제목·인물명·여울띠 명칭 선호
- 정확한 문자 수·원고지·판형·삽화·가격
- 작가의 장면·감정·문체 판단

## 현재 승인 의미

원고 단계 승인은 초고와 내부 수정까지의 승인이다. 이 원고가 canon·출판 원고·최종 교정본이 됐다는 뜻은 아니다.
