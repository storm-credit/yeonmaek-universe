# 세계관·접점·생태·수련·교육 통합 후보 v0.1

## 통합 판정

현재 새 브랜치에서 독립적으로 설계된 후보들은 다음 구조로 가장 잘 맞물린다.

### 세계의 공간

현실 장소에는 서로 다른 이용자와 생태가 사용하는 숨은 길·경계·머묾터가 겹쳐 있다.

### 발견 방식

시간·날씨·이동 순서·동행·관계 이력·표식 중 일부가 맞을 때 다른 기능이 드러난다. 스마트폰과 센서는 완전히 무력화되지 않고 불완전한 흔적을 남긴다.

### 감정적 중심

비인간 존재는 수집품이 아니라 독립된 생태·이동·거부·관계 목표를 가진다. 관계가 생겨도 소유를 의미하지 않는다.

### 성장 방식

학생 또는 견습자는 몸과 호흡을 다루고, 장소를 읽고, 도구를 조율하고, 사람·생물과 동행 조건을 맞추는 법을 배운다.

### 교육 구조

기숙·통학 혼합형 홈베이스와 지역 학단 네트워크의 결합이 가장 유력한 후보이다. 가족·현실 친구·학교생활을 유지하면서 지역별 탐사와 문화 확장이 가능하다.

### 기록의 역할

지도·도감·영상·현장 기록은 세계를 창조하거나 정답을 자동 출력하지 않는다. 서로 다른 관찰을 비교하고 오류와 위험을 줄이는 보조 체계다.

## 한 문장 후보

> 평범한 현실의 길 뒤에는 서로 다른 생명과 공동체가 사용하는 또 다른 경로가 겹쳐 있고, 학생들은 그것을 지배하는 대신 읽고 동행하고 복구하는 법을 배운다.

## 독자 경험 순서

1. 먼저 이상하고 아름다운 길·생물·공간을 발견한다.
2. 친구·가족·학교생활 속에서 다시 방문하고 싶어진다.
3. 몸과 기술이 실제로 늘어나는 성장을 본다.
4. 탐사와 경기에서 팀 역할과 선택의 결과를 경험한다.
5. 그 뒤에 기록·기관·공개·책임의 복잡성이 확장된다.

행정·윤리·제도 설명이 경이와 관계보다 먼저 나오지 않는다.

## 현재 확정하지 않는 항목

- 작품명과 세계관 고유 명칭
- 주인공과 핵심 인물
- 학교명·위치·학제
- 작품 수·권수·장 수·회차 수
- 사가 구조와 결말
- 적대 세력과 장기 맥거핀
- 구체 생물·유물·지역 목록
