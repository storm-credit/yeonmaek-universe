# 독자 톤·메인 브랜드 candidate 결정 v0.1

## 결정

### 톤 상승

**이중 레이어·대형막 단차 혼합형**을 1순위 candidate로 둔다.

- 모든 부제작의 표면에는 학교·탐사·관계·수집의 구체적 즐거움을 유지한다.
- 심층 질문은 대형막마다 책임·번역·권력·공동관리로 깊어진다.
- 심층 질문은 설명이 아니라 사건의 선택·대가·결과를 바꿔야 한다.
- 중심 심층 질문은 부제작당 하나를 기본 상한으로 둔다.

### 메인 시리즈명

**《겹길》**을 1순위 예비 candidate로 둔다.

선택 이유:

- 다층 생태와 실제 이동 회랑을 동시에 암시한다.
- 한국 홈베이스와 범지역 확장을 함께 수용한다.
- 도감·동행종·유물 중 하나에 시리즈를 종속시키지 않는다.
- 짧고 구전 가능하다.
- 공개 웹 예비 검색에서 강한 동명 작품·브랜드를 찾지 못했다.

### 부제 명명 문법

**물건·장소·기록 변주형**을 candidate로 둔다.

- 구체 명사 최소 1개
- 2~6어절
- 이상 상태나 결핍 암시
- 결말·범인·최종 선택 비공개
- 동일 문법 세 작품 연속 금지
- 사건 게이트 이전의 예시는 확정명으로 사용하지 않음

## 하향 후보

- `딥루트`: 자율주행 기업·국내 브랜드 충돌과 철자 혼동으로 메인 1순위에서 하향
- `숨은결`: 동명 사용례와 조용한 문학·로맨스 인상으로 하향
- `깊은결학교`: 학교 작업명으로 유지, 메인 사가 후반 확장성 부족
- `사이길`: 실제 장소 고유명과 검색 충돌로 제외

## 아직 확정하지 않는 것

- 《겹길》의 canon 승격
- 최종 로고·표지
- 영문 메인명
- 일곱 부제의 최종 제목
- 출판·상표 법률 안전성

## 재검토 조건

- 실제 10~15세 발음·기억 테스트 실패
- KIPRIS·ISBN·서점·게임·앱 정밀 조사에서 강한 충돌
- 1부제 핵심 사건에서 길·회랑 이미지가 제거됨
- 영문 브랜드 4안에서 일관된 번역명 확보 실패
- 대형막 후반에 한국 홈베이스와 이동·귀환 구조가 사라짐
