# 캐릭터 기능·관계 아키텍처 후보 결정 기록 v0.1

## 결정

5권 본편의 인물은 이름·성별·국적보다 먼저 **선택 기능·욕망·오신념·관계 변화**로 설계한다.

핵심 기능 후보는 다음 10개다.

1. C01 주인공 — 생활권·기록·관계를 연결하고 최종 독점권을 거부
2. C02 절차형 동료 — 안전 규칙을 재검토 가능한 절차로 변화
3. C03 관계형 동료 — 개인적 신뢰와 공공 책임의 경계 학습
4. C04 경쟁자 — 기술·측정·중앙화의 실제 장점과 위험을 대표
5. C05 일반 세계 친구 — 현실 기록·신뢰·제한적 사회 인정의 당사자
6. C06 보호자·가족 — 미성년 안전·학력·의료·경제·돌봄의 현실 고정점
7. C07 교사·멘토 — 실제 보호 능력과 과거 타협·권한 포기의 성인 사례
8. C08 지성종 당사자 — 자치·거부·비접촉·기록권을 가진 독립 주체
9. C09 국제·현지 대응자 — 3권 현지 사건의 독립 주체와 지역 자치 관점
10. C10 중앙화 옹호자 — 빠른 안전과 독점 통제의 강한 논리를 행동으로 증명

## 핵심 원칙

- 핵심 기능 10개가 주요 인물 10명을 의미하지 않는다.
- 1권 핵심 활성 인물은 6~7개 기능으로 제한한다.
- 권별 신규 주요 인물은 최대 2~3명이며 5권에는 신규 주요 인물을 추가하지 않는다.
- 한 인물이 국가·문화·지성종 전체를 대표하지 않는다.
- 주인공이 모든 단서와 해결을 독점하지 않는다.
- 성인은 학생보다 구조·법·의료·기술·역사에서 실제 전문성을 가진다.
- 학생의 중요성은 성인의 무능이 아니라 생활권·또래망·분리된 기록층을 동시에 경험하는 위치에서 나온다.
- 일반 친구·보호자·가족은 중간권 이후에도 사라지지 않는다.
- 지성종 당사자는 마스코트·반려동물·현실 소수집단의 직접 은유가 아니다.
- 국제 동료는 문화 설명서나 국가별 능력 대표가 아니다.

## 주인공 변화 기준선

초기 오신념:

> 더 정확한 정보와 더 큰 접근권을 내가 가지면 모두를 더 안전하게 지킬 수 있다.

5권 변화:

1. 혼자 정확히 보는 것보다 보고·중지·구조·기록 연결을 배움
2. 학교와 도감의 더 큰 접근권을 원하고 보호 명목의 통제에 일부 가담
3. 자신의 분류와 해결법이 지역·당사자에게 보편적이지 않음을 경험
4. 중앙 기록과 독점 접근이 실제로 생명을 구하는 유혹을 경험
5. 독점적 접근·최종 결정권을 포기하고 여러 당사자의 참여 구조를 선택

## 단서 기능 분산

- 생활·일반 기록: C05·C06
- 학교 절차·접근 로그: C02·C07
- 생물 행동·관계 철회: C03·C08
- 장비·측정·중앙화 성공: C04·C10
- 해외 판본·번역 실패: C09와 현지 당사자
- 여러 단서의 최종 연결과 선택: C01

## 관계 설계 제한

- C01·C02·C03을 항상 같은 삼인조로 묶지 않는다.
- 권마다 다른 인물 조합이 핵심 행동을 수행한다.
- 인물마다 세계관 갈등과 무관한 가족·취미·학업·경제·진로·유머가 필요하다.
- 경쟁자는 틀리고 패배해야만 완결되는 인물이 아니다.
- 멘토는 모든 비밀을 알고 마지막에 설명하는 전지적 인물이 아니다.
- 보호자는 무지한 모험 방해자 또는 인질이 아니다.
- 중앙화 옹호자의 패배가 중앙화의 모든 장점을 자동 부정하지 않는다.

## 배경 배정 전 필수 검사

성별·국적·지역·계층·장애·가족 형태를 정하기 전에 최소 4개 교차 조합을 비교한다.

금지되는 자동 배정:

- 여성=관계·돌봄
- 남성=기술·경쟁
- 부유층=냉정한 악역
- 저소득층=도덕적 순수성
- 동남아=정령·자연
- 일본=규칙·결계
- 중국=무공·권위
- 장애·질환=특별한 감지력·저주·순수성

## 재검토 조건

- 1권 핵심 인물이 8명 이상으로 늘어날 때
- 주인공·두 동료가 모든 사건을 함께 해결하는 고정 삼인조가 될 때
- 주인공이 모든 핵심 단서를 직접 발견할 때
- 성인이 무능하거나 침묵해야 학생이 활약할 때
- C08이 마스코트·현자 스승·현실 집단 우화로 축소될 때
- C09가 한 국가의 문화와 술법을 대표할 때
- 후반권에서 가족·일반 친구·학교생활이 사라질 때
- 모든 관계 변화가 세계관 이념 토론으로만 발생할 때

## 다음 의존 작업

2. 1권 사건에 필요한 최소 인물 기능 6~7개 확정
3. 핵심 인물의 배경·성별·지역·계층 조합 4안 비교
4. 이름·외모·말투는 기능·배경 검증 후 결정
