# 첫 부제작 비인간 이동 당사자 candidate 결정 v0.1

## 결정

첫 부제작의 비인간 이동 당사자는 **`여울띠` 가족·무리 이동형**을 1순위 candidate로 둔다.

`여울띠`는 완전 창작 생태의 작업명이며 최종명·외형·삽화는 아니다.

## 핵심 생태

- 5~12개체의 느슨한 가족군
- 성체 길이 60~90cm, 폭 8~12cm의 납작한 이중 막 형태
- 앞뒤가 고정되지 않고 이동 방향에 따라 선두 가장자리가 바뀜
- 개체마다 3~7개의 밝은 마디 배열이 다름
- 낮은 진동·압력 차이·구조물 연속성을 감지
- 도시 구조 주변의 미세 부담 입자를 몸에 축적
- 계절마다 깊은 광물층과 수분 경계가 겹치는 창작 방출지로 이동해 부담을 재분배

## 첫 사건 인과

1. 과거 학교 조사는 이동 뒤 남은 벗은 띠막과 고립 방출 사고만 관찰.
2. 이를 고정 전도성 위험막·공격 위험종으로 잠정 분류.
3. 잠정 분류가 갱신되지 않고 공사 전 조건의 안정 지도에 고정.
4. 시설 보수의 진동 차단·밀폐로 오래된 이동 경로가 끊김.
5. 가족군이 통학 구간에 머물며 부담을 방출하고 위험이 다른 구간으로 이동.
6. 인간은 처치가 아니라 안전 거리·우회·경로 연속성·방출지 접근을 복구해야 함.

## 의사표현

- 접근 허용: 일정 거리 유지와 안정된 밝기 순서
- 경고: 간격 축소와 가장자리 떨림 증가
- 거부: 제안 경로 앞에서 선두 방향 반복 반전
- 거리 두기: 관측 깊이를 바꾸고 얕은 층에서 사라짐
- 재협상: 여러 개체가 서로 다른 방향을 시험

복잡한 감정·역사·이름을 인간에게 번역하지 않는다. 현재 접근·거부·방향 행동만 다중 기록으로 추정한다.

## 관계 상태

- 관찰
- 접촉 제한
- 접근 허용
- 이동 보조
- 거부
- 거리 두기
- 이동 완료
- 위치 비공개
- 다음 계절 재검증

영구 계약·소유·동행·진화 상태는 없다.

## 작품 종료

- 가족군은 방출지로 독립 이동한다.
- 주인공이나 학교에 남지 않는다.
- 이후 같은 마디 배열의 관측 가능성은 열어 두지만 동일 개체임을 자동 확정하지 않는다.
- 도감은 `고정 공격 위험종`에서 `조건부 이동 당사자·고립 시 위험`으로 정정한다.
- 지도는 경로를 공개 개방하지 않고 일부 보호 폐쇄·위치 비공개를 허용한다.

## 수집 매력

- 밝은 마디 배열과 벗은 띠막 무늬
- 관계·이동·관찰 상태 변화
- 열린 길뿐 아니라 보호 폐쇄·이동 완료 기록
- 장기 재회 가능성

강함·희귀도·포획 수량으로 평가하지 않는다.

## 하드 가드레일

- 눈·입·표정·인간식 몸짓 기본 금지
- 인간 부모·자녀·성별 구조 직접 투영 금지
- 주인공만 이해하는 언어 금지
- 실제 물고기·뱀·철새·곤충·민속 존재 1:1 변형 금지
- 현실 하천 오염·침수의 원인화 금지
- 학교의 과거 분류를 단순 무능으로 처리하지 않음
- 고립 위험과 이동·거부 권리를 동시에 기록

## 아직 확정하지 않는 것

- 최종 종명과 자기명칭
- 정확한 색·재질·빛 패턴
- 개체 수와 생애 길이
- 번식·성숙 구조
- 방출지의 구체 위치
- 상품·카드·삽화 형태
