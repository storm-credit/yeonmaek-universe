# 부제작 3 원고 단계 승인 v0.1

사용자의 `이어서 진행`을 부제작 3 원고 단계 승인으로 기록한다.

## 승인 범위

- 15장 브리프와 15장 초고
- 30개 장면 카드 원고화
- 57~82화 연재 단위 컴파일
- 작품 내부 단서·복선·회수 추적
- 문체·공간·탐사·지역 권한 회귀 감사

## 제한

- 실제 지명·기관·생업·방언·보호종 세부는 인간 지역·생태 검토 전 확정하지 않는다.
- 합성 하구 생활권과 기능명 중심으로 집필한다.
- 하진·학교가 지역을 대신 구하거나 최종 결정하지 않는다.
- 현지 인물의 이름과 세부 배경은 provisional 상태를 유지한다.
- 원고 완료는 인간 편집·출판 완료를 의미하지 않는다.
