# 부제작 7 원고 단계 승인 v0.1

작가의 연속 진행 지시를 최종 부제작 원고 단계 승인으로 기록한다.

## 승인 범위

- 20장 초고
- 40개 장면 카드 원고화
- 170~200화 연재 원장
- F01~F26 회수
- P-17 검증 가능한 비공개 결말
- 단독 접근·자동 복귀·우선 순서 해체
- 졸업·진로·가족·친구 관계 완결

## 제한

- 지역·해외 현장 결정은 각 현지 주체가 수행한다.
- 중앙 연장의 실제 효용을 부정하지 않는다.
- P-17 원문과 민감 위치를 폭로하지 않는다.
- 하진은 능력을 잃지 않지만 독점 권한과 일부 엘리트 진로 이점을 잃는다.
- 실제 제도·법률·기반시설 전환은 전문가 검토 전 candidate로 유지한다.
