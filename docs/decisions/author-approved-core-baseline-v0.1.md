# 작가 승인 핵심 기준선 v0.1

## 승인 근거

사용자가 2026-08-02 `이어서진행`을 요청했다. 직전 대화에서 제시한 추천 기본값과 자동 진행 순서를 수정 없이 이어가라는 승인으로 해석한다.

## 작가 승인된 기준선

1. 메인 사가는 7부제·2/3/2 대형막·약 6년이다.
2. 주인공은 `서하진`, 남자, 만 12세 시작이다.
3. 보호자 `서지현`은 하진의 아버지다.
4. 하진은 연결 관측자이며 특별 혈통·예언·천재 해커 설정이 없다.
5. 하진은 설명서·노선도·보증서와 실제 사용 흔적을 비교하는 취미와 건조한 사실 확인 유머를 가진다.
6. 학교의 감정적 얼굴은 `관계가 자라는 수업형`을 중심으로 한다.
7. 대표 수집 얼굴은 `정정되는 생태 도감`이다.
8. 설정집의 시각 인터페이스는 `현장기록·정정형`을 사용한다.
9. 7부제의 장르 진행은 도시 미스터리→학교 스포츠→국내 탐사→해외 재난·번역→도시 추적→시스템 구조→분산 최종 임무·졸업이다.
10. 최종 감정은 졸업과 새 책임, 독점 우선권 만료다.
11. `겹길`은 최종 상표·출판 검토 전까지 working title로 유지한다.

## 승인 효과

- 위 항목은 작가 의도와 서사 설계의 기준선으로 사용한다.
- 이름·성별·가족 관계·사가 구조는 임의로 되돌리지 않는다.
- 첫 부제작 v0.3 국소 연속성 패치와 독자 테스트 패키지를 진행한다.
- 길문전 관전성·안전성 게이트와 부제작 2 비원고 설계를 진행한다.

## 여전히 확정되지 않은 것

다음은 작가 승인만으로 최종 canon 또는 출판 승격하지 않는다.

- 학교의 실제 법적 형태와 현실 행정 적합성
- 금강하구·방콕 등 실제 지역 문화·언어·생태 세부
- 제목·상표·출판·분권·삽화·접근성
- 생태권리·연구윤리·보험·개인정보·의료 절차
- 실제 10~15세·성인·보호자 독자 반응
- 모든 조연·생물·기관 작업명의 최종 표기

## 변경 규칙

이 기준선을 바꾸려면 `명확화 / 확장 / 수정 / 레트콘` 중 하나로 분류하고 N16·P09 영향 검토를 거친다.
