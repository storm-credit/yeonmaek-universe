# 첫 부제작 내부 구조 후보 결정 v0.1

## 결정

`《겹길: 사라진 통학로》`의 내부 구조는 **3막·8시퀀스 이중 시계 수렴형**을 1순위 candidate로 둔다.

## 8시퀀스

1. 통학 기록의 작은 어긋남
2. 첫 신고 창의 상실
3. 감독된 관찰과 여울띠의 경로 거부
4. 폐쇄 뒤 다른 구간으로 이동하는 이상
5. 비가 먼저 닫는 길
6. 공사가 나중에 닫는 길과 학생 철수
7. 복수 경로 시험·불완전한 기록 공유·판단권 이양
8. 독립 이동·현실 보수 재개·생활과 기록의 변화

## 핵심 전환

- 1막 종료: 개인 기록과 신고 지연이 공식 검토 시간을 줄인다.
- 중간점: 여울띠의 거부를 공격성으로 보던 해석이 깨지고, 단일 기록의 한계가 드러난다.
- 저점: 이안은 현장에서 철수하고 숨긴 기록과 모르는 부분까지 공개해야 한다.
- 클라이맥스: 성인 전문팀이 현실 통제와 공정 결정을 맡고 여울띠가 경로를 선택한다. 이안은 판단 근거를 전달하지만 결정을 독점하지 않는다.
- 결말: 현재 사건은 완결하고 삭제 항목 ID 하나만 장기 미확인으로 남긴다.

## 선택 이유

- 두 시간 압력과 사건 인과가 가장 쉽게 보인다.
- 주인공의 오신념 변화가 선택과 비용으로 누적된다.
- 학생·보호자·학교·전문 책임자의 역할을 분리할 수 있다.
- 여울띠의 거부와 독립 이동이 실제 플롯 행동으로 남는다.
- 첫 작품의 정보량과 장기 복선 예산을 통제하기 쉽다.

## 후퇴안

`통학 주간 4부 교차형`을 후퇴안으로 둔다. 실제 사건 기간을 5~8일로 압축할 때 사용할 수 있지만 중간점·저점·클라이맥스 기능은 8시퀀스 안에서 유지한다.

## 장면 카드 단계의 하드 제약

1. 강우 통제와 시설 보수는 서로 다른 반복 표식으로 구분한다.
2. 학생 철수 뒤에도 이안의 핵심 선택은 유지하되 원격 지휘로 바꾸지 않는다.
3. 기관 전체 설명보다 현재 결정권을 보여 준다.
4. 반복 관찰마다 증거 종류와 선택 주체를 바꾼다.
5. 모든 시퀀스에 감각적 현상·관계 선택·현실 결과를 최소 하나씩 둔다.
6. 장면당 새 고유명사는 1~2개 이내로 제한한다.
7. 마지막의 삭제 ID는 현재 결말보다 작아야 한다.
