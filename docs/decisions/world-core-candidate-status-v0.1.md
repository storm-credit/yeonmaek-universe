## 자동 진행 규칙

1. 새 설계는 한 번에 최소 4안을 비교한다.
2. 추천안은 `candidate`로만 기록한다.
3. 기존 브랜치와 우연히 같은 아이디어가 나와도 출처를 새 문서의 논리로 설명한다.
4. 작품 분량과 사가 구조는 세계관·설정집 골격 뒤에 설계한다.
5. 실제 원고 문장·대사·장면 서술은 작성하지 않는다.
