# 결말 상태 후보 결정 기록 v0.1

## 결정

시리즈 결말의 1순위 후보로 **단계적 인정·회랑 공동관리형**을 채택한다.

## 핵심 상태

- 숨은 생태의 존재·피해·권리·책임은 제한적으로 사회 인정
- 위험 위치·미성년자·수사·당사자 통제 지식은 제한 가능
- 생태 회랑은 국가·학교·기업의 소유물이 아닌 공동관리 대상
- 지성종·주민·학생·현실 기관·전승 공동체가 영향에 따라 결정 참여
- 힘과 시설의 부담 이동을 추적하는 독립 공공 원장 도입
- 학교의 교육 기능과 연구·보호·허가 기능 분리
- 국제 조정망을 당사자 참여형 구조·검역·중재망으로 개편

## 주인공의 최종 선택 후보

주인공은 자신 또는 학교가 핵심 관계 열쇠와 기록을 독점해 세계를 안정시키는 길을 거부한다. 독점적 접근·우선 열람·최종 결정권을 포기하고, 관계 열쇠와 부담 기록을 여러 당사자의 절차에 귀속시킨다.

## 필수 대가

- 특별한 접근·지위·일부 관계 방식의 상실
- 학교와 가까운 사람들의 특권·예외 축소
- 과거 학교·교사·가족·공동체 책임의 공개 가능성
- 더 느리고 갈등 많은 결정 구조
- 일부 탐사·경기·회랑 사용 제한

## 선택 이유

- 8개 세계관 게이트와 가장 높은 정합성
- 공개·비공개, 국가·공동체, 보호·자치를 이분법으로 끝내지 않음
- 주인공이 최강자가 되지 않고 명확한 권력 포기 선택을 가짐
- 학교·가족·기록·회랑·국제 질서의 변화를 모두 확인 가능
- 악당 제거 뒤 남는 구조 문제를 실제로 회수 가능

## 재검토 조건

- 주인공이 명목상 포기 후 사실상 최종 권한을 계속 보유할 때
- 공동관리 기구 외 개인·생활·관계 변화가 없을 때
- 최종 현장 위기와 단기 안전의 유혹을 설계할 수 없을 때
- 한국 학교가 세계 개혁의 중심 본부가 될 때
- 공개·보호·권리 갈등이 청소년 생활로 번역되지 않을 때
