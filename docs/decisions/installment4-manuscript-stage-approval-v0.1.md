# 부제작 4 원고 단계 승인 v0.1

## 승인 근거

작가의 `이어서진행` 지시를 부제작 4 원고 단계 진입 승인으로 기록한다.

## 승인 범위

- 16장 초고 작성
- 32개 장면 카드 원고화
- 83~110화 연재 원장 작성
- 공정 단서 F01~F20과 장기 복선의 심기·진전·회수 추적
- 프로젝트 맞춤 집필법 부속계약 적용
- 내부 회귀 감사와 인간 검토 패키지 작성

## 제한

- 태국어·실제 기관명·실제 수문 시설 절차·구체 생활권·문화 세부는 현지 검토 전 working placeholder로 유지한다.
- 실제 종교·왕실·의례·민감 문양을 판타지 장식으로 사용하지 않는다.
- 현지 인물의 이름·가족·말투·문화 배경은 기능 중심 provisional 상태로 둔다.
- 하진은 수문·검역·대피·의료를 지휘하지 않는다.
- 국제 검역은 악역이 아니라 실제 사람 안전을 높이는 합리적 제도 압력으로 쓴다.
- 원고는 인간 검토 전 `draft-complete` 이상으로 승격하지 않는다.
