# 원고 직전 통합 준비도 결정 v0.1

## 결정

현재 저장소는 다음 상태로 판정한다.

- **공유세계관·7부제 메인 사가:** `candidate-baseline-ready`
- **첫 부제작:** `candidate-ready-for-author-gate`
- **첫 부제작 장면·회차 설계:** `author-gate blocked`
- **부제작 2~7:** `blueprint-ready` 또는 `function-ready`
- **실재 문화·법률·상표·출판:** `human-review blocked`

## 완료로 인정하는 범위

### 공유세계관

- 다층 생태 위상
- 결합 조율과 부담 보존
- 비인간 당사자 이동·거부·철회 권리
- 분산 현실 관할과 학교·센터·외부 전문 주체 분리
- 다중 협정망과 지역 판본
- 부담 전가형 구조 갈등

### 메인 사가

- 동일 주인공의 7부제 장기 성장
- 만 12세 전후에서 만 18세 전후까지 약 6년
- 2/3/2 대형막
- 일곱 부제작의 중심 질문·독립 사건 기능·감정적 완결·사가 진전
- 한국 학교·가족·현실 친구·도시 생활 홈베이스
- 최종 독점 우선권 포기와 공동관리 결말

### 인물·수집·반복

- 홈베이스 관계 누적+현장팀 회전
- 고정 삼인조 금지
- 동행종·도감·지도·유물·영웅 기록 5축
- 중심 1축+보조 1축+이전 항목 재맥락화
- 학교·탐사·경기·가족·귀환 루프의 대형막별 진화

### 첫 부제작

- 작업 제목 `《겹길: 사라진 통학로》`
- 서안 합성 생활권
- 활성 인간 6명과 여울띠 가족군
- 잘못 분류된 통학 회랑 사건
- 비/보수의 두 폐쇄 시계
- 학생 관찰·기록과 성인 구조·철수 권한 분리
- 불완전한 기록 공유와 판단권 이양 클라이맥스
- 현장 해결·구조 해결·남는 비용
- 도감 정정과 회랑 지도 수집 예산
- 장기 미확인 삭제 항목 ID 1개

## 자동 진행 종료 근거

CLAUDE.md는 다음 경우 자동 진행을 멈추도록 한다.

1. `candidate`를 사실상 작품 기본값으로 채택해야 다음 단계가 가능한 경우
2. 장면·회차 설계로 들어가 이름·성별·사건 순서·제목이 굳어지는 경우
3. 실제 문화·법률·상표 검토가 필요한 경우

첫 부제작은 위 세 조건 중 1과 2에 도달했다. 따라서 자동으로 장면·대사·원고를 생성하지 않는다.

## 작가가 선택할 핵심 묶음

### 사가 묶음

- 7부제 장기 성장형
- 만 12→18세, 약 6년
- 2/3/2 대형막
- 한국 홈베이스
- 최종 독점권 포기·공동관리

### 첫 부제작 묶음

- 가족·통학 현실 사건 우선
- 서안 합성 생활권
- 여울띠 가족군
- 비/보수 두 폐쇄 시계
- 활성 인물 작업 후보
- P1의 기록 공유·판단권 이양 클라이맥스

### 명칭 묶음

- `겹길` 작업 메인명
- `사라진 통학로` 작업 부제
- `깊은결학교`, `길문전`, `여울띠` 작업명

명칭은 작가가 선호해도 상표·출판 검토 전 canon이 아니다.

## 승인 뒤 다음 순서

1. 첫 부제작 내부 3막·시퀀스 4안
2. 사건 장면 카드와 단서 배치
3. 인물 관계 장면·학교/가족 일상 배치
4. 정보 공개·용어 밀도·10~15세 독자 테스트
5. 장별 개요
6. 원고 작성은 별도 승인 후 시작

## 부제작 2~7 정책

후속 부제작의 기능 청사진은 완료했다. 장면 수준 상세화는 첫 부제작의 실제 결과·인물 선택·작가 승인 내용을 반영해 순차 실행한다. 지금 모든 작품의 장면을 미리 고정하면 장기 성장의 누적 결과를 무시하게 되므로 하지 않는다.
