# 기존 자료 출처·오염 이관 원장 v0.1

## 판정 원칙

기존 `canon/world-bible-blueprint-clean`의 파일은 제목이나 완성도와 무관하게 자동 채택하지 않는다. 각 파일은 내용 단위로 아래 판정을 받아야 한다.

| 등급 | 의미 | 새 브랜치 처리 |
|---|---|---|
| P0 | 사용자 직접 명시 | 활성 기준선으로 이관 가능 |
| P1 | 직접 의도에서 독립적으로 도출 | 근거 기록 후 후보 이관 |
| P2 | 조사·감수 의존 | 조사 대기 영역에 이관 |
| Q | 출처 불명·파생 경로 불명 | 격리, 활성 사용 금지 |
| X | 다른 프로젝트 유입 확인 | 이관 금지 |

## 즉시 X 판정

- 200화 연재 지도
- 200화 생성 스크립트·번호표
- 200화를 목표로 한 분할·결합 규칙
- 다른 프로젝트에서 가져온 화수·계약·플랫폼 전제

## 즉시 Q 판정

출처 확인 전까지 다음 전체 묶음을 격리한다.

- 7부제 고정 구조
- 117장·234장면 카드 수치
- 하진·유나를 포함한 고유 인물명
- P-17·돌림패·중앙 조율망
- 각 부제작의 구체 사건·클라이맥스·결말
- 원고에서 역산되었을 가능성이 있는 복선·회수 원장
- `internal-complete`, `candidate-complete` 등 완료 판정

Q는 폐기 판정이 아니다. 사용자 직접 대화·초기 기획·독립 설계 근거를 찾으면 P0/P1/P2로 승격할 수 있다.

1. 작가 의도 문서

3. 학교의 역할과 생활 구조

5. 생물·유물·지역 카탈로그
6. 인물·사가·복선·결말
