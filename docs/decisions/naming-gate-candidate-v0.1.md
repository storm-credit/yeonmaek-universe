# 학교·도감·한국 기관 작업명 후보 결정 v0.1

## 결정

다음 세 명칭을 작품 설계 단계의 1순위 작업명으로 둔다.

- 학교: `깊은결학교`
- 핵심 기록물의 학생·독자용 별칭: `빈자리 도감`
- 한국 측 운영·지원 법인: `경계생태협력재단`

모두 `candidate`이며 정본 교명·출판명·법인명으로 확정하지 않는다.

# 1. 깊은결학교

## 선택 이유

- 같은 현실의 더 깊은 생태 위상이라는 세계관을 한국어 감각으로 암시한다.
- 한자 장식·문파·마법학교 표현 없이 동양 중심 작품의 정체성을 만든다.
- 통학·가족·일반 교과가 존재하는 현대 학교 이름으로 사용할 수 있다.
- 해외 학교를 한국식 체계의 분교로 만들 필요가 없다.

## 제한

- 법적 교명 여부는 학교 제도 조사 뒤 확정한다.
- 학교 이름의 어원을 장황한 세계관 설명으로 사용하지 않는다.
- 해외 지역의 학교 이름과 분류를 `깊은결식`으로 통일하지 않는다.
- 영문 `Gipeungyeol School`과 `Deepgrain School`은 작업표기일 뿐이다.

# 2. 빈자리 도감

## 선택 이유

- 생물의 멸종·미확인 상태뿐 아니라 삭제된 서명, 누락된 당사자, 전가된 부담을 함께 가리킨다.
- 만능 정답책이 아니라 기록의 공백을 찾는 맥거핀 기능에 적합하다.
- 짧고 기억하기 쉬우며 청소년·성인 독자에게 다른 의미층을 제공한다.

## 조건

기존 멸종동물 서적 `자연의 빈 자리`와 의미 영역이 인접하므로 현재는 내부 작업명으로만 유지한다.

출판용 정본 검토 시 다음 대체안을 함께 비교한다.

- 미기록 도감
- 빈칸 도감
- 빠진 기록장
- 공식명과 학생 별칭의 이중 명명

## 공식 기록과의 분리

- 학생 별칭: 빈자리 도감
- 공식 문서: 경계생태 현장대장, 분류·구조 기록, 판본 번호
- 해외 기록: 각 지역의 독립 자기명칭

# 3. 경계생태협력재단

## 선택 이유

- 현대 한국의 공익법인·학교 지원·연구·피해 지원 구조에 자연스럽다.
- `협력`이 분산 관할과 공동 대응 원칙을 반영한다.
- 정부 비밀부처나 범아시아 중앙 권력처럼 보이지 않는다.
- 판타지적 이름이 과밀해지는 것을 막는 현실 행정층 역할을 한다.

## 직접 갖지 않는 권한

- 경찰 수사
- 사법·징계 최종 판단
- 모든 생물의 지성·권리 판정
- 보호자 동의 대체
- 국제 회랑 강제 폐쇄
- 학교 사고의 자체 종결

## 약칭

일상 대화에서는 `협력재단`을 우선 사용한다.

# 명명 층위

## 독자·학생 층

- 깊은결학교
- 빈자리 도감

## 현실 행정 층

- 경계생태협력재단
- 경계생태 현장대장
- 일반 사고기록+제한 부속기록

## 국제·해외 층

지역별 자기명칭을 사용한다. 한국 작업명을 국제 공통어로 승격하지 않는다.

# 보류

- 작품 제목
- 시리즈 제목
- 학교의 법적 정식 명칭
- 학교 약칭·교표·교가·기숙 조직명
- 도감의 공식 판본명과 최초 제작자
- 재단의 구체 법인 형태·이사회·예산
- 범아시아 조정체 공식명
- 최종 영문명

# 재검토 조건

- 실존 학교·출판물·법인·상표와 충돌
- 독자 테스트에서 유아적 또는 지나치게 행정적으로 인식
- `빈자리 도감`이 기존 멸종동물 작품과 혼동
- 재단이 실제 설계에서 마법부형 중앙기관으로 비대화
- 해외 학교를 한국식 명명으로 종속시키는 사용 발생
