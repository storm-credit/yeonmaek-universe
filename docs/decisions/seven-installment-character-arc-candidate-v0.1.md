# 7부제 인물·관계·능력·책임 후보 결정 기록 v0.1

## 결정

장기 인물 구조는 **홈베이스 고정+현장 회전 혼합형**을 1순위 `candidate`로 둔다.

- 가족·현실 친구·학교 동료·멘토의 관계는 장기 누적
- 부제작별 현장 핵심팀은 2~4명 조합으로 회전
- 국내·해외 현지 당사자는 독립 욕망과 최종 지역 결정권 보유
- 고정 삼인조와 주인공 허브 독점을 모두 피함

## 장기 핵심 기능

1. 연결 관측자 — 주인공
2. 절차·성과형 학교 동료
3. 관계·생태형 학교 동료
4. 현실 생활 친구·독립 기록자
5. 보호자·가족 앵커
6. 멘토·현장 안전 책임자
7. 비인간 당사자·이동권 주체

기능은 인물의 이름·성별·지역·가정형태와 자동 연결하지 않는다.

## 주인공 성장 축

| 부제작 | 성장의 핵심 |
|---|---|
| 1 | 혼자 관찰→도움 요청·기록 공유 |
| 2 | 인정 욕구→성과보다 당사자 거부권 |
| 3 | 표준 적용→다중 판본·기준 보류 |
| 4 | 국제 유능함→번역 불확실성·결정권 양도 |
| 5 | 전면 공개 충동→제한 공개·증거·이의 절차 |
| 6 | 늦지 않기 위한 통제→독점권 사용과 결과 책임 |
| 7 | 자신의 포기만으로 해결하려 함→권한 분산·감사·지속 참여 |

능력 상승은 공격 출력이 아니라 불확실성·동의·권한·책임을 다루는 능력이다.

## 권한 상승

- 예비 관찰자
- 감독 아래 기록·철수 보조
- 제한된 팀 역할
- 국내 학단 역할
- 국제 공동 현장 보조
- 공식 권한 제한 속 독립 기록 책임
- 제한 독점권 사용과 감사 책임
- 독점권 포기 뒤 공동관리 견습·감사·지역 참여

주인공의 특수 관측은 유일한 정답이 아니며 장소·상태·관계 열쇠와 타인의 기록이 필요하다.

## 학교 동료 분화

### 절차·성과형

규칙을 맹신하는 인물에서 감사 가능한 절차·이의 제기·책임 구조를 설계하는 인물로 성장한다. 후반 중앙 통제의 일부 장점을 지지할 수 있으나 악역으로 고정하지 않는다.

### 관계·생태형

관계와 직감을 우선하는 인물에서 당사자 해석의 한계와 기록·동의 절차의 필요성을 배우는 인물로 성장한다. 중앙 통제 반대가 자동 도덕 정답이 아니다.

두 인물은 서로의 강점을 한 번 이상 사용하고 자기 강점의 그림자로 실패한다.

## 현실 친구

- 학교 밖 생활 변화와 독립 기록을 보존
- 주인공의 서술을 반증 가능
- 폭로 장치가 아니라 공개·비공개·증거 보존을 독립 판단
- 다른 학교·진로·지역 이동과 연락 재협상 가능

## 가족

- 허락자·걱정 역할이 아니라 학적·의료·통학·계약·경제·거주 결정권자
- 예비과정, 기숙, 국내 현장, 해외 참여, 정보 공개마다 동의 범위 재협상
- 후반에는 학교와 주인공 모두에 책임 요구
- 최종에는 주인공의 자기결정과 가족 관계 조건을 다시 정함

## 멘토

- 안전·철수·절차의 실제 전문성을 유지
- 과거 타협·침묵·제한된 정보·직책 책임 가능
- 갑작스러운 흑막 전환 금지
- 현재 협력과 과거 책임이 동시에 성립
- 사과가 직책·자격·관계 결과를 지우지 않음

## 비인간 당사자·동행 관계

- 인간과 독립된 서식·무리·이동·관계 목표 보유
- 거부·이탈·비공개·다른 인간과 협력 가능
- 7부제 전체 고정 마스코트 의무 없음
- 진화·희귀도보다 신뢰·거리·의사소통·공동 선택 변화
- 인간식 언어·계약을 받아들여야만 권리를 얻는 구조 금지

## 작품별 현장 조합 후보

| 부제작 | 핵심 조합 |
|---|---|
| 1 | 주인공+가족/현실 전문직+멘토 |
| 2 | 주인공+학교 동료 2명+비인간 당사자 |
| 3 | 주인공+학교 동료 1명+현지 또래·공동체 |
| 4 | 주인공+현지 파트너+학교 안전 책임자 |
| 5 | 주인공+현실 친구+가족+학교 내부 이의 제기자 |
| 6 | 주인공+서로 다른 선택의 동료·멘토·기관 팀 |
| 7 | 현장 핵심 4~6명 이내+분산 지역 관계망 |

이는 기능 배치 후보이며 고정 등장 명단이 아니다.

## 인물 예산

- 부제작별 현장 핵심팀: 2~4명 기본
- 부제작별 신규 핵심 인물: 1~3명 기본 상한
- 최종부 현장 핵심 행동 인물: 4~6명 이내
- 재등장하지 않을 인물은 필요 이상 상세 프로필 금지
- 상태: `active / distant / exited / local-only / unresolved`

## 비가역 이탈 수단

죽음 외에도 다음을 사용한다.

- 전학·중도 철회
- 현지 장기 체류
- 진로·전문화 분화
- 기록 공유 거부
- 동행 관계 철회
- 멘토 직책·자격 제한
- 가족의 기숙·해외 동의 철회
- 친밀성 감소
- 독점 접근권 상실
- 유물 반환·공동 보관·폐기

## 하드 가드레일

1. 동일 3인 팀을 모든 부제작에 강제하지 않는다.
2. 대형막마다 주인공 없이 작동하는 관계·협력·갈등 최소 1개.
3. 주인공 특수성은 해결 독점이 아니라 권한 유혹과 부담을 키운다.
4. 가족·현실 친구·멘토는 각각 독립 욕망과 선택 결과를 가진다.
5. 비인간 당사자는 마스코트·펫·진화 트리로 축소하지 않는다.
6. 후반 분열은 동일 결론으로 화해하지 않아도 공동 행동 가능.
7. 이름·성별·가정형태·지역 배경 확정 전 기능 스왑 테스트.

## 아직 확정하지 않는 것

- 주인공과 핵심 인물 이름
- 성별·외형·가정형태·경제 배경
- 정확한 고정 핵심 인물 수
- 부제작 6의 중앙 통제 지지자
- 전학·이탈·졸업 경로
- 특정 인물의 죽음
- 비인간 당사자의 종·형태·언어
