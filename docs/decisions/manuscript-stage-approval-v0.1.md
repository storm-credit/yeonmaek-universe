# 원고 단계 승인 기록 v0.1

사용자가 `원고 단계 승인`을 명시했다.

승인 범위:
- 첫 부제작 15장 초고
- 시점·문체·서술거리 선택
- 장별 브리프·원고·검토·수정
- 설계 대비 편차 기록

승인 제외:
- 작업 명칭의 최종 canon 확정
- 부제작 2~7 원고
- 법률·상표·출판 판단
- 설계에 없는 대형 설정 추가
