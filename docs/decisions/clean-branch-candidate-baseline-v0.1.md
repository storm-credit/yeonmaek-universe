# 설정집·설계도 정리 브랜치 후보 기준선 v0.1

## 교정 사유

기존 문서 일부는 사용자의 `이어서진행`을 7부제·117장·200화 및 실제 원고 작성에 대한 포괄 승인으로 해석했다. 현재 확인된 사용자 의도는 세계관 설정집과 이야기 설계도 완성이며, 실제 소설 원고 작성 승인은 성립하지 않은 것으로 교정한다.

## 현재 유지 가능한 후보

- 연맥 세계의 핵심 원리와 다층 생태 구조
- 학교·기관·지역·생태·권리·능력 체계
- 서하진·유나를 포함한 인물 후보와 관계 기능
- 7부제 장기 성장 구조 후보
- 부제별 사건·장·장면 카드·복선·연표·권한 구조
- 집필 지침과 검토 규칙

## 인간 승인 전 확정하지 않는 항목

- 7부제 최종 채택
- 총 117장
- 웹연재 200화
- 주인공·조연의 최종 이름·성별·가족 관계
- 태국·수문·검역·생태 사건의 최종 사용
- 제목·상표·출판·플랫폼

## 금지 범위

- 실제 소설 본문 생성
- 장별 draft 생성
- 연재 화 원고 생성
- 사용자의 일반적인 `이어서진행`을 원고 승인으로 해석
- 원고 완료·인간 검토 준비 완료 상태 선언

## 승인 규칙

실제 원고 단계는 사용자가 작품명과 범위를 특정하여 명시적으로 승인한 경우에만 시작한다. 예: `제1부 1장 본문 집필을 승인한다.` 그 전까지 모든 서사 산출물은 설정집·설계도·장면 카드 수준에 머문다.

## 보존 규칙

기존 전체 원고와 관련 패키지는 `archive/full-saga-draft-unapproved` 브랜치에 보존한다. 정리 브랜치에서 제외된 파일은 삭제된 자료가 아니라 비정본 보관 자료다.
