# 첫 부제작 원고 직전 설계 패키지 후보

## 작업 제목

`《겹길: 사라진 통학로》`

메인명 `겹길`과 부제 `사라진 통학로` 모두 제목 문법 시험용 `candidate`다. 실제 독자 발음·표지·상표·출판 검토 뒤 교체 가능하다. 이전 작업 메인명 `틈너머`는 `superseded working title`로 보존한다.

## 도입 구조

**가족·통학 현실 사건 우선형**.

학교 초대가 이야기를 시작하지 않는다. 현실 통학 동선의 반복 불일치가 가족·주민·교통·학교 기록과 충돌하며 학교는 여러 대응 주체 중 하나로 등장한다.

## 시작 상태

- 주인공: 만 12세 전후, 일반 학적 유지
- 이상을 숨기고 더 정확히 관찰하면 혼자 해결할 수 있다고 믿음
- 가족: 반복 일정·연락·안전 문제만 알고 숨은 생태는 모름
- 학교: 정식 소속 전, 예비·외래 관찰 가능성
- 기록: 해당 회랑을 안정 구역, 이동 주체를 고정 위험종으로 분류

## 중심 질문

> 이상을 숨기고 혼자 해결하는 것이 가족과 다른 존재를 지키는 길인가?

## 독립 사건

**잘못 분류된 통학 회랑 사건**.

- 표면: 통학 회랑 불안정과 사람·비인간 이동 주체 고립
- 내부: 이동 주체 오분류와 학교 안전 부담의 외부 생활권 전가
- 현장 해결: 고립 구조, 이동 경로 확보, 표면 교통·생활 정상화
- 구조 해결: 회랑 폐쇄·공동 점검·기록 범위 확대·분류 정정 절차

## 미스터리 질문 사다리

1. 왜 같은 통학 구간에서 사람·기록·시간이 어긋나는가?
2. 왜 학교 지도는 안정으로 표시하는가?
3. 왜 안전 폐쇄 뒤 위험이 다른 구간으로 이동하는가?
4. 현재 고립과 이동 문제를 어떻게 끝내는가?
5. 왜 다른 기록에도 같은 삭제 항목 ID가 남아 있는가?

1~4는 첫 작품에서 해결한다. 5만 장기 미확인으로 남긴다.

## 공정 단서

- 현상이 감정이 아니라 시간·공사·교통 조건과 연동
- 안정 지도와 주민·가족·통학 기록의 반복 불일치
- 폐쇄 뒤 다른 구간으로 증상 이동
- 비인간 당사자가 지정 안전 경로를 반복 거부
- 수리·차단이 위험을 제거하지 않고 위치만 변경
- 학교 기록의 관찰 범위가 오래전에 고정됨

주인공 관측만으로 답을 얻지 않으며 가족 연락 기록, 현실 친구 자료, 주민·시설·교통 정보, 학교 기록, 현장 행동을 교차 검증한다.

## 인물 기능

- 주인공: 연결 관측자
- 학교 동료 2명: 절차·성과 / 관계·생태
- 현실 친구: 독립 생활 기록
- 가족: 학적·의료·통학·동의
- 멘토: 구조·철수·안전
- 비인간 당사자: 독립 이동 목표·거부권

모두 같은 비중이 아니며 현장 단계별 핵심 조합은 2~4명이다.

## 수집 예산

- 중심: 도감 항목 1개와 정정 이력
- 보조: 회랑 지도 구역 1개
- 장기 미확인: 삭제 항목 ID 1개
- 동행종 소유·유물 획득·영웅 목록 전면화 없음

## 반복 루프

`통학 이상→가족·현실 전문직→예비학교 관찰→감독 구조→집·통학·기록 변화`

## 종료 상태

- 사람과 이동 주체의 현재 고립 해결
- 통학·표면 생활 정상화와 잔여 제한 명시
- 도감 분류와 지도 상태 정정
- 학교·현실 기관 공동 점검 절차 도입
- 주인공은 도움 요청과 기록 공유를 선택
- 가족은 통학·의료·정보·철회 조건 아래 예비과정 참여에 동의
- 비인간 당사자는 학교·주인공에게 남을 의무 없이 이동·관계 선택

## 이중 결말

### 현장 결말

구조·경로·생활 정상화.

### 구조 결말

기록 범위와 정정 권한 변화, 가족과 학교의 조건부 관계 시작.

## 둘째 부제작과의 관계

첫 작품은 현재 사건과 감정을 완결한다. 둘째 작품의 새 질문은 정식 학교 공동체 안에서 보호·성과·소유가 충돌하는 문제다.

정식 입학식·대표 경기·동행 관계·상급 수업을 첫 작품에서 미리 소진하지 않는다.

## 학교 현실 후보 연결

- 표면 학적·일반 교과·출결·보건·통학은 인가 학교가 담당한다.
- 예비·외래 관찰과 현장교육은 별도 현장교육센터 candidate의 감독·철수·감사 규칙을 사용한다.
- 실제 법적 명칭과 운영 가능성은 교육행정·학교안전·법률 전문가 검토 전 canon으로 확정하지 않는다.

## 하드 가드레일

- 주인공 혈통·예언·전생 금지
- 주인공 단독 해독·구조 금지
- 학교·성인 무능화 금지
- 이동 주체 처치·포획 금지
- 도감 자동 해답 금지
- 기억 삭제·가짜 유학·가족 배제 금지
- 현장 사건과 구조 변화 모두 첫 작품 안에서 완결
- 세계적 음모·최종 악당 설명 금지
- 장기 미확인 항목 1개 이하

## 아직 확정하지 않는 것

- 최종 메인 시리즈명과 부제
- 서울·수도권 내 정확한 지역과 노선
- 이동 주체의 종·형태·자기명칭
- 인물 이름·성별·가정형태
- 사건의 세부 순서·장면·회차
- 학교의 실제 법적 명칭과 설립 가능성
