# 첫 부제작 원고 직전 설계 패키지 후보 v0.2

## 작업 제목

`《겹길: 사라진 통학로》`

메인명 `겹길`과 부제 `사라진 통학로` 모두 작업 `candidate`다. 실제 독자 발음·표지·상표·출판 검토 뒤 교체 가능하다. 이전 메인 작업명 `틈너머`는 `superseded working title`이다.

## 한 문장

완전한 증거를 모을 때까지 이상을 숨기던 만 12세 아이가, 안전 공사와 비로 두 이동로가 순서대로 닫히는 통학 구간에서 `고정 위험종`으로 오분류된 여울띠 가족군을 발견하고, 불완전한 기록을 공유해 다른 사람과 당사자에게 판단권을 넘기는 법을 배운다.

## 도입 구조

**가족·통학 현실 사건 우선형**.

학교 초대가 이야기를 시작하지 않는다. 현실 통학 동선의 반복 불일치가 가족·주민·교통·학교 기록과 충돌하며 학교는 여러 대응 주체 중 하나로 등장한다.

## 생활권 candidate

**서안 생활권** — 서울 서남권의 하천·철도·산업/주거 경계 기능을 합친 창작 생활권.

- 집: 하천에서 도보 10~15분 떨어진 중층 주거지
- 평시 통학: 현실 대중교통 1회 환승, 편도 35~50분
- 전면 거점: 집·정류장 / 사건 통학 구간 / 예비학교
- 보조 거점: 동네 상가·주민 기록 / 현장교육센터
- 실재 자치구·역·교량·학교·취약 시설 1:1 사용 금지

## 시작 상태

- 주인공: 만 12세 전후, 일반 학적 유지
- 이상을 숨기고 더 정확히 관찰하면 혼자 해결할 수 있다고 믿음
- 가족: 반복 일정·연락·안전 문제만 알고 숨은 생태는 모름
- 학교: 정식 소속 전, 예비·외래 관찰 가능성
- 기록: 해당 회랑을 안정 구역, 여울띠를 고정 위험종으로 분류
- 시설: 현실 안전 결함을 해결하기 위한 보수가 예정됨
- 날씨: 하천 인접 보행 구간의 예방 통제 가능성이 공지됨

## 중심 질문

> 이상을 숨기고 혼자 해결하는 것이 가족과 다른 존재를 지키는 길인가?

## 독립 사건

**잘못 분류된 통학 회랑 사건**.

- 표면: 통학 회랑 불안정과 사람·여울띠 가족군의 이동 고립
- 내부: 이동 당사자 오분류와 학교 안전 부담의 외부 생활권 전가
- 시간 압력: 비 때문에 먼저 닫히는 길 / 안전 공사 때문에 나중에 닫히는 길
- 현장 해결: 사람 접근 통제 유지, 공정 순서 변경, 복수 경로 제공, 여울띠 독립 이동, 현실 보수 재개
- 구조 해결: 회랑 폐쇄·공동 점검·최소 정보 공유·가족/학생 절차·분류 정정

## 비인간 이동 당사자

### 작업명 `여울띠`

- 5~12개체의 가족군
- 납작한 이중 막 형태, 개체마다 다른 밝은 마디 배열
- 낮은 진동·압력·구조 연속성을 감지
- 도시 주변 부담 입자를 축적하고 계절 방출지로 이동
- 이동 뒤 남은 띠막과 고립 방출 사고만 관찰돼 고정 공격 위험종으로 오분류
- 접근·경고·거부·거리 두기·재협상을 간격·방향 반전·떨림으로 표현
- 주인공만 이해하지 않으며 여러 기록을 교차해 현재 행동만 추정
- 사건 뒤 주인공이나 학교에 남지 않고 독립 이동

## 활성 인물 candidate

| ID | 작업 이름 | 기능 | 첫 작품 변화 |
|---|---|---|---|
| P1 | 서하진 | 연결 관측자 | 완전한 정답을 기다리다 불완전한 기록을 공유하고 판단권을 넘김 |
| P2 | 문하람 | 절차·성과 동료 | 비공식 기록 저평가를 수정하되 신고·철수 절차의 실제 효용을 증명 |
| P3 | 차도겸 | 관계·생태 동료 | 거부를 대신 번역하지 않고 환경 조건 재검토를 요구 |
| P4 | 강유나 | 현실 친구·독립 기록자 | 통학·공사 기록의 공개 범위를 직접 결정하고 관계의 정보 비대칭을 문제 삼음 |
| P5 | 서지현 | 가족 앵커 | 학적·의료·통학·정보·철회 조건을 기관과 협상 |
| P6 | 오세린 | 센터 안전 책임자 | 학생 행동 범위와 철수를 결정하고 외부 전문팀에 인계 |
| P7 | 여울띠 가족군 | 독립 이동 당사자 | 인간 경로를 거부·시험하고 방출지로 독립 이동 |

모든 인간 이름·성별·직업은 `working candidate`다.

## 등장·조합 규칙

- 생활 이상 발견: P1+P4+P5
- 학교 관찰: P1+P2 또는 P3+P6
- 초기 오판: P1+P2
- 거부 패턴 확인: P1+P3+P7
- 학생 철수: P5+P6
- 물리 구조: 외부 성인 전문팀+시설/교통 책임자+P7 경로 선택
- 기록 정정·참여 조건: P1+P4+P5+P6, P7의 이동 결과

P1/P2/P3가 항상 함께 있지 않는다.

## 욕망자·책임자 구조

### 학생·가족

- P1: 완전한 증거 욕망, 보고 지연, 불완전한 기록 공유로 변화
- P2: 절차 신뢰, 공식 신고·철수의 옳음과 비공식 기록 저평가의 한계
- P3: 거부권 존중, 독점 번역 금지
- P4: 관계 정직성과 기록 공개 범위
- P5: 미성년 안전·학적·의료·귀가·철회 결정
- P6: 학생 범위·철수·외부 인계

### 성인 전문 책임

- 시설 운영 책임자: 공정 정지·순서 변경·부분 재개
- 교통/수방 책임자: 현실 접근 통제·대체 동선
- 외부 구조 책임자: 안전선·진입·구조·철수
- 학교 기록 책임자: 임시 분류·최소 정보 공유·사후 정정

학생은 법적·물리적 지휘를 대신하지 않는다.

## 실패 단계

1. P1의 보고 지연으로 공식 검토 창이 줄어듦.
2. 인간이 연 짧은 우회로를 여울띠가 거부해 `비협조적 위험종` 오판이 강화됨.
3. 강우 통제로 대체 경로가 닫히며 무리 간격과 통학 이상이 악화됨.
4. P1은 철수해 물리 해결을 통제할 수 없게 됨.
5. 공정을 그대로 진행하면 장기 경로 단절, 전면 취소하면 사람 안전 결함이 남음.

## 클라이맥스 선택

P1은 위험 구역에서 능력을 각성하거나 정답을 발표하지 않는다.

> 확정하지 못한 부분과 모르는 것을 표시한 채 기록을 공유하고, 성인 전문 책임자와 여울띠에게 판단권을 넘긴다.

성인팀은 현실 통제를 유지하며 공정 순서를 바꾸고 복수 경로를 제공한다. 여울띠가 시험·거부·선택해 이동을 완성한다.

## 미스터리 질문 사다리

1. 왜 같은 통학 구간에서 사람·기록·시간이 어긋나는가?
2. 왜 학교 지도는 안정으로 표시하는가?
3. 왜 여울띠는 인간이 연 가장 짧은 길을 거부하는가?
4. 왜 한 길을 닫으면 위험이 다른 구간으로 이동하는가?
5. 현재 사람과 여울띠의 고립을 어떻게 끝내는가?
6. 왜 다른 기록에도 같은 삭제 항목 ID가 남아 있는가?

1~5는 첫 작품에서 해결한다. 6만 장기 미확인으로 남긴다.

## 공정 단서

- 현상이 감정이 아니라 시간·공사·교통·강우 조건과 연동
- 안정 지도와 주민·가족·통학 기록의 반복 불일치
- 폐쇄 뒤 다른 구간으로 증상 이동
- 벽면 띠막과 살아 있는 여울띠의 행동 차이
- 여울띠가 가장 짧은 안전 경로를 반복 거부
- 수리·차단이 위험을 제거하지 않고 위치만 변경
- 학교 기록의 관찰 범위가 공사 전 시설 조건에 고정
- 시설 센서·주민 시간 기록·학교 지도·여울띠 행동이 합쳐질 때만 공정 변경 근거 성립

## 수집 예산

- 중심: 여울띠 도감 항목 1개와 정정 이력
- 보조: 통학 회랑 지도 구역 1개
- 시각 구별: 개체별 밝은 마디 배열과 띠막 무늬
- 상태 보상: 접근 허용·거부·이동 완료·보호 폐쇄·위치 비공개
- 장기 미확인: 삭제 항목 ID 1개
- 유물 획득·영웅 목록·동행 계약 전면화 없음

## 반복 루프

`통학 이상→가족·현실 기록→예비학교 관찰→감독 철수→성인 구조·당사자 선택→집·통학·기록 변화`

## 종료 상태

- 사람과 여울띠의 현재 고립 해결
- 강우 통제와 현실 보수의 안전 목적 유지
- 보수·교통 일정 지연과 추가 안전 부담 발생
- 일부 경로 장기 보호 폐쇄
- 통학·표면 생활 정상화와 잔여 제한 명시
- 도감 분류와 지도 상태 정정
- 학교·현실 기관 최소 정보·공동 점검 절차 도입
- P1은 도움 요청·기록 공유·판단권 이양을 선택
- P1–P4와 가족 관계에 정보 비대칭 후유증이 남음
- 가족은 통학·의료·정보·철회 조건 아래 예비과정 참여에 동의
- 여울띠는 학교·주인공에게 남을 의무 없이 독립 이동

## 이중 결말

### 현장 결말

여울띠 이동, 사람 접근·통학·시설 안전 확보, 현실 보수 재개.

### 구조 결말

기록 범위와 정정 권한 변화, 최소 정보 공유, 가족과 학교의 조건부 관계 시작.

독자가 보는 마지막 변화는 회의가 아니라 바뀐 통학 경로·닫힌 구간·가족 연락 방식·도감 정정 표식·여울띠가 떠난 빈 공간이다.

## 학교 현실 연결

- 인가 학교: 학적·교과·출결·보건·통학
- 별도 현장교육센터: 예비 관찰·장비·감독·철수
- 외부 독립 주체: 시설·교통·수방·구조·의료·권리·분쟁
- 보호자·학생 동의는 단계별이며 면책서가 아님

실제 법적 명칭과 운영 가능성은 전문가 검토 전 canon으로 확정하지 않는다.

## 둘째 부제작과의 관계

첫 작품은 현재 사건과 감정을 완결한다. 둘째 작품의 새 질문은 정식 학교 공동체 안에서 보호·성과·소유가 충돌하는 문제다.

정식 입학식·대표 경기·철회 가능한 동행 관계·상급 수업을 첫 작품에서 미리 소진하지 않는다.

## 하드 가드레일

- 주인공 혈통·예언·전생 금지
- 주인공 단독 해독·구조·지휘 금지
- 학교·성인 전문직 무능화 금지
- 공사·시설·지역 악당화 금지
- 여울띠 처치·포획·계약·영구 동행 금지
- 도감 자동 해답 금지
- 기억 삭제·가짜 유학·가족 배제 금지
- 현실 풍수해·하천 오염의 초자연 원인화 금지
- 현장 사건과 구조 변화 모두 첫 작품 안에서 완결
- 세계적 음모·최종 악당 설명 금지
- 장기 미확인 항목 1개 이하
