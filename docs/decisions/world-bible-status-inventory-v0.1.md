# 세계 설정집 상태 인벤토리 v0.1

## 목적

상세 설정집을 조립하기 전에 현재 핵심 설정이 어떤 상태이며 무엇을 근거로 사용되는지 고정한다.

이 문서는 1차 고영향 인벤토리다. 모든 보조·연구·테스트 파일의 전수 목록은 후속 갱신에서 추가한다.

## 상태 우선순위

동일 개념이 여러 문서에 있을 때 다음 순서를 적용한다.

1. 최신 작가 의도 기록
2. 최신 decision 문서
3. 통합 기준선·사가 지도
4. 도메인별 candidate 문서
5. 테스트·레드팀
6. 과거 후보·연구·초기 질문

낮은 순위 문서가 높은 순위 문서와 충돌하면 삭제하지 않고 `superseded / reframing required`로 표시한다.
