# 출처 검증형 순수 브랜치 기준선 v0.1

## 목적

이 브랜치는 승인되지 않은 원고와 다른 프로젝트에서 유입된 구조를 제거하는 수준을 넘어, 모든 설정·설계 자산의 출처를 다시 검증하기 위해 `main`에서 직접 분기했다.

## 현재 확정된 범위

사용자 대화에서 직접 확인된 항목만 작업 기준으로 둔다.

- 현재 한국에서 시작하는 숨은 세계 판타지
- 동양권의 수련·의례·지식 전통을 중심 관점으로 사용
- 범아시아 확장이 가능한 세계 구조
- 학교는 중요한 생활 무대이지만 세계 전체를 독점하지 않음
- 생물·지역 탐사·학교생활·수련·경이가 핵심 재미 축
- 해리포터의 기능적 장점은 분석하되 고유 장치와 대응 구조는 복제하지 않음
- 소설 원고보다 세계관·설정집·설계도를 먼저 완성
- 실제 소설 원고는 별도 명시 승인 전 작성 금지

## 모두 미정으로 되돌리는 항목

- 작품 길이와 연재 회차 수
- 권수·부제작 수·막 수
- 장 수·장면 카드 수
- 주인공과 조연의 이름
- 특정 인물 관계와 이탈·죽음·졸업 경로
- 장기 맥거핀·복선·결말
- 특정 지역과 해외 무대
- 학교 이름·기관명·고유 용어
- 최종 정본 상태

## 이관 등급

- `P0-direct`: 사용자가 직접 명시한 사실
- `P1-derived`: 사용자 의도에서 직접 도출되며 다른 프로젝트 의존이 없는 구조
- `P2-research`: 외부 조사 기반이며 출처·문화 감수가 필요한 자료
- `Q-quarantine`: 출처가 불명확하거나 오염 가능성이 있는 기존 자료
- `X-reject`: 다른 프로젝트에서 유입된 것으로 확인된 자료

P0와 검증된 P1만 이 브랜치의 활성 기준선으로 사용할 수 있다. P2는 조사 대기, Q는 격리, X는 이관 금지다.

## 금지

1. 기존 clean 브랜치의 파일을 일괄 복사하지 않는다.
2. 7부제·117장·234장면·200화를 기본값으로 사용하지 않는다.
3. 하진·유나·P-17·돌림패 등 기존 고유명과 장기 장치를 출처 확인 없이 채택하지 않는다.
4. `complete`, `author-approved`, `final canon` 상태를 자동 부여하지 않는다.
5. 설정집을 근거로 원고·대사·완성 장면을 작성하지 않는다.

## 다음 순서

1. 사용자 직접 의도 원장 작성
2. 기존 clean 브랜치 파일별 출처 등급화
3. 세계 규칙·학교·탐사·수련·생태 자료 선별 이관
4. 오염 없는 설정집 목차 재구성
5. 이야기 규모와 구조를 백지에서 다시 후보화
