## 작가 승인 기준선

- 전체 구조: **5부 책임 성장형**
- 성장 단계: **관찰 → 중지 → 보조 → 수행 → 조율**
- 주인공 핵심: **돌아오는 길을 잘 만드는 아이**
- 최종 성장: 모든 길을 혼자 관리하지 않고 권한·도구·교육을 분산하는 조율자

## 완료

### 프로젝트 운영·출처 안전

- 작가 직접 확인 범위
- 교차 프로젝트 오염 격리 원장
- 세계관 재구축 로드맵
- 자동 진행·컨텍스트 인수인계 계약
- 역할 분리형 오케스트레이션 운영안

### 세계관

- 세계관 핵심 약속과 현실 접점
- 세계 규칙·명명·길·장소·생태 분류
- 수련·능력·교육기관 구조
- 학교·탐사·수집·대표 경기 반복 루프
- 지역·기관·세력 구조
- 역사·시대 기준선

### 설정집

- 공통 카탈로그 스키마
- 지역·기관·세력 최초 카탈로그
- 생물·현상 12종 최초 카탈로그
- 유물·도구 12종 최초 카탈로그
- 장편 확장 목표: 거점 25, 생물·현상 36, 유물·도구 30, 교과 12
- 확장 시 복제·희귀도·전투력 채우기 방지 규칙

### 인물·관계

- 주인공 핵심 정체성 작가 승인
- 주인공 정본 프로필 후보
- 핵심 인물 9역 정본 후보
- 5부 관계 변화표
- 가족·친구·동료·경쟁자·교사·현장 멘토의 책임 변화

### 전체 이야기 설계도

- 5부 책임 성장형 작가 승인
- 5부 전체 줄거리
- 각 부 3막·9시퀀스
- 45개 장 기능 단위
- 복선 10개와 정확한 제시·재등장·회수 위치
- 최종 결말 기능: 권한 분산과 다음 세대의 일상 복귀

### 감사·최종 패키지

- 기존 200화·7부제·117장·234장면 미사용 확인
- 기존 인물명·맥거핀·원고·결말 미사용 확인
- 표면적 해리포터 복제 방지 감사
- 청소년 권한·안전 감사
- 세계 규칙·인물·사건 인과·복선 교차 감사
- 최종 패키지 인덱스 v1.0

## 현재 판정

- 세계관: 원고 이전 내부 완성
- 설정집: 핵심 구조·최초 카탈로그·확장 규칙 완성
- 인물 설계: 고유명 외 핵심 역할·욕망·관계 변화 완성
- 전체 이야기 설계도: 5부·3막·9시퀀스·장 기능·복선 배치 완성
- 실제 원고: 잠금

## 작가 취향 확정이 필요한 항목

다음은 자동으로 임의 확정하지 않는다.

- 주인공·조연 고유명
- 성별과 정확한 학년
- 가족 구성 상세
- 각 부 정식 제목
- 지역·기관·생물·도구의 최종 고유명
- 장 수·회차 수·플랫폼 분량

이 항목들은 세계관·설정집·설계도의 논리적 완성을 막지 않는다.
