# 역할 분리형 오케스트레이션 운영안 v0.1

## 총괄

총괄 오케스트레이터는 모든 산출물을 하나의 세계관 규칙과 출처 원장 아래 통합한다. 실제 별도 에이전트가 저장소에 독립적으로 접근하는 방식이 아니라, 역할별 검토 관점을 분리해 순차·교차 감사하는 방식으로 운영한다.

## 역할

1. 세계 규칙 설계자: 핵심 약속, 힘의 비용, 현실 접점, 금지 규칙 관리.
2. 생태 설계자: 생물·현상·장소 관계와 비소유 원칙 관리.
3. 유물·도구 설계자: 제작 계보, 사용 비용, 안전·반납 규칙 관리.
4. 역사 설계자: 시대 구분, 제도 변화, 기록 편향과 현재 영향 관리.
5. 기관·정치 설계자: 권한 분리, 세력 가치축, 주민 권리 관리.
6. 학교·청소년 매력 설계자: 수업, 동아리, 경기, 축제, 성장 보상 관리.
7. 인물 설계자: 주인공 후보, 관계망, 욕망·약점·책임 성장 관리.
8. 사가 설계자: 작품 수 후보, 장기 서사, 작품별 완결과 확장성 관리.
9. 복선·연표 감사자: 원인·결과·나이·이동·공개 정보 관리.
10. 독창성·오염 감사자: 타 프로젝트 숫자·인물·사건·결말 유입 검사.

## 교차 승인 규칙

- 새 설정은 최소 두 역할 관점에서 충돌 검사를 거친다.
- 생물·유물·기관은 권리와 책임 주체가 반드시 기록되어야 한다.
- 이야기 구조는 세계관에서 파생되어야 하며 원고나 회차 목표에서 역산하지 않는다.
- 후보는 사용자 승인 전까지 P1 또는 P2 상태를 유지한다.
- 실제 원고는 작성하지 않는다.
