## 핵심 사건

문답결 배열·빗마디 압력 변화·위치 비공개·시설 제한 경고가 국제 최소 코드에서 하나의 고위험 항목으로 합쳐진다. 자동 검역은 사람 안전을 실제로 높일 수 있지만 수문 운영 창을 놓치고 지역 생활·생태·시설 부담을 다른 곳으로 옮길 수 있다.

하진은 제한 기록 우선권과 수정 코드로 대피를 성공시키지만, 접근 순서와 번역 범위를 정하면서 현지 철회·대표·비공개를 다시 위험으로 남긴다.

## 클라이맥스

- 하진이 제한 접근 토큰을 현지 학생 기록자·통역 책임자에게 넘긴다.
- 국제 경보에는 사람·시설의 확정 위험과 미확인 생태 조건만 남긴다.
- 현지 수문 책임자가 단계 운영·중지·대체 동선을 결정한다.
- 문답결은 복수 경로를 거리 두기·배열 변화·철회로 시험한다.
- 검역팀은 전면 격리 대신 제한 관찰·재검증을 선택한다.

## 활성 인물

- 서하진·문하람·차도겸
- 강유나·서지현은 한국 생활·자료·동의 축
- 한국 학교 책임자
- 현지 학생 기록자
- 현지 통역·중재자
- 현지 수문 운영 책임자
- 현지 생태·권리 담당
- 국제 검역 책임자

현지 인물의 이름·가족·말투·문화 배경은 태국어·현지 감수 전 provisional이다.
