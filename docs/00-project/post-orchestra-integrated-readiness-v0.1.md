## 4. 학교 감정적 얼굴

중심 candidate: 관계가 자라는 수업형.

대표 반복 요소:
- 빈자리 수첩
- 두 기록 사이 수업
- 도서관 정정대
- 유리온실 배수정원
- 빈길 전시
- 장비 수리 시장
- 통학 아침 지도
- 금요일 중지 판단 공유

부제작 2에서 사건과 직접 무관한 학교생활을 25~30% 확보한다. 실제 10~15세가 입학하고 싶다고 느끼는지는 독자 테스트 전 미검증이다.

## 5. 7부제 장르 구분

1. 발견한다 — 도시 통학 미스터리
2. 경쟁하다 멈춘다 — 학교 스포츠·소속
3. 여행하고 다시 그린다 — 국내 수계 탐사
4. 번역하며 구조한다 — 해외 재난·번역 스릴러
5. 추적하고 공개 범위를 정한다 — 도시 사회 미스터리
6. 실제로 운용하고 제한한다 — 시스템 구조·권력 선택
7. 분산해 완수하고 떠난다 — 최종 임무·졸업

각 작품의 물리적 목표·시간 제한·클라이맥스 행동·수집 보상을 교환하지 않는다.

## 6. 수집 시각 언어

중심 인터페이스: 현장기록·정정형.

- 생물: 반투명 겹막·간격·접힘·진동
- 회랑: 지층선·끊긴 경로·보호된 공백
- 유물: 구조신호·모듈·사용 흔적
- 도감·지도: 관찰 스케치·판본 탭·정정 이력

실제 이미지가 아니라 인간 아트디렉터와 일러스트레이터에게 넘길 텍스트 사양이다. 흑백·색각·저시력·작은 화면 검토가 필요하다.
