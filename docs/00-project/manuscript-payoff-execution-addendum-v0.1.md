# 맥거핀·복선·결말 회수 실행 부속계약 v0.1

## 1. 기능을 섞지 않는다

모든 강조 요소를 다음 중 하나로 분류한다.

1. `MACGUFFIN` — 여러 욕망자를 움직이고 갈등의 추적 방향을 만든다.
2. `MYSTERY_CLUE` — 독자가 결론을 공정하게 추론할 근거다.
3. `SETUP_PAYOFF` — 앞의 행동·사물·규칙이 뒤의 선택과 결과를 가능하게 한다.
4. `CHARACTER_PROMISE` — 인물의 오신념·관계·약속·상처를 뒤에서 행동으로 회수한다.
5. `WORLD_PAYOFF` — 학교·기관·지도·법·생태 상태가 실제로 변경된다.
6. `MOTIF` — 의미를 누적하는 반복 이미지·문장·장소다. 비밀 정답이 없어도 된다.
7. `ATMOSPHERE_ONLY` — 분위기·현실감 기능을 수행한 뒤 종료한다.
8. `INTENTIONAL_PRIVATE` — 내용을 폭로하지 않고 접근 이력·근거·감사·기한으로 완결한다.

모든 소품과 배경을 맥거핀이나 복선으로 만들지 않는다.

## 2. 장·회차 브리프 필수 필드

앞으로 모든 장과 연재 화 브리프에는 아래를 기록한다.

- `plant_ids`: 이번 단위에서 새로 심는 ID
- `advance_ids`: 의미·오독·욕망자 충돌을 진전시키는 ID
- `payoff_ids`: 현재 회수하는 ID
- `carry_debt_ids`: 다음 단위로 넘기는 ID
- `motif_ids`: 정답 회수 없이 의미를 누적하는 ID
- `false_emphasis_check`: 독자가 복선으로 오해할 과도한 강조 여부

ID가 없는 생활·유머·풍경 장면도 허용한다. 장면 기능이 있으면 억지 복선을 넣지 않는다.

## 3. 작품 종료 조건

- 현재 사건 핵심 회수 부채: 0
- 현재 인물 감정 약속 부채: 0 또는 의도적 관계 미회복으로 명시
- 장기 부채: 소유자·다음 진전 위치·최종 회수 위치가 있음
- 의도적 비공개: 비공개 이유·접근 이력·감사자·재검증 기한이 있음
- 장기 떡밥이 현재 결말의 물리·관계·제도 해결을 대신하지 않음

## 4. 과잉 회수 방지

- 모든 묘사를 비밀 단서로 만들지 않는다.
- 같은 복선을 세 번 이상 반복할 때는 정보·관계·의미 중 하나가 달라져야 한다.
- 회수는 설명 문단만으로 끝내지 않고 선택·결과·관계·제도·공간 중 최소 하나를 바꾼다.
- 반전은 기존 단서를 무효화하지 않고 재해석한다.
- 맥거핀의 정체보다 누가 왜 원하고 어떤 비용을 감수하는지가 먼저다.

## 5. 하네스 연결

- H0: 활성 원장과 작품별 ID 잠금
- H1/H2: 장·화 브리프에 ID 삽입
- H8: 회차 보상과 단서 진전을 구분
- H9: 모든 강조 요소 분류·부채 추적
- H10: 부제작 현재 부채 청산
- H11: 대형막·사가 장기 부채 청산
- H12: 인간 독자가 복선을 공정하게 알아차렸는지 확인
