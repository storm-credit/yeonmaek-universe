# 자동 설계 완주 실행 큐 v0.2

## 목표

소설 원고를 쓰기 직전까지 필요한 세계관·메인 사가·부제작·수집 구조·동반 출판 설계를 `CLAUDE.md` 절차에 따라 자동으로 완주한다.

## 고정 작가 의도

- 같은 주인공이 여러 부제작에 걸쳐 성장하는 장기 성장형 메인 사가
- 한국의 학교·가족·현실 생활을 지속적인 홈베이스로 유지
- 각 부제작은 독립 사건과 감정적 결말을 가지며 메인 사가를 전진
- 부제작과 물리적 분권을 구분
- 핵심 독자 10~15세, 성인까지 읽는 크로스오버
- 수집욕구는 동행종·도감·지도·유물·영웅 기록 중심
- 본편 완결 후 같은 세계관의 도감·지도·외전·다른 시대 작품 확장 가능

## 각 게이트 공통 산출물

- 구조적으로 다른 4안
- 가장 단순한 안
- 설계 전 함정 체크
- 시나리오·삭제·독자 이해 테스트
- 독창성·연령 적합성·문화 무결성 레드팀
- 변경 영향도와 deprecated 보존
- 1순위 candidate와 후퇴안
- 다음 의존 작업

## 자동 중지 조건

- candidate를 canon으로 올려야만 다음 단계가 가능한 경우
- 실재 문화·종교·소수집단의 인간 현지 감수가 필요한 경우
- 상표·법률·출판 계약 판단이 필요한 경우
- 기존 canon을 삭제하는 레트콘이 필요한 경우
- 서로 양립할 수 없는 작가 의도가 발견된 경우

## 완료 정의

- 메인 사가→대형막→부제작→부제작 내부 막 계층 완성
- 주인공 연령·능력·관계·책임 성장선 연결
- 각 부제작 독립 사건과 전체 복선 회수 검증
- 수집축과 사건·인물·세계 진실 연결
- 한국 홈베이스와 해외 확장 균형 검증
- 동반 출판물 없이 본편 완결
- 원고 작성자가 첫 부제작 장면 설계에 진입 가능한 패키지 준비
- 미승인 사항과 인간 검토 사항 분리
