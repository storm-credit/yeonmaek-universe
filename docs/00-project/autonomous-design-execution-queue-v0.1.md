# 자동 설계 완주 실행 큐 v0.1

## 목표

소설 원고를 쓰기 직전까지 필요한 세계관·메인 사가·부제작·수집 구조·동반 출판 설계를 `CLAUDE.md` 절차에 따라 자동으로 완주한다.

## 고정 작가 의도

- 같은 주인공이 여러 부제작에 걸쳐 성장하는 장기 성장형 메인 사가
- 한국의 학교·가족·현실 생활을 지속적인 홈베이스로 유지
- 각 부제작은 독립 사건과 감정적 결말을 가지며 메인 사가를 전진
- 부제작과 물리적 분권을 구분
- 핵심 독자 10~15세, 성인까지 읽는 크로스오버
- 수집욕구는 동행종·도감·지도·유물·영웅 기록을 중심으로 설계
- 본편 완결 후 같은 세계관의 도감·지도·외전·다른 시대 작품 확장 가능

## 자동 실행 순서

1. #39 공유세계관·동반출판 전문 에이전트 추가
2. 장기 성장형 메인 사가 구조 4안 재설계
3. 기존 5권 완결 후보 영향 분석 및 deprecated/candidate 상태 정리
4. 메인 사가 부제작 수·성장 기간·대형막 배치 4안
5. 각 부제작의 중심 사건·미스터리·감정 변화·비가역 변화 설계
6. 수집욕구 시스템 4안과 공개 예산 설계
7. 메인 시리즈명 4안과 연령·발음·검색 충돌 테스트
8. #37 공유세계관 확장 구조
9. #38 도감·지도·기록물 출판선
10. #36 해외 지역 후보는 메인 사가 구조 확정 뒤 재배치하여 수행
11. 전 문서 인과·복선·문화·연속성 통합 레드팀
12. 원고 직전 설계 패키지와 미확정 승인 목록 작성

## 각 게이트 공통 산출물

- 구조적으로 다른 4안
- 가장 단순한 안
- 시나리오 테스트
- 맹점 훑기
- 독창성·연령 적합성·문화 무결성 레드팀
- 변경 영향도와 deprecated 보존
- 1순위 candidate 결정 기록
- 다음 의존 작업

## 자동 중지 조건

- candidate를 canon으로 올려야만 다음 단계가 가능한 경우
- 실재 문화·종교·소수집단의 인간 현지 감수가 필요한 경우
- 상표·법률·출판 계약 판단이 필요한 경우
- 기존 canon을 삭제하는 레트콘이 필요한 경우
- 서로 양립할 수 없는 작가 의도가 발견된 경우

그 외 사소한 명칭·파일 위치·순서·보수적 가정은 질문하지 않고 기록 후 진행한다.

## 완료 정의

- 메인 사가→대형막→부제작→부제작 내부 막의 계층이 완성됨
- 주인공의 연령·능력·관계·책임 성장선이 전 부제작에 연결됨
- 각 부제작의 독립 사건과 전체 복선 회수가 검증됨
- 수집축이 사건·인물·세계 진실과 연결됨
- 한국 홈베이스와 해외 확장의 균형이 검증됨
- 동반 출판물 없이도 본편이 완결됨
- 원고 작성자가 장면 설계에 진입할 수 있는 패키지가 준비됨
