# 자동 설계 완주 실행 큐 v0.3

## 목표

소설 원고를 쓰기 직전까지 필요한 세계관·메인 사가·부제작·수집 구조·동반 출판 설계를 `CLAUDE.md` 절차에 따라 자동으로 완주한다.

## 고정 작가 의도

- 같은 주인공이 여러 부제작에 걸쳐 성장하는 장기 성장형 메인 사가
- 한국의 학교·가족·현실 생활을 지속적인 홈베이스로 유지
- 각 부제작은 독립 사건과 감정적 결말을 가지며 메인 사가를 전진
- 부제작과 물리적 분권을 구분
- 핵심 독자 10~15세, 성인까지 읽는 크로스오버
- 수집욕구는 동행종·도감·지도·유물·영웅 기록 중심
- 본편 완결 후 같은 세계관의 도감·지도·외전·다른 시대 작품 확장 가능

## 자동 진행 종료 이유

다음 단계는 후보 묶음을 작가의 작품 기본값으로 선택하고, 첫 부제작 내부 막·시퀀스·장면·인물 정체성을 고정한다. 이는 CLAUDE.md의 자동 중지 조건인 **작가 승인과 candidate 채택이 필요한 단계**다.

설계 부족이나 도구 실패로 중단한 것이 아니다.

## 승인 뒤 재개 큐

1. 첫 부제작 내부 3막·시퀀스 4안
2. 사건 장면 카드·공정 단서·정보 공개 배치
3. 학교·가족·통학·관계 장면 리듬
4. 독자 용어·정보량·페이싱 테스트
5. 장별 개요
6. 원고 작성은 별도 승인 뒤 시작
7. 첫 부제작 결과를 반영해 부제작 2부터 순차 상세 설계
