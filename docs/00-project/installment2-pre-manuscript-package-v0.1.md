## 5. 사건 설정

기준: `story/30-books/installment2-protection-ownership-setting-bible-v0.1.md`

학교는 길문전 시설 안전을 위해 모서리잠 일부를 보호 관찰실로 옮기고, 온기고리를 학생 안전 동행으로 등록하려 한다.

이 계획은 실제로:

- 주요 경기 동선을 안정시키고
- 학생 피로를 조기 경고하며
- 학교 공동체와 행사를 보호한다.

그러나:

- 구조 부담이 비상 동선으로 이동하고
- 활동별 관계가 반복 호출 가능한 등록으로 바뀌며
- 보호·홍보·팀 전술이 철회와 자료 맥락을 이용한다.

## 10. 하진의 성장

### 시작

규칙을 잘 따르고 끝까지 남아 팀에 도움이 되면 믿을 만한 구성원으로 인정받는다고 믿는다.

### 오류

온기고리의 철회 가능성을 규정 안에서 안전·전술 데이터로 이용한다.

### 비용

- 온기고리 접근 거부
- 도겸·유나와 신뢰 균열
- 관련 판단 권한 제한
- 팀 승리 포기
- 일부 팀 신뢰 미회복

### 클라이맥스

봉화 점화까지 2초가 남았을 때 완벽한 원인을 설명하지 못해도 중지 조건이 충족됐다고 판단해 멈춤종을 사용한다.

하진은 중지 신호만 내고 실제 시설·의료·생태 판단은 성인 전문 책임자에게 넘긴다.

### 종료

학교에 남되 모든 활동에 참여하고 완주해야만 소속이라는 믿음을 버린다.
