# 작가 승인·인간 감수·전문 검토 체크리스트 v0.1

## A. 첫 부제작 장면 설계 전 작가 승인

다음은 `candidate`를 묶어서 선택하는 작가 결정이다. 개별 문장을 쓰기 전 필요하다.

### A1 메인 사가

- [ ] 같은 주인공의 7부제 장기 성장형
- [ ] 만 12세 전후→만 18세 전후, 약 6년
- [ ] 대형막 2/3/2
- [ ] 한국 학교·가족·현실 친구 홈베이스
- [ ] 최종 독점 우선권 포기·공동관리 결말 방향

### A2 첫 부제작 구조

- [ ] 가족·통학 현실 사건 우선형
- [ ] 잘못 분류된 통학 회랑 사건
- [ ] 서안 합성 생활권
- [ ] 여울띠 가족군
- [ ] 예정 보수+강우 통제의 두 시계
- [ ] P1의 클라이맥스가 기록 공유·판단권 이양이라는 방향

### A3 인물 기본값

- [ ] 주인공 작업명 `서하진` 유지/교체
- [ ] 주인공 성별·외형 방향
- [ ] P2 `문하람`, P3 `차도겸`, P4 `강유나`, P5 `서지현`, P6 `오세린` 작업명 유지/교체
- [ ] 가족 구조·보호자 수·주거·경제의 기본 범위

### A4 제목

- [ ] `겹길`을 계속 작업명으로 사용할지
- [ ] `사라진 통학로`를 첫 부제 작업명으로 사용할지

제목 승인과 상표 안전은 별개다. 작가가 좋아해도 법률·출판 검토 전 canon 브랜드로 확정하지 않는다.

## B. 첫 부제작 원고 초안 전 전문 검토

### B1 교육·학교 운영

- [ ] 인가 중·고+별도 현장교육센터 구조의 한국 교육행정 검토
- [ ] 미성년자 현장활동·동의·보험·통학·기숙·철수 절차 검토
- [ ] 실제 학교 명칭과 혼동 가능성 검토

### B2 위치·시설·안전

- [ ] 서안 합성 생활권이 특정 실재 취약 시설을 재현하지 않는지
- [ ] 통학 시간·환승·보행·장마 통제 현실성
- [ ] 시설 보수·수방·구조 역할의 기능 정확성
- [ ] 독자용 지도에서 민감 위치·침입 동선 제거

### B3 아동·청소년 독자

- [ ] 10~12세 제목 소리내기·기억 테스트
- [ ] 30초 세계·첫 사건 설명 이해
- [ ] 인물 6명 구분 가능성
- [ ] 두 시간 시계 이해
- [ ] 여울띠가 펫·포획 대상으로 읽히지 않는지
- [ ] 정책 설명보다 모험·관계·발견의 재미가 앞서는지

## C. 3·4부제 상세 설계 전 현지 인간 감수

### C1 금강하구

- [ ] 서천·군산 생활권 복수 현지 검토
- [ ] 어업·농업·보전·행정·청소년 생활 자기서술
- [ ] 실제 철새·보호종·하굿둑 갈등의 판타지 전용 방지
- [ ] 지역이 중앙 주인공의 교훈 장소로 소비되지 않는지

### C2 방콕–차오프라야

- [ ] 태국어 1차 자료와 현지 도시·수계·청소년 생활 검토
- [ ] 종교·왕실·정령 신앙 직접 전용 금지
- [ ] 홍수·배수·주거 취약성을 초자연 원인화하지 않는지
- [ ] 현지 당사자의 공개·차단·장기 관리 최종 결정권

## D. 출판·브랜드·동반 출판 전 법률/상업 검토

- [ ] `겹길` KIPRIS·ISBN·서점·웹소설·게임·앱·법인·도메인 정밀 조사
- [ ] `깊은결학교`, `길문전`, `여울띠`, 도감 작업명 조사
- [ ] 영문 메인명 4안과 국제 표기
- [ ] 실제 지도·사진·공공자료 이용 조건
- [ ] 개인정보·미성년자·초상·실재 기관 오인
- [ ] 동반 출판·카드·게임에서 랜덤 희귀도·포획·소유 금지 라이선스 조항

다음은 승인 없이 추가 검증·정리 가능하다.

- 파일 링크·용어·상태·결정 ID 정합성
- 기존 `권/5권/틈너머` 잔재 마이그레이션
- 테스트 보강
- 가정·편차·deprecated 기록
- PR 설명·색인·영향도 갱신
