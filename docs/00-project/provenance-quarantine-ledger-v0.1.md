# 출처 감사·격리 원장 v0.1

## 판정 등급

- `P0`: 작가가 이 프로젝트에서 직접 확인
- `P1`: P0에서 직접 도출되며 다른 프로젝트 의존 없음
- `P2`: 조사·감수 후 사용할 수 있는 후보
- `Q`: 출처 불명 또는 교차 프로젝트 오염 가능성
- `X`: 다른 프로젝트 유입 또는 잘못된 자동 확정이 확인됨

## 파일 이관 규칙

기존 브랜치 파일은 다음 조건을 모두 통과해야 새 브랜치에 들어올 수 있다.

1. 특정 작품 길이·화수·장 수에 의존하지 않는다.
2. 원고에서 역산된 설정이 아니다.
3. 다른 프로젝트 인물·사건·고유명사를 포함하지 않는다.
4. 작가의 직접 의도와 충돌하지 않는다.
5. 후보를 확정값으로 표시하지 않는다.
6. 문화·지역·종교·생태 자료는 조사 출처와 감수 상태를 표시한다.

## 우선 감사 순서

1. 프로젝트 운영·범위 문서
2. 세계의 핵심 원리
3. 현실과 숨은 세계의 접점
4. 학교의 존재 목적과 생활 구조
5. 수련·탐사·생태의 관계
6. 지역 확장 원칙
7. 인물·사가·복선·결말

7번은 1~6번이 정리된 뒤 새로 설계하며 기존안을 자동 이관하지 않는다.
