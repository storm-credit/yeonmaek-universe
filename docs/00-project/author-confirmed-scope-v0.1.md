# 작가 직접 확인 프로젝트 범위 v0.1

## 직접 확인된 목표

이 저장소의 현재 작업 대상은 다음 세 가지다.

1. 세계관
2. 설정집
3. 이야기 설계도

현재 단계에서는 실제 소설 원고를 작성하지 않는다.

## 작업 순서

1. 작품의 세계와 규칙을 설계한다.
2. 인물·조직·지역·능력·생물·유물 등 설정집을 만든다.
3. 전체 이야기 구조와 사건 흐름을 설계한다.
4. 설정집과 설계도가 검토·승인된 뒤에만 별도 원고 단계를 논의한다.

## 현재 미확정 항목

다음은 작가가 이 프로젝트에서 확정한 것으로 취급하지 않는다.

- 전체 작품 수 또는 부제작 수
- 전체 장 수
- 전체 연재 회차 수
- 200화 구조
- 7부제 구조
- 117장·234장면 구조
- 주인공 및 핵심 인물 이름
- 구체적인 결말
- 장기 복선·맥거핀 이름
- 특정 플랫폼 분량

## 금지

- 다른 소설 프로젝트의 화수·인물·사건·설계 구조 이식
- 자동 진행을 원고 작성 승인으로 해석
- 후보 설정을 `author-approved`, `final`, `canon-complete`로 자동 승격
- 분량 목표에 맞추기 위해 사건을 추가하거나 늘이기
- 원고에서 역으로 설정집을 확정하기

## 승인 규칙

작가가 직접 선택하거나 승인하지 않은 구체 설정은 모두 후보 또는 격리 상태로 둔다.

`이어 진행`, `자동으로 진행`, `끝까지 진행`은 세계관·설정집·설계도 작업을 계속하라는 뜻이며 실제 소설 본문을 쓰라는 뜻이 아니다.
