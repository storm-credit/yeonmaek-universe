# 원고 모드 운영 계약 v0.2

## 1. 원고 승인 범위

원고 승인은 작품별이다.

- 첫 부제작: 기존 `원고 단계 승인`으로 초고·v0.3 리뷰본까지 허용
- 부제작 2~7: 각 작품의 명시적 원고 승인 전 차단
- 한 작품 승인이 외전·다음 작품·출판 정본 승인으로 확장되지 않음

## 2. 기준 하네스

원고 작업은 다음을 함께 따른다.

- `docs/00-project/manuscript-completion-harness-v0.1.md`
- `docs/14-agent-orchestra-v0.4.md`
- 해당 부제작 원고 직전 패키지

- 작품별 voice anchor와 episode brief

## 3. 집필 기본 문체

- 3인칭 제한근접·과거형을 현재 기본값으로 유지
- 특정 작가 문체·문장·말투 모사 금지
- 명료한 중단문과 짧은 복문을 기본으로 가변 리듬 사용
- 단문은 금지하지 않으며 연속 남발만 제한
- 한 줄 문단은 충격·판단·전환·잔향에 선택적으로 사용
- 현상을 감각·행동·물건·기록 충돌로 먼저 보여 주고 이름을 붙임
- 어린 독자에게 읽히되 감정·제도·책임을 유아화하지 않음

## 4. 전투·액션

- 전투가 있는 작품에서는 동작을 결과만으로 압축하지 않음
- 위치·거리·시야·발판·장비·상대 저항·부상·피로를 연속적으로 갱신
- 기술명보다 궤적·접촉·실패·새 위치를 우선
- 모든 타격을 같은 밀도로 묘사하지 않고 결정적 비트에 세부 묘사 집중
- 학생이 현실 구조·시설·의료 지휘를 대체하지 않음

## 5. 풍경·공간

- 첫 등장: 전체 형태+구별 디테일+인물 행동 조건
- 재등장: 변화·기억·사용 흔적을 보여 줌
- 여행 안내문식 정보 나열 금지
- 실제 지역은 조사·현지 검토 전 합성 기능과 provisional 묘사 사용
- 액션 장면에서 풍경은 장애물·높이·바닥·엄폐·시야로 작동

## 6. 웹소설 회차

각 화는 다음 네 기능 중 최소 세 개를 가진다.

1. 약속
2. 진전
3. 보상
4. 추진

- 첫 10~20% 안에 화의 목표·이상·갈등을 제시
- 중간에 상태 변화 최소 1회
- 모든 화를 충격 훅으로 끝내지 않음
- 이전 화 요약을 반복하지 않음
- 실제 글자수는 플랫폼 계약·낭독·독자 테스트 전 확정하지 않음

## 7. 맥거핀·복선·결말

- 현재 작품 부채는 작품 안에서 0으로 닫음
- 장기 부채는 ID·담당 작품·회수 행동을 가짐
- 분위기 소품은 기능을 수행했으면 종료 처리
- 의도적 비공개는 근거·접근 이력·감사·재검증으로 완결
- P-17은 후속 떡밥이 아니라 7부제에서 검증 가능한 비공개로 종료
- 결말 회수는 설명문보다 인물 선택·생활 결과·기록·지도·권한 상태로 보여 줌
