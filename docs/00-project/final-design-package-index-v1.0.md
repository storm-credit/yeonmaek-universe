## 작업 종료 판정

세계관·설정집·이야기 설계도는 원고 이전 내부 완성 상태다.

향후 작업은 다음 두 종류로만 구분한다.

1. 작가 취향 확정: 이름·성별·가족·제목·고유명.
2. 원고 단계 준비: 플랫폼과 분량 정책에 맞춘 장·회차 분할.

작가의 별도 승인 없이 실제 소설 본문을 작성하지 않는다.
