# 자동 진행·컨텍스트 인수인계 규칙 v0.1

## 사용자 지시

세계관·설정집·설계도를 자동으로 끝까지 진행한다.

실제 소설 원고는 작성하지 않는다.

## 평상시 진행

다음 순서로 작업한다.

1. 세계관 핵심 원리와 현실 접점
2. 학교·수련·탐사·수집·경기·생활 루프
3. 지역·기관·세력·생물·유물·역사·용어·연표·지도
4. 주인공과 핵심 인물 후보
5. 작품 수와 전체 사가 구조 후보
6. 작품별 줄거리·갈등·성장·복선·회수
7. 설정 모순·오염·독창성·연표·안전성 통합 감사
8. 작가 검토용 세계관·설정집·설계도 최종 패키지

사용자가 중간에 별도 수정을 지시하지 않으면 위 순서를 자동으로 계속한다.

## 컨텍스트 종료 감지 시 필수 처리

대화 컨텍스트가 부족해질 가능성이 생기면 새 설정 작업보다 인수인계를 먼저 수행한다.

필수 산출물:

- 현재까지 작업을 원격 브랜치에 커밋
- `docs/00-project/current-work-status.md` 갱신
- 마지막 커밋 SHA 기록
- 완료 파일과 다음 작업 목록 기록
- 오염·격리 상태 기록
- 새 창용 프롬프트 생성

## 새 창용 프롬프트 필수 내용

- 저장소 주소
- 작업 브랜치
- 최신 커밋 SHA
- 작업 목표: 세계관·설정집·설계도
- 원고 작성 금지
- 기존 오염 브랜치 자료 자동 이관 금지
- 완료한 작업
- 다음에 이어서 할 정확한 작업
- 자동 진행 지시
- 컨텍스트 종료 전 다시 커밋하고 후속 프롬프트를 만들라는 지시

## 원격 보존

이 프로젝트의 작업은 GitHub contents API를 통해 직접 원격 브랜치에 커밋한다. 따라서 각 파일 생성·수정 작업이 곧 푸시된 원격 기록이다.
