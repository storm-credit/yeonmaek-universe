# 7부제 전체 초고 이후 최종 제작 로드맵 v0.1

## AI 내부에서 계속 가능한 작업

1. 117장 전체 문장 리듬·반복어·한 줄 문단·종결어미 국소 감사
2. 인물별 대화 음성·서술 거리·설명 밀도 감사
3. 액션·탐사·재난·경기 공간 연속성 전수 감사
4. 1~200화 약속·진전·보상·추진과 유료 분기 후보 감사
5. 용어·연표·나이·학사·이동 거리·권한·유물 상태 전수 감사
6. 작가·독자·전문가 응답을 받을 수정 위치·교체 범위 템플릿 정리
7. 최종 인간 검토용 통합본과 변경 이력 패키지

## 실제 인간이 필요한 작업

- 작가 완독과 작품 감정·재미 판단
- 10~12세·13~15세·성인·보호자 베타 독자
- 교육·청소년 안전·스포츠·의료·보험
- 국내 지역·생태·시설
- 태국어·현지 문화·수문·검역·해외 미성년 안전
- 개인정보·언론·플랫폼·교통·보상
- 기반시설·긴급 권한·분산 공동관리·법률
- 발달편집·라인편집·카피편집·교정쇄
- 제목·상표·출판·플랫폼·등급·접근성

## 편집 원칙

- 전면 재작성보다 문제 위치·교체 범위 우선
- 사건·설정·결말 변경은 작가 승인과 영향도 분석 필요
- 인간 반응 반복 없이 AI 취향으로 문체를 일괄 변경하지 않음
- 실제 지역·법률·시설 세부는 전문가 검토 전 final canon 금지
- PR은 Draft 유지, 자동 Ready·병합 금지

## 현재 정확한 상태

설계 완료, 7부제 전체 초고 완료, 내부 구조 감사 완료.
인간 편집·감수·출판 정본은 미완료.
