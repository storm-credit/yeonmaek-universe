# 《겹길》 프로젝트 맞춤 집필법 부속계약 v0.1

## 목적

맥거핀·복선만으로 원고 품질을 보증하지 않는다. 이 작품은 현대 생활, 학교, 탐사, 경기, 재난, 기관 책임, 비인간 당사자의 권리를 함께 다루므로 각 장면에서 인과·감정·공간·정보·독자 보상을 동시에 관리해야 한다.

이 문서는 기존 `소설 완성본 집필 하네스`와 `작품 설계를 위한 작법·구조 방법 목록`을 원고 실행 수준으로 보강한다.

## 1. 장면-후속 반응 구조

모든 장면을 기계적으로 같은 형식으로 만들지는 않지만, 큰 행동 장면 뒤에는 결과를 소화하는 후속 반응이 필요하다.

### 행동 장면

`목표 → 방해 → 선택 → 결과/실패 → 즉시 비용`

### 후속 반응

`감각·감정 반응 → 무엇이 달라졌는지 인식 → 선택지 비교 → 다음 목표 결정`

적용:
- 길문전·추격·시설 이상·재난 뒤 곧바로 새 위기를 던지지 않는다.
- 하진의 잘못은 설명문이 아니라 성공 직후의 관계·권한·생활 반응에서 체감하게 한다.
- 후속 반응은 장면 전체가 될 수도 있고 짧은 비트가 될 수도 있다.

실패:
- 사건 직후 인물이 아무 감정·신체·관계 반응 없이 다음 임무로 이동
- 반성 독백만 길고 다음 선택이 없음

## 2. 단계적 실패와 진행성 복잡화

같은 실패를 반복하지 않는다. 시도마다 일부는 성공하고 더 비싼 문제를 만든다.

기본 계단:
1. 첫 시도: 문제를 좁히거나 작은 보상을 얻는다.
2. 둘째 시도: 실제 효용을 증명하지만 비용의 위치가 바뀐다.
3. 셋째 시도: 주인공의 오신념 때문에 성공이 권한·관계 문제로 커진다.
4. 최종 선택: 더 큰 힘이 아니라 규칙·권한·관계의 사용 방식을 바꾼다.

작품별 적용:
- 1부제: 관찰 성공 → 신고 지연 비용 → 불완전 기록 공개
- 2부제: 보호 성공 → 관리권 전환 → 멈춤종
- 3부제: 호환표 성공 → 단독 근거화 → 사용 조건·만료 추가
- 4부제: 번역 성공 → 자동 검역 확대 → 접근 순서 이양
- 5부제: 공개 성공 → 민감 위치 특정 → 층별 공개
- 6부제: 중앙 조율 성공 → 반복 수용처 발생 → 권한 분해
- 7부제: 중앙 연장 성공 가능 → 하진 병목 → 자동 복귀 해체

## 3. 서술 거리와 시점 규율

기본은 하진 근접 3인칭이다. 장면 목적에 따라 거리를 조절하되 하진이 알 수 없는 정답을 서술자가 먼저 말하지 않는다.

### 근접

사용:
- 선택 직전
- 실수·수치·두려움·경이
- 경기·추격·재난의 즉각 감각

표현:
- 몸의 반응
- 시선이 먼저 향하는 것
- 하진식 비교와 건조한 유머
- 확정과 추측의 구분

### 중간 거리

사용:
- 이동·시간 압축
- 학교·지역 생활의 전체 리듬
- 장면 사이 연결

### 금지

- POV 밖 인물의 진짜 속마음 확정
- 기관 전체의 의도 단정
- 생물의 거부 이유를 인간 언어로 확정
- 긴장 장면에서 갑자기 전지적 역사 강의

## 4. 행동 속 설명과 정보 직조

설정은 설명 블록보다 인물이 물건을 쓰고, 길을 걷고, 기록을 고치고, 책임자와 충돌하는 과정에서 공개한다.

설명 비트는 다음 중 최소 하나를 바꿔야 한다.
- 현재 선택
- 위험 판단
- 인물 관계
- 공간 사용
- 독자의 오해 후보

방법:
- 공지문과 실제 현장의 어긋남
- 장비 설명서와 마모 흔적 비교
- 서로 다른 지도·기록을 동시에 사용
- 질문에 완전한 답을 주지 않는 대화
- 행동 실패 뒤 필요한 규칙만 공개

금지:
- 설정집 문단을 등장인물이 그대로 말함
- 이미 본 장면을 회의에서 다시 요약
- 독자가 이해할 필요 없는 기관 연혁 선행 설명

## 5. 장면 가치 변화

모든 핵심 장면은 시작과 끝에서 최소 한 가지 가치가 달라져야 한다.

추적 가치:
- 안전 ↔ 위험
- 소속 ↔ 배제
- 신뢰 ↔ 의심
- 접근 가능 ↔ 철회
- 공개 ↔ 비공개
- 개인 판단 ↔ 공동 판단
- 임시 사용 ↔ 지속 관리권
- 정확한 기록 ↔ 목적에 맞는 불완전 기록

장면이 끝났는데 정보·관계·위치·권한·시간·감정 중 아무것도 달라지지 않으면 삭제·결합 후보로 본다.

## 6. 인물 약속과 관계 회수

인물 변화는 선언이 아니라 반복 행동으로 확인한다.

- 사과 뒤 접근권·자료권·역할이 실제로 달라지는가
- 신뢰가 회복되지 않은 부분이 다음 협업 방식에 남는가
- 조연이 하진의 결론을 승인하는 대신 자기 조건을 제시하는가
- 가족·친구·교사의 관계가 사건 종료 뒤 생활 장면에 남는가

## 7. 긴장 파형과 회복 구간

긴장만 계속 올리지 않는다.

기본 파형:
`경이/일상 → 작은 이상 → 시도와 보상 → 비용 발견 → 관계 압력 → 제한된 회복 → 더 비싼 선택 → 클라이맥스 → 생활 결과`

회복 구간도 기능을 가져야 한다.
- 관계 변화
- 장소 애착
- 다음 손실의 대상 제시
- 독자 수집 보상
- 유머와 생활감

## 8. 웹소설 독자 보상 다변화

매 화의 보상은 반전만이 아니다.

보상 유형:
- 경이: 새 생물·장소·유물의 행동
- 능력: 하진의 관찰·연결이 유용하게 작동
- 관계: 농담·협업·갈등·화해의 진전
- 이해: 단서 하나의 의미가 선명해짐
- 행동: 경기·탐사·구조의 명확한 성취
- 생활: 학교·가족·통학·여행의 만족
- 도덕적 긴장: 어느 선택도 공짜가 아님을 느낌

같은 보상 유형을 세 화 이상 연속 사용하지 않는다.

## 9. 결말 회수의 다섯 층

작품 결말은 정보 정답만 공개해서 끝내지 않는다.

1. 물리: 시설·경로·위험 상태
2. 제도: 규칙·권한·기록 양식
3. 관계: 신뢰·접근·역할·거리
4. 생활: 학교·가족·통학·진로에 남는 변화
5. 장기 사가: 다음 질문은 남기되 현재 사건을 빼앗지 않음

현재 작품에서 약속한 층이 회수되지 않으면 `draft-complete` 판정을 보류한다.

## 10. 적용 게이트

앞으로 4~7부제 원고는 각 장·화 브리프에서 다음을 명시한다.

- scene_type: action / reaction / mixed
- value_shift
- progressive_complication_level
- pov_distance: close / medium
- exposition_delivery
- reader_reward_type
- relationship_debt
- physical/institutional/relationship/life payoff 상태

1~3부제는 전면 재작성하지 않고 이 필드로 국소 감사한 뒤 문제 위치와 교체 범위만 제시한다.
