# 원고 모드 운영 계약 v0.1

## 효력

사용자가 `원고 단계 승인`을 명시했으므로 첫 부제작의 원고 모드를 활성화한다.

이 문서는 기존 `CLAUDE.md`의 설계 전용 기본값에 대한 **범위 제한형 부속 계약**이다. 다음 범위에서만 원고·장면·대사를 작성할 수 있다.

- 대상: 첫 부제작 작업 후보 `《겹길: 사라진 통학로》`
- 기준선: D-065, D-067~D-070과 이슈 #55~#58
- 범위: 15장 초고와 장별 수정·회귀 검사
- 제외: 부제작 2~7 원고, 외전, 출판본 확정, canon 승격

## 상태 규칙

- 원고 파일은 `draft`다.
- 제목·인물명·지역명·생물명은 `working candidate`로 사용한다.
- 초고에 사용됐다는 이유로 `canon`이 되지 않는다.
- 설계와 충돌하면 원고 편의를 위해 설정을 바꾸지 않고 원고를 수정한다.
- 설계 변경이 더 합리적이면 편차 로그와 영향 검토를 먼저 남긴다.

## 장별 집필 루프

1. 해당 장의 개요·장면 카드·단서·관계 원장을 읽는다.
2. 장의 독자 보상·목표·방해·선택·대가·미스터리·관계·다음 추진을 한 장짜리 브리프로 압축한다.
3. 초고를 작성한다.
4. 구조·인물·단서·권한·연령·용어·문체를 검사한다.
5. 실패하면 설명으로 방어하지 않고 원고를 수정한다.
6. 장 설계와 달라진 부분은 편차 원장에 기록한다.
7. 통과한 장만 다음 장의 입력으로 사용한다.

## 기본 문체 계약

- 특정 작가나 작품의 문장을 모사하지 않는다.
- 3인칭 제한근접, 이안 중심, 과거형을 기본 후보로 둔다.
- 서술자는 이안이 현재 보고·듣고·추론할 수 있는 범위를 넘지 않는다.
- 현상을 먼저 감각과 행동으로 보여 준 뒤 이름을 붙인다.
- 세계관 설명보다 통학·가족·친구·학교 행동을 앞세운다.
- 어른의 전문성과 아이의 행위 가능성을 동시에 유지한다.
- 어린 독자가 이해할 수 있게 쓰되 감정·갈등·제도를 유아화하지 않는다.
- 유머는 관찰 차이와 관계에서 나오며 긴장을 무효화하는 농담을 남발하지 않는다.

## 원고 가드레일

- 한 장의 새 고유명사는 원칙적으로 1~2개 이하.
- 설정 설명만을 위한 장면 금지.
- 주인공 감각을 자동 정답으로 만들지 않는다.
- 주인공만 생물 의사를 독점 번역하지 않는다.
- 학생이 구조·교통·시설의 법적·물리적 지휘를 대신하지 않는다.
- 여울띠를 포획·계약·영구 동행·마스코트화하지 않는다.
- 혈통·예언·전생·숨은 최강자·절대악을 새로 추가하지 않는다.
- 삭제 항목 ID는 현재 사건과 감정이 완결된 뒤 작은 장기 질문으로만 둔다.

## 장 길이와 리듬

- 장 길이는 기능에 따라 가변적이며 동일 분량을 강제하지 않는다.
- 도입 장은 접근성을, 중반 장은 추리와 관계 비용을, 후반 장은 선택과 결과를 우선한다.
- 모든 장 끝을 충격 훅으로 만들지 않는다. 질문·관계·일정·결정·감각 추진을 교대한다.
- 제11장은 새 위기를 추가하지 않고 철수·정직·권한 상실의 감정 저점에 집중한다.
- 제15장은 생활 60%→관계·제도 30%→삭제 ID 10% 이하의 순서를 유지한다.
