# 오케스트라 원고 진입 게이트 v0.1

## 목적

상세 설정이 부족한 상태에서 장별 개요나 원고가 먼저 작성되는 일을 막는다. 첫 부제작에서 발생한 `설계 최소 기준 통과를 상세 설정집 완료로 오인한 편차`를 후속 작품에서 반복하지 않는다.

## 원고 전 필수 순서

각 부제작은 다음 순서를 모두 통과해야 한다.

1. C0 세계 설정집의 최신 상태 읽기
2. 해당 작품이 사용하는 세계 규칙·학교·기관·지역·생물·유물·영웅·회랑 ID 확인
3. 중심 사건 4안 비교와 후퇴안
4. 해당 작품 상세 설정 바이블
5. 생활 기준선·욕망자·책임자·시간 제한·비용·독립 결말
6. 수집 중심축 1개, 예외적으로 2개와 공개 예산
7. 앞 작품 결과·관계·공개 수준·권한의 누적 검사
8. 문화·법률·안전·현지 검토 상태와 검토 전 금지사항 표시
9. 원본성·맹점·삭제·교환 테스트
10. 작가가 작품 방향 candidate를 승인
11. 내부 구조·장면 카드·단서·관계·장별 개요
12. 원고 직전 회귀 검사
13. 사용자의 명시적 원고 단계 승인

하나라도 빠지면 완성 문장·대사·장면·회차 원고를 작성하지 않는다.

## 상세 설정 바이블 최소 필드

- 작품의 시간·나이·학적·가족·현실 생활
- 중심 질문
- 독립 중심 사건
- 시작 상태와 종료 상태
- 욕망자와 각자의 합리성·맹점
- 학생·학교·시설·교통·구조·의료·당사자·감사의 책임 분리
- 서로 다른 최소 두 개의 시간 압력 또는 비가역 조건
- 중심 생물·유물·영웅·회랑의 사건 필수성
- 주인공·가족·친구·학교 관계 변화
- 현재 작품에서 해결하는 질문과 장기 미확인 1개 이하
- 사건 뒤 남는 생활·시설·관계·기록 비용
- 지역·문화·법률·안전 검토 상태와 후퇴안

## 원고 진입 차단 상태

다음 상태는 원고 승인이 아니다.

- `blueprint-ready`
- `function-ready`
- `candidate-baseline-ready`
- `detailed-setting-candidate`
- `chapter-outline-ready`
- `reader-sample-candidate`
- `human-review-pending`

원고 진입에는 별도 `manuscript-approved` 기록이 필요하다.

## 작가 승인과 전문가 검토의 구분

### 작가 승인

- 작품 질문·사건·주인공 변화·감정 결말
- 학교 매력·수집 얼굴·인물 관계·제목 작업 방향

### 전문가·현지 검토

- 법적 형태·안전·의료·보험·개인정보
- 실제 지역·언어·생활·문화·시설
- 상표·출판·시각·접근성

작가 승인은 사실 검토를 대신하지 않고, 전문가 검토는 작품 결말을 대신 결정하지 않는다.

## 첫 부제작 예외 처리

첫 부제작 v0.2는 상세 C0 이전에 작성됐으므로 다음 상태로 동결한다.

- 구조·사건·인물·결말: 유지
- 세계 설정집 역검증: 완료
- 국소 교체: 12문장 패치 큐
- 실제 v0.3 반영: #79 작가 게이트 뒤
- 전면 재작성: 금지

## 부제작 2 진입 조건

부제작 2는 다음 전까지 원고 금지다.

1. #79 작가 핵심 선택
2. 학교의 중심 매력 승인
3. 길문전 30초 설명·관전·안전 설계
4. 활성 인물·내부 구조·장면 카드·단서 원장
5. 학교·시설·생태 검토 상태 확인
6. 명시적 `부제작 2 원고 단계 승인`

## 자동 오케스트라 행동

- 조건 미충족 시 부족한 가장 상위 게이트로 되돌아간다.
- 원고 편의를 위해 설정을 조용히 바꾸지 않는다.
- 앞 작품과 충돌하면 원고보다 C0·결정·편차 로그를 먼저 갱신한다.
- 인간 검토가 필요한 항목은 provisional로 유지하고 안전한 후퇴안을 함께 쓴다.
- 사용자가 `계속`, `이어서`, `자동으로`라고 해도 명시적 원고 승인이 없는 작품의 원고는 쓰지 않는다.

## 완료 기준

해당 부제작의 원고가 끝난 뒤에도 다음을 수행한다.

1. 원고→설정집에서 새로 검증된 생활·관계·사례 추출
2. 설정집→원고 역검증
3. 국소 교체 위치와 문장만 제시
4. 다음 부제작의 입력 상태 갱신
5. 독자·전문가 검토 결과를 canon 승격과 분리
