# 소설 완성본 집필 하네스 v0.1

## 1. 목적

세계관과 장별 개요가 있다는 이유만으로 원고 완성도를 선언하지 않는다. 이 하네스는 설계 입력을 실제 웹소설 원고로 변환하고, 문장·장면·회차·내부막·부제작·사가·출판 교정 단계에서 서로 다른 실패를 탐지한다.

## 2. 고정 계층

`공유세계관 → 메인 사가 → 대형막 → 부제작 → 부제작 내부막 → 시퀀스/서브액트 → 장 → 연재 화 → 장면 → 비트`

각 계층은 시작 상태, 목표, 압력, 비가역 전환, 종료 상태, 다음 계층으로 넘기는 부채를 가진다.

- 대형막: 여러 부제작이 모여 하나의 비가역 성장 전환을 만든다.
- 부제작 내부막: 한 작품의 현재 사건과 감정 질문을 닫는다.
- 시퀀스/서브액트: 3~5개 장면이 하나의 질문·시도·실패·전환을 만든다.
- 장: 단행본 독서 리듬.
- 연재 화: 모바일 결제·공개 리듬. 장과 동일하지 않을 수 있다.
- 장면: 인물의 목표가 방해를 만나 선택과 상태 변화를 만드는 단위.
- 비트: 정보·행동·감정이 한 단계 움직이는 최소 단위.

## 3. 하네스 단계

### H0 — 기준선 잠금

입력:
- C0 설정집
- 작가 승인 기준선
- 부제작 원고 직전 패키지
- 활성 인물·단서·맥거핀·연표·용어 원장

검사:
- 후보와 정본 구분
- 인간 검토 대기 사실 표시
- 작품별 원고 승인 확인

실패 시 원고 작성 금지.

### H1 — 회차 컴파일

장면 카드를 연재 화로 컴파일한다.

각 화 필수 필드:
- 독자 약속
- 즉시 목표
- 갈등 또는 탐색
- 상태 변화
- 최소 보상
- 다음 추진
- 이번 화에서 새로 생긴 부채

모든 화를 충격 반전으로 끝내지 않는다. 행동, 질문, 관계, 일정, 발견, 결정, 비용 훅을 교대한다.

### H2 — 장면 프리플라이트

집필 전 다음을 한 화면에 둔다.
- POV가 아는 것과 모르는 것
- 장면 시작 위치·시간·인원
- 인물별 목표와 숨기는 정보
- 공간의 출입구·거리·위험·사용 가능한 물건
- 이번 장면의 단서·오해·회수
- 종료 후 바뀌는 위치·관계·부상·권한·기록

### H3 — 초고

초고에서는 완벽한 문장보다 인과·행동·감정의 연속성을 우선한다.

금지:
- 설정집 문단 붙여넣기
- 인물이 아는 범위를 넘는 정답 해설
- 회차 분량을 맞추기 위한 무의미한 위기
- 특정 작가의 문장·말투 모사

### H4 — 문장·문단 리듬 검사

`단문 금지`가 아니라 **단문 남발 금지**를 적용한다.

- 단문은 충격, 판단, 실패, 전환, 대사의 잔향에 사용한다.
- 5개 이상 한 줄 문단이 연속되면 특별한 액션 장면이 아닌 한 재검토한다.
- 같은 길이와 같은 종결어미의 문장이 3회 이상 반복되면 리듬을 바꾼다.
- 긴 문장은 이동·관찰·사고의 연결이 필요할 때 사용하며, 주체와 공간 방향을 잃지 않는다.
- 문단은 하나의 초점 행동·관찰·생각을 중심으로 묶는다.
- 감정을 형용사로 확정하기 전에 행동, 망설임, 말의 순서, 몸의 반응을 우선한다.
- 단문과 중문, 짧은 복문을 장면 압력에 맞춰 섞는다.

### H5 — 대화·인물 음성 검사

- 이름을 지워도 핵심 인물의 목적·관계·말의 선택이 구분되는가.
- 대사가 이미 서술한 사실을 다시 말하지 않는가.
- 질문과 답이 정확히 맞물리기만 하지 않고 회피·오해·숨김이 인물답게 발생하는가.
- 아동·청소년이 성인 행정 보고서처럼 말하지 않는가.
- 유머가 긴장과 손실을 무효화하지 않는가.
- 조연이 주인공 결론을 확인해 주기 위해서만 존재하지 않는가.

### H6 — 전투·추격·경기·구조 액션 검사

액션은 `의도 → 공간 기준점 → 움직임 → 접촉/실패 → 저항 → 결과 → 비용 → 새 위치` 순환을 따른다.

필수:
- 누가 어디서 무엇을 보며 시작하는가
- 상대·환경·규칙이 어떻게 저항하는가
- 공격 또는 행동의 궤적과 거리
- 접촉 뒤 자세·호흡·통증·장비·시야 변화
- 이전 행동이 다음 선택을 제한하는 연속성
- 승패보다 인물의 선택과 비용

금지:
- 기술명 나열만으로 공간과 결과를 생략
- 모든 타격을 슬로모션으로 묘사
- 부상·피로·장비 손상을 다음 문단에서 초기화
- 주인공만 물리법칙과 안전 규칙에서 예외
- 전투 중 세계관 설명 강의

전투가 적은 작품에서도 길문전, 추격, 구조, 회랑 통과, 재난 대응에 같은 공간 연속성 규칙을 적용한다.

### H7 — 풍경·공간·경이 묘사 검사

풍경은 장식이 아니라 방향, 분위기, 단서, 행동 조건 중 하나를 바꿔야 한다.

3층 묘사:
1. 방향을 잡는 전체 형태
2. 그 장소만의 구별 디테일 1~3개
3. 인물의 이동·사건·시간에 따라 변하는 요소

- 장면당 감각 2~3개를 중심으로 선택한다.
- 여행 안내문처럼 역사·색·냄새를 모두 나열하지 않는다.
- 같은 장소가 재등장하면 같은 묘사를 반복하지 않고 변화·기억·사용 흔적을 보여 준다.
- 아름다운 풍경도 통행, 날씨, 소음, 사람의 노동과 연결한다.
- 전투와 추격 중에는 풍경을 멈춰 감상하지 않고 장애물·엄폐·높이·바닥·시야로 변환한다.

### H8 — 웹소설 회차 검사

각 화는 `약속-진전-보상-추진` 네 기능 중 최소 세 개를 가진다.

- 첫 10~20% 안에 현재 화의 목표 또는 이상을 제시한다.
- 중간에 최소 한 번 정보·관계·위치·계획이 변한다.
- 독자는 화를 읽은 대가로 발견, 감정, 관계, 행동, 경이 중 하나를 받는다.
- 마지막 문장은 놀람 부호가 아니라 다음 행동을 발생시켜야 한다.
- 이전 화 요약을 본문 첫머리에 반복하지 않는다.
- 플랫폼별 글자수는 계약 전 확정하지 않고 낭독 시간·화 기능·독자 테스트로 조정한다.

### H9 — 복선·맥거핀·미스터리 부채 검사

모든 강조 요소는 다음 중 하나로 분류한다.
- 현재 작품 회수
- 장기 사가 회수
- 분위기/인물 기능 수행 후 종료
- 의도적 비공개이며 검증 절차로 완결
- 삭제 또는 강조 하향 필요

맥거핀은 대상의 비밀보다 욕망자 충돌을 움직여야 한다. 도감·P-17·돌림패가 주인공의 힘 인증서가 되면 실패다.

회수는 설명 한 문단이 아니라 인물의 선택, 결과, 관계, 제도, 지도, 기록 상태를 바꿔야 한다.

### H10 — 내부막·부제작 회귀

각 내부막 종료 시:
- 시작 질문이 더 어려운 질문으로 전환됐는가
- 동일한 실패를 반복했는가, 더 비싼 선택으로 발전했는가
- 인물·권한·관계·시간·물리 상태가 실제로 변했는가

부제작 종료 시:
- 현재 사건과 감정 질문이 닫혔는가
- 다음 작품 떡밥이 현재 결말을 빼앗지 않는가
- 주요 인물의 비용이 생활에 남는가
- 수집 보상이 포획·등급·만능 아이템이 아닌가

### H11 — 대형막·사가 회귀

- 대형막의 마지막 부제작이 앞 작품의 비용을 합산해 비가역 전환을 만드는가
- 2/3/2 구조의 각 막이 발견·제도 확장·권력 선택으로 구분되는가
- 마지막 해결이 첫 작품의 문제를 더 큰 힘으로 반복하지 않는가
- 하진의 독점 접근 해체가 1~6부제에서 충분히 준비됐는가
- 모든 장기 부채가 회수, 의도적 비공개 완결, 폐기 중 하나로 정산됐는가

### H12 — 인간 편집 파이프라인

AI 내부 통과 뒤에도 다음은 별도다.
1. 작가 완독·감정 판단
2. 10~15세/성인 베타 독자
3. 발달편집: 구조·인물·정보·중복
4. 분야 검토: 교육·안전·시설·생태·지역·언어·법률
5. 라인 편집: 문장 리듬·이미지·대화·서술 거리
6. 카피 편집: 맞춤법·표기·용어·연표·숫자
7. 교정쇄: 누락·오탈자·레이아웃·회차/장 번호
8. 출판·플랫폼 분량·등급·접근성 검토

## 4. 완성 판정

### 내부 원고 완성 후보

- H0~H11 통과
- 현재 작품 회수 부채 0
- 장기 부채는 소유자와 회수 위치가 있음
- 치명적 POV·공간·권한·연표 오류 0
- 장면 기능 없는 장·화 0

### 검토 완료 원고

- 인간 베타·발달·분야·라인·카피 편집 결과 반영
- 남은 이견과 의도적 비공개 기록

### 출판 완성본

- 교정쇄·플랫폼·상표·계약·등급·접근성 통과
- 작가 최종 승인

`내부 설계 완료`, `초고 완료`, `검토 완료`, `출판 완성본`을 서로 바꾸어 부르지 않는다.
