# 작가용 상세 세계 설정집 최소 검토 패키지 v0.1

## 목적

내부 candidate 설정집 전체를 다시 읽지 않아도 작품의 정체성을 바꾸는 여섯 결정을 한 번에 검토할 수 있게 한다.

아래 추천 기본값은 자동 설계의 1순위이며 작가 승인 전 canon이 아니다.

# 1. 메인 사가 규모

## 추천 기본값 A — 7부제·2/3/2

- 1~2: 발견·소속
- 3~5: 한국 내부 기준 확장→해외 번역→한국 공개 붕괴
- 6~7: 중앙 통제의 실제 성공→권한 재분산·졸업
- 약 6년, 만 12→18세

### 장점

- 학교·가족·친구를 사랑할 시간 확보
- 4부제에서 해외 전환
- 5부제에서 한국 귀환과 사회 공개
- 6부제의 중앙 성공을 거쳐 7부제 결말이 공정해짐

### 약점

- 장기 연재 부담
- 첫 2부제에서 충분히 흥행하지 못하면 후반 설계가 사용되지 않을 수 있음

### 후퇴

- 6부제 압축: 3·4 또는 5·6 기능 일부 통합
- 사건은 삭제보다 부제작 기능 재배치

## 선택지

- A. 7부제·2/3/2 — 추천
- B. 6부제 압축
- C. 8부제 확장
- D. 권수 미확정, 첫 2부제 후 재판정

# 2. 주인공 정체성

## 현재 기능

- 작업명 서이안
- 만 12세 시작
- 연결 관측자
- 규칙과 순서를 찾아 실수를 막고 싶어 함
- 완전한 기록→소속→통합→번역→공개→권한→분산 책임으로 성장

## 추천 기본값 A

- 이름 `서이안`은 working 상태 유지
- 성별은 첫 작가 검토에서 확정
- 특별 혈통·유명 가문·예언 없음
- 중산층 도시 통학 생활, 보호자 서지현과 현실 친구 강유나 유지
- 능력보다 기록 습관·실수·선택이 중심

## 선택지

- A. 현재 기능 유지, 성별만 작가 결정 — 추천
- B. 여자 주인공으로 확정
- C. 남자 주인공으로 확정
- D. 이름·성별·가족 구성을 모두 재설계

## 영향

성별과 가족 구성은 이름·대사·학교 관계·성장·표지에 영향이 크므로 원고 canon 전에 필요하다.

# 3. 학교의 가장 강한 감정적 매력

## 추천 기본값 A — 친구·수업·생물 관계 중심

우선순위:

2. 신기한 수업과 실습

경기는 학교의 얼굴 중 하나이지 작품 전체의 최상위 중심이 아니다.

## 선택지

- B. 길문전·팀 경쟁 중심
- C. 탐사·도감·회랑 발견 중심
- D. 가족·통학·현실 생활 중심

## 영향

부제작 2의 장면 예산·표지·독자 연령·반복 루프가 달라진다.

# 4. 대표 수집 얼굴

## 추천 기본값 A — 정정되는 생태 도감

브랜드 순서:

### 이유

- 작품의 기록·오분류·권리 주제와 직접 연결

## 선택지

- A. 정정되는 생태 도감 — 추천
- B. 회랑 지도첩
- C. 유물·보물 기록
- D. 영웅·탐사자 기록

중심 하나를 정해도 나머지는 보조 수집축으로 유지한다.

# 6. 메인 제목·부제 문법

## 현재

- `연맥`: 저장소 코드명, 독자 제목 우선 제외
- `딥루트`: 기존 기업·브랜드 충돌로 우선순위 하락
- `겹길`: preliminary candidate
- `틈너머`: superseded

## 추천 기본값

구조와 원고 검토 동안 `겹길`을 작업명으로 유지하되, 최종 제목은 출판·상표·독자 발음 테스트 전에 확정하지 않는다.

부제 문법:

> 《메인명: 구체 물건·장소·현상》

예:

- 사라진 통학로
- 중지된 경기
- 갈라지는 물목
- 번역되지 않은 배열
- 무음 구간의 기록
- 빌린 권한
- 마지막 연결점

위 예시는 기능명이며 최종 제목이 아니다.

## 선택지

- A. `겹길` 작업명 유지, 최종 제목은 나중 — 추천
- B. 지금 새 메인 제목 4안 재개
- C. 순한국어 이름 중심 재탐색
- D. 영문·혼합 브랜드 중심 재탐색

# 7. 한 번에 승인하는 방법

다음 문구는 위 여섯 항목의 추천 기본값을 승인한다.

> `추천 기본값 승인`

승인 범위:

- 7부제·2/3/2
- 서이안 기능 유지, 단 성별은 별도 결정 필요
- 학교 매력은 친구·수업·생물 관계 중심
- 대표 수집 얼굴은 정정되는 생태 도감
- 최종 감정은 졸업과 새 책임
- `겹길`은 작업명으로만 유지

`추천 기본값 승인`은 법률·문화·상표·출판 검토를 대신하지 않는다.

# 8. 성별만 별도 선택해야 하는 이유

성별은 단순 외형 필드가 아니라 다음에 영향을 준다.

- 이름의 독자 인식
- 친구·교사·보호자 관계의 사회적 읽힘
- 표지·마케팅
- 장기 성장과 또래 관계
- 원고의 대명사·호칭·생활 묘사

추천 기본값 승인과 함께 `남자`, `여자`, `성별 노출 최소화` 중 하나를 덧붙이면 작가 게이트를 닫을 수 있다.
