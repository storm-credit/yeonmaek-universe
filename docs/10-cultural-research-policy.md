# 문화 조사와 창작 변형 정책

## 출처 등급

- A: 현지 공공기관, 박물관, 대학, 학술 논문, 국제기구, 원전 번역
- B: 전문 연구서, 신뢰할 수 있는 언론의 심층 자료
- C: 대중 해설, 여행/문화 소개
- D: 위키, 블로그, 영상, 커뮤니티 — 탐색용이며 단독 근거 금지

## 지역 문서 최소 요건

- 내부 하위 지역 3개 이상
- 현대 도시/생활 맥락
- 역사적 교류와 변화
- 다수자 전통과 소수자/지역 전통 구분
- 실재 사실과 창작 변형의 별도 표기
- 금기와 현지 감수 필요 항목
- 독립 출처 2개 이상

## 변형 거리

1. 직접 재현: 사실 설명에만 사용
2. 기능 추상화: 공간·계절·공동체 같은 원리만 차용
3. 복합 변형: 여러 비신성 자료를 조합해 독자 체계 생성
4. 완전 창작: 실제 문화와 유사성을 검토하되 직접 대응시키지 않음

현존 종교의 신성 의례와 소수 공동체의 비공개 전통은 2~4단계를 우선한다.
