# 장기 성장형 자동 설계 마스터 체크리스트 v0.1

## 사용법

A00은 매 작업 시작 시 이 체크리스트와 `docs/13-execution-order-v0.1.md`를 읽고, 완료되지 않은 가장 상위 의존 게이트를 선택한다.

각 게이트는 다음 4개 산출물 묶음으로 완료한다.

1. 구조적으로 다른 4안
2. 시나리오 테스트
3. 레드팀·맹점 훑기
4. 1순위 `candidate` 결정 기록

`candidate → canon`은 작가 승인 전 자동 수행하지 않는다.
