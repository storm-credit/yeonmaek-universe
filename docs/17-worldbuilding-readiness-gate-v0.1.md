# 세계관 최소 정본 게이트 v0.1

## 판단

현재 저장소에는 설계 방법, 조사 체계, 전문가 조직은 충분하지만 실제 작품을 지탱할 핵심 세계관은 아직 `provisional` 수준이다. 결말 역산과 시리즈 구조를 확정하기 전에 아래 설정 묶음을 최소한 후보 4안과 레드팀 검토 수준까지 채워야 한다.

이 문서의 목적은 설정을 무한히 늘리는 것이 아니라 **이야기의 원인·선택·대가를 결정할 최소한의 세계 규칙**을 정하는 것이다.

## 게이트 A — 존재론과 경계

- 현실과 숨은 세계는 왜 겹치는가?
- 숨은 세계는 자연 발생, 분리된 생태권, 인간 인식의 한계 중 무엇인가?
- 깊이·경계·입구·귀환의 공통 규칙은 무엇인가?
- 죽음, 시간, 거리, 물질 보존은 현실과 같은가?
- 이면종과 현실 생물은 어떤 관계인가?

## 게이트 B — 힘과 수련

- 공통 관측 현상과 지역별 해석의 경계
- 힘의 사용 조건, 비용, 실패, 회복
- 재능·혈통·훈련·도구·환경의 비중
- 학생과 성인의 사용 가능 범위
- 무공·도술·영술·선법·서양 마법의 호환 한계
- 현대 기술과 결합하거나 충돌하는 방식

## 게이트 C — 지성종·생태·권리

- 지성종과 비지성종의 구분 기준
- 인간과의 의사소통, 협정, 소유·보호·포획의 법적 지위
- 포식·공생·이동·번식·멸종 규칙
- 인간 문화가 생물에 미치는 영향의 범위
- 국제 이동과 검역

## 게이트 D — 비밀 사회와 현실 제도

- 일반인, 가족, 정부, 언론, 병원, 보험, 경찰이 각각 무엇을 아는가?
- 증거와 목격은 어떻게 처리되는가?
- 대형 노출 사건이 발생했을 때 절차
- 숨은 공동체의 법, 분쟁 조정, 처벌, 책임
- 국가 기관과 초국가 연맹의 권한 경계

## 게이트 E — 학교·교육·생활

- 입학 연령, 선발 방식, 학제, 학사 일정
- 통학·기숙·보호자 동의
- 필수 과목, 실습, 평가, 탈락·전학·졸업
- 학생 안전과 사고 책임
- 식사, 통신, 돈, 의료, 교복·장비, 방학
- 졸업 후 직업과 일반 사회 복귀

## 게이트 F — 역사와 국제 질서

- 숨은 세계와 인간 세계가 분리된 핵심 역사적 전환
- 한국 기관의 창립과 국제 연맹 가입
- 기존 협정·전쟁·재난·노출 사건
- 중국·일본·동남아·내륙아시아·서양 조직과의 관계
- 현대 국경과 오래된 생태 회랑이 충돌하는 방식

## 게이트 G — 한국 첫 무대의 생활감

- 서울·수도권에서 반복해서 사용할 현실 동선
- 학교의 표면 위치와 심층 공간
- 학생이 집과 학교를 오가는 방식
- 일상적으로 접하는 작은 이면 현상
- 한국 내부 지역 전통의 복수성
- 계절·장마·한강·산·지하 인프라와 사건 가능성

## 게이트 H — 갈등 엔진

- 세계가 평상시에 유지되는 이유
- 현재 균형이 깨지는 압력 3개 이상
- 기관·보호자·학생·이면종의 이해 충돌
- 악당 없이도 사건이 발생하는 구조
- 결말까지 확대될 수 있는 구조적 문제

## 정본화 수준

결말 설계 전 모든 세부가 `canon`일 필요는 없다. 다만 각 게이트는 다음을 충족해야 한다.

1. 구조적으로 다른 4안 비교
2. 1순위 `candidate` 제안
3. 현실성·문화 무결성·인과 레드팀
4. 미해결 질문과 금지선 기록
5. 결말과 시리즈 구조에 영향을 주는 변수 표시

## 중지 조건

- 국가별 생물·학교·술법을 대량 생성하기 시작하면 중지한다.
- 이름·장식·전설 목록만 늘고 규칙·비용·생활·갈등이 정해지지 않으면 중지한다.
- 실제 문화 조사 없이 정식 설정으로 변환하면 중지한다.
- 결말과 무관한 백과사전 설정이 늘어나면 삭제 또는 보류한다.

## 작업 순서

`존재론 → 힘·생태 → 비밀사회·제도 → 학교생활 → 역사·국제질서 → 한국 생활감 → 갈등 엔진 → 결말 역산`

결말 역산 이슈는 이 게이트의 핵심 8항목이 최소 `candidate`에 도달한 뒤 진행한다.
