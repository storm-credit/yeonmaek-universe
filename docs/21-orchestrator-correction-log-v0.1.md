# 오케스트레이터 판단 수정 기록

## 기존 판단

설계 시스템과 지역 조사 체계가 마련된 뒤 결말 역산으로 이동하려 했다.

## 발견된 문제

- 실제 핵심 세계 규칙이 다수 `hypothesis` 또는 일부 `candidate` 상태였다.
- 결말을 먼저 고르면 세계 규칙이 결말에 맞춰 편의적으로 수정될 위험이 있었다.
- 학교 생활, 현실 제도, 지성종 권리, 힘의 비용이 부족했다.

## 수정

- A14 세계관 준비도 통제관 추가
- 8개 세계관 게이트 추가
- 결말·시리즈 설계 착수 차단
- 설정 범위 규칙 추가
- 실행 순서를 세계관 게이트 우선으로 변경

## 원칙

오케스트레이터는 계획을 고수하는 것이 아니라, 계획의 전제가 틀렸을 때 즉시 편차를 기록하고 순서를 수정한다.
