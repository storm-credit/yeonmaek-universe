# 에이전트 구성 맹점 감사 v0.1

## 감사 결론

기존 14개 에이전트는 세계관 구조를 만들기에는 충분했지만, 작품을 끝까지 설계하고 국가별 문화 단순화를 막기에는 부족했다. 따라서 국가 데스크, 서사 평의회, 제작 관리팀을 추가했다.

## 발견된 공백과 보강

| 공백 | 위험 | 보강 |
|---|---|---|
| 권역 연구자만 존재 | 한 명이 여러 국가를 얕게 대표 | 국가별 데스크 + 권역 리드 이중 구조 |
| 결말 설계 담당 없음 | 설정 뒤에 임의 결말 부착 | N01 결말 역산 |
| 복선 관리 없음 | 회수되지 않는 설정과 미스터리 | N05 복선 원장 |
| 맥거핀 검증 없음 | 만능 유물·선택받은 혈통 | N04 욕망 객체 설계 |
| 추리 공정성 없음 | 작가만 아는 반전 | N07 공정 단서 |
| 캐릭터 기능 검토 없음 | 외국인 캐릭터의 국적 토큰화 | N09 관계·기능 설계 |
| 정보량 관리 없음 | 세계관 백과사전화 | N11 정보 공개 |
| 정본 외 데이터 관리 약함 | 용어·연표·거리 충돌 | P01~P05 |
| 출처와 독자 이해 검증 분리 부족 | 학술적으로 맞아도 읽기 어려움 | P06 출처, P07 독자 테스트 |

## 과잉 구성 위험

에이전트 수가 많다고 매 작업에 모두 호출하지 않는다. A00이 실패 위험에 맞춰 최소 패널을 구성한다. 국가 데스크는 해당 국가가 실제 등장하거나 구조 검증에 필요할 때만 호출한다.

## 권한 충돌 해결

- 국가 데스크는 사실·내부 다양성에 우선 발언권을 가진다.
- A12는 문화적 사용 금지와 감수 필요 여부에 중지권을 가진다.
- N00은 이야기 인과에 필요 없는 설정 삭제를 제안할 수 있다.
- A01은 세계 공통 규칙의 충돌을 판정한다.
- N16/P01은 조용한 정본 변경을 차단한다.
- 최종 선택은 작가가 하되 고위험 문화 설정은 검증 없이 정본화할 수 없다.

## 아직 필요한 미래 에이전트

- 실제 집필 단계의 문체·시점·대사 검토자는 별도 저장소에서 구성한다.
- 법률/IP 검토는 출판·영상화 단계에서 전문가 확인이 필요하다.
- 현지 감수자는 AI 에이전트로 대체할 수 없다.
