# 프로젝트 헌장

## 목표

한국을 출발점으로 하는 범아시아 동양 판타지 세계관의 **설계 운영체계와 정본 구조**를 만든다.

## 1차 산출물

- 세계 공통 원리와 지역별 해석의 경계
- 현실과 숨은 세계의 연결 규칙
- 아시아 권역별 조사 지도
- 힘 체계, 생태, 학교/기관, 대표 경기 설계 틀
- 전문가 에이전트와 검증 절차
- 결정·편차·맹점·메모리 관리 체계

## 비목표

- 소설 본문 작성
- 캐릭터 서사와 회차 구성
- 모든 국가의 세부 설정을 초기에 완성
- 특정 전승을 그대로 판타지 기술로 복제
- 앱이나 자동화 코드 구현

## 사용자

1. 작가: 방향 결정과 정본 승인
2. AI 오케스트레이터: 조사·비교·검증 관리
3. 지역/문화 전문가: 사실성과 맥락 검토
4. 향후 집필 에이전트: 승인된 정본만 참조

## 성공 정의

세계가 커져도 한국 시작점이 유지되면서 다른 지역이 한국 설정의 변형판으로 보이지 않고, 모든 중요한 결정의 이유와 영향이 추적 가능해야 한다.
