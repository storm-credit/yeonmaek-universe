# 세계관·작품 설계 청사진 1단계 완료 요약 v0.1

## 완료 범위

### 세계관 최소 기준선

- 다층 생태 위상형 존재론
- 장소·상태·관계 기반 경계 조건
- 결합 조율·부담 보존형 힘 체계
- 다축 지성·권리 묶음
- 분산 이중관할과 공동 사고 대응
- 표면 특성화학교+심층 학궁 혼합형
- 다중 지역 협정망+후발 국제 조정체
- 안정 캠퍼스+반복 도시 거점형 한국 첫 생활권
- 결합 압력·부담 전가형 구조 갈등 엔진

### 작품 전체 아키텍처

- 결말 후보: 단계적 인정·회랑 공동관리형
- 본편 길이: 5권 핵심 완결형
- 핵심 비밀: 기존 질서는 부담을 없애지 않고 분산·은폐해 왔음
- 맥거핀: 잘못 분류된 도감·분산 부담 기록형
- 미스터리: 기록 불일치→삭제 이유→해외 판본 충돌→기존 질서→주인공 접근→중앙화 선택
- 복선: 공정 단서·레드 헤링·회수 부채 원장
- 캐릭터: 선택 기능·욕망·오신념·관계 변화 중심

### 연구·검증 운영

- 국가별·권역별 전문가 이중 라우팅
- 국가 데스크 준비도 4단계
- 문화 출처 카드와 직접 전용 금지선
- 현지 인간 감수 비대체 원칙
- 세계관 준비도 통제관 A14
- 연속성·독창성·문화·독자 이해도 레드팀

## 아직 확정하지 않은 것

- 작품·학교·도감·기관 정식 명칭
- 구체 주인공과 조연의 이름·성별·외모
- 1권 사건·범인·장면
- 주인공의 최종 개인 대가
- 첫 장기 관계 생물
- 대표 경기 정식 규칙
- 3권 해외 지역
- 실제 학교·도시 거점 위치
- 국가별 술법·생물·학교
- 소설 원고

## 다음 단계의 목적

1단계에서 만든 구조가 실제로 사건과 인물 선택을 강제하는지 검증한다.

검증 질문:

- 주인공은 무엇을 잃어야 독점권 포기가 실제 대가가 되는가?
- 1권 사건은 세계관 설명 없이 독립적으로 재미있고 완결되는가?
- 도감이 없어도 현장 사건을 해결할 수 있는가?
- 학교 절차는 실제로 생명을 구하면서도 작은 부담을 전가하는가?
- 학생·가족·일반 친구·생물·교사에게 각자 선택이 있는가?
- 1권 복선 5~7개만으로 장기 결말을 공정하게 준비할 수 있는가?

## 중지 조건

다음이 발생하면 이전 단계로 돌아간다.

- 1권 사건 해결에 새 세계 규칙이 필요함
- 주인공이 혈통·예언·최종 유물로 특별해짐
- 학교와 어른이 무능해야 학생이 활약함
- 생물·지성종이 목표물이나 마스코트로만 사용됨
- 1권에 국가·기관·술법 설명이 과도함
- 장기 미스터리가 1권 독립 사건의 해결을 빼앗음
- 주인공의 최종 대가가 일시적 능력 봉인에 그침
