# 원고 직전 설계 의존 그래프 v0.1

## 1. 최상위 인과 사슬

```text
다층 생태 위상
  → 같은 장소에 겹친 생태·이동 경로
  → 결합 조율을 통한 관찰·개입
  → 모든 개입의 부담 보존
  → 기존 기관이 부담을 다른 장소·생물·주민·기록에 전가
  → 도감·지도·협정의 누락과 오분류
  → 주인공이 더 정확한 단일 기록과 빠른 통제를 욕망
  → 국내·해외 판본과 당사자 결정권이 그 욕망을 반박
  → 독점 통제가 실제 위기를 성공적으로 해결
  → 주인공이 효율성을 인정한 채 우선 결정권을 포기
  → 지역 판본·당사자·기관이 감사 가능한 공동관리 구조를 운영
```

## 2. 설계 계층

```text
공유세계관
├─ 메인 사가: 동일 주인공 7부제, 약 6년
│  ├─ 대형막 I: 1~2 발견과 소속
│  ├─ 대형막 II: 3~5 기준 확장과 신뢰 붕괴
│  └─ 대형막 III: 6~7 선택과 재구성
├─ 한국 홈베이스
│  ├─ 인가 중학교·고등학교 candidate
│  ├─ 별도 현장교육센터 candidate
│  ├─ 가족·현실 친구·통학·도시 생활
│  └─ 외부 의료·구조·수사·권리·분쟁 주체
├─ 지역 확장
│  ├─ 부제작 3: 서천–군산 금강하구 candidate
│  └─ 부제작 4: 방콕–차오프라야 candidate
├─ 수집 생태계
│  ├─ 동행종·협력 생물
│  ├─ 도감·정정 이력
│  ├─ 회랑 지도·숨은 장소
│  ├─ 유물·도구·보물
│  └─ 영웅·탐사자·실패자 기록
└─ 동반 출판
   ├─ 정정되는 생태 도감
   ├─ 겹길 회랑 지도첩
   └─ 나머지 출판선은 확장 슬롯
```

## 3. 7부제 입력·출력 상태표

| 부제작 | 시작 믿음·상태 | 독립 현장 기능 | 중심/보조 수집축 | 관계·권한 출력 | 다음 작품 필수 입력 |
|---|---|---|---|---|---|
| 1 발견과 부담 | 이상을 숨기고 혼자 관찰하면 해결 가능 | 잘못 분류된 통학 회랑 고립 구조 | 도감 / 회랑 지도 | 도움 요청, 가족 조건부 동의, 예비과정, 첫 정정 | 학교 안에서 보호와 소유가 충돌할 관계 기반 |
| 2 보호와 소유 | 학교 절차와 성과가 가장 안전한 기준 | 대표 경기·시설·이동권 충돌 | 동행 관계 / 배지·경기 장비 | 정식 소속, 이의 제기권, 철회 가능한 협력 | 중앙 기준이 지역마다 다르게 작동한다는 문제 |
| 3 서로 다른 한국 | 같은 국가 안에서는 공통 지도가 가능 | 금강하구의 조수·계절·행정·생업 판본 충돌 | 지역 지도 / 탐사자 기록 | 지역 판본 동등성, 보호 폐쇄 권한 | 한국 기준이 국제 호환 규칙이 될 때 생기는 권력 문제 |
| 4 번역과 국경 | 더 좋은 호환 기록이 모두를 보호 | 방콕 도시 수계의 기록 호환·검역·구조 충돌 | 판본·번역 / 국제 도구·유물 | 현지 최종 결정권 인정, 한국 접근권 조사 | 귀환 후 학교·가족·도시에서 발생할 실제 통제 후폭풍 |
| 5 기록과 공개 | 진실을 공개하면 정의가 회복 | 한국의 새 회랑·통제·생활 위험 사건 | 삭제·현실 증거 / 도시 회랑 지도 | 학교와 결별하지 않는 독립 입장, 제한 공개 | 분산 방식의 느림과 중앙 방식의 효율을 공정하게 비교할 조건 |
| 6 선택권과 독점 | 자신이 통제하면 더 많이 구할 수 있음 | 분산 실패 뒤 중앙 통제·우선권의 실제 성공 | 유물·독점 열쇠 / 영웅·기관 책임 | 성공 인정, 자기 제한, 관계 분화 | 독점 포기가 감정적 희생이 아니라 구조 선택이 될 근거 |
| 7 결정과 공동관리 | 빠른 독점과 느린 분산 중 선택 | 복수 회랑·생활·기반시설·이동의 분산 최종 위기 | 공동 원장·분산 지도 / 반환·정정 | 우선권 해체, 학교 권한 분리, 공동관리, 졸업 후 역할 | 본편 완결. 외전·설정집에 결말 부채 없음 |

## 4. 장기 인물 연결

### 주인공

`관찰·은폐 → 도움 요청 → 팀 역할·거부권 → 다중 판본 → 번역·권한 경계 → 제한 공개 → 독점 성공과 책임 → 권한 분산·감사·지속 참여`

### 홈베이스 관계

- 가족: 허락자에서 학적·의료·정보·진로의 공동 결정자로 변화.
- 현실 친구: 단서 제공자에서 독립 기록자·공개 책임의 당사자로 변화.
- 학교 동료: 고정 삼인조가 아니라 절차·성과와 관계·생태 축이 작품별로 분화·이탈·재협력.
- 멘토: 비밀 설명자나 배신 반전이 아니라 구조·철수·안전 책임과 과거 제도 선택의 당사자.
- 비인간 당사자: 구조 대상에서 협력·거부·거리 두기·철회·재협상 가능한 관계 주체로 변화.

## 5. 핵심 비밀·복선 연결

### 장기 질문

> 왜 서로 다른 사건과 판본에 같은 삭제 항목 ID와 부담 이동 흔적이 남아 있는가?

### 공개 단계

1. **부제작 1**: 삭제 ID 존재와 오분류 반복 가능성만 공개.
2. **부제작 2**: 보호·경기·연구 기록에도 동일한 누락 구조가 있음을 확인.
3. **부제작 3**: 중앙 지도가 지역 판본을 부록화하며 누락을 재생산함을 확인.
4. **부제작 4**: 국제 호환 규칙과 오래된 협정에도 누락 당사자가 있음을 확인.
5. **부제작 5**: 과거 부담 전가가 현재 한국 생활 위험으로 이어짐을 공개.
6. **부제작 6**: 삭제가 단순 은폐가 아니라 빠른 중앙 통제를 가능하게 한 설계 일부였음을 확인.
7. **부제작 7**: 삭제 원장·부담 기록·우선 접근권의 전체 인과를 회수하고 공동 정정 구조로 전환.

### 제한

- 삭제 ID 하나만 장기 미확인으로 유지한다.
- 매 작품에 새로운 비밀 조직·삭제 코드·예언을 추가하지 않는다.
- 부제작 1~6의 현장 사건은 삭제 ID의 답을 몰라도 완결된다.

## 6. 학교·현실 제도 연결

- 인가 학교는 학적·교과·출결·평가·졸업·생활·보건·통학·선택 기숙을 담당.
- 별도 현장교육센터는 관찰·기록·구조 보조 교육, 장비, 전문인력, 철수, 감사를 담당.
- 의료·구조·수사·권리 옹호·분쟁 판단·국제 조정은 외부 독립 주체가 담당.
- 학생 권한은 연령보다 자격·감독·동의·철회 가능성에 따라 상승.
- 보호자 동의는 6년 백지 위임이 아니라 단계별 재협상.

## 7. 수집과 결말 연결

- 도감의 보상: 더 많이 소유하는 것이 아니라 틀린 분류를 정정하고 자기명칭·이견을 남김.
- 지도의 보상: 모든 길을 여는 것이 아니라 보호 폐쇄·거부·공동관리 상태를 정확히 기록.
- 동행의 보상: 영구 계약이 아니라 신뢰·거부·재협상 가능한 관계.
- 유물의 보상: 강한 기능보다 사용 대가·감사·반환·공동 보관의 선택.
- 영웅 기록의 보상: 숨은 진짜 영웅 찾기가 아니라 공적·피해·누락 당사자의 복수 평가.
- 최종 공동 원장은 모든 판본을 흡수하는 중앙 데이터베이스가 아니라 최소 호환·접근·감사·정정 규칙.

## 8. 동반 출판 연결

- 본편 C1 사건을 기반으로 C2 공식판·C3 현장/당사자판·C4 오분류 이력을 확장.
- C0 작가 내부 정본은 판매하지 않음.
- CX 비공개·철회·보호 기록은 사가 종료 후에도 비공개일 수 있음.
- 첫 착수는 `정정되는 생태 도감`과 `겹길 회랑 지도첩`으로 제한.
- 본편의 필수 인과·결말을 설정집에서 보충하지 않음.
