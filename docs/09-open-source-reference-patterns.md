# 오픈소스 본보기와 차용할 패턴

표현이나 세계관을 복제하지 않고 **작업 방법과 정보 구조**만 참고한다.

## AI 작업 규칙

- [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills): 가정 공개, 단순성 우선, 필요한 부분만 변경, 검증 가능한 목표.
- [obra/superpowers](https://github.com/obra/superpowers): 인터뷰→설계 승인→작업 계획→하위 에이전트→이중 검토.
- [bradautomates/claude-video](https://github.com/bradautomates/claude-video): 전체를 무조건 소모하지 않고 필요한 범위와 상세도를 조절하는 조사 예산 개념.
- [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything): 지식 그래프, 안내 순서, 변경 영향, 증분 분석.
- [rohitg00/agentmemory](https://github.com/rohitg00/agentmemory): 지속 메모리, 변경 시 동기화 목록, 감사 로그.

## 세계관 저장소 구조

- [juliandeleonguerrero/obsidian-worldbuilding-template](https://github.com/juliandeleonguerrero/obsidian-worldbuilding-template): 시작 안내, 구조화된 노트, 템플릿형 볼트.
- [hopeoverture/Worldbuilding-System](https://github.com/hopeoverture/Worldbuilding-System): YAML 상태, 재사용 템플릿, 연결 검증, 감사 명령 구조.
- [fenrir22/interactive-fantasy-map-wiki](https://github.com/fenrir22/interactive-fantasy-map-wiki): 지도와 위키의 연결 가능성 참고.

## 참고 금지선

- 고유 명칭, 문장, 설정, 캐릭터, 세계사를 가져오지 않는다.
- 구조를 도입할 때 이 프로젝트의 목적에 필요한 최소 부분만 쓴다.
- 참고 저장소의 규모와 기능을 그대로 재현하려 하지 않는다.
