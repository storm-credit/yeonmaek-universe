# 설정 범위 규칙 v0.1

## 더 만들어야 하는 설정

작품의 원인·선택·대가·일상을 바꾸는 설정은 지금 만든다.

- 존재와 경계의 규칙
- 힘의 비용과 실패
- 생물의 지성·권리·생태
- 비밀 유지와 현실 제도
- 학교 생활과 교육
- 국제 질서와 역사적 전환
- 한국 첫 무대의 반복 생활
- 사건을 계속 발생시키는 구조적 압력

## 아직 만들지 않는 설정

- 모든 국가의 학교 이름과 교과목
- 수백 종의 생물 도감
- 모든 술법 기술 목록
- 전체 역사 연표
- 완성된 캐릭터 이름·외모·대사
- 각 권의 장면·회차·문장
- 상품·게임용 세부 수치

## 판별 질문

새 설정을 제안할 때 다음 중 두 개 이상에 답하지 못하면 보류한다.

1. 어떤 선택을 어렵게 만드는가?
2. 어떤 사건의 원인이 되는가?
3. 어떤 대가 또는 제한을 만드는가?
4. 학교·가정·도시의 일상에서 어떻게 보이는가?
5. 결말의 가능성을 어떻게 바꾸는가?
6. 다른 지역과 충돌하거나 번역되지 않는 차이는 무엇인가?

## 결론

현재 단계는 설정을 멈출 때가 아니라 **핵심 설정을 집중적으로 채우고 장식 설정을 막아야 하는 단계**다.
