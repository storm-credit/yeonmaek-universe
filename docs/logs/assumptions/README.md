# 가정 로그

진행을 위해 임시로 둔 가정을 명시하고 검증 시점과 되돌리는 방법을 관리한다.

## 파일명

`YYYY-MM-DD-<gate-or-topic>-assumptions-v0.1.md`

## 템플릿

```markdown
---
status: open|validated|rejected|superseded
related_issue:
---
# <주제> 가정 로그

| ID | 가정 | 근거 | 틀렸을 때 영향 | 검증 방법·시점 | 되돌리는 방법 | 상태 |
|---|---|---|---|---|---|---|
| A-01 | | | | | | open |
```

## 규칙

- 사실처럼 보이는 추측을 본문에 숨기지 않는다.
- 사소하고 쉽게 되돌릴 수 있는 선택은 가정 로그에 남기고 자동 진행한다.
- 결말·주인공·독자층·실재 문화에 영향을 주는 가정은 인간 승인 또는 별도 게이트가 필요하다.
- 검증 후에도 행을 삭제하지 않고 상태를 바꾼다.
