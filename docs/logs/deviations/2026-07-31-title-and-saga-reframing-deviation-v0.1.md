# 제목·사가 구조 재정의 편차 로그 v0.1

## 편차 1 — 전체 5권 완결형에서 장기 성장형 7부제로 변경

### 원래 계획

`5권 핵심 완결형`을 메인 사가 전체로 사용한다.

### 실제 변경

같은 주인공을 만 12세 전후부터 만 18세 전후까지 따라가는 7부제 장기 성장형 메인 사가, 2/3/2 대형막 candidate로 재정의했다.

### 발견 위치

사용자가 해리포터의 `부제작`과 한국어 물리적 `분권`을 구분하며 장기 성장형 의도를 명확히 한 대화와 #37 사가 게이트.

### 변경 이유

기존 설계는 `권`을 부제작과 물리적 분권으로 혼용했고, 학교·가족·관계·국내 확장·해외 전환·신뢰 붕괴·최종 선택을 5부제에 압축했다.

### 영향

- 기존 5개 기능은 폐기하지 않고 7부제 기능 카드에 재배치.
- 5권 후보 결정은 `reframing required`로 관리.
- 시간축·인물·수집·반복 루프·첫 부제작을 모두 재검토.

### 후속 작업

#37, #41~#48 완료. 통합 회귀 감사에서 남은 `5권/1권` 용어를 검색한다.

## 편차 2 — 첫 부제작 작업 메인명 `틈너머`에서 `겹길` 예비 candidate로 변경

### 원래 계획

첫 부제작 작업 제목을 `《틈너머: 사라진 통학로》`로 사용한다.

### 실제 변경

#49 브랜드 게이트에서 `《겹길》`을 메인 시리즈명 예비 candidate로 제안했다. `틈너머`는 구조 검토 없이 먼저 굳어진 작업명으로 하향한다.

### 변경 이유

- `연맥`·`딥루트`·`숨은결`·학교명 중심 후보를 다시 비교함.
- 전체 7부제의 지도·회랑·귀환·다층 세계 이미지를 포괄하는 제목이 필요함.
- 공개 웹 예비 검색에서 `겹길`의 직접 충돌이 상대적으로 적었음.

### 영향

- 첫 부제작 사건·구조는 유지.
- 첫 부제작 문서의 메인명 표기만 `working title superseded`로 갱신 필요.
- `사라진 통학로`도 최종 부제가 아니라 작업 예시로 유지.
- 영문명·상표·실제 독자 테스트 전 canon 승격 금지.

### 새 위험

- `겹길` 뜻이 어린 독자에게 즉시 전달되지 않을 수 있음.
- 로마자·영문 브랜드 일관성이 불확실함.

### 복구·후퇴안

독자 테스트나 상표 조사 실패 시 핵심 사건과 브랜드를 분리하고 새로운 순한국어·혼합어 4안 게이트를 다시 연다.

## 승인 필요 여부

- `겹길` canon 승격: 작가 승인 필요.
- 현재 문서상 candidate 재표기: 자동 진행 가능.
