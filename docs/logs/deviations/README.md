# 편차 로그

계획이 실제 작업 중 변경되면 변경 사실과 이유를 숨기지 않고 이 디렉터리에 남긴다.

## 파일명

`YYYY-MM-DD-<gate-or-topic>-deviation-v0.1.md`

## 템플릿

```markdown
---
status: open|resolved|accepted
related_issue:
related_decision:
---
# <주제> 편차 로그

## 원래 계획

## 실제 변경

## 발견 위치

## 변경 이유

## 막힌 원인

## 영향받는 항목

- 문서:
- 정본·결정:
- 복선:
- 인물:
- 지역·기관:
- 수집축:

## 새로 생긴 위험

## 복구·후속 작업

## 승인 필요 여부

## 종료 상태
```

## 규칙

- 단순한 문장 다듬기나 파일 정렬은 기록하지 않는다.
- 사건 인과, 사가 구조, 정본 상태, 조사 지역, 완료 순서가 바뀌면 기록한다.
- 실패한 시도도 재발 방지를 위해 남긴다.
- 계획과 달라졌다는 사실을 결과 보고에서 숨기지 않는다.
- 해결된 편차도 삭제하지 않고 `resolved`로 남긴다.
