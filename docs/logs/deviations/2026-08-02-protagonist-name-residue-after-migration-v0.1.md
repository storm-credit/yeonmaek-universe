# 주인공 이름 마이그레이션 후 옛 호칭 잔재 발견

## 발견

`story/30-books/installments-02-07-setting-bible-index-v0.1.md`의 유나 성장 설명에 이전 단독 호칭 `이안` 1건이 남아 있었다.

## 영향

- 사건·인물·복선·원고에는 영향 없음.
- 최신 이름 기준선 `서하진/하진`과 색인 문구가 불일치함.
- 기존 마이그레이션 보고의 `활성 옛 이름 잔재 0건`은 검색 범위 또는 색인 갱신 시점상 완전하지 않았음.

## 원인

1. 대량 이름 변경 뒤 코드 검색 색인이 최신 커밋을 즉시 반영하지 않음.
2. 검색 결과 0건을 저장소 전체 직접 스캔과 동일하게 취급함.
3. 후속 생성·갱신된 색인 문서를 마이그레이션 재검사 범위에 다시 넣지 않음.

## 복구

- 해당 문구를 `하진의 개인 기록 관리자가 아닌 독립 시민 참여자`로 수정.
- 부제작 2~7 색인을 v0.2로 갱신.
- 이전 이름은 변경 이력·편차 문서에서만 허용.

## 재발 방지

- 이름·용어 마이그레이션 완료 뒤 후속 생성 문서까지 포함한 2차 검사 실시.
- 검색 색인 0건만으로 완료 판정하지 않음.
- 핵심 색인·PR 설명·README·원고 최신본을 별도 수동 표본 검사.
- `P02 용어 관리자 + N16 연속성 + P09 정본` 공동 서명 전 완료 선언 금지.
