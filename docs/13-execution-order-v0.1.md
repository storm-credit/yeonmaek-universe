# 장기 성장형 세계관·작품 설계 자동 실행 순서 v0.2

## 목적

이 문서는 세계관 설정을 늘어놓는 순서가 아니라, **같은 주인공의 장기 성장형 메인 사가를 원고 직전 설계 패키지까지 자동으로 완주하는 의존 순서**를 정한다.

사용자가 `진행`, `계속`, `끝까지 설계`를 승인한 상태에서는 각 단계의 `candidate` 산출물까지 불필요한 재질문 없이 진행한다. `candidate → canon`, 실제 문화의 민감한 전용, 법률·상표 판단만 인간 승인 게이트로 남긴다.

## 서사 단위

`공유세계관 → 메인 사가 → 대형막 → 부제작 → 부제작 내부 막 → 사건`

- 부제작: 고유 부제를 가진 독립 장편
- 분권: 한 부제작을 나눈 물리적 책이며 출판 단계에서만 결정
- `권`이라는 단독 표현은 사용하지 않는다.

### 상태

`complete / active contract`

### 확정된 의도

- 동일 주인공의 장기 성장형 본편
- 한국 학교·가족·현실 생활의 지속적 홈베이스
- 초등 고학년~중학생 핵심, 성인까지 확장되는 크로스오버

- 수집욕구를 만드는 동행종·도감·지도·유물·영웅 기록
- 본편 완결 뒤 동반 설정집·다른 시대·지역 작품 확장 가능
- 원고·장면·대사는 설계 완료 전 작성하지 않음

## Phase 8 — 학교·탐사·경기·가족 반복 루프

### 작업

- 학교 일상이 매 부제작에서 같은 일정으로 반복되지 않게 변주

- 해외 활동 뒤 한국 귀환이 단순 휴식이 아니라 변화 확인이 되게 설계

## 자동 진행 중지 조건

- 양립 불가능한 작가 의도
- 실제 문화의 민감한 직접 전용
- `candidate → canon` 승격 필수
- 되돌리기 어려운 레트콘
- 안전한 사실 검증 불가

그 밖의 사소한 명칭·파일·순서는 가장 보수적인 안으로 진행하고 가정·편차 로그에 남긴다.
