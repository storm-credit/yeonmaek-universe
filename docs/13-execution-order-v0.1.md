# 설계 실행 순서 v0.1

## 원칙

세계관 문서를 많이 만드는 것이 목표가 아니다. 다음 단계가 앞 단계의 가정을 소비하므로 의존 순서를 지킨다.

## Phase 0 — 작가 기준선

### 입력

- 사용자 대화
- `docs/12-author-intent-v0.1.md`

### 완료 조건

- 목표 독자와 톤의 잠정 기준
- 현재 현실과의 거리
- 한국 시작점
- 소설 원고 미작성 원칙

### 상태

`provisional complete`

---

## Phase 1 — 세계 상위 구조

### 작업

1. 범아시아 중첩 구조 4안 비교
2. 지역 조사권 지도
3. 문화 출처와 감수 정책
4. 국제 조정 조직의 기능만 정의

### 선행 문서

- `world/10-regions/pan-asian-architecture-v0.1.md`
- `docs/10-cultural-research-policy.md`

### 중지 조건

- 국가 하나가 술법 하나로 환원되면 중지
- 조사 없는 현존 종교·민족 설정이 정본화되면 중지

### 승인 게이트

작가가 혼합 중첩형을 1순위로 승인하거나 대안을 선택한다.

---

## Phase 2 — 현실 연결 규칙

### 작업

1. 현실 깊이와 출입 조건
2. 일반인의 지각 정상화
3. 스마트폰·CCTV·SNS 규칙
4. 교육·의료·법·교통 접점
5. 대규모 노출 실패 사례

### 선행 문서

- `world/20-systems/hidden-world-interface-v0.1.md`

### 검증

- 동일 사건을 일반인, 학생, 카메라, 경찰이 각각 어떻게 기록하는지 사례 테스트
- 서울 지하철, 산길, 항구, 공항 사례 테스트

---

## Phase 3 — 힘과 수련 체계

### 작업

1. 공통 관측층과 지역 해석층
2. 기능 분류 F1~F6 검증
3. 비용·실패·현대 기술 상호작용
4. 학교 공통 안전 교육
5. 지역별 호환성 카드

### 선행 문서

- `world/20-systems/power-system-architecture-v0.1.md`

### 중지 조건

- 모든 체계를 에너지 수치 하나로 환산하면 중지
- 지역 전통이 주인공용 스킬 목록으로 축소되면 중지

---

## Phase 4 — 한국 첫 기관

### 작업

1. 현실 학교의 법적 형태
2. 표면·경계·심층 캠퍼스
3. 입학과 학생 신분
4. 교과와 일상
5. 국내 계절원과 국제 교류

### 선행 문서

- `world/30-korea/korea-entry-architecture-v0.1.md`

### 승인 게이트

- 서울·수도권 혼합형 여부
- 특성화 학교+연구재단 구조 여부
- 기숙/통학 비율 방향

---

## Phase 5 — 이면 생물 생태

### 작업

1. 현실 생물과의 관계
2. 진화·이동·계절·지성·보존 분류
3. 전설과 실제 종의 관계
4. 인간 문화가 생물에 미치는 영향
5. 생물 보호 윤리

### 의존성

지역 구조와 현실 연결 규칙이 확정되기 전 완성 생물을 대량 생성하지 않는다.

---

## Phase 6 — 학교 대표 경기

### 작업

1. 4안 비교
2. 권장 결합안 규칙 테스트
3. 안전·반칙·관전 화면
4. 학교 리그와 국제대회
5. 지역별 경기장 변형

### 선행 문서

- `world/20-systems/ritual-sport-options-v0.1.md`

### 승인 게이트

`맥로 개척전+진문 쟁탈전` 결합을 유지할지 결정한다.

---

## Phase 7 — 권역별 파일럿 조사

### 첫 비교 묶음

1. 한국 내부 4~5권
2. 중국 동북부의 특정 지역 1곳
3. 일본 서부 또는 규슈의 특정 지역 1곳
4. 태국의 특정 도시·수계 1곳
5. 베트남의 특정 도시·수계 1곳

국가 전체를 한 번에 설정하지 않는다.

### 결과물

- 출처 카드
- 실제 사실과 창작 변형 분리
- 지역 내부 다양성
- 교류 가능한 생태 회랑 후보
- 피해야 할 클리셰
