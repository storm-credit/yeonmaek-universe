# 성공 조건

## 저장소 수준

- README 첫 화면에서 목적, 비목표, 시작 문서를 알 수 있다.
- 모든 핵심 문서에 상태가 표시된다.
- 정본 변경은 결정 로그와 영향 검토 없이 병합되지 않는다.
- AI가 새 세션에서도 `CLAUDE.md`, `AGENTS.md`, `memory/`로 맥락을 복구한다.

## 세계관 수준

- 한국 중심의 시작과 범아시아 확장이 동시에 설명된다.
- 국가 하나에 마법 하나를 배정하지 않는다.
- 공통 세계 원리와 지역별 해석이 분리된다.
- 현실의 스마트폰·교통·국경·도시개발과 모순되지 않는 연결 규칙이 있다.
- 대표 경기 또는 공동 활동이 학교 일상, 라이벌, 국제 교류를 담당한다.
- 생물은 서식지와 생태 관계를 가진다.

## 문화 수준

- 주요 지역 문서는 현지/학술/공공 출처를 포함한다.
- 살아 있는 종교와 의례의 직접 전용 여부를 검토한다.
- 각 권역 내부의 다양성과 반례가 기록된다.
- 현지 감수가 필요한 항목이 명시된다.

## 완료 판정

문서 수가 아니라 `결정 가능성`, `추적 가능성`, `확장 안정성`, `문화적 책임성`으로 판정한다.
