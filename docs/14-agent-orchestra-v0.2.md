# 에이전트 오케스트라 v0.2

## 1. 우리가 만드는 것

이 프로젝트의 산출물은 소설 원고가 아니라 다음을 포함한 **세계관 및 작품 설계도**다.

- 세계의 존재 원리와 현실 연결 규칙
- 범아시아 지역 구조와 국가·지역별 조사 문서
- 힘·수련·생태·기관·교육·경기 체계
- 시리즈 전체 결말과 권별 인과 구조
- 맥거핀, 비밀, 복선, 회수표, 반전 검증표
- 캐릭터 기능, 관계 변화, 감정선 설계
- 도감·지도·연표·용어집·정본 관리

작성 금지: 완성 장면, 대사, 문체 모사, 회차 원고.

## 2. 총괄 구조

### A00 총괄 오케스트레이터

모든 요청을 다음 순서로 처리한다.

`의도 확인 → 산출물 정의 → 관련 에이전트 선발 → 병렬 조사/설계 → 상호 반박 → 통합안 → 맹점 검토 → 정본 상태 결정 → 영향도·메모리 갱신`

A00은 직접 모든 분야를 아는 역할이 아니라, 충돌하는 전문 의견을 드러내고 무엇이 아직 미확정인지 관리한다.

### 세 개의 평의회

1. **세계 평의회**: 세계 원리, 지역, 문화, 생태, 힘, 현실성
2. **서사 평의회**: 결말, 권별 구조, 복선, 미스터리, 캐릭터, 주제
3. **검증 평의회**: 문화 무결성, 인과·연속성, 독창성, 독자 이해도, 정본 관리

중요한 결정은 세 평의회 중 최소 두 곳의 검토를 받아야 한다.

## 3. 에이전트가 필요한 이유

| 위험 | 필요한 에이전트 |
|---|---|
| 국가 하나를 하나의 마법으로 단순화 | 국가별 조사 데스크 + 문화 무결성 |
| 세계관은 크지만 이야기가 움직이지 않음 | 결말 역산·인과 구조·권별 아키텍트 |
| 복선이 장식이거나 회수되지 않음 | 복선·회수 회계관 |
| 맥거핀이 편의적 열쇠로 변함 | 욕망 객체·맥거핀 설계자 |
| 반전이 정보 은폐나 거짓말에 의존 | 미스터리·공정성 검증자 |
| 학교·경기·생물이 해리포터 복제처럼 보임 | 독창성·비교작 레드팀 |
| 캐릭터가 세계관 설명 도구가 됨 | 캐릭터 기능·관계 설계자 |
| 지역 조사와 판타지 기능의 경계가 흐림 | 출처 감사·변형 거리 담당 |
| 설정 변경이 다른 문서와 충돌 | 정본·영향도·연속성 관리자 |

## 4. 국가별 에이전트의 공통 계약

각 국가 데스크는 반드시 다음을 제출한다.

- 국가 내부 하위 지역 최소 4개
- 현대 도시·농촌·교통·생업
- 산맥·강·해류·계절풍·재해·생태 회랑
- 언어·민족·종교·계층의 복수성
- 역사적 층위를 현재 생활과 분리하지 않는 설명
- A/B급 출처와 자기서술 자료
- 피해야 할 관광·민족성 클리셰
- 판타지로 직접 전용하면 안 되는 신성 대상
- 세계관에 사용할 수 있는 것은 `기능 추상화`까지만 제안

국가 데스크는 술법·학교·생물의 최종 이름을 확정하지 않는다.

## 5. 서사 설계의 공통 계약

서사 에이전트는 모든 제안을 다음 표로 제출한다.

- 독자가 처음 아는 사실
- 실제 진실
- 누가 무엇을 원해서 사건을 움직이는가
- 원인과 결과
- 심는 정보
- 오독 가능성
- 회수 시점과 형태
- 회수되지 않으면 삭제할 항목
- 세계관 설정에 미치는 영향

## 6. 승인 단계

- `hypothesis`: 한 에이전트의 작업 가설
- `candidate`: 다른 구조 4안 중 비교 대상
- `provisional`: 평의회 검토를 통과한 임시안
- `canon`: 작가 승인 + 문화/인과/연속성 검토 통과

국가별 실제 문화 기반 설정은 작가 승인만으로 canon이 되지 않는다. 출처·문화 무결성 게이트도 통과해야 한다.
