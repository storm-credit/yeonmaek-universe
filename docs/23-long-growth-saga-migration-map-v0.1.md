# 장기 성장형 메인 사가 마이그레이션 지도 v0.1

## 변경 요약

기존 설계는 `5권 핵심 완결형`을 메인 사가 전체로 취급했다. 현재 작가 의도는 **같은 주인공이 여러 고유 부제작을 통과하며 성장하고, 여러 부제작이 대형막을 이루는 장기 성장형 메인 사가**다.

따라서 기존 산출물을 삭제하지 않고 다음 세 상태로 분류한다.

- `retain`: 장기 사가에서도 그대로 유지
- `reframe`: 기능은 유지하되 서사 단위와 배치 재검토
- `rebuild`: 새 사가 구조 이후 다시 설계

## 유지 retain

- 다층 생태 위상과 부담 보존 규칙
- 지성종·생태·권리 원칙
- 표면 특성화학교+심층 교육 혼합형
- 통학·가족·현실 생활 고정점
- 다중 협정망·후발 국제 조정체
- 부담 전가형 구조 갈등 엔진
- 잘못 분류된 도감·분산 부담 기록형 핵심 비밀
- 주인공의 독점 고정점 해체·관계 재구성형 최종 개인 대가
- 통학 회랑 사건의 핵심 인과
- 대표 경기의 단일 승리 조건과 안전 원칙

## 재구성 reframe

### 기존 다섯 기능

- 발견과 부담
- 보호와 소유
- 번역과 국경
- 기록과 공개
- 결정과 공동관리

고정된 다섯 부제작에서 해제하고 대형막 질문·부제작 압력축·사가 회수 기능으로 재배치한다.

### 기존 `1권` 문서

현재의 첫 작품 후보로 임시 연결하되, #37에서 메인 사가 길이와 대형막이 결정되기 전에는 `첫 부제작 후보`로만 부른다.

### 해외 3권 배치

해외 확장 자체는 유지하지만 세 번째 부제작 자동 배치는 해제한다. 해외 지역 연구 #36은 필요한 서사 기능이 정해진 뒤 실행한다.

### 경기 배치

대표 경기의 규칙 후보는 유지하되 두 번째 또는 세 번째 부제작 자동 배치를 해제한다.

## 재설계 rebuild

- 메인 사가의 부제작 수
- 대형막 수와 각 대형막의 부제작 분배
- 주인공 시작·종료 연령과 시간 경과
- 중앙 전환점의 위치와 기능
- 각 부제작의 고유 부제와 독립 사건
- 부제작별 수집축 공개 예산
- 한국 홈베이스의 장기 변화 지도
- 동반 출판물의 공개 시점
- 메인 사가 완결 뒤 다른 시대·지역 작품의 착수 조건

## 용어 마이그레이션

| 기존 표현 | 새 표현 | 처리 |
|---|---|---|
| 시리즈 5권 | 메인 사가 5부제 후보 | 재검토 |
| 1권 | 첫 부제작 후보 | 임시 변환 |
| 권별 구조 | 부제작별 구조 | 문서 마이그레이션 |
| 큰 액트 | 대형막 | 통일 |
| 실제 책 1~N권 | 분권 | 출판 단계로 이동 |
| 나라별 사이클 | 메인 사가 완결 후 지역·시대 확장 작품 | 후순위 |

## 우선순위

1. #37 메인 사가 4안
2. 대형막 구조
3. 주인공 성장 연표
4. 부제작 전체 지도
5. 수집욕구 공개 예산
6. 첫 부제작 재설계
7. 해외 지역 연구 #36
8. 동반 출판선 #38
9. 통합 레드팀과 정본 승격 제안

## 완료 조건

- 기존 문서가 삭제 없이 retain/reframe/rebuild 중 하나로 분류됨
- `권`의 모호한 용례가 활성 결정 문서에서 제거됨
- #37의 새 후보가 기존 사건·복선·캐릭터 모듈을 어디에 재배치하는지 추적 가능함
