# 제2장 — 우선 연결자

계약서에는 하진이 할 수 없는 일이 먼저 적혀 있었다.

시설 조작 금지. 의료·구조 지휘 금지. 지역 중지 결정 금지. 수용처 지정 금지.

할 수 있는 일은 기록 연결, 공통 경보 제안, 요청 순서 정리, 제한 유물 사용이었다.

“최종권한은 없네요.” 하진이 말했다.

독립 감사관이 대답했다.

“그래서 약한 권한이라고 생각하면 안 됩니다. 무엇이 먼저 보이고 먼저 요청되는지가 실제 행동 순서를 바꿉니다.”

돌림패에는 만료 시각이 붙었다. 숨은추와 비움매듭은 성인 운영자의 승인 없이는 사용할 수 없었다.

지현은 계약서를 끝까지 읽었다.

“거절해도 돼.”

하진은 세 생활권 경보를 떠올렸다. 모두 합리적으로 기다리는 동안 시간이 줄고 있었다.

“안 하면 더 늦어질 수도 있어.”

“그것도 선택이지. 하지만 수락한 뒤 나올 책임도 네 거고.”

하진은 서명했다.

손목 화면에 새 항목이 떴다.

`제한 우선 연결권 활성.`

최종 결정권은 없었다.

그런데 가장 먼저 울리는 요청은 이제 하진에게 도착했다.
