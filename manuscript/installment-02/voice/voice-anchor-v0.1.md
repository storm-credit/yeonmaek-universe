# 두 번째 부제작 문체·서술 앵커 v0.1

## 핵심

첫 부제작의 가까운 3인칭과 기록 중심 감각을 유지하되, 학교 공동체·친구 대화·길문전의 움직임을 늘려 더 밝고 넓은 독자 경험을 만든다.

## 시점

- 서하진 중심 3인칭 제한근접, 과거형
- 한 장 안의 무표지 시점 전환 금지
- 하진이 모르는 생물의 의도·교사의 비공개 대화·다른 팀 작전을 확정하지 않음
- 경기 장면에서도 관중 전체의 감정을 전지적으로 요약하지 않음

## 문장 리듬

- 기본: 명료한 중단문과 짧은 복문
- 학교 일상: 대화와 행동을 교차해 속도를 올림
- 경이·공간 발견: 문장 길이를 조금 늘려 시선의 이동을 연결
- 경기: 결정적 동작은 세부적으로, 반복 이동은 압축
- 단문 금지 아님. 단문 다섯 개 이상 연속은 의도 점검
- 한 줄 문단은 판단·접촉·반전·중지 신호에 제한

## 학교 톤

갈등 전에 다음을 충분히 보여 준다.

- 통학 아침 지도
- 빈자리 수첩과 정정 도장
- 급식·온실·수리 시장·동아리·응원 구역
- 서툰 신입 훈련과 팀 농담
- 교사가 잘 가르치고 학생이 실제로 성장하는 순간

학교는 처음부터 수상한 기관처럼 보이면 실패다.

## 하진의 감각

우선순위:

1. 순서·반복·마모 흔적
2. 길표와 사람의 이동선
3. 호흡·발밑 진동·장비 반응
4. 빛·재질·공간의 겹침
5. 냄새·온도·소음

하진은 모든 것을 정확히 보는 천재가 아니다. 설명서와 실제 사용 흔적의 차이를 오래 보는 습관이 있다.

## 대화 음성

- 하진: 확인 질문, 건조한 반응, 필요할 때 말을 늦춤
- 하람: 절차의 이유와 확인 가능한 항목을 말함
- 도겸: 의미 확정보다 행동 조건을 구분함
- 유나: 생활 맥락과 자료의 사용 범위를 되묻음
- 다온: 팀 약속·완주·교대 책임을 중시함
- 재율: 공개 규칙 안의 공정성과 실제 유리함을 찌름
- 유림: 규칙을 몸으로 이해시키며 재미있게 가르치지만 일정과 관계 문제를 분리하려 함
- 지현: 활동별 동의 근거와 생활 비용을 확인함
- 세린: 중지·철수·인계 범위를 짧고 명료하게 말함

이름을 지운 대화에서도 관점과 목적이 구분돼야 한다.

## 길문전 액션

매 중요 비트마다:

`목표 → 현재 연결 길표 → 위치·거리 → 움직임 → 방해/저항 → 연결 상태 변화 → 신체·팀 비용 → 새 선택`

- 기술명 나열 금지
- 봉화까지 남은 연결 상태를 관중이 이해할 수 있어야 함
- 부딪힘보다 차단·우회·교대·연결·중지가 중심
- 피로와 장비 상태가 다음 선택에 남음

## 생물 묘사

### 온기고리

- 따뜻함·간격·접근·이탈을 행동으로만 묘사
- 호감·걱정·배신 같은 인간 감정으로 확정 금지
- 하진이 부르거나 소환하지 않음

### 모서리잠

- 구조물과 생물의 경계를 흐리는 접힘·판·간격·하중 반응
- 귀여운 마스코트나 경기 장애물로 축소 금지
- 이동을 거부하거나 남는 개체가 있을 수 있음

## 웹연재 화

각 화는 약속·진전·보상·추진 중 최소 3개를 가진다.

- 1~4장에서는 학교의 매력 보상이 갈등 경고보다 앞서야 함
- 매 장 끝을 음모·공포로 닫지 않음
- 팀 후보, 보호 계획, 새로운 관계처럼 긍정적 추진도 사용

## 금지

- 특정 한국 웹소설 작가의 문장·말투 모사
- 모든 문단 한 줄화
- 학교 설정 강의
- 경기 규칙을 인물이 설명서처럼 전부 낭독
- 생물 철회를 주인공의 감정 평가로 대체
- 보호 계획 책임자를 악역처럼 미리 코딩
- 하진이 중지 권한을 시설 지휘권으로 확대
