# 부제작 3 문체·서술 앵커 v0.1

## 기본

- 근접 3인칭 과거형, 하진 중심
- 중단문·짧은 복문 중심의 가변 리듬
- 단문은 발견·판단·실패·전환에 제한
- 여행 안내문식 설명 금지
- 지도 정보는 걷기·측정·표식 이동·생활 시간표의 충돌 속에서 공개

## 장르 차별화

1부제의 도시 미스터리, 2부제의 학교 스포츠와 달리 3부제는 `움직이며 측정하는 국내 탐사물`이다.

- 풍경은 방향과 이동 조건을 바꾼다.
- 길은 거리보다 조수·작업·돌봄·수분 상태에 따라 달라진다.
- 회의에서 정답을 얻지 않고 현장 표식을 다시 놓으며 판단한다.
- 실제 지역을 대리 설명하지 않고 합성 하구 생활권의 기능만 사용한다.

## 하진의 음성

- 설명서·지도·마모 흔적을 비교하는 습관 유지
- 둘을 하나로 합치면 더 정확해진다고 믿는 경향 강화
- 유머는 건조하고 관찰 중심
- 지역 인물의 말을 곧바로 교훈으로 번역하지 않는다.

## 액션·탐사

`목표 → 기준점 → 이동 → 바닥/수분/시설 저항 → 측정 변화 → 비용 → 새 위치`

- 발이 빠지는 깊이, 표식 간 거리, 물러나는 시간, 장비 무게를 연속성 있게 기록
- 생물은 정답을 가르치지 않고 상태 변화에 반응
- 학생은 표식·관찰·중지 요청까지만 수행
- 시설 운전·통제·복구 결정은 지역 책임자가 수행

## 반복 이미지

- 서로 어긋난 네 장의 지도
- 뒤집힌 잎의 은빛 면
- 수분선에서 갈라지는 물갈피
- 한 번 박았다 다시 뽑는 표식
- 학교 전시본의 작은 각주

## 금지

- 지역판은 선하고 중앙판은 악하다는 구도
- 전통과 현대 시설의 단순 대립
- 하진이 현지인보다 지역을 더 잘 아는 장면
- 생물이 길을 직접 안내하는 예언 장치
- 실제 지역·보호종·기관의 단정적 재현
