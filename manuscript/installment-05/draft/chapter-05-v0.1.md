# 제5장 — 학교 안의 빈칸

학교 기록실에는 지워진 문장보다 남은 칸이 더 많았다.

하진은 삭제 ID를 검색했다. 화면에는 내용 대신 처리된 필드와 시각, 작업 권한만 떴다.

`위치.`

`생활 피해 연결.`

`대체교통 참조.`

세 필드가 같은 묶음 작업에서 사라졌다.

“위치 보호 때문에 같이 지운 건가?” 하람이 물었다.

학교 기록 책임자는 작업 이력을 열었다.

“민감 위치가 여러 문서에 반복돼 한 번에 정리했습니다.”

“생활 피해랑 대체교통도 같은 이유였어요?”

책임자는 바로 대답하지 못했다.

유나는 시민 영상 목록을 띄웠다. 학교 로그에서 비어 있는 시간대에도 주민 영상과 교통 지연 기록은 남아 있었다.

“학교 안에서는 위치 보호가 먼저였고, 밖에서는 생활 피해가 먼저 남았네.”

“둘 다 거짓은 아니야.” 하진이 말했다.

오세린은 학생들에게 공개 초안을 만들지 말라고 했다.

“같은 삭제라도 이유가 다를 수 있다. 지금은 분류부터 해야 해.”

하진은 삭제 ID 옆에 `확인 필요`라고 적었다.

기록실을 나가기 전, 학교 책임자는 같은 날 처리된 다른 문서 목록을 보여 줬다. 생태 위치 보호 요청, 통학 피해 기록, 상가 문의, 학생 상담 메모가 한 작업 번호 아래 있었다.

“한 사람이 전부 지운 거예요?”

“작업 계정은 하나였지만 요청한 곳은 여러 곳이었습니다.”

한 명을 찾아내면 끝나는 구조가 아니었다.

학교 안에서 사라진 것은 내용만이 아니었다. 서로 다른 이유가 하나의 삭제로 합쳐진 흔적도 함께 희미해지고 있었다.
