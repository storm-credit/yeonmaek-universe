# 제2장 집필 브리프 — 집으로 가져온 빈칸

- 목표: 귀가·연락 지연을 설명하고 통학 이상을 기존 관찰 지도와 대조한다.
- 시작: 하진은 사진·메모의 시간 불일치를 혼자 확인 중이다.
- 가족 갈등: 지현은 위험 자체보다 설명 없이 연락 규칙이 깨진 것을 문제 삼는다.
- 선택: 하진은 흰 띠와 시간 이상을 숨기고 단순 지연으로 설명한다.
- 비용: 정보 비대칭이 시작되고 통학 확인 조건이 강화된다.
- 공식 단서: 깊은결학교 예비과정의 생활 관찰 지도는 해당 구간을 `안정`으로 표시한다.
- 장 끝: 현실 기록과 학교 지도가 동시에 맞을 수 없다고 판단하고 직접 재확인을 결심한다.
- 새 고유명사 예산: 깊은결학교 1개.
- 금지: 지현을 모험 방해자로 만들기, 학교 지도를 절대 정답처럼 서술하기.
