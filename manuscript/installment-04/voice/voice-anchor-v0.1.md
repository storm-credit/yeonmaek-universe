# 부제작 4 문체·번역·재난 스릴러 앵커 v0.1

## 기본 시점

- 서하진 근접 3인칭, 과거형
- 하진이 본 화면·들은 번역·직접 확인한 행동만 확정한다.
- 현지 인물의 속마음과 문답결의 의도를 서술자가 대신 번역하지 않는다.

## 장르 체감

- 해외 관광물이 아니라 36시간 이중 카운트다운 스릴러
- 첫 시계: 검역 이송까지 남은 시간
- 둘째 시계: 수문 단계 운영 가능 창
- 표준 절차가 실제 사고를 줄이는 성공을 먼저 보여 준다.
- 위험은 악당 폭로가 아니라 번역·접근 순서·운영 창의 충돌에서 커진다.

## 문장 리듬

- 이동·관찰·화면 비교: 중단문과 짧은 복문
- 경보·철수·운영 전환: 명확한 단문을 제한적으로 사용
- 번역 설명은 긴 정의문보다 서로 다른 화면·표식·행동 결과를 병치
- 같은 전문 용어를 연속 반복하지 않고 현재 행동에 필요한 뜻만 사용

## 장면-반응

행동 장면 뒤 반드시 최소 하나를 남긴다.

- 몸의 피로·습기·소음·시야 변화
- 현지 기록자와의 신뢰 변화
- 한국 학교 책임자의 접근 축소
- 하진의 화면에서 사라지거나 추가된 권한
- 다음 행동의 선택지와 포기 비용

## 설명 전달

- 국제 코드: 경보 작성·변환·송신·오독 결과 속에서 설명
- 수문 운영: 운영실 관찰·대체 동선·시간 창 판단 속에서 설명
- 현지 생활: 이동·식사·학교 교류·우회·대기 속에서 제한적으로 제시
- 실제 태국어·기관명·시설 구조는 사용하지 않고 기능명·합성 지명 사용

## 액션·재난 공간

- 물 위 보행로·운영실·대기 구역·검역 이송선·대체 동선을 기준점으로 삼는다.
- 하진은 경보 작성·자료 비교·중지 요청·접근 토큰 이양만 수행한다.
- 수문 조작·대피 지휘·검역 판정·의료 판단은 성인 책임자가 한다.

## 현지 인물 원칙

- 현지 학생 기록자는 하진의 안내자나 문화 설명서가 아니다.
- 통역·중재자는 단어 치환자가 아니라 대표·비공개·철회 필드를 관리한다.
- 수문 책임자는 결말의 실제 운영 결정을 한다.
- 국제 검역 책임자는 과거 성공 경험과 현재 책임 때문에 표준 격리를 지지한다.

## 결말 회수

- 물리: 전면 격리 축소, 단계 운영, 대체 동선
- 제도: 최소 경보와 현지 원문 분리
- 관계: 하진과 현지 기록자의 자료 범위 재협상
- 생활: 귀환·보호자 동의·학교 접근 범위 변화
- 사가: 누락 협정 서명 형식 하나만 이월
