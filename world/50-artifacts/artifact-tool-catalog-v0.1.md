# 유물·도구 최초 카탈로그 v0.1

상태: P1 후보. 기존 프로젝트의 유물명과 수량을 이관하지 않고 세계 규칙에서 새로 도출했다.

## 기본 원칙

- 도구는 능력을 대신하지 않고 관찰·중지·복구를 돕는다.
- 강한 도구일수록 더 큰 소유권이 아니라 더 큰 책임과 기록 의무를 요구한다.
- 제작자·수리자·사용자·보관자를 분리 기록한다.
- 생물·장소에서 떼어낸 구성품은 동의·회수·반납 규칙을 가진다.

## 도구 성장 방식

도구는 레벨업하지 않는다. 성장의 표지는 다음과 같다.

1. 사용자가 한계를 정확히 설명한다.
2. 사용하지 말아야 할 상황을 안다.
3. 동료에게 안전하게 넘길 수 있다.
4. 수리·반납·폐기 책임을 수행한다.
5. 더 단순한 도구로 같은 문제를 해결할 수 있다.

## 금지

- 만능 탐지기
- 기억 삭제 장치
- 거리·시간 비용을 무시하는 순간이동 도구
- 유물 소유만으로 신분이 결정되는 구조
- 수집 수량이 곧 전투력인 구조
