# 유물·도구 심층 카탈로그 v0.2

상태: P1 심층 후보. 총 30종. 무기·전투력 증폭·소유권 자동 부여를 금지한다.

## 공통 필드

- 기능 / 사용 조건 / 실패 방식 / 오용 위험 / 제작·수리 계보
- 보관·반납 권한 / 사건 활용 / 대체 가능성

## 1. 관찰 도구 1~6

### 1. 겹길자
서로 겹친 이동선의 폭과 어긋남을 잰다. 한 사람이 혼자 들면 현재 위치만 측정되고, 두 사람이 각기 다른 귀환 목표를 말해야 비교값이 열린다. 강제로 정답 경로를 표시하지 않는다. 축이 휘면 가까운 길을 안전한 길로 오판한다. 지역 수리공이 눈금보다 사용 이력을 먼저 교정한다.

### 2. 물결판
수계 표면의 흐름과 숨은 이동 폭을 비교한다. 오염 탐지기가 아니며, 생물 반응과 인간 시설의 차이를 분리해서 기록한다. 장시간 고정 설치하면 수계 생물이 장치를 피하므로 이동 관찰만 허용한다.

### 3. 잔흔붓
지워진 표식의 층위를 드러낸다. 누가 지웠는지는 표시하지 않고, 덧쓰기·마모·의도적 비움만 구분한다. 증거 조작 위험 때문에 두 기관의 공동 입회가 필요하다.

### 4. 둘레종
관찰자가 안전거리 안으로 들어가면 소리 대신 진동으로 경고한다. 생물마다 거리가 달라 범용 수치가 없다. 훈련생이 경고를 견디는 식으로 사용하면 감각 손상이 생긴다.

### 5. 안개실
시야가 아니라 습도·소리·보폭을 기록하는 가는 실. 팽팽히 당길수록 정보가 줄어든다. 통제 욕구가 강한 사용자의 오판을 드러내는 교육 도구다.

### 6. 판본경
두 기록의 차이를 비추되 어느 쪽이 진실인지는 판정하지 않는다. 기관 감사에 유용하지만 문맥 없는 차이 공개로 갈등을 키울 수 있다.

## 2. 중지·철수 도구 7~12

### 7. 멈춤끈
팀원 누구나 당겨 임무를 중지할 수 있다. 매듭을 풀기 전에는 다수결로 재개할 수 없다. 반복 오작동을 이유로 제거하면 학교 안전 규정 위반이다.

### 8. 숨고름패
호흡과 보폭이 급격히 어긋날 때 빛이 흐려진다. 체력 점수 장치가 아니며 공황·피로·공간 반응을 구분하지 않는다. 사용자가 스스로 중지를 요청하도록 돕는다.

### 9. 되짚등
철수 때 지나온 선택점만 비춘다. 새 지름길을 만들지 않는다. 기록이 누락되면 마지막 확인 지점에서 꺼져 구조자의 과신을 막는다.

### 10. 반납못
임시 설치 도구를 회수하지 않으면 손잡이가 무거워진다. 소유자를 벌주는 장치가 아니라 현장에 남은 책임을 알린다. 공공기관이 책임 추적용으로 악용하지 못하도록 개인 식별은 저장하지 않는다.

### 11. 비움갑
도구를 가져가기 전 빈 공간을 확보하게 하는 보관함. 채집 충동을 억제하며 반납품이 없으면 열리지 않는다. 고가품 저장용으로 개조하면 내부 구획이 사라진다.

### 12. 귀환표
각자 다른 귀환 조건을 적어 교환하는 얇은 표. 목적지보다 동행자·중지 조건·연락 방법을 기록한다. 위치 정보는 임무 종료 뒤 자동 흐림 처리된다.

## 3. 복구 도구 13~18

### 13. 나눔판
복구 작업을 개인 공로가 아니라 역할·시간·지역 기여로 나눈다. 점수판으로 사용하면 기록이 닫힌다. 주민 노동을 학생 실적으로 빼앗지 않게 한다.

### 14. 첫길 조각
훼손 전 경로의 최초 기록이 아니라, 처음 합의된 이용 조건을 저장한다. 과거 복원 만능주의를 막고 현재 주민의 변경권을 보장한다.

### 15. 틈메움풀통
건축 틈의 잔류 생태를 해치지 않고 임시 봉합한다. 영구 보수재가 아니며 72시간 뒤 분해된다. 기관이 예산 절감용으로 반복 사용하면 경고 무늬가 생긴다.

### 16. 물돌림홈
빗물과 숨은 수계의 흐름을 임시 분산한다. 한쪽 피해를 다른 지역으로 넘기지 않도록 하류 동의가 없으면 작동 폭이 제한된다.

### 17. 소리되돌림판
공사·행사 뒤 달라진 생활 소음을 비교한다. 원래 상태를 정답으로 두지 않고 주민별 허용 범위를 겹쳐 보여준다.

### 18. 자리접이천
임시 보호구역의 경계를 만든다. 내부 존재를 가두지 않고 외부 접근만 늦춘다. 장기 사용하면 장소가 고립되므로 종료 시각을 반드시 기록한다.

## 4. 기록·공개 도구 19~24

### 19. 빈칸목록
기록하지 않기로 합의한 항목과 아직 모르는 항목을 구분한다. 빈칸을 실패로 취급하지 않는다. 감사자가 강제로 내용을 채우면 판본 추적이 남는다.

### 20. 겹장부
기관·주민·학생 기록을 한 화면에 병합하지 않고 나란히 유지한다. 차이를 삭제하지 않는 것이 핵심이다. 합의된 공통항목만 색이 겹친다.

### 21. 흐림도장
사진·지도·문서의 공개 범위를 단계별로 제한한다. 원본 삭제가 아니라 열람 권한을 분리한다. 도장을 찍은 사람도 단독 해제할 수 없다.

### 22. 자기이름패
대상이 스스로 선택한 명칭과 외부 임시 분류를 병기한다. 자기명칭이 없을 때는 비워 둔다. 번역 편의를 이유로 강제 명명하지 않는다.

### 23. 오독실
한 기록이 어떤 경로로 잘못 해석됐는지 연결한다. 거짓말 탐지기가 아니며, 독자의 전제와 생략된 문맥을 추적한다.

### 24. 잊힘봉투
민감 기록의 보존 기간과 폐기 조건을 물리적으로 표시한다. 영구 보관을 기본값으로 두지 않는다. 만료 뒤에는 요약 통계만 남길 수 있다.

## 5. 협업·교육 도구 25~30

### 25. 역할바꿈패
팀원이 같은 역할을 독점하지 않도록 임무 중 교대 시점을 알린다. 능력 차이를 무시한 강제 교대는 금지하며, 관찰·기록·철수 중 최소 두 역할만 순환한다.

### 26. 질문돌
답을 저장하지 않고 현장에서 나온 질문 순서를 보존한다. 교사가 모범답안을 덮어쓰면 표면이 거칠어진다. 학생의 판단 과정 평가에 사용한다.

### 27. 실패본
성공 기록과 별도로 중지·오판·철수 사례를 보존하는 책. 벌점 장부가 아니며 후배가 같은 위험을 피하도록 공개 범위를 정한다.

### 28. 동의매듭
기관·주민·학생·생태 대리자 중 필요한 당사자의 동의 상태를 매듭 수로 표시한다. 동의 철회 시 매듭이 풀린다. 서명 대체물이 아니라 현장 확인 도구다.

### 29. 느린지도
빠른 경로가 아니라 휴식·우회·접근 제한을 포함한 이동 시간을 표시한다. 장애·연령·동행 조건에 따라 여러 판본을 유지한다.

### 30. 다음손상자
도구를 사용한 사람이 다음 사용자에게 고장 가능성과 주의점을 직접 남긴다. 제작자 권위보다 유지보수 공동체를 강화한다. 이름 대신 역할과 날짜만 기록한다.

## 계보와 소유권 규칙

1. 도구 제작자는 사용 장소의 영구 소유권을 얻지 않는다.
2. 학교 지급품도 지역 현장에서 변형되면 공동 관리품이 된다.
3. 수리는 원형 복원이 아니라 실패 이력 보존을 포함한다.
4. 학생 개인에게 고가·희귀 도구를 독점 지급하지 않는다.
5. 같은 기능은 일상 물품·사람의 협업으로 대체 가능해야 한다.
