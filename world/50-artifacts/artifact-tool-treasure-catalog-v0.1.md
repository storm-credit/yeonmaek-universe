# 유물·도구·보물 카탈로그 v0.1

## 1. 공통 필드

유물은 다음을 모두 가져야 한다.

- 제작 목적과 당시 해결하려던 문제
- 제작·수리·사용·실패·이전 이력
- 현재 보관·접근·사용 권한
- 발동 조건과 중지 조건
- 신체·장소·관계·도구·시간·법적 부담
- 원상 복구 또는 폐기 조건
- 현재 작품의 선택을 어렵게 만드는 기능

유물은 생명·문화·지역 기록을 자동 소유하게 하지 않는다.

# ART-001 되짚등

## 외형

손바닥 두 개 높이의 낮은 등. 불꽃 대신 안쪽 벽에 얇은 선들이 역순으로 켜진다.

## 기능

현재 경로를 안내하지 않는다. 최근 상호작용에서 `마지막으로 조건이 안정됐던 지점`을 제한 시간 동안 표시한다.

## 사용 조건

- 관측 기록 두 종류 이상
- 사용자가 중지 기준을 먼저 선언
- 위치 이동 중 사용 금지

## 비용·실패

- 되짚등이 보여 주는 것은 안전한 미래가 아니라 마지막 안정 지점
- 사용 중 현재 변화 관측이 둔해짐
- 오래 켜면 이전 기록의 미세 차이가 사라져 한 줄처럼 보임

## 권한

학교·센터 공동 장비. 학생 단독 반출 금지.

## 사건 기능

- 선택: 앞으로 밀어붙일지 마지막 안정 지점으로 철수할지
- 관계: 중지 판단을 약함이 아니라 기술로 만듦
- 미스터리: 과거 영웅이 ‘길을 찾았다’는 기록이 사실 철수 경로였음

## 배정

부제작 2 첫 등장, 부제작 6에서 중앙 장치의 보조 도구로 오용될 위험.

## 현재 상태

`사용 가능 / 학기별 재검증 / 렌즈 일부 손상`

# ART-002 겹눈틀

## 외형

두 개의 서로 다른 크기 렌즈가 평행하지 않게 달린 접이식 관측틀. 혼자 들면 초점이 맞지 않는다.

## 기능

두 기록을 겹쳐 같은 부분이 아니라 `서로가 보지 못한 범위`를 표시한다. 어느 쪽이 진실인지 판정하지 않는다.

## 사용 조건

- 독립 관측자 두 명
- 각 기록의 작성 시각·범위·목적 표시
- 관측자 중 한 명이 언제든 비교 철회 가능

## 비용·실패

- 기록 범위를 숨기면 빈칸이 거짓 윤곽으로 나타남
- 같은 기관이 만든 두 기록은 독립 입력으로 인정되지 않을 수 있음
- 민감 정보가 우연히 드러날 수 있어 공개 범위 사전 합의 필요

## 사건 기능

- 선택: 불일치를 오류로 지울지 미확인 범위로 남길지
- 관계: 유나 같은 독립 기록자의 권리를 구조적으로 중요하게 만듦
- 미스터리: 중앙판과 지역판의 누락 방향 발견

## 배정

부제작 3 중심 유물, 부제작 5 공개 갈등에서 재등장.

## 현재 상태

`공동 보관 / 기록권자 승인 필요`

# ART-003 비움매듭

## 외형

서로 다른 재료로 만든 세 가닥 매듭. 사용 전에는 어느 가닥도 완전히 당겨지지 않는다.

## 기능

부담을 없애지 않는다. 지정된 임시 수용처로 `어떤 부담을 어디에서 어디로 옮겼는지` 기록하며 전환한다.

## 사용 조건

- 원래 부담 위치 확인
- 수용처의 허용량·관리자·복구 계획
- 이동 종료 시각
- 영향을 받는 당사자의 동의 또는 긴급 사용 사후 심사

## 비용·실패

- 수용처가 불명확하면 매듭이 잠기지 않음
- 허용량을 넘기면 세 가닥 중 하나가 끊어져 부담이 양쪽에 나뉨
- 긴급 사용은 즉시 구조에 유리하지만 장기 책임을 남김

## 사건 기능

- 선택: 지금 사람을 구하기 위해 다른 장소에 부담을 맡길지
- 관계: 누가 위험을 대신 감당하는지 가시화
- 미스터리: 과거 구조 기록에서 수용처 이름이 삭제됨

## 배정

부제작 5 과거 기록, 부제작 6 중앙 통제 성공의 핵심 구성품.

## 현재 상태

`제한 보관 / 과거 사용 이력 일부 비공개`

# ART-004 반납열쇠

## 외형

손잡이와 이가 구분되지 않는 빈 고리 형태. 대상 물건 가까이에서만 일시적으로 이가 생긴다.

## 기능

무언가를 꺼내거나 차지하기 위해서는 작동하지 않는다. 분실·압수·오보관된 물건을 `현재 정당한 보관 관계`로 돌려보낼 때만 제한 경로를 연다.

## 사용 조건

- 단일 소유자를 요구하지 않음
- 제작자·사용자·피해자·지역·기관의 보관권 검토
- 반환 뒤 접근 조건 합의

## 비용·실패

- 정당한 보관 주체가 하나가 아니면 여러 경로가 열렸다 닫힘
- 반환이 과거 상태 회복을 의미하지 않음
- 물건이 위험하면 안전 격리와 권리 판단을 동시에 진행

## 사건 기능

- 선택: 강한 유물을 학교에 둘지 지역·당사자와 공동 보관할지
- 관계: 소유 대신 보관 책임
- 미스터리: 공식 영웅이 ‘획득’한 유물이 실제로는 반환되지 못한 물건

## 배정

부제작 3 영웅 기록에서 첫 언급, 부제작 6 실제 사용.

## 현재 상태

`휴면 / 정당한 반환 대상 미확정`

# ART-005 멈춤종

## 외형

소리가 나는 종이 아니라 얇은 금속판 여러 장이 서로 닿지 않고 매달린 형태.

## 기능

울리는 순간 주변 여러 위상에 `활동 중지 신호`를 전달한다. 생물이나 사람을 강제로 멈추게 하지 않으며, 신호를 이해·감지한 주체가 중지를 선택하도록 한다.

## 사용 조건

- 사용 전 중지 이유와 집결점 기록
- 현장 책임자의 승인 또는 학생의 긴급 안전권
- 한 번 사용 뒤 재조정 전 재사용 불가

## 비용·실패

- 너무 자주 사용하면 신호 신뢰가 무너짐
- 강제 정지 장치로 오해하면 위험 행동이 계속될 수 있음
- 사용자의 위치와 위험 상태가 기록에 남음

## 사건 기능

- 선택: 팀 승리·현장 진행을 포기하고 전체 중지를 선언할지
- 관계: 학생에게 제한적이지만 실제적인 안전 권한 부여
- 미스터리: 과거 경기 결승에서 종이 울리지 않은 이유

## 배정

부제작 2 경기·수업, 부제작 7 분산 현장 신호 체계로 회수.

## 현재 상태

`학교 안전 장비 / 사용 후 수동 재조정`

# ART-006 숨은추

## 외형

눈금 없는 추와 세 갈래 실. 평평한 곳에 세우면 한 방향이 아니라 서로 다른 세 방향으로 기울어진다.

## 기능

부담의 총량을 재지 않는다. 신체·장소·관계·도구 중 `어느 영역의 균형이 다른 영역과 어긋나는지` 방향만 보여 준다.

## 사용 조건

- 완전히 정지된 바닥
- 최소 세 영역의 기준 기록
- 측정 중 개입 금지

## 비용·실패

- 원인을 알려 주지 않음
- 기준 기록이 편향되면 보이지 않는 영역을 0으로 취급
- 이동식 중앙 장치에 넣으면 빠른 판단은 가능하지만 지역 기준이 사라짐

## 사건 기능

- 선택: 빠른 중앙 기준을 사용할지 느린 지역 기준을 합칠지
- 관계: 전문가·주민·당사자의 서로 다른 부담 인식
- 미스터리: 중앙 장치가 구조에 성공한 이유와 숨긴 영역

## 배정

부제작 6 중심 도구.

## 현재 상태

`국제 공동 연구 대여 중 / 기준판 분쟁`

# ART-007 잔기록판

## 외형

지우개 자국처럼 흐린 층이 여러 겹 쌓인 얇은 판. 새로운 글을 쓰면 오래된 흔적 일부가 밝아진다.

## 기능

삭제된 문장의 내용을 복원하는 도구가 아니다. 수정·삭제·접근 변경이 일어난 `시각·권한·필드 위치`를 보여 준다.

## 사용 조건

- 원기록의 물리·디지털 식별자
- 접근권 또는 독립 감사 명령
- 복원하지 말아야 할 보호 정보 표시

## 비용·실패

- 오래된 수정 흔적을 볼수록 현재 기록의 일부가 흐려짐
- 삭제 이유를 알 수 없음
- 민감 정보의 존재 자체가 노출될 수 있음

## 사건 기능

- 선택: 삭제 사실을 공개할지 보호 이유를 먼저 확인할지
- 관계: 피해자·기록자·기관·당사자의 공개권 충돌
- 미스터리: 반복 삭제 ID의 형식과 권한 체계 확인

## 배정

부제작 5 중심 유물, 부제작 7 공동 원장 감사 도구로 제한 사용.

## 현재 상태

`독립 감사 보관 / 일반 학생 접근 금지`

# ART-008 돌림패

## 외형

여러 조각이 원형으로 맞물린 패. 권한이 이동할 때 한 조각씩 다른 보관자에게 돌아간다.

## 기능

특정 경로·장비·기록의 제한 권한을 정해진 기간과 조건 아래 다른 주체에게 위임한다. 모든 위임·재위임·거부가 패 표면에 물리적 틈으로 남는다.

## 사용 조건

- 위임 범위·시간·중지 조건
- 위임자와 수임자의 별도 승인
- 독립 감사 조각 보관
- 당사자·지역 거부권이 존재하면 별도 조각 필요

## 비용·실패

- 조각을 한곳에 모으면 매우 빠른 중앙 통제가 가능
- 일부 조각이 빠지면 권한은 제한되지만 기록도 불완전
- 긴급 위임이 반복되면 임시 권한이 사실상 상설화

## 사건 기능

- 선택: 실제 구조 성공을 위해 주인공에게 조각을 모을지
- 관계: 신뢰·효율·거부·감사의 물리적 표현
- 미스터리: 과거 공동관리 선례가 왜 해체됐는가

## 배정

부제작 6 중심, 부제작 7에서 조각을 지역·기관·당사자에게 재분산.

## 현재 상태

`조각 분산 / 일부 보관처 비공개`

# 2. 부제작 배정

| 부제작 | 중심 유물 | 보조·선행 | 핵심 선택 |
|---:|---|---|---|
| 1 | 없음 | 도구보다 생활 기록 중심 | 유물 없이도 사건 해결 가능 |
| 2 | 되짚등·멈춤종 | 학교 안전 장비 | 진행보다 중지 선택 |
| 3 | 겹눈틀 | 반납열쇠 기록 | 중앙/지역 판본과 보관권 |
| 4 | 지역 국제 도구 provisional | 겹눈틀 원리 재해석 | 호환과 번역 권력 |
| 5 | 잔기록판 | 비움매듭 과거 이력 | 공개와 보호 |
| 6 | 숨은추·돌림패·비움매듭 | 반납열쇠 | 중앙 통제의 실제 성공과 비용 |
| 7 | 돌림패 재분산 | 멈춤종·잔기록판 제한 사용 | 권한을 포기하되 감사 책임 유지 |

# 3. 상위호환 방지

- 되짚등은 미래 경로를 찾지 못함
- 겹눈틀은 진실을 판정하지 못함
- 비움매듭은 부담을 없애지 못함
- 반납열쇠는 정당한 보관 관계가 없으면 열리지 않음
- 멈춤종은 강제 정지하지 못함
- 숨은추는 원인을 찾지 못함
- 잔기록판은 삭제 내용을 자동 복원하지 못함
- 돌림패는 권한 정당성을 자동 만들지 못함

# 4. 보관·수리·폐기 상태

| 상태 | 의미 |
|---|---|
| 사용 가능 | 조건·감사·점검 통과 |
| 제한 사용 | 특정 목적·기간·사용자만 |
| 손상 | 기능 일부와 부담 기록 불완전 |
| 휴면 | 조건·보관 관계 미충족 |
| 공동 보관 | 복수 주체 승인 필요 |
| 반환 대기 | 정당한 보관 관계 판단 중 |
| 분해 검사 | 기능보다 부담·이력 검토 우선 |
| 폐기 후보 | 안전한 기능 해제·재료 처리 필요 |
| 위치 비공개 | 밀수·접근·당사자 권리 보호 |

# 5. 가드레일

1. 유물은 마법 지팡이·최강 무기 목록이 아니다.
2. 사용 전 조건·실패·부담을 공정하게 제시한다.
3. 강한 기능은 더 넓은 감사와 결정권 비용을 만든다.
4. 학생이 유물을 소유해 법적 권한을 얻지 않는다.
5. 실제 문화재·종교물·유물을 직접 변형하지 않는다.
6. 유물 회수는 획득보다 반환·수리·공동 보관·폐기로 보상한다.
7. 최종부에서 모든 유물을 한곳에 모으지 않는다.
8. 상품화는 개체 소유증이 아니라 기록 순간·판본으로만 검토한다.
