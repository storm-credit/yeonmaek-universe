# 수집 보상 구조 4안 v0.1

## 전제

이 작품의 수집은 생명·장소·문화를 소유하는 행위가 아니다. 수집 대상은 관계를 해치지 않는 정보, 사용권, 복구 기록, 교환 가능한 제작물이다.

## A. 관찰 도감형

생물·현상·장소의 행동 조건과 거부 조건을 기록한다.

- 항목: 발견 조건, 안전 거리, 계절, 먹이·환경, 접촉 금지, 자기명칭
- 보상: 잘못된 분류 수정, 새 행동 패턴 확인
- 장점: 생태와 학습의 재미
- 위험: 생명을 숫자 목록으로만 소비할 수 있음

## B. 도구 계보형

지역별 도구·장비·표식의 쓰임과 제작 계보를 모은다.

- 항목: 용도, 사용자, 재료, 수리법, 빌림 조건, 반납 방식
- 보상: 새로운 조합과 상황 대응법
- 장점: 장비 성장과 지역 문화 표현
- 위험: 희귀도 경쟁과 아이템 인플레이션

## C. 경로 인장형

탐사자가 정복 증표가 아니라, 특정 역할을 안전하게 수행할 수 있다는 제한적 인증을 얻는다.

- 예: 야간 동행, 구조 보조, 기록 열람, 특정 길 통과
- 보상: 선택지와 책임 범위 확대
- 장점: 성장과 권한을 연결
- 위험: 배지 수집 게임처럼 보일 수 있음

## D. 교환 기록형

서로 다른 지역의 학생·주민·생물이 합의한 지식과 물건을 교환하고 출처를 기록한다.

- 항목: 제공자, 사용 범위, 재배포 금지, 반환 조건
- 보상: 관계망 확장과 문화적 발견
- 장점: 세계 확장에 적합
- 위험: 문화 요소를 기념품처럼 소비할 수 있음

## 추천 구조

독자에게 보이는 주 수집축은 다음 세 개다.

1. `관찰 도감`: 무엇을 이해했는가
2. `도구 계보`: 무엇을 다룰 수 있는가
3. `경로 인장`: 어떤 책임을 맡을 수 있는가

`교환 기록`은 지역 교류와 국제 확장 때 사용한다.

## 수집 완료의 정의

항목을 발견했다고 완료되지 않는다. 아래 조건을 충족해야 한다.

- 출처가 기록됨
- 공개 가능 범위가 표시됨
- 거부·반납 조건이 기록됨
- 오분류 수정 이력이 남음
- 해당 대상에게 불이익을 주지 않음

## 금지

- 생물을 카드·펫·전리품으로 소유
- 희귀도가 윤리보다 우선
- 지역 문화의 원형을 주인공이 최초 발견한 것처럼 처리
- 비공개 정보를 완성률 때문에 공개
