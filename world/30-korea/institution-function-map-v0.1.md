# 한국 첫 기관 기능 분리도 v0.1

## 문제

학교가 교육, 생물 보호, 재난 대응, 국제 협상, 현실 은폐를 모두 수행하면 한 기관의 권한이 과도해지고 세계가 비밀 국가기관물로 기울어진다.

## 권장 구조

하나의 재단 또는 오래된 협약 아래 여러 기관이 협력하지만 권한과 책임은 분리한다.

```text
공익 재단/협약체
├─ 교육원: 중등학교와 심층 학궁
├─ 생태보호원: 구조·치료·보전·검역
├─ 현상연구원: 관측·분류·장비·기록
├─ 현실협력실: 정부·병원·교통·법률·보험
└─ 국제조정실: 타 권역 기관·이동·분쟁·번역
```

정식 명칭은 확정하지 않는다.

## 1. 교육원

### 책임

- 학생의 현실 교과와 숨은 기초 교육
- 교사·사범·현장 지도자 자격 관리
- 학교 대표 경기와 학생 안전
- 국내 계절원과 교환 과정

### 권한 제한

- 야생 생물 포획 결정권 없음
- 대형 재난 지휘권 없음
- 국제 협정 체결권 없음
- 학생을 비밀 작전 인력으로 사용하지 않음

### 갈등 가능성

- 교육과 현장 경험의 균형
- 학생 보호와 세계의 실제 위험
- 현실 진학·취업과 숨은 역할

## 2. 생태보호원

### 책임

- 부상·유실·이동 생물 구조
- 보호구역과 이동로 관리
- 생물 복지와 동행·접촉 기준
- 국내외 검역과 방사

### 권한 제한

- 지성종을 일방적으로 동물 보호 대상으로 규정하지 않음
- 학교 교육을 직접 지배하지 않음
- 위험도를 이유로 자동 제거하지 않음

### 갈등 가능성

- 인간 안전과 멸종위기종 보호
- 도시 개발과 서식지 보전
- 외래종·이동종·침입종의 구분

## 3. 현상연구원

### 책임

- 현실 깊이 L0~L4 관측
- 센서와 현장 기록 교차 검증
- 힘 체계 호환성 카드
- 생물 다축 프로필과 도감 기록
- 장비·재료·안전 규격 연구

### 권한 제한

- 연구를 위해 생물·공동체의 동의를 무시하지 않음
- 하나의 보편 이론을 국제 표준으로 강요하지 않음
- 민감한 문화 자료의 공개 여부를 단독 결정하지 않음

### 갈등 가능성

- 재현 가능한 데이터와 지역 전승의 충돌
- 공개 과학과 비밀 유지
- 연구 경쟁과 문화적 소유권

## 4. 현실협력실

### 책임

- 교육부·지방정부·경찰·소방·환경·교통기관 접점
- 병원·보험·법률·토지·재개발 문제
- 대형 사건의 현실 피해 처리
- 학교와 직원의 표면 신분
- 언론·온라인 증거·제한 공개 정책 지원

### 권한 제한

- 기억 삭제와 강압적 침묵을 일상 수단으로 사용하지 않음
- 생태·문화 판단을 행정 편의로 덮지 않음
- 사건의 모든 원인을 허위 발표하지 않음

### 갈등 가능성

- 공공 안전과 비밀 유지
- 피해자 알 권리와 사회 혼란
- 개발 이익과 보호 비용

## 5. 국제조정실

### 책임

- 외국 학생·교사·연구자의 신분과 이동
- 지역별 용어·술법 호환성 번역
- 초국경 생물 이동과 공동 대응
- 국제대회와 공동 탐사
- 분쟁 조정과 기록 공유

### 권한 제한

- 아시아 전체를 통치하지 않음
- 지역 공동체의 내부 규칙을 일괄 표준화하지 않음
- 한국식 분류와 교육을 국제 기준으로 강요하지 않음

### 갈등 가능성

- 국가 법과 오래된 협정의 충돌
- 문화 자료와 생물 표본의 반환
- 위험 정보 공유와 지역 자율성

## 재단 또는 협약체의 역할

상위 조직은 실무를 직접 지휘하기보다 다음을 담당한다.

- 예산과 시설의 공동 기반
- 기관 간 책임 충돌 조정
- 이사회 또는 협의회 운영
- 독립 감사와 피해 보상 기금
- 장기 보호구역 신탁

## 의사결정 예시

### 학생이 탐사 중 희귀 위험종을 발견

- 교육원: 학생 철수와 교육 책임
- 보호원: 종과 서식지 대응
- 연구원: 관측·분류
- 현실협력실: 현실 사고와 현장 통제
- 국제조정실: 초국경 종이면 출신 권역 연락

한 기관이 모든 결정을 내리지 않는다.

### 재개발로 경계구역이 붕괴

- 현실협력실: 시공사·정부·주민 협의
- 보호원: 생물과 이동로 대책
- 연구원: 공간 변화 분석
- 교육원: 학생 접근 제한과 학습 자료화
- 상위 재단: 보상 기금과 책임 분쟁 조정

## 학교의 신비감 보존

기관이 세분화되어도 학생 시점에서 학교가 행정 조직처럼 보이지 않게 한다.

- 학생이 자주 만나는 것은 교사, 사감, 치료사, 기록관 정도
- 조직 전체는 사건이 커질 때 조금씩 드러남
- 각 기관은 독특한 공간·복장·작업 문화가 있음
- 설명보다 충돌하는 지시와 현장 경험으로 기능 차이를 보여 줌

## 확정 필요 항목

- 상위 조직이 재단인지 오래된 협약체인지
- 학교가 사립인지 공익 특수학교인지
- 정부가 이사회에 참여하는지
- 국제조정실이 한국 조직인지 범아시아 연락소인지
- 피해 보상 기금의 재원
- 지성종 대표가 의사결정에 참여하는지
