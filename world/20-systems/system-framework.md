# 시스템 모듈 설계표

| 모듈 | 핵심 질문 | 선행 의존성 |
|---|---|---|
| 현실-이면 접점 | 같은 도시에서 왜 공존 가능한가? | 세계 가설 |
| 힘 체계 | 무엇을 할 수 있고 무엇을 대가로 하는가? | 지역 해석, 현실 접점 |
| 생태·생물 | 어디서 살고 어떻게 이동하는가? | 권역, 기후, 힘 체계 |
| 학교·기관 | 누가 왜 가르치고 관리하는가? | 사회, 힘 체계, 비밀 규칙 |
| 국제 연맹 | 국경을 넘는 사건을 누가 조정하는가? | 지역 기관, 이동 규칙 |
| 대표 경기 | 학생 사회와 지역 차이를 어떻게 보여 주는가? | 학교, 힘 체계, 안전 규칙 |
| 기록·도감 | 누가 무엇을 분류하고 무엇을 숨기는가? | 생물, 기관, 역사 |

각 모듈은 `templates/system-spec.md`로 작성하며, 만능 해법과 예외를 함께 기록한다.
