# 현실과 숨은 세계 연결 4안

| 안 | 원리 | 장점 | 약점 |
|---|---|---|---|
| A 분리 차원형 | 특정 문을 통과하면 별도 세계 | 명료하고 모험성이 큼 | 현실 밀착감이 약함 |
| B 지각 여과형 | 같은 공간을 일반인이 다르게 인식 | 현대 도시에 잘 맞음 | 카메라·집단 목격 설명 필요 |
| C 계절·조건 중첩형 | 비·안개·시간·의식에 따라 깊이가 열림 | 지역 기후와 연결 | 출입 규칙이 복잡해질 수 있음 |
| D 기반시설 틈형 | 지하철·수로·항구·산길이 통로 | 한국 현실성이 강함 | 모든 지역을 도시 인프라로 설명할 수 없음 |

## 혼합 후보

- 같은 지리의 다른 깊이
- 지역마다 여는 조건이 다름
- 일반인은 모순을 합리화하지만 증거가 완전히 삭제되지는 않음
- 오래된 자연길과 현대 기반시설이 서로 겹침
- 대규모 사건은 비밀 유지가 아니라 사회적 은폐·오인·제한 공개 문제로 발전

## 반드시 해결할 현실 질문

스마트폰, CCTV, 위성지도, SNS, 재개발, 관광객, 국경검문, 항공·해운, 보험·의료 기록.
