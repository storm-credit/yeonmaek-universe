# 대표 경기 설계 틀

## 쿼디치에서 가져올 기능

- 학교의 반복 일상
- 팀 소속과 라이벌
- 스타 선수와 관중 문화
- 지역별 전술 차이
- 국제대회 확장
- 힘을 설명하지 않고 보여 주는 무대

## 복제하지 않을 것

빗자루 비행, 공 세 종류, 골대 구조, 포지션 대응, 한 선수의 과도한 역전 규칙.

## 4개 후보 방향

1. `맥로 개척전`: 변화하는 지형에서 경로를 연결
2. `진문 쟁탈전`: 팀이 이동식 진을 완성하고 상대 진을 해체
3. `영물 동행전`: 중립 생물과 협력해 목표를 달성
4. `계절 순환전`: 경기장의 계절과 수위를 전환하며 거점을 확보

## 성공 테스트

- 30초 안에 승리 조건 설명
- 한 장 그림으로 경기 흐름 이해
- 직접 공격 없이도 긴장감 유지
- 지역 전술이 고정 민족성으로 보이지 않음
- 안전 규칙과 반칙의 이유가 세계 원리와 연결
