# 이면 생물 생태 분류 4안 v0.1

## 목표

이면 생물을 귀여운 수집 캐릭터, 전투 몬스터, 특정 문화의 신성 존재를 바꾼 장식으로 만들지 않는다. 생태·이동·지성·인간 관계·보존 문제를 함께 설명할 수 있는 분류가 필요하다.

## 기본 가설

- 이면 생물은 독립적인 생명과 생활사를 가진다.
- 인간 감정과 문화는 모든 종의 탄생 원인이 아니다.
- 일부 종은 인간 환경에 적응하며 모습·행동·분포가 바뀔 수 있다.
- 전설은 실제 종을 정확히 기록한 도감이 아니라 목격, 오인, 상징, 정치적 편집이 섞인 문화 기록이다.
- 위험도와 보호가치는 별도 축이다.
- 지성의 기준은 인간 언어 사용 여부만으로 정하지 않는다.

## A안: 서식 회랑 중심 분류

생물이 어느 환경 연결망에 의존하는지로 분류한다.

### 예시 축

- 산림·산악 회랑
- 강·호수·범람 회랑
- 연안·해류·군도 회랑
- 초원·사막 이동 회랑
- 도시 지하·기반시설 회랑
- 대기·계절풍 회랑
- 꿈·기억 등 비물질 환경 회랑 후보

### 장점

- 범아시아 지역 구조와 직접 연결
- 기후변화·개발·국경 문제를 다루기 좋음
- 해외 확장이 자연스러움

### 약점

- 같은 종의 복합 서식과 계절 이동을 단순화할 수 있음
- 분류가 지리 정보에 치우침
- 독자가 생물의 특징을 즉시 파악하기 어려움

## B안: 생활사·이동 주기 중심 분류

생물의 탄생, 성장, 번식, 변태, 이동, 휴면 주기로 분류한다.

### 예시 축

- 정주종
- 계절 이동종
- 장거리 순환종
- 우기·건기 변태종
- 다세대 군체종
- 장소를 몸처럼 사용하는 피각종
- 수십 년 이상 휴면하는 장주기종

### 장점

- 동남아 계절성, 초원 이동, 해류 이동을 깊게 표현
- 같은 생물이 지역마다 다르게 목격된 이유를 설명
- 발견과 연구의 재미가 큼

### 약점

- 도감 분류로는 복잡할 수 있음
- 이야기 초반에 생활사를 모두 알기 어려움
- 미확인종을 분류하기 힘듦

## C안: 인간 접촉 방식 중심 분류

생물이 인간 사회와 어떤 방식으로 관계 맺는지 분류한다.

### 예시 축

- 회피형
- 공생형
- 의존형
- 모방형
- 계약·협상형
- 기생·포식형
- 기반시설 적응형
- 비접촉 보호형

### 장점

- 학교 수업과 현장 대응에 실용적
- 사고·법·윤리·보호 정책과 연결
- 독자가 행동 규칙을 이해하기 쉬움

### 약점

- 인간 중심적
- 생물 자체의 생태를 부차화할 위험
- 동일 종도 상황에 따라 관계가 달라짐

## D안: 다축 프로필형

하나의 계통표보다 생물마다 여러 축을 기록한다.

### 필수 축

1. **서식 회랑**: 어디와 연결되는가
2. **생활사**: 성장·번식·이동·휴면
3. **영양·에너지**: 무엇을 소비하고 환경에 무엇을 돌려주는가
4. **감각·의사소통**: 무엇을 감지하고 어떻게 신호를 주는가
5. **인지·사회성**: 학습, 도구, 기억, 집단 규칙, 협상 능력
6. **인간 접촉**: 회피·공생·충돌·의존·협상
7. **현실 깊이**: 주로 활동하는 L0~L4
8. **위험도**: 즉각적 피해 가능성
9. **보존도**: 개체수·서식지·이동로의 취약성
10. **문화 기록**: 지역별 명칭·목격·오인·금기
11. **확실성**: 관측·가설·논쟁 중 무엇인가

### 장점

- 위험종=악한 종, 희귀종=약한 종 같은 오류 방지
- 지성·보호·문화 기록을 분리 가능
- 실제 생태 연구 문서처럼 축적 가능
- 지역마다 다른 해석을 같은 개체에 병기 가능

### 약점

- 작성 비용이 높음
- 초반 독자에게 모든 축을 보여 줄 수 없음
- 분류표보다 데이터베이스에 가까워질 위험

## 권장안

D 다축 프로필형을 정본 기록 체계의 1순위로 두고, A·B·C는 현장 목적에 따라 쓰는 보조 분류로 둔다.

- 연구자는 D 프로필을 사용한다.
- 이동 관리자는 A와 B를 사용한다.
- 학생·구조대·현장 기관은 C를 빠른 대응 분류로 사용한다.
- 일반 도감은 독자에게 필요한 4~5개 축만 선별해 보여 준다.

## 지성 분류 원칙

`말을 한다/못 한다`로 나누지 않는다.

### 지성 관측축

- 장기 기억과 전승
- 미래 계획
- 타자 관점 추론
- 규칙 생성과 변경
- 협상·동의·거부
- 상징과 이름 사용
- 공동체·영역·재산 개념
- 죽음·조상·역사 인식

지성 판정은 인간 기관이 일방적으로 확정할 수 없으며, 오판 사례가 세계의 역사와 갈등을 만들 수 있다.

## 위험도와 보호도

### 위험도

| 등급 | 의미 |
|---|---|
| H0 | 통상 환경에서 직접 위험 거의 없음 |
| H1 | 특정 접촉·조건에서 경미한 피해 |
| H2 | 훈련 없이 접근 시 중대한 위험 |
| H3 | 지역 단위 격리·전문 대응 필요 |
| H4 | 대규모 생태·사회 재난 가능 |

### 보존도

| 등급 | 의미 |
|---|---|
| C0 | 안정 |
| C1 | 관찰 필요 |
| C2 | 서식지 또는 이동로 감소 |
| C3 | 심각한 감소·지역 소멸 |
| C4 | 멸종 추정 또는 극소수 |
| CX | 자료 부족 |

H4이면서 C4일 수 있고, H0이면서 침입종일 수도 있다.

## 문화 기록 처리

한 생물은 지역마다 여러 이름과 이야기를 가질 수 있다.

기록은 다음을 분리한다.

- 자기명칭: 지성종이 스스로 사용하는 명칭
- 현지명: 지역 공동체의 명칭
- 학술 작업명: 기관 간 비교용 명칭
- 오인 기록: 다른 종이나 자연현상과 혼동한 사례
- 신성·의례 기록: 공개·재현에 제한이 필요한 정보
- 창작 변형: 작품이 실제 전승에서 얼마나 이동했는지

실재 신성 존재의 이름을 생물 종명으로 직접 전용하지 않는다.

## 전설과 실제 종의 관계 4유형

1. **부분 목격형**: 실제 생물의 행동 일부가 기록됨
2. **복합 오인형**: 여러 생물과 사건이 하나의 전설로 합쳐짐
3. **상징 차용형**: 인간이 실제 생물에 기존 상징을 덧씌움
4. **무관형**: 유사성이 우연하거나 후대 기관이 잘못 연결함

`전설은 사실이었다`만 반복하지 않는다.

## 생물 생성 전 체크

- 실제 문화의 신성 존재를 외형만 바꿔 몬스터화하지 않았는가?
- 환경에서 무엇을 먹고 무엇을 돌려주는가?
- 번식·성장·죽음 또는 이에 대응하는 생활사가 있는가?
- 인간이 없어도 존재 이유가 있는가?
- 서식지와 다른 생물에 어떤 영향을 주는가?
- 위험과 보호가치를 분리했는가?
- 지역별 서로 다른 이름과 관찰이 가능한가?
- 포획·계약·사육이 윤리적으로 검토되었는가?
- 이야기 장치 하나를 위해 생태가 임의로 변하지 않는가?

## 시험 프로필 3종의 범위

다음 단계에서는 완성 생물이 아닌 구조 시험용 가상 프로필만 만든다.

1. 서울 지하 수계와 산지를 오가는 중형 이동종
2. 메콩권에서 우기·건기에 생활사가 바뀌는 수생·육상 전환종
3. 동북아와 내륙아시아를 장거리 순환하는 대형 이동종

실제 전승 명칭과 종교 모티브는 문화 조사 전 사용하지 않는다.
