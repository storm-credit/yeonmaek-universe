# 동행종·도감·지도·유물·영웅 기록 수집 생태계 4안 v0.1

## 목적

독자가 ‘다음에는 무엇을 발견하고, 이전 기록이 어떻게 바뀔까’를 기다리게 하면서 생명·문화·권리를 소유 목록으로 만들지 않는 수집 구조를 설계한다.

## 수집욕구의 네 단계

1. **식별** — 이름·형태·표식·기능이 구별된다.
2. **빈칸** — 아직 모르는 상태·지역·판본이 보인다.
3. **관계 변화** — 발견 뒤 동행·거부·정정·반환·폐기·공동 보관이 발생한다.
4. **재맥락화** — 이전에 모았다고 생각한 정보의 의미가 바뀐다.

100% 완성은 목표가 아니다. 어떤 빈칸은 당사자의 비공개·서식 보호·번역 불가 때문에 의도적으로 남는다.

# 안 A — 전 작품 전 축 카탈로그형

## 정의

매 부제작마다 신규 동행종·도감 항목·지도 구역·유물·영웅을 일정 수량씩 공개한다.

## 장점

- 독자가 기대할 고정 보상이 명확하다.
- 삽화·카드·도감·게임 확장이 쉽다.
- 시리즈별 구성 균형을 만들기 쉽다.

## 약점

- 모바일게임 업데이트·완구 카탈로그처럼 보인다.
- 사건보다 신규 목록 할당이 우선한다.
- 생물·유물·인물이 이름과 외형만 다른 복제품으로 늘어난다.
- 후반 수집 부채와 최종 회수 과밀이 심해진다.

# 안 B — 부제작당 한 축 집중형

## 정의

각 부제작은 하나의 핵심 수집축만 전면화하고 나머지는 거의 등장시키지 않는다.

## 예

1 도감 / 2 동행종 / 3 지도 / 4 유물 / 5 영웅 기록 / 6 기록편 / 7 통합.

## 장점

- 각 작품의 시각·마케팅·미스터리 정체성이 선명하다.
- 정보 과부하와 항목 증식을 줄인다.
- 한 수집축을 사건과 깊게 연결하기 쉽다.

## 약점

- 세계가 작품마다 장르를 바꾸는 것처럼 보인다.
- 초반 핵심축이 오랫동안 사라질 수 있다.
- 독자가 좋아한 동행종·도감·보물이 후반에 버려진 느낌을 받는다.
- 최종 통합이 갑작스럽다.

# 안 C — 중심 1축+보조 1축+재맥락화형

## 정의

각 부제작은 중심 수집축 1개와 보조축 1개를 기본으로 삼고, 이전 작품의 항목 하나를 새 의미로 재맥락화한다.

## 기본 공개 예산

- 중심축 신규 핵심 항목: 1~3개
- 보조축 신규 항목: 0~2개
- 이전 항목 재등장·정정·관계 변화: 1~2개
- 장기 미확인 항목: 1개 이하
- 단순 배경 항목: 이름 없이 군집·환경으로 처리 가능

수량은 상한 후보이며 사건 밀도에 따라 더 줄인다.

## 장점

- 매 작품의 발견 보상과 장기 연속성을 함께 만든다.
- 신규보다 정정·반환·관계 변화가 수집 재미가 된다.
- 후반에도 초반 수집축을 버리지 않고 주제와 결합할 수 있다.
- 설정집·카드·게임으로 옮겨도 상태 변화가 콘텐츠가 된다.

## 약점

- 항목 상태 원장과 공개 시점 관리가 복잡하다.
- 중심축과 보조축이 사건에 억지로 붙을 수 있다.
- 숫자 예산이 다시 체크리스트 공식으로 굳을 위험이 있다.

## 안전장치

- 항목은 선택·비용·관계·미스터리 중 셋 이상을 만족해야 한다.
- 사건에서 제거해도 아무 변화가 없으면 삭제한다.
- 수량은 목표가 아니라 상한이다.
- 재맥락화가 이전 감동을 조롱하거나 무효화하지 않는다.

# 안 D — 인물별 전문 수집축형

## 정의

핵심 인물마다 주로 추적·관리하는 수집축이 다르다.

- 주인공: 불일치 기록과 관계 열쇠
- 절차형 동료: 배지·규칙·감사 기록
- 관계형 동료: 동행종·서식·당사자 관계
- 현실 친구: 현실 증거·지도·사진·삭제 기록
- 멘토: 유물·사고·영웅 책임 기록

## 장점

- 수집이 인물 성격과 관계 갈등에 연결된다.
- 주인공 혼자 모든 것을 모으지 않는다.
- 독자는 좋아하는 인물의 전문 영역을 기대할 수 있다.

## 약점

- 인물이 기능 설명서·직업 클래스처럼 굳는다.
- 인물 이탈 시 해당 수집축이 사라질 수 있다.
- 기능·성별·배경을 자동 연결하는 위험이 있다.
- 지역 당사자의 기록이 핵심 인물 컬렉션에 흡수될 수 있다.

# 핵심 수집축 데이터 규칙

## 1. 동행종·협력 생물

### 수집 대상이 아닌 것

개체 자체를 소유·포획·등록하는 것이 아니다.

### 기록 대상

- 지역 자기명칭·관찰자가 붙인 임시명
- 개체/무리/종 수준의 불확실성
- 서식·계절·이동 범위
- 감지 가능한 의사표현 방식
- 인간 접촉 선호·거부 조건
- 알려진 관계·공생·갈등
- 공개 가능한 정보와 비공개 요청
- 구조·접촉·협력 이력
- 현재 관계 상태

### 관계 상태

- 미확인 흔적
- 관찰됨
- 접촉 허용
- 제한 협력
- 동행 합의
- 거부
- 거리 둠
- 관계 철회
- 재협상
- 별도 공동체 참여

### 금지

희귀도, 전투력 등급, 포획률, 소유자, 거래 가격, 진화 트리.

## 2. 도감 항목·정정 이력

- 항목 ID와 판본
- 명칭·자기명칭·금지된 옛 명칭

- 추정과 확인 구분
- 위험·권리·보존·접촉 정보
- 오류·누락·삭제 이력
- 정정 요청자와 승인·거부 상태
- 공개 수준
- 연결된 사건·지도·유물·인물

### 항목 상태

- 빈칸
- 임시 관찰
- 검증 중
- 판본 충돌
- 당사자 정정 요청

- 복수 판본 병존

### 완성 원칙

‘정정됨’도 최종 진실이 아니다. 새 증거·당사자 요구로 다시 바뀔 수 있다.

## 3. 회랑 지도·숨은 장소

### 지도 필드

- 표면 지리·심층 관계
- 계절·시간·기반시설 조건

- 공개·접근 수준

### 상태

- 계절 개방
- 관계 조건부
- 공사·기후로 변형
- 보호 폐쇄
- 당사자 거부
- 단절

‘숨은 진짜 영웅’을 찾아 공식 인물을 단순 악인으로 뒤집지 않는다. 공적과 피해·책임이 동시에 남을 수 있다.

# 보조 수집축 규칙

## 기술 조합

- 관측·연결·보호·교섭·회복·기록·철수 역할
- 같은 기술도 사용자·환경·팀 구성에 따라 결과가 다름
- 습득보다 사용 조건·실패·책임 기록이 중요

## 배지·인장·칭호

- 전투력 등급이 아니라 경험·자격·책임·선택을 표시
- 영구 계급이 아니며 정지·반납·갱신 가능
- 비공식 칭호는 관계에서 생기며 기관 권한을 주지 않음

## 변형 장비

- 사용자 흔적·수리·지역 개조·안전 제한이 누적
- 외형 변화와 기능 변화가 연결됨
- 새 장비가 이전 장비를 단순 상위호환하지 않음

## 생태 회복 재료

- 채집량·재생 기간·서식 영향·공동체 권리 기록
- 무한 농사·조합 재료가 아님
- 실제 약용·신앙 식물을 그대로 마법 재료화하지 않음

## 삭제 기록·협정 개정본

- 미스터리 단서이자 권한·공개 범위의 기록
- 완전한 진실 문서가 아니라 작성자·편집자·누락을 가짐
- 부제작 결말을 설정집에 숨기지 않음

# ‘모았다’의 대체 동사

수집욕구를 유지하되 세계 내부 행위는 다음처럼 구분한다.

- 발견했다
- 관찰했다
- 연결했다
- 허락받았다
- 정정했다
- 돌려주었다
- 공동 보관했다
- 폐기했다
- 닫아 두었다
- 공개하지 않기로 합의했다
- 관계를 다시 맺었다
- 이견을 병기했다

# 시각 식별 원칙

각 항목은 최소 두 가지로 구별된다.

- 실루엣·구조
- 표식·문양
- 재료·마모·수리 흔적
- 지도 선형·개방 조건
- 판본 테두리·정정 표시
- 관계 상태 아이콘
- 보관·공개 등급 표시

특정 색만으로 구별하지 않으며 색각 접근성을 고려한다. 완성 시각물은 별도 승인 후 제작한다.

# 본편·동반 출판·게임 재사용

## 본편

인물의 선택과 사건 해결에 필요한 항목만 전면화한다.

## 동반 출판

판본 차이·정정 이력·지도 변화·유물 보관·영웅 평가를 독립 탐색 대상으로 확장한다. 본편 결말의 유일한 설명은 넣지 않는다.

## 게임·디지털

- 포획 대신 관찰·관계·구조·기록 정정
- 희귀도 대신 환경 적합성·신뢰·공개 상태
- 지도 100% 밝히기 대신 보호 폐쇄·당사자 거부 존중
- 아이템 소비 대신 수리·반환·공동 보관·감사

# 아직 확정하지 않는 것

- 실제 동행종·유물·영웅의 이름과 수
- 카드·앱·게임 구현
- 희귀도 대체 UI
- 지역별 자기명칭
- 설정집 출판 순서
