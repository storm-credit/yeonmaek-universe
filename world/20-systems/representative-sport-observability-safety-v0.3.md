# 길문전 관전성·안전·모의진행 규격 v0.3

## 1. 경기의 독자 약속

길문전은 강한 선수가 상대를 쓰러뜨리는 경기가 아니다.

> 제한된 시간 안에 팀이 여러 길을 이어 중앙 목표에 접근하고, 상대는 사람을 공격하지 않은 채 연결을 끊거나 우회시킨다.

독자는 한 장면만 보아도 다음 세 가지를 알아야 한다.

1. 어느 팀의 길이 더 많이 이어졌는가
2. 중앙 봉화가 열렸는가
3. 누가 위험하거나 중지가 필요한가

## 2. 네 운영안 비교

| 안 | 기본 규칙 | 장점 | 약점 | 판정 |
|---|---|---|---|---|
| A 세 길·중앙 봉화 | 길표 5개 중 3개 이상 연결 후 중앙 봉화 점화 | 설명·관전·클라이맥스가 가장 명료 | 중앙 주변 교착 위험 | 1순위 |
| B 회전 봉화·시간창 | 봉화 위치가 일정 시간마다 이동 | 움직임과 역전이 많음 | 규칙 설명과 운 요소 증가 | 보류 |
| C 양쪽 귀환점·왕복 | 중앙 표식을 가져와 자기 진영에 반환 | 추격 장면이 쉬움 | 물건 쟁탈·특수 운반자 고정 | 탈락 |
| D 구역 점유·누적 점수 | 길표를 오래 점유해 점수 획득 | 리그 운영과 통계에 좋음 | 관중이 즉시 승리 순간을 알기 어려움 | 탈락 |

### 선택 이유

A안은 승리 조건이 하나이고 숨은 점수가 없다. 점화자는 고정 포지션이 아니며, 연결이 끊기면 누구도 봉화를 점화할 수 없다. 팀 전체의 탐로·연결·차단·교대가 모두 필요하다.

## 3. 설명 계층

### 한 문장

> 다섯 길표 중 세 개를 자기 진영과 이어 중앙 길을 연 뒤, 아무 선수나 봉화를 먼저 켜면 이긴다.

### 30초 설명

> 양 팀은 경기장에 흩어진 다섯 길표를 연결해 자기 시작진에서 중앙까지 길을 만든다. 세 길표 이상이 끊기지 않고 이어져야 중앙 봉화가 열린다. 열린 동안 팀의 아무 선수나 봉화에 닿아 점화하면 즉시 승리한다. 상대는 사람을 때리지 않고 길표 연결을 끊거나 우회시키며, 위험 신호가 뜨면 경기는 바로 멈춘다.

### 2분 설명

- 팀당 코트 선수 5명, 교대 2명
- 길표 5개는 양 팀 모두 사용할 수 있는 중립 구조물
- 선수는 자신의 장비로 길표와 길표 사이에 짧은 연결선을 만든다
- 자기 시작진부터 중앙까지 길표 3개 이상이 연속 연결되면 봉화 접근이 열림
- 상대는 다른 길표를 먼저 연결하거나, 허용된 차단 신호로 연결 지속 시간을 줄일 수 있음
- 신체 접촉·장비 탈취·생물 이용·정신 간섭 금지
- 연결은 영구 점유가 아니라 유지와 재연결이 필요함
- 봉화는 열린 길과 연결된 팀의 선수라면 누구나 점화 가능
- 정규 12분 안에 점화가 없으면 리그전 무승부, 토너먼트는 길표 3개로 축소한 제한 연장

## 4. 2D 경기장

```text
                    [중앙 봉화 B]
                 /       |       \
              [L2]-----[L3]-----[L4]
               |  \      |      /  |
               |    [L1]---[L5]    |
               |       \ /         |
        [청 시작진 S]   X    [백 시작진 W]

L1~L5: 중립 길표
실선: 기본 안전 통로가 아니라 연결 가능 관계
X: 교차 완충구역, 신체 접촉 금지
```

실제 경기장은 원형 또는 부채꼴 후보지만, 관중 화면에는 위와 같은 단순 연결도로 표시한다.

### 거리 후보

- 시작진↔가까운 길표: 8~10m
- 길표↔길표: 6~9m
- 외곽 길표↔봉화: 8~12m
- 코트 최대 폭: 청소년부 36~42m

정확한 거리는 실제 체력·장비·안전 시험 전 확정하지 않는다.

## 5. 선수 기능

고정 포지션이 아니라 한 경기 안에서 바뀌는 기능이다.

### 탐로

현재 연결 가능 길표와 위험한 연결을 먼저 확인한다.

### 결선

두 길표 사이 연결선을 만들고 안정시키며, 끊긴 선을 복구한다.

### 차단

상대 선을 직접 파괴하지 않고 길표의 중립 상태를 되돌리거나 우회 연결을 강제한다.

### 점화

봉화가 열린 순간 접근한다. 전담 점화자는 금지하며 모든 선수는 점화 자격을 가진다.

### 교대

부담 경고가 뜨기 전에 스스로 빠져나와 팀의 연결 정보를 전달한다. 교대도 경기 기술로 평가한다.

## 6. 연결 규칙

- 한 선수는 동시에 연결선 하나만 직접 유지
- 한 팀은 최대 네 연결선을 활성화 가능
- 같은 두 길표 사이에 양 팀 연결이 동시에 존재할 수 없음
- 중립화에는 3초 연속 접촉 또는 표준 차단 신호가 필요
- 한 길표를 20초 이상 독점하면 자동 중립 펄스가 발생해 고정 수비를 방지
- 봉화가 열린 뒤 연결이 하나라도 끊겨 3개 미만이 되면 즉시 닫힘
- 점화 동작은 2초 유지가 필요하며, 봉화가 닫히면 중단

숫자는 모의 규칙 candidate이며 인간 스포츠·안전 시험 뒤 조정한다.

## 7. 관중 화면 — 5개만 표시

1. **길표 상태:** 청/백/중립
2. **현재 연결선:** 굵은 선으로 표시
3. **봉화:** 열림/닫힘
4. **선수 부담:** 정상/경고/교대 필요
5. **경기장 안정:** 정상/주의/중지

점수판에는 숨은 부담 수치·장비 세부·심판 내부 확률을 표시하지 않는다.

### 색 이외 표식

- 청 팀: 실선+삼각 표식
- 백 팀: 이중선+사각 표식
- 중립: 점선+원 표식
- 경고: 빗금
- 중지: 큰 가로 막대

흑백 인쇄와 색각 차이를 고려해 형태가 색보다 우선한다.

## 8. 표준 장비

### 길표 결합기

연결 가능 여부와 유지 상태만 보여 준다. 공격 기능 없음.

### 조건판

선수의 허용 기능·부담 상한·교대 상태를 표시한다.

### 이중 안전선

코트와 관중·시설 구역 사이의 비정상 연결을 감지한다.

### 멈춤종

긴급 중지 신호를 여러 위상에 전달한다. 사람이나 생물을 강제로 멈추게 하지 않는다.

### 장비 원칙

- 필수 장비는 학교·리그 표준품 제공
- 개인 장비는 편의·착용감 차이만 허용
- 연결 출력·안전 측정·심판 판정에 유료 우위 금지
- 모든 장비는 사용 뒤 부담·수리 기록 공개

## 9. 반칙

즉시 중지·몰수 가능:

- 직접 타격·밀기·붙잡기
- 상대 장비 탈취·해킹·감각 교란
- 생물·관계 열쇠·비공개 위치 이용
- 허가되지 않은 부담 외부화
- 선수 경고 신호 은폐
- 관중·시설·비상동선과 연결

일반 반칙:

- 제한구역 침범
- 중립화 시간 미준수
- 교대 정보의 고의 허위 전달
- 봉화 닫힌 상태에서 점화 시도 지속

## 10. 자동 중지

다음 중 하나면 승패와 무관하게 중지한다.

1. 선수 부담 `교대 필요` 초과
2. 실제 인원과 위치 기록 불일치
3. 경기장 안정 `중지`
4. 관중·시설·비상동선과 연결
5. 허가되지 않은 생물·장비·관계 조건 개입
6. 의료·시설 책임자의 중지 요구
7. 선수의 멈춤종 사용

재개는 안전심판·의료·시설 책임자 셋 중 필요한 두 기능의 확인 뒤 가능하다. 학생 주장만으로 재개하지 않는다.

## 11. 모의 경기 A — 명료한 승리

### 0:00~2:00

청 팀은 L1-L3-L4를 빠르게 잇지만 시작진과 L1 연결이 불안하다. 백 팀은 L5-L3를 잡고 L2를 탐색한다.

관중이 보는 것:
- 청 3길표처럼 보이지만 시작진 연결이 없어 봉화 닫힘
- 백 2길표

### 2:00~4:30

청 탐로 선수가 L1 연결 대신 L2 우회를 제안한다. 청은 L2-L3-L4와 시작진을 잇고 봉화를 연다.

백은 L3 중립화를 시도한다. 청의 점화 접근 선수가 고정 스타가 아니라 직전까지 결선을 맡던 선수로 바뀐다.

### 4:42

청이 2초 점화를 유지해 승리.

검사:
- 단순 길표 수가 아니라 시작진 연결이 중요함
- 누구나 점화 가능
- 관중은 봉화 열림을 즉시 봄

## 12. 모의 경기 B — 역전과 교대

백 팀이 초반 L1-L3-L4로 봉화를 연다. 점화를 맡으려던 선수가 부담 경고를 무시하면 5초 안에 교대 필요 상태가 된다.

백 팀은 점화를 강행하지 않고 교대한다. 봉화는 그 사이 닫힌다.

청 팀은 L2-L3-L5 우회로를 열지만, 백의 차단으로 L3가 중립화된다. 마지막 30초에 백은 교대 정보를 이용해 L2-L4-L5를 연결하고 다른 선수가 점화한다.

검사:
- 교대가 패배가 아니라 역전의 원인
- 점화 전담자 없음
- 부담 경고가 경기 외 도덕 설명이 아니라 전술 정보

## 13. 모의 경기 C — 중지와 무효가 아닌 안전 기록

두 팀이 중앙 접근을 두고 L3 주변에 몰린다. 시설 안정 표시가 `주의`로 바뀌고 모서리잠 군집의 거리 두기 패턴이 관측된다.

운영팀은 경기장 안전에는 문제가 없다고 보지만, 하진이 온기고리 철회 신호와 조건판 불일치를 확인한다. 하진은 멈춤종을 사용한다.

결과:
- 즉시 선수 활동 중지
- 시설·생태·의료 확인
- 승리 선언 없음
- 기록은 `학생 중지 사용 / 경기 중단 / 시설 조건 재검토`
- 리그 승점과 안전 평가는 별도 처리

이 장면은 부제작 2의 클라이맥스 후보가 될 수 있으나 실제 원고는 별도 승인 전 작성하지 않는다.

## 14. 교착 방지

- 길표 20초 독점 시 중립 펄스
- 팀 최대 활성 연결선 4개
- 봉화 주변 완충구역에서 신체 접촉 금지
- 정규 시간 12분
- 리그전 무승부 허용
- 토너먼트 연장에서는 길표를 3개로 줄이되 승리 조건은 동일

숨은 점수나 심판 재량으로 승자를 만들지 않는다.

## 15. 부제작 2 장면 예산

경기·훈련이 작품 전체를 삼키지 않도록 제한한다.

- 입학·첫 관전: 규칙 30초 설명
- 기초 수업: 길표 하나와 중지 훈련
- 팀 선발: 기능 교대와 소속 욕망
- 연습 경기 1: 온기고리 경고의 실제 효용
- 시설 점검: 모서리잠과 경기장 구조 연결
- 공개 경기 전반: 보호 계획의 성공
- 공개 경기 후반: 철회·부담·중지 충돌
- 결말: 규칙·등록·안전 기록 개정

전체 부제작에서 완전한 경기는 최대 2회, 부분 훈련·관전은 3~4회로 제한한다.

## 16. 독창성 레드팀

### 쿼디치와의 차이

- 비행·공·골대·점수 누적 없음
- 특별한 단일 선수와 압도적 특수 득점 없음
- 생물 도구 사용 없음
- 승리는 팀 연결 상태와 단일 목표 점화
- 신체 충돌보다 경로·교대·중지 중심

### 게임화 위험

- 스킬 쿨다운·등급·희귀 장비로 설명하지 않음
- 숫자보다 선·길표·봉화 상태로 보여 줌
- 국가별 고정 능력·전술 금지
- 장비 후원이 승부를 사지 못함

### 서사 위험

- 경기 승리가 부제작의 윤리 문제를 자동 해결하지 않음
- 학교를 악의 조직으로 만들지 않음
- 중지는 언제나 옳은 버튼이 아니라 실제 팀·행사·재정 비용을 남김
- 하진의 중지 사용이 과거 철수 위반을 단순 상쇄하지 않음
