# 세계 규칙·실패·복구 사례 원장 v0.1

## 목적

이 원장은 새로운 사건을 만들 때 `가능한가 / 누가 결정하는가 / 어떤 비용이 남는가 / 어떻게 중지·복구하는가 / 어떤 기록이 남는가`를 일관되게 판정한다.

규칙은 능력 목록이 아니라 사건 제약이다.

# 1. 핵심 규칙 ID

## 존재론

### O-01 하나의 세계·복수 위상

- 심층은 별도 우주가 아니다.
- 같은 지리·물질·시간의 상호작용 깊이다.
- 현실에서 존재하지 않는 지름길·목적지를 임의 생성하지 않는다.

### O-02 조건 정족수

안정적 상호작용에는 `장소 / 상태 / 관계` 중 둘 이상이 맞아야 한다.

- 장소: 지형·수계·해류·기반시설·오래된 거점
- 상태: 계절·수위·조수·기상·시간·생물 이동
- 관계: 지성 당사자의 승인·거부·철회 또는 비지성 생태의 적합 조건

한 조건만 맞으면 관측은 가능할 수 있으나 안정 진입·이동·변경은 불가하다.

### O-03 보존

- 사람·물건 복제 금지
- 과거 귀환·사건 순서 역전 금지
- 부상·죽음·계약·재산 피해·기록 결과 초기화 금지

### O-04 실제 경로

목적지는 실제 지리·생태·기반시설 연결을 가져야 한다. 심층 경로는 현실 통학·물류·국경을 무시하는 무료 포털이 아니다.

### O-05 기록 불일치

심층 사건의 기록은 완전히 사라지지 않는다. 사람 기억, 센서, 사진, 시간표, 시설 로그가 서로 다른 일부를 남긴다.

## 힘·기술

### P-01 결합 조율

사람은 공통 에너지를 생성하지 않는다. 몸·환경·관계·도구의 결합을 조율한다.

### P-02 부담 보존

효과의 부담은 신체·장소·생태·관계·도구·시간·법적 책임 중 하나 이상에 남는다.

### P-03 중지 우선

훈련과 현장 평가는 최대 출력보다 다음을 우선한다.

1. 이상 감지
2. 중지 판단
3. 안전선 확보
4. 부담 위치 확인
5. 해제·복구·인계

### P-04 회복 비동일성

휴식 하나로 모든 비용이 회복되지 않는다.

- 신체 부담: 휴식·치료·재활
- 장소 부담: 폐쇄·보수·생태 회복
- 관계 부담: 설명·동의 갱신·배상·거리 두기
- 도구 부담: 수리·재검증·폐기
- 기록 부담: 정정·감사·공개 범위 재결정

### P-05 전문성 분산

한 사람이 관측·통역·구조·의료·시설·법적 결정을 모두 수행할 수 없다.

## 생태·권리

### R-01 불확실성 보호

지성·권리 상태가 불명확하면 비소유·비파괴·비가역 개입 보류를 우선한다.

### R-02 위험과 권리 분리

위험한 존재도 이동·서식·신체·기록 권리를 가질 수 있다. 보호는 위험 통제를 배제하지 않는다.

### R-03 거부는 정보이자 결정

거부를 공격성·비협조로 자동 번역하지 않는다. 현재 조건에 대한 데이터이자 권리 행사일 수 있다.

### R-04 대표권 제한

관찰자·통역자·학교·정부는 당사자의 의도 전체를 대신 확정하지 않는다.

### R-05 위치·기억·사체 기록 통제

민감 서식지, 이동 경로, 사체, 기억, 자기명칭은 자동 공개·소유 대상이 아니다.

## 제도·기록

### I-01 분산 관할

- 현실 기관: 의료·구조·교통·수사·교육·보험·재산
- 경계 전문 조직: 위상·회랑·부담·생태 복구
- 당사자·지역 공동체: 권리·접근·협정
- 독립 기능: 감사·권리 옹호·연구윤리·분쟁 판단

### I-02 공동지휘는 임시

혼합 사고에서 공동 대응표를 만들 수 있으나 상설 통합정부나 단일 지휘권으로 변하지 않는다.

### I-03 현실 기록 유지

학적·출결·치료·교통·시설·보험·재산·사고 기록을 삭제하거나 허위 원인으로 바꾸지 않는다.

### I-04 최소 공개

공개는 피해 처리에 필요한 범위와 서식지·미성년자·수사·권리를 보호하는 범위를 함께 고려한다.

### I-05 미성년 권한 상한

학생은 관찰·기록·신고·제한 보조·거부가 가능하지만 구조·시설·의료·수사·분쟁 최종 지휘를 대신하지 않는다.

# 2. 정상 작동 사례

## N-01 감독 관찰

- 조건: 장소+상태 일치, 관계 불명확
- 허용: 경계 밖 센서·생활 기록·원격 관측
- 금지: 접근·포획·경로 강제
- 부담: 시간·인력·통제 비용
- 기록: 관찰 범위와 모르는 항목 표시
- 적용: 부제작 1의 초기 여울띠 관찰

## N-02 조건부 통과

- 조건: 장소+상태+관계 승인
- 행동: 성인팀이 현실 접근을 통제하고 당사자가 경로를 시험
- 부담: 경로 보호 폐쇄, 일정 지연, 시설 순서 변경
- 기록: 경로 위치는 제한 공개
- 적용: 부제작 1 클라이맥스

## N-03 교육용 결합 조율

- 조건: 승인된 훈련실+안정 상태
- 학생 역할: 관측·중지·복구 순서 훈련
- 성인 역할: 장비·안전·의료 감독
- 성공 기준: 효과 크기가 아니라 정지와 원상 복구
- 적용: 부제작 2 학교 수업

## N-04 유물 제한 사용

- 조건: 보관권자 승인+사용 조건 충족
- 행동: 한 기능만 제한 시간 사용
- 부담: 도구 손상·사용 기록·후속 감사
- 종료: 기능 회수·수리·재검증
- 적용: 부제작 4 또는 6

## N-05 지역 판본 병존

- 조건: 중앙 기록과 지역 기록이 충돌
- 행동: 어느 한쪽을 삭제하지 않고 관찰 범위·작성 목적·권한을 병기
- 부담: 호환 속도 저하
- 보상: 오분류 감소·당사자 발언권 유지
- 적용: 부제작 3

# 3. 실패 사례

## F-01 장소 단절

- 상황: 상태와 관계는 맞지만 공사로 구조 연속성이 끊김
- 결과: 진입 실패가 아니라 인접 구간에 부담·이상 이동
- 위험: 단일 구역 폐쇄를 성공으로 오판
- 중지: 범위 확대 관측
- 복구: 복수 경로·공정 순서 변경
- 적용: 부제작 1

## F-02 상태 시차

- 상황: 장소·관계는 맞지만 수위·계절·기상 상태가 예상보다 빨리 변함
- 결과: 통로 깊이·센서 시간·생물 간격 불일치
- 중지: 예방 통제와 철수
- 복구: 다음 상태 창까지 보호 폐쇄
- 적용: 부제작 3·4

## F-03 관계 철회

- 상황: 장소·상태는 맞지만 지성 당사자가 동의를 철회
- 결과: 기술적으로 가능해도 진행 불가
- 오판: 이미 받은 동의를 영구 허가로 취급
- 중지: 접근·기록·공개 중단
- 복구: 이유 설명, 조건 재협상, 불참 보장
- 적용: 부제작 2

## F-04 신체 안정 붕괴

- 상황: 조율자가 감각 과부하를 무시하고 지속
- 결과: 방향·순서·자기 위치 판정 오류
- 중지: 자기 안정 실패 기준 충족 시 즉시 이탈
- 복구: 의료 평가·재활·자격 제한
- 적용: 부제작 2·6

## F-05 도구 부담 누락

- 상황: 유물이 정상 작동했지만 내부 부담 기록이 빠짐
- 결과: 다음 사용자가 안전 한도를 잘못 판단
- 중지: 도구 격리
- 복구: 분해 검사·이력 정정·사용권 재심사
- 적용: 부제작 6

# 4. 오용 사례

## M-01 강제 경로 개방

- 명분: 구조 시간 단축
- 위반: R-03, I-01
- 단기 효과: 사람 이동 성공 가능
- 전가: 생태·지역·다음 이동군에 부담
- 장기 결과: 협력 철회·경로 위치 비공개

## M-02 부담 외부화

- 명분: 학교·도시 안전 유지
- 방식: 부담을 보이지 않는 장소·주민·생물에 이동
- 단기 효과: 중심 시설 안정
- 위반: P-02, R-02
- 사가 기능: 기존 질서의 핵심 구조 문제

## M-03 센서 불일치 삭제

- 명분: 혼란·공황 방지
- 방식: 맞지 않는 기록을 오류로 제거
- 위반: O-05, I-03
- 결과: 다음 사건의 공정 단서와 피해자 신뢰 상실

## M-04 유물 상위권한 집중

- 명분: 빠른 위기 대응
- 방식: 한 사람에게 접근·사용·기록 수정 권한 집중
- 단기 효과: 실제 구조 성공
- 장기 위험: 거부·지역 판본·감사 우회
- 적용: 부제작 6

## M-05 전면 공개

- 명분: 진실과 책임
- 방식: 서식지·미성년자·피해자·제한 기록까지 공개
- 위반: R-05, I-04
- 결과: 밀수·추적·낙인·2차 피해
- 적용: 부제작 5

# 5. 중지·복구 절차

## S-01 현장 중지

1. 이상 신호 확인
2. 학생 활동 중지
3. 현실 접근 통제
4. 인원·당사자·시설 상태 확인
5. 기록 보존
6. 전문 책임자별 인계

## S-02 부담 위치 확인

- 신체
- 장소·시설
- 생태·이동
- 관계·동의
- 도구·재료
- 일정·인력
- 법적·재산·기록

하나만 확인하고 복구 완료로 처리하지 않는다.

## S-03 단계별 재개

- 관측만 재개
- 제한 접근
- 복수 조건 시험
- 당사자 선택
- 시설 부분 재개
- 사후 점검

전면 정상화는 마지막 단계이며 필수가 아니다.

## S-04 기록 정정

- 원기록 보존
- 오류·관찰 범위 표시
- 새 근거와 이견 병기
- 공개 범위·권리 재검토
- 다음 재검증 조건 설정

## S-05 관계 복구

- 정보 비대칭 인정
- 피해·책임 설명
- 자료 사용·재사용 범위 재동의
- 불참·거리 두기 허용
- 신뢰 회복을 즉시 완결하지 않음

## 잠재 점검

- 원고의 시간 어긋남이 `시간여행`으로 읽히지 않도록 기록 불일치와 경로 체감 변화로 한정되는지 확인
- 센터가 시설·교통 기관의 최종 권한을 대신하는 문장 탐지
- 여울띠를 `가족`이라고 인간식 친족 구조로 확정하는 표현 점검
