# 세계관 용어·명명 원칙 4안 v0.1

## 목적

고유명사를 성급히 확정하지 않고, 세계관의 언어가 어떤 인상을 줄지 비교한다. 실제 명칭은 작가 승인 전까지 작업명으로만 사용한다.

## A안 — 생활어 확장형

길, 문턱, 틈, 결, 숨, 맥, 물목, 고리처럼 일상에서 이해 가능한 한국어를 조합한다.

장점:
- 어린 독자가 처음부터 뜻을 짐작할 수 있다.
- 현실 세계와 숨은 세계의 거리가 가깝다.

위험:
- 모든 용어가 비슷하고 추상적으로 들릴 수 있다.
- 한자어를 어색하게 피하다가 유아적으로 보일 수 있다.

## B안 — 기관별 다중 명칭형

같은 현상도 학교, 현장 탐사자, 지역 주민, 연구자, 생물이 서로 다른 이름으로 부른다.

장점:
- 세계의 관점 차이와 역사를 보여 준다.
- 하나의 중앙 정답어가 세계를 지배하지 않는다.

위험:
- 독자가 같은 대상을 여러 개로 오해할 수 있다.
- 용어표 관리 부담이 크다.

## C안 — 기능 코드+생활 별칭형

설정집 내부에는 중립적인 기능 코드가 있고, 본편·학교·지역에서는 생활 별칭을 사용한다.

예:
- 내부 코드: `ROUTE-THRESHOLD-01`
- 생활 별칭 후보: `비문턱`, `잠긴 샛길`, `세 번 도는 길`

장점:
- 제작 관리와 독자 친화성을 동시에 확보한다.
- 이름 변경과 문화 감수 수정이 쉽다.

위험:
- 코드가 작품 전면에 나오면 게임 데이터처럼 보인다.

## D안 — 지역 자기명칭 우선형

각 지역 공동체와 당사자가 사용하는 자기명칭을 우선하고, 한국어 작업 번역을 병기한다.

장점:
- 범지역 확장 때 문화 단일화를 피한다.
- 번역·오해·명칭 갈등을 서사 자원으로 쓸 수 있다.

위험:
- 실제 언어·문화 감수가 필수다.
- 초기 설정 단계에서 임의 외국어 조어를 만들 위험이 있다.

## 권장 결합

- 제작 내부: C의 기능 코드
- 독자·학교 생활: A의 생활어
- 관점 차이: B를 제한적으로 사용
- 해외·지역 확장: D는 인간 감수 뒤 적용

## 명명 가드레일

1. 실제 종교의 신성 명칭을 전투 기술·몬스터 이름으로 직접 사용하지 않는다.
2. 한 국가·민족·언어를 하나의 능력명으로 고정하지 않는다.
3. 어려운 한자어를 권위의 증거로 남용하지 않는다.
4. 모든 고유명사는 한 문장 안에서 기능을 짐작할 단서를 준다.
5. 같은 접미사로 수십 개 용어를 양산하지 않는다.
6. 작중 인물의 이름은 세계 규칙과 별도로 결정한다.

## 현재 작업명

다음은 개념을 구분하기 위한 임시 작업명이며 정식 고유명사가 아니다.

- 숨은 길: 현실 공간에 겹친 다른 이용 경로
- 문턱: 접근 조건이 바뀌는 경계
- 잔흔: 실패·접근·현상 뒤 남은 관측 흔적
- 동행체: 인간과 독립된 목적을 가진 비인간 존재의 임시 분류어
- 수련술: 몸·도구·장소·관계를 사용하는 기술군의 임시 총칭
