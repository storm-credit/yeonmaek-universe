# C0 내부 세계 설정집 통합 색인 v0.1

## 목적

이 문서는 작가·설계 에이전트가 세계 규칙, 기관, 인물, 지역, 수집 항목, 작품 구조와 원고 영향을 한곳에서 추적하는 내부 설정집의 단일 진입점이다.

`C0`는 독자용 백과사전이 아니다. 후보·폐기·비공개·지역 판본·인간 검토 상태까지 포함하며 판매하지 않는다.
