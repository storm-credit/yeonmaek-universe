# 정본 상태 규칙

| 상태 | 의미 | 사용 가능 범위 |
|---|---|---|
| hypothesis | 조사 전 가설 | 브레인스토밍만 |
| candidate | 4안 비교 대상 | 설계 비교 |
| provisional | 임시 채택 | 하위 설계 가능, 변경 주의 |
| canon | 작가 승인과 검증 완료 | 모든 후속 작업의 기준 |
| deprecated | 폐기 | 역사 추적만 |

## 정본 승격 요건

- 작가 의도와 성공 조건 충족
- 대안 비교
- 필요한 문화 조사
- 연속성·현실성 검토
- 의존성 영향 확인
- 결정 로그 기록
