# 생물·유물·회랑·도감 시각 언어 4안 v0.1

## 목표

글을 읽지 않아도 대표 생물·유물·회랑 상태가 서로 구별되고, 어린 독자에게 수집욕구를 주면서 성인 독자에게도 유치하지 않은 시각 체계를 만든다.

공통 금지:
- 모든 생물에 눈·입·귀여운 얼굴 부여
- 색만 바꾼 동일 실루엣
- 별 개수·희귀도·전투력 등급
- 실제 전통 문양·종교 상징을 장식으로 직접 사용
- 보호 위치를 정확한 실제 지도처럼 공개

## 한눈 비교

| 안 | 핵심 문법 | 강점 | 위험 |
|---|---|---|---|
| A 지층선·빈공간형 | 등고선, 끊긴 선, 보호된 공백 | 세계의 길·부담·비공개 주제와 강하게 연결 | 차갑고 지리 교과서처럼 보일 수 있음 |
| B 반투명 겹막형 | 겹치는 막, 투과, 밝기·흐림 | 생물과 다층 위상을 감각적으로 표현 | 인쇄와 작은 화면에서 뭉개질 수 있음 |
| C 현장기록·정정형 | 손기록, 도장, 수정선, 판본 탭 | 도감 수집·정정 재미가 강함 | 빈티지 탐험물·연구 노트 상투성 |
| D 구조신호·모듈형 | 기하 모듈, 상태 아이콘, 조립 흔적 | 유물·장비·지도 가독성과 상품성 | 게임 UI처럼 보일 위험 |

# 안 A — 지층선·빈공간형

## 핵심

완성된 면보다 `어디서 선이 끊기고 무엇을 표시하지 않는가`가 중요하다.

### 생물

- 몸의 외곽선을 한 번에 닫지 않는다.
- 이동·거부·거리 두기 상태에 따라 선의 연결 방식이 달라진다.
- 크기는 사람·문·계단 등 생활 기준물과 함께 표시한다.

### 유물

- 사용 가능한 기능은 실선, 현재 부담은 겹선, 금지된 사용은 빈 칸으로 표시한다.
- 오래 사용할수록 표면에 새 장식이 생기는 대신 선이 닳거나 끊긴다.

### 지도

- 개방: 연속선
- 조건부: 끊긴 이중선
- 복구 중: 서로 맞지 않는 평행선
- 보호 폐쇄: 선을 둘러싼 넓은 여백
- 위치 비공개: 좌표 대신 상태 카드만 표시

# 안 B — 반투명 겹막형

## 핵심

현실과 심층이 별도 세계가 아니라 같은 장소의 다른 상호작용 깊이라는 점을 투명층으로 표현한다.

### 생물

- 여울띠: 길고 낮은 이중 막과 밝은 마디
- 모서리잠: 접힌 여섯 판과 각도 변화
- 온기고리: 닿지 않는 고리의 간격
- 물갈피: 앞뒤가 고정되지 않은 얇은 판
- 문답결: 서로 겹치지 않는 결 방향
- 숨돌: 다공성 덩어리 내부의 빈 층

얼굴 표정 대신 간격·접힘·투명도·진동으로 상태를 보여 준다.

### 위험

색 없이도 구별되도록 실루엣과 표면 패턴을 함께 설계해야 한다.

# 안 C — 현장기록·정정형

## 핵심

독자가 완성 도감을 받는 것이 아니라 판본이 바뀌는 과정을 수집한다.

### 카드 구성

- 관찰 스케치
- 크기 기준
- 처음 분류명
- 현재 작업명
- 자기명칭 공개 상태
- 관찰 범위
- 정정 이유
- 현재 관계 상태
- 다음 검토 시점

### 정정 표시

- 삭제선은 원문을 완전히 가리지 않는다.
- `틀림` 도장 대신 `관찰 범위 변경`, `당사자 이의`, `위치 보호`, `재검증`을 구분한다.
- 카드 번호는 강함 순서가 아니라 기록 ID다.

### 지도책

같은 구역의 학생판·시설판·지역판을 투명 페이지 또는 탭으로 비교한다.

# 안 D — 구조신호·모듈형

## 핵심

학교 장비·유물·회랑 상태가 같은 신호 체계를 공유하되, 생물의 몸은 시스템 아이콘으로 축소하지 않는다.

### 유물 형태 문법

- 관측 도구: 서로 맞지 않는 두 프레임
- 중지 도구: 서로 닿지 않는 판
- 부담 이동 도구: 세 갈래 연결
- 반환 도구: 중심이 빈 고리
- 권한 도구: 분리·결합 가능한 조각

### 지도 상태 기호

- 관찰 가능: 열린 괄호
- 접근 제한: 한쪽 닫힌 괄호
- 철회: 바깥으로 향한 화살표
- 보호 폐쇄: 빈 원과 외곽 점선
- 재검증: 겹친 시계 표식
- 기록 충돌: 어긋난 두 격자

# 1순위 제안

**안 C 현장기록·정정형**을 전체 출판·수집 인터페이스의 중심으로 둔다.

단, 대상 자체의 디자인은 다음을 결합한다.
- 생물 실루엣: 안 B 반투명 겹막형
- 회랑 지도: 안 A 지층선·빈공간형
- 유물·장비: 안 D 구조신호·모듈형

즉 하나의 화풍으로 모두 뭉개지 않고, `도감 인터페이스`가 서로 다른 대상을 묶는다.

# 대표 생물 6종 식별표

| 생물 | 외곽 형태 | 크기 | 움직임 | 표면/소리 |
|---|---|---|---|---|
| 여울띠 | 낮고 긴 이중 막 | 사람 다리 길이~여러 개체 띠 | 간격 유지·방향 반전 | 밝은 마디, 낮은 떨림 |
| 모서리잠 | 접힌 육면 판 | 손바닥 | 접힘·구조 안쪽 이동 | 반투명 판, 클릭음 |
| 온기고리 | 닿지 않는 고리 군 | 팔 둘레 | 회전·간격 축소·흩어짐 | 열에 따른 흐림 |
| 물갈피 | 앞뒤 없는 얇은 판 | 책장~작은 우산 | 수면 경계에서 뒤집힘 | 젖지 않는 투명면 |
| 문답결 | 서로 다른 방향의 결 덩어리 | 머리~문 폭 | 결 방향 분리·재배열 | 겹치지 않는 잔향 |
| 숨돌 | 구멍 많은 무거운 덩어리 | 주먹~바위 | 거의 이동하지 않음 | 내부 빈 층의 낮은 울림 |

# 유물 8종 식별 규칙

- 되짚등: 낮은 등+역순 선
- 겹눈틀: 비평행 이중 렌즈
- 비움매듭: 재질이 다른 세 가닥
- 반납열쇠: 중심이 빈 고리
- 멈춤종: 서로 닿지 않는 판
- 숨은추: 눈금 없는 추+세 갈래 실
- 잔기록판: 흐린 수정층이 쌓인 판
- 돌림패: 분리·결합 가능한 권한 조각

손에 쥔 실루엣만으로 최소 6개 이상을 구별할 수 있어야 한다.

# 접근성

- 색 없이도 외곽·패턴·아이콘으로 상태 구분
- 도감 카드 작은 화면에서 핵심 필드 5개만 먼저 표시
- 본문 글자와 배경 대비 확보
- 보호 폐쇄·위치 비공개를 위험·금지 색 하나로만 구분하지 않음
- 반투명 효과는 흑백 인쇄용 선 패턴 대체본 제공

# 인간 시안 요청 규격

실제 아트디렉터·일러스트레이터에게는 다음 4장을 요청한다.

1. 대표 생물 6종 흑백 실루엣 한눈 비교
2. 유물 8종 손 크기 기준 형태 비교
3. 회랑 상태 6종 지도 기호
4. 도감 카드의 모바일·단행본·흑백 인쇄 버전

이 단계의 텍스트는 최종 삽화가 아니다.
