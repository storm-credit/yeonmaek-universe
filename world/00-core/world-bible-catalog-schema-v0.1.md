# 설정집 카탈로그 공통 스키마 v0.1

## 목적

지역·기관·세력·인물·생물·현상·도구·유물·역사·경로를 같은 출처 규칙으로 관리한다. 항목 수를 먼저 정하지 않으며, 다른 프로젝트의 숫자나 목록을 가져오지 않는다.

## 공통 필수 필드

| 필드 | 설명 |
|---|---|
| ID | 내부 식별자. 의미를 과도하게 담지 않는다. |
| 정식명 | 현재 후보 명칭 |
| 현지명·자기명칭 | 당사자 또는 지역에서 사용하는 이름 |
| 분류 | 카탈로그 종류와 하위 유형 |
| 상태 | P0·P1·P2·Q·X 및 canon 여부 |
| 출처 | 사용자 지시, 독립 설계, 조사 자료, 격리 자료 |
| 한줄 기능 | 작품에서 담당하는 기능 |
| 독자 보상 | 경이·웃음·긴장·관계·수집·미스터리 중 핵심 |
| 공개 범위 | 공개·제한·비공개·상황별 공개 |
| 연결 항목 | 관련 지역·기관·인물·경로·사건 |
| 충돌 검사 | 기존 규칙과의 모순 여부 |
| 감수 필요 | 문화·생태·법률·안전·언어 등 |
| 변경 이력 | 오분류·이름 변경·격리·승격 기록 |

## 지역 항목 추가 필드

- 현실 지리와의 관계
- 이용자 공동체
- 계절·시간 변화
- 주요 경로와 폐쇄 조건
- 생활 기능
- 외부인이 오해하기 쉬운 점
- 지역 주민에게 발생할 수 있는 피해

## 품질 게이트

항목은 다음 조건을 충족하기 전까지 `candidate`를 벗어나지 않는다.

1. 출처가 명시됨
2. 세계 규칙과 충돌하지 않음
3. 다른 작품에서 이식된 흔적이 없음
4. 독자 보상과 서사 기능이 구분됨
5. 공개·소유·접근 권한이 분리됨
6. 필요한 감수 항목이 표시됨
