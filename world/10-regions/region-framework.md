# 권역 설계 원칙

## 상위 분류 후보

1. 한반도·동북 산해권
2. 중국 대륙 복합권
3. 일본 열도·화산해양권
4. 메콩·대륙부 동남아권
5. 남양 군도·해양부 동남아권
6. 몽골·내륙아시아 초원권
7. 남아시아 평야·고원·인도양권
8. 히말라야·고산 접경권
9. 서아시아·중앙아시아 접촉권
10. 유럽·서양 마법 접촉권

이 이름은 조사용 임시 분류이며 문화권의 실제 자기명칭을 대체하지 않는다.

## 권역 생성 기준

- 기후와 지형
- 생물 이동로
- 언어와 교역 네트워크
- 종교·지식 전승의 중첩
- 현대 국가와 도시 인프라
- 식민·전쟁·이주의 변화

하나의 국가는 여러 권역에 걸칠 수 있고, 하나의 권역은 여러 국가를 지난다.
