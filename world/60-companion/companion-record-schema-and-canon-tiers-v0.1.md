# 동반 기록 스키마·정본 등급·스포일러 정책 v0.1

## 1. 기록 항목 공통 필드

모든 도감·지도·유물·인물 기록은 가능한 범위에서 다음을 가진다.

### 식별

- 내부 기록 ID
- 공개 제목
- 지역 자기명칭
- 한국어 작업 번역
- 다른 판본 명칭
- 항목 종류
- 최초 기록일 / 최신 정정일

### 출처와 목소리

- 관찰자·작성자 역할
- 편집자 역할
- 검토 당사자
- 기관·지역·공동체 소속
- 직접 관찰 / 전언 / 장비 기록 / 추론 / 창작 편집 구분

### 상태

- `confirmed-event`: 복수 독립 증거가 합치하는 사건 사실
- `institutional-claim`: 기관이 공식 주장하지만 편향 가능
- `field-observation`: 현장 관찰, 조건부 재현 가능
- `party-statement`: 당사자의 자기서술; 외부가 진위 등급화하지 않음
- `contested`: 판본 또는 당사자 사이 이견
- `misclassified`: 과거 분류 오류 확인
- `withdrawn`: 공개 동의 철회 또는 안전상 철회
- `unknown`: 판단 근거 부족

### 공개와 권리

- 공개 동의 범위
- 위치 정밀도 등급
- 이름 공개 범위
- 사진·삽화·음성 재현 허용 범위
- 미성년자·주민·당사자 개인정보 처리
- 철회 요청과 반영 일자
- 이의 제기 링크

### 서사 연결

- 첫 등장 부제작
- 독자가 본편에서 이미 아는 범위
- 스포일러 해제 부제작
- 관련 인물·사건·지도·유물
- 정정 전후 의미 변화
- 장기 복선 사용 여부

### 제작

- 실제 사실 / 기능 추상화 / 복합 변형 / 완전 창작
- 출처 등급
- 현지 인간 감수 상태
- 법률·상표·민감 위치 검토 상태
- 삽화 상태
- 영상·게임·카드 재사용 허용 범위

## 2. 정본 계층

정본 계층은 `더 진실한 판매판`을 만들기 위한 서열이 아니다.

### C0 — 작가 내부 세계 정본

- 존재론·비용·연표·사건 결과의 실제 설계.
- 독자에게 그대로 판매하지 않는다.
- 본편 미스터리와 비공개 정보를 포함할 수 있다.

### C1 — 본편 확정 사건

- 출간된 본편에서 독자가 확인할 수 있는 사건과 결과.
- 후속 레트콘 없이 유지해야 한다.

### C2 — 세계내 공식 기록

- 학교·기관·지역 조직이 발행한 문서.
- 공식이지만 틀리거나 누락될 수 있다.
- 문서의 편집자·권한·시점을 표시한다.

### C3 — 세계내 현장·당사자 기록

- 학생 노트, 주민 기록, 당사자 자기서술, 비공식 지도.
- C2보다 낮은 진실 등급이 아니다. 관점과 검증 방식이 다르다.

### C4 — 소문·오분류·폐기 기록

- 의도적으로 틀린 정답이 아니라 세계의 과거 인식과 편향을 보여준다.
- 현재 편집부가 오류 상태와 정정 경로를 표시한다.

### CX — 비공개·철회·보호 기록

- 정보가 존재해도 독자용 판본에 내용을 공개하지 않는다.
- 비공개 사유의 범주만 공개할 수 있다.
- `빈칸=풀어야 할 비밀`로 자동 취급하지 않는다.

## 3. 상호 모순 처리

1. C0와 C1이 충돌하면 제작 오류로 보고 수정 게이트를 연다.
2. C2와 C3의 충돌은 자동 해결하지 않고 편집 시점·권한·근거를 표시한다.
3. 당사자 자기명칭은 기관 분류명 아래의 별칭으로 종속하지 않는다.
4. 정정은 이전 판본을 삭제하지 않고 변경 이유와 영향을 기록한다.
5. 실제 사실 오류는 세계내 편향으로 변명하지 않고 즉시 수정한다.
6. 문화 감수 지적은 설정 내부 논쟁으로 소비하지 않고 제작 오류로 처리할 수 있다.

## 4. 스포일러 잠금

각 항목은 다음 중 하나를 가진다.

- `open-after-I1` ... `open-after-I7`
- `never-public`: 제작·안전·동의상 비공개
- `companion-original-safe`: 본편 결말과 무관한 독립 정보
- `edition-dependent`: 특정 판본에서만 공개

### 원칙

- 설정집은 다음 부제작의 범인·희생·배신·해결법을 선행 공개하지 않는다.
- 출간 전 작품의 핵심 유물·동행종·판본은 실루엣·빈 ID 정도만 허용한다.
- 이전 작품의 결말을 다루더라도 해당 작품을 읽지 않은 독자를 위한 경고와 분리 구역을 둔다.
- 본편에서 설명하지 않은 필수 인과를 설정집에서 보충해 결말을 성립시키지 않는다.

## 5. 위치·생태 보안

- 실제 민감 서식지, 주거지, 기반시설 취약점은 좌표·정밀 동선으로 공개하지 않는다.
- 독자용 지도는 합성·축척 변형·구역 단위 일반화를 사용한다.
- 창작 회랑도 현실 안전시설 우회·침입 안내로 읽히지 않게 한다.
- 폐쇄·비공개된 길은 수집 미완성 항목이 아니라 정당한 관리 결과일 수 있다.

## 6. 매체 재사용

### 가능

- 항목 ID, 실루엣, 상징, 상태 변화, 판본 비교, 안전한 일반 지도, 장비 외형, 유물 이력.

### 조건부

- 지성종 카드: 공격력·희귀도 대신 관계 상태·동의·환경 역할 중심.
- 게임 지도: 실제 민감 위치와 분리된 합성 공간.
- 영웅 기록: 공식 명성과 반대 기록을 함께 제공.

### 금지

- 당사자 동의 철회 정보를 데이터마이닝 보상으로 공개.
- 지성종 거래·포획·합성·진화 확률화.
- 문화·종교 상징을 희귀 스킨으로 판매.
- C0 비공개 진실을 게임 설명에서 먼저 공개.
