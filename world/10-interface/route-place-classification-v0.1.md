# 숨은 길·장소 분류 체계 v0.1

## 목적

숨은 길을 사건 편의적 비밀 통로로 사용하지 않도록, 접근·이용·위험·복구 상태를 분리해 기록한다.

## 1. 길의 기능 분류

### T1 통과로

현실의 두 지점을 다른 이용 순서로 연결한다. 이동 시간 단축이 주목적이 아닐 수 있으며, 특정 이용자에게는 오히려 더 긴 안전 경로가 된다.

### T2 순환로

출발점과 도착점이 같아도 이동 중 감각·시간표·관계 상태를 바꾼다. 훈련·정화·관찰에 사용될 수 있다.

### T3 머묾길

통과보다 대기·교환·휴식·번식·피난이 핵심인 경로다. 인간에게 복도로 보여도 다른 존재에게는 서식지일 수 있다.

### T4 전달로

사람보다 소리·냄새·열·물·신호·기억 흔적 같은 것이 먼저 이동한다. 통신과 경보에 활용할 수 있지만 오염과 왜곡 위험이 있다.

### T5 닫힌길

고장이나 미발견이 아니라 의도적으로 닫혔거나 현재 이용을 거부한 길이다. 닫힘 자체가 정당한 상태일 수 있다.

## 2. 장소의 역할 분류

- `경계점`: 접근 조건이 바뀌는 곳
- `겹침터`: 두 이용 체계가 동시에 강하게 나타나는 곳
- `머묾터`: 생물·사람·현상이 장기간 머무는 곳
- `반납터`: 도구·생물·부담을 원래 관계로 돌려놓는 곳
- `잔흔터`: 과거 실패나 사건의 흔적이 누적된 곳
- `공유터`: 여러 공동체가 합의한 조건으로 함께 쓰는 곳
- `보호폐쇄`: 위치·이용 목적은 존재하지만 공개하지 않는 곳

## 3. 접근 상태

| 상태 | 의미 |
|---|---|
| open | 현재 조건에서 안전하게 이용 가능 |
| conditional | 시간·날씨·동행·관계 등 조건부 가능 |
| supervised | 감독자·장비·안전팀 필요 |
| refused | 당사자 또는 장소가 현재 이용을 거부 |
| unstable | 조건이 흔들려 이용 금지 또는 제한 |
| closed | 운영·생태·안전 이유로 폐쇄 |
| unknown | 정보 부족, 미개방과 동일하지 않음 |

## 4. 위험 분류

위험은 한 숫자로 합치지 않는다.

- 신체 위험
- 방향·시간 감각 위험
- 현실 기반시설 위험
- 생태 교란 위험
- 관계·동의 침해 위험
- 정보 노출 위험
- 잔여 부담 위험

각 길은 최소 두 위험 항목을 별도로 기록한다.

## 5. 복구 상태

- 관찰 중
- 임시 안정
- 부분 재개
- 공동관리
- 장기 폐쇄
- 자연 회복 대기
- 반환 완료
- 해결 불가가 아니라 개입 중지

## 6. 지도 기록 필드

- 작업 ID
- 생활 별칭
- 위치 정밀도 등급
- 기능 분류
- 장소 역할
- 접근 상태
- 재현 조건
- 실패 조건
- 이용 당사자
- 인간 이용 이력
- 위험 항목
- 복구 상태
- 공개 범위
- 마지막 검증일

## 7. 가드레일

1. 실제 기반시설 침입 안내가 되는 좌표·동선을 만들지 않는다.
2. 모든 길을 인간의 이동 편의로 평가하지 않는다.
3. 닫힌길을 반드시 열어야 하는 미스터리로 취급하지 않는다.
4. 지도 미완성을 수집 실패로만 보지 않는다.
5. 주인공만 통과 가능한 예외는 핵심 설정으로 자동 채택하지 않는다.
