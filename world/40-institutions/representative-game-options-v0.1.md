# 대표 경기 4안 v0.1

## 설계 목표

학교를 기억하게 만드는 반복 경기이되, 단순 결투나 공격력 서열이 아니라 경로 읽기·팀워크·판단·중지 능력을 보여 준다.

## A. 길잇기 경기

여러 팀이 제한 시간 안에 끊어진 경로를 안전하게 연결한다.

- 역할: 선행 관찰, 표식, 장비, 동행 보호, 복구 판단
- 득점: 안전성, 재현 가능성, 지역 이용자 동의, 철수 판단
- 장점: 세계관 핵심과 직접 연결
- 위험: 시각적으로 정적인 작업처럼 보일 수 있음

## B. 이동 구조 경기

변화하는 경기장에서 사람·생물·물품을 지정 위치까지 안전하게 옮긴다.

- 역할: 길잡이, 운반, 방어, 교신, 대체 경로
- 득점: 구조 성공, 부상 최소화, 자원 관리, 팀 분산 대응
- 장점: 박진감과 협업이 강함
- 위험: 재난을 스포츠로 소비하는 인상을 줄 수 있음

## C. 표식 쟁탈 경기

상대의 표식을 빼앗는 것이 아니라, 여러 목적지의 상태를 먼저 정확히 판독하고 올바른 표식을 설치한다.

- 역할: 정찰, 판독, 교란 식별, 설치, 검증
- 득점: 정확도, 속도, 오류 수정, 상대의 안전 보장
- 장점: 관전성이 좋고 전략 변화가 많음
- 위험: 규칙이 복잡해질 수 있음

## D. 동행 순환 경기

각 팀이 서로 다른 특성을 가진 동행 대상과 여러 구간을 순환하며 신뢰를 유지한다.

- 역할: 관찰, 소통, 휴식, 경계 통과, 예상 밖 거부 대응
- 득점: 완주보다 관계 안정과 무리하지 않은 판단
- 장점: 생태·관계 중심 세계관과 잘 맞음
- 위험: 승패가 모호하게 느껴질 수 있음

## 추천안

대표 경기는 `A 길잇기 경기`를 기본으로 하고, 관전성과 속도를 높이기 위해 `C 표식 판독`과 `B 이동 구조` 요소를 일부 결합한다.

경기 핵심 장면은 다음 다섯 가지가 반복 가능해야 한다.

1. 예상 밖 경로 변화
2. 역할 교대
3. 상대 팀과의 일시 협력
4. 계속할지 중지할지의 선택
5. 승패와 별개인 관계·평판 변화

## 승패 규칙

- 가장 빠른 팀이 반드시 이기지 않는다.
- 위험 신호를 무시하면 큰 감점 또는 실격이다.
- 상대의 안전을 지킨 행동은 득점된다.
- 잘못된 판단을 신속히 인정하고 수정하면 일부 점수를 회복한다.
- 경기 후 공개 검토에서 판정 근거를 설명한다.

## 금지

- 학생 부상을 흥행 요소로 사용
- 생물을 강제 출전
- 명문 가문·재능만으로 유리한 장비 독점
- 주인공 팀만 규칙 밖 특혜
