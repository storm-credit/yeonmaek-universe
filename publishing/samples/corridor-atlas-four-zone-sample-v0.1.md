# 《회랑 지도첩》 4구역 샘플 v0.1

## 지도첩 원칙

- 독자용 지도는 실제 취약 시설·민감 서식지·당사자 위치를 1:1로 보여 주지 않는다.
- 길의 정확한 좌표보다 표면 생활, 개방 조건, 책임자, 보호 상태, 다음 검증을 보여 준다.
- 열림이 최고 상태가 아니다. 보호 폐쇄·부분 재개·위치 비공개·지도 폐기도 정당한 결과다.
- 같은 구역도 학교판·시설판·지역판·당사자판의 공개 범위가 다를 수 있다.

# MAP-01 서안 통학 회랑

**등장:** 부제작 1  
**지도 상태:** 부분 재개 / 공동 점검 / 일부 보호 폐쇄  
**정확한 위치:** 합성 생활권, 비공개

## 표면 생활

중층 주거지에서 버스 한 번을 갈아타고 철길 아래 짧은 보행 통로를 지나 일반 학교와 예비과정에 접근하는 일상 통학 구간이다. 하천·철도·배수·공사·상가·학원 생활이 가까이 겹친다.

## 조건판

| 조건 | 현재 상태 |
|---|---|
| 장소 | 철도 진동·배수 구조·하천 인접 지층 |
| 상태 | 강우·보수 공정·교통 진동에 따라 변경 |
| 관계 | 여울띠 이동군이 제안 경로를 시험·거부·선택 |

## 판본 차이

### 생활판

- 통학 지연
- 상가·학원 접근
- 가족 연락
- 우회 시간

### 시설판

- 보행 폭
- 배수·벽면·조명
- 공사 순서
- 통제·재개 조건

### 학교판

- 학생 관찰 범위
- 안전선·철수
- 지도 정정

### 보호판

- 여울띠 이동 경로 일부
- 방출지·다음 계절 위치는 비공개

## 사건 뒤 변화

- 통로 일부 재개
- 한 우회 구역 장기 보호 폐쇄
- 공사 일정 지연
- 학교·시설·주민 공동 점검
- `안정` 단일 표시 폐기

## 독자용 범례

`● 생활 사용` / `△ 조건부 통행` / `× 보호 폐쇄` / `… 위치 비공개`

## 다음 검증

다음 계절의 강우·시설 상태·여울띠 재관측 뒤 갱신.

# MAP-02 삼면계단

**등장:** 부제작 2  
**지도 상태:** 교육 개방 / 경기 조건부 / 비상동선 우선  
**정확한 위치:** 학교 캠퍼스 내부 합성 구조

## 표면 생활

교실·도서관·체육공간을 잇는 계단, 접근성 경사로, 화물 서비스 통로가 세 높이 차에서 만나는 구역이다. 점심시간에는 학생들이 가장 자주 지나고, 방과후에는 길문전 훈련에 사용된다.

## 중요한 구분

- 일상 통행로
- 비상 대피로
- 경기 경로
- 시설 점검로

네 동선을 하나의 `최단 길`로 합치지 않는다.

## 조건판

| 조건 | 현재 상태 |
|---|---|
| 장소 | 세 구조면·문 개폐·하중 분산 |
| 상태 | 이용 인원·경기 장비·온실 열·보수 |
| 관계 | 모서리잠 서식 구조·온기고리 활동별 철회 |

## 판본 차이

### 학생 경기판

연결 가능한 세 경로와 중앙 목표만 보인다. 비상 경로는 경기 점수에 사용하지 않는다.

### 시설판

하중·균열·통제·보수 순서를 표시한다. 생태 위치는 필요한 범위만 포함한다.

### 생태판

모서리잠이 머문 구조면과 접근 제한을 표시하지만 공개 전시판에는 정확한 개체 위치를 숨긴다.

## 사건 뒤 변화

- 길문전 코스 단축·중지 규칙 추가
- 모서리잠 보호실 영구 이동안 취소
- 경기·생활·비상 동선 분리 강화
- 온기고리의 팀 등록 대신 활동별 관계 기록

## 독자 보상

지도 위에서 `더 긴 길을 선택한 이유`와 `경기를 멈춘 지점`을 비교할 수 있다.

# MAP-03 갈림물목

**등장:** 부제작 3  
**지도 상태:** 지역판 우선 / 부분 복구 / 계절 재검증  
**지역:** 금강하구 기능을 합성한 provisional 생활권

## 주의

실제 금강하구의 철새·생업·시설·분쟁을 판타지 문제로 대체하지 않는다. 정확한 지명·마을·항로·서식 위치는 지역 감수 전 사용하지 않는다.

## 표면 생활

수분 경계, 제방·수문, 생활 항로, 농어업, 보행·차량 이동이 계절별로 달라지는 지역이다.

## 하나가 아닌 네 지도

### 중앙 호환판

- 연중 비교 가능한 최소 선
- 긴급 지원과 기관 연락에 유리
- 계절·작성 목적·비공개 이유가 축약될 수 있음

### 지역 생활판

- 통행·생업·주민 안전
- 월·상태별 갱신
- 지역 내부에서도 하나의 의견이 아님

### 시설판

- 수문·제방·점검·부분 운영
- 법적 책임과 안전 기준

### 생태판

- 물갈피 이동
- 뒤집잎 상태
- 민감 위치·관찰 범위

## 사건 뒤 변화

- 현재 고립 구간은 부분 복구
- 다음 상태 전 자동 중지·재검증
- 일부 구역 보호 폐쇄
- 지역 갱신권과 최소 경보 필드 공식화
- 중앙판은 지역판을 흡수하지 않음

## 독자용 표현

하나의 완성 지도를 겹쳐 보여 주지 않는다. 네 판을 나란히 놓고 같은 구역의 선이 왜 다른지 설명한다.

## 다음 검증

지역 생활·환경·시설·언어 감수 뒤 구체화.

# MAP-04 수문겹길

**등장:** 부제작 4  
**지도 상태:** 현지 단계 운영 / 국제 경보 최소 유지 / 민감 위치 비공개  
**지역:** 방콕–차오프라야 기능을 합성한 provisional 도시 수계

## 주의

실제 운하·수문·주거 취약 지역·종교 장소를 1:1로 사용하지 않는다. 태국어 이름·현지 기관·주민 생활은 현지 감수 전 미정이다.

## 표면 생활

강·운하·도로·수상 이동·배수·주거·상업·시설 운영이 서로 영향을 주는 도시 수계다.

## 판본 차이

### 현지 운영판

- 수문·교통·대체 동선
- 주민·시설 운영 시간
- 단계적 중지·부분 재개

### 현지 생태·당사자판

- 빗마디의 상태
- 문답결의 배열·철회
- 자기명칭·위치·대표 범위

### 국제 최소판

- 사람·시설 위험 코드
- 검역·구조에 필요한 최소 필드
- 빠르지만 맥락을 잃을 수 있음

### 한국 학생판

- 한국 학교가 본 관찰 범위
- 현지 원문을 대신하지 않음
- 한국 독자에게 공개할 수 있는 제한 요약

## 사건 뒤 변화

- 전면 격리 대신 제한 관찰·재검증
- 현지 수문 책임자의 단계 운영
- 국제 코드에 `번역 불가·대표 범위·위치 비공개` 필드 논쟁
- 한국 학생의 우선 접근권 조사

## 독자 보상

같은 위험 표시가 어느 판에서는 `즉시 차단`, 다른 판에서는 `접근 철회`, 또 다른 판에서는 `상태 미확인`으로 나타나는 이유를 비교한다.

## 다음 검증

태국어·수계·교통·주민·문화·시설 안전의 현지 복수 감수.

# 공통 상태 범례

| 상태 | 지도 의미 |
|---|---|
| 생활 개방 | 표면 생활에 사용 가능 |
| 조건부 통행 | 정해진 상태·시간·책임 아래 사용 |
| 부분 재개 | 일부 기능만 복구 |
| 재검증 | 다음 상태 창에 다시 판단 |
| 공동관리 | 복수 주체가 기록·결정·복구 분담 |
| 보호 폐쇄 | 열지 않는 것이 현재의 안전·권리 결정 |
| 위치 비공개 | 정확한 좌표를 공개하지 않음 |
| 판본 충돌 | 선의 차이가 오류가 아니라 관찰 목적 차이일 수 있음 |
| 지도 폐기 | 현재 조건에 더 이상 안전하게 쓰지 못함 |

# 접근성 요구

- 상태는 색만으로 구분하지 않는다.
- 선 모양·아이콘·텍스트를 함께 사용한다.
- 오디오북·전자책에서는 판본별 차이를 순서대로 설명한다.
- 작은 글씨에 핵심 안전·권리 정보를 숨기지 않는다.
- 어린 독자가 30초 안에 `왜 길을 안 여는 것이 성공일 수 있는지` 설명할 수 있어야 한다.

이 샘플은 실제 지도 그림이 아니라 시각 설계 전 정보·판본·권리 구조를 검증하는 텍스트 프로토타입이다.
