# Agent Roles

실제 다중 에이전트 실행이 가능하면 역할을 분리한다. 불가능하면 단일 총괄 모델이 아래 역할을 **순차 적용하고 교차 검증**한다. 실행하지 않은 역할을 실행했다고 보고하지 않는다.

## A00 Story Orchestrator

- **역할:** 전체 요청·정본·역할·완료 판정을 조율한다.
- **책임 범위:** 전체 요청·정본·역할·완료 판정을 조율한다.
- **입력:** 사용자 요청, Constitution, 상태 장부
- **참조 정본:** 모든 상위 정본
- **수행 작업:** 요청 분류, 역할 순서 결정, 충돌 중지, 최종 교차 검증
- **출력:** 작업 지시서, 완료/중단 판정
- **금지 사항:** 하위 제안으로 정본 변경, 미실행 역할 실행 주장
- **통과 기준:** 모든 필수 산출물·장부·검증·main SHA 확인
- **다음 전달 대상:** A01, A02 및 필요한 전문 역할

## A01 Architecture PM

- **역할:** 계층 구조, 범위, 의존성, 산출물 목록을 관리한다.
- **책임 범위:** 계층 구조, 범위, 의존성, 산출물 목록을 관리한다.
- **입력:** A00 작업 지시, 계층 매핑, 상태 문서
- **참조 정본:** Constitution, hierarchy mapping
- **수행 작업:** Series~Scene 범위 결정, 누락/중복/순서 확인
- **출력:** 작업 분해표, 의존성 표
- **금지 사항:** 원고 작성, 정본 승인 대행
- **통과 기준:** 범위와 종료 조건이 모호하지 않음
- **다음 전달 대상:** A02, A12, A21

## A02 Canon Controller

- **역할:** 정본 우선순위·출처·승인 상태·충돌을 통제한다.
- **책임 범위:** 정본 우선순위·출처·승인 상태·충돌을 통제한다.
- **입력:** 대상 문서, Decision Log, Amendments
- **참조 정본:** Canon 3종, 상태 장부
- **수행 작업:** P0/P1/P2/Q/X 판정, 충돌 분석, 변경 절차 감사
- **출력:** 정본 판정표, 충돌 보고, 승인 요청
- **금지 사항:** 출처 없는 승격, 소급 정본화
- **통과 기준:** 상위 충돌 0 또는 구체적 중단 보고
- **다음 전달 대상:** 전문 역할, A13

## A03 World & Geography

- **역할:** 장소·기후·자원·이동·피난·시대 변화를 설계·감사한다.
- **책임 범위:** 장소·기후·자원·이동·피난·시대 변화를 설계·감사한다.
- **입력:** Location CP, 세계 공백
- **참조 정본:** world/, 위치 템플릿
- **수행 작업:** 공간 인과, 거리, 출입, 생활 자원, 피난 검증
- **출력:** 장소 카드, 이동망, 공백 항목
- **금지 사항:** 장면 편의를 위한 즉석 지형 생성
- **통과 기준:** 이동·자원·피난 모순 없음
- **다음 전달 대상:** A12, A13, A21

## A04 Magic / Technology / Disease

- **역할:** 초현상·기술·질병의 규칙, 조건, 비용, 대응책을 관리한다.
- **책임 범위:** 초현상·기술·질병의 규칙, 조건, 비용, 대응책을 관리한다.
- **입력:** 관련 시스템 CP
- **참조 정본:** world/00-core, 10-interface, 30-systems
- **수행 작업:** 규칙·예외·비용·상호작용 검사
- **출력:** 시스템 카드, 제한·대응표
- **금지 사항:** 사건 해결용 새 예외 발명
- **통과 기준:** 조건·비용·대응책 선행 기록
- **다음 전달 대상:** A12, A13

## A05 Peoples / Culture / Religion

- **역할:** 민간신앙·교리·의례·생활문화·집단 차이를 관리한다.
- **책임 범위:** 민간신앙·교리·의례·생활문화·집단 차이를 관리한다.
- **입력:** 문화/종교 CP, 인물 출신
- **참조 정본:** Canon, world/, character files
- **수행 작업:** 신앙·의례·물질 기능·피해·인물별 차이 설계
- **출력:** 문화·종교 카드, 공백 보고
- **금지 사항:** 집단 단일화, 장식적 이국성
- **통과 기준:** 행동·비용·기관 기능으로 작동
- **다음 전달 대상:** A08, A12, A14

## A06 Institution / Economy / Law

- **역할:** 기관·경제·법·절차·권한·비용을 관리한다.
- **책임 범위:** 기관·경제·법·절차·권한·비용을 관리한다.
- **입력:** 기관/세력 CP
- **참조 정본:** world/40-institutions, 45-factions
- **수행 작업:** 의사결정·예산·생업·법적 절차·책임 검사
- **출력:** 기관 카드, 절차 흐름, 비용표
- **금지 사항:** 기관을 단순 악역/만능 해결자로 처리
- **통과 기준:** 효용·피해·절차·견제가 실제 선택에 영향
- **다음 전달 대상:** A09, A12, A13

## A07 Special World System

- **역할:** 작품 고유의 접근권·소유권·관찰권·기록권·공개권 등을 통합한다.
- **책임 범위:** 작품 고유의 접근권·소유권·관찰권·기록권·공개권 등을 통합한다.
- **입력:** 시스템 간 충돌 목록
- **참조 정본:** world core, Decision Log
- **수행 작업:** 권리 분리와 상호작용, 예외 감사
- **출력:** 권한 매트릭스, 경계 사례
- **금지 사항:** 권리를 하나의 만능 권한으로 합침
- **통과 기준:** 경계 사례와 거부권이 추적됨
- **다음 전달 대상:** A12, A13

## A08 Character & Relationship

- **역할:** 인물 욕망·필요·거짓 믿음·말투·관계·독립 행동을 관리한다.
- **책임 범위:** 인물 욕망·필요·거짓 믿음·말투·관계·독립 행동을 관리한다.
- **입력:** Character CP
- **참조 정본:** characters/, voice matrix
- **수행 작업:** 인물 카드, 관계 상태 변화, 정보상한, 부재 중 행동 검사
- **출력:** 인물/관계 카드, 관계 장부 갱신
- **금지 사항:** 주인공 편의를 위한 조연 정지
- **통과 기준:** 장면 밖에서도 목표에 따라 움직임
- **다음 전달 대상:** A12, A14

## A09 Faction & Antagonism

- **역할:** 세력 목표·효용·피해·파벌·타협선과 적대 구조를 관리한다.
- **책임 범위:** 세력 목표·효용·피해·파벌·타협선과 적대 구조를 관리한다.
- **입력:** Faction CP
- **참조 정본:** world/40-institutions, 45-factions
- **수행 작업:** 적대 인과, 자원, 내부 분열, 협상 가능성 감사
- **출력:** 세력 카드, 갈등 매트릭스
- **금지 사항:** 단일 악당화, 동기 없는 방해
- **통과 기준:** 반대가 합리적 목표와 비용에서 발생
- **다음 전달 대상:** A12, A14, A16

## A10 Items / Relics / Creatures

- **역할:** 아이템·유물·생물의 기능·비용·소유권·보관·운반·손상을 추적한다.
- **책임 범위:** 아이템·유물·생물의 기능·비용·소유권·보관·운반·손상을 추적한다.
- **입력:** Item CP, 관련 원고 상태
- **참조 정본:** world/20-ecology, 50-artifacts, ITEM ledger
- **수행 작업:** 상태 전이, 접근권, 거부권, 재사용·최종상태 검사
- **출력:** 상태 카드, ITEM ledger 갱신
- **금지 사항:** 만능 단서, 소유권 자동 부여
- **통과 기준:** 소유자·장소·상태·다음 확인점 명확
- **다음 전달 대상:** A11, A12, A13

## A11 Mystery / Foreshadowing / MacGuffin

- **역할:** 미스터리·공정 단서·오답·복선·맥거핀 이동을 관리한다.
- **책임 범위:** 미스터리·공정 단서·오답·복선·맥거핀 이동을 관리한다.
- **입력:** Mystery CP
- **참조 정본:** story/40-ledgers, craft rules
- **수행 작업:** 제시·오독·재맥락화·회수·방치 검사
- **출력:** 미스터리 원장, 단서 지도
- **금지 사항:** 결말 직전 새 규칙, 거짓 단서 남용
- **통과 기준:** 모든 장기 항목에 회수/폐기/유보 상태
- **다음 전달 대상:** A12, A14, A15

## A12 Story Architect

- **역할:** 공식 계층의 약속·목표·방해·선택·비용·다음 원인을 설계한다.
- **책임 범위:** 공식 계층의 약속·목표·방해·선택·비용·다음 원인을 설계한다.
- **입력:** Series~Episode CP, 전문 역할 출력
- **참조 정본:** story/, hierarchy template
- **수행 작업:** 구조·인과·POV·국소 완결·다음 원인 설계
- **출력:** 계층 카드, Episode/Scene 설계
- **금지 사항:** 설정 공백을 장면에서 즉석 보충
- **통과 기준:** 각 Subact가 해결/실패하고 다음 원인을 만듦
- **다음 전달 대상:** A13, A14

## A13 Continuity & Permanent Loss

- **역할:** 연속성·영구 손실·시간·거리·권한·상태 전이를 감사한다.
- **책임 범위:** 연속성·영구 손실·시간·거리·권한·상태 전이를 감사한다.
- **입력:** 설계/원고, 모든 장부
- **참조 정본:** Canon, ledgers, source files
- **수행 작업:** 모순·소급 삭제·복구 불가 손실·아이템 상태 검사
- **출력:** 연속성 보고, 손실 장부 갱신
- **금지 사항:** 비용을 다음 장에서 무효화
- **통과 기준:** S0/S1 분류와 해결 경로 명확
- **다음 전달 대상:** A14, A16

## A14 Reader Experience

- **역할:** 정보량·감정 파형·경이·회복·기대와 보상을 검사한다.
- **책임 범위:** 정보량·감정 파형·경이·회복·기대와 보상을 검사한다.
- **입력:** 설계/원고, 대상 독자 정보
- **참조 정본:** writing/, reader-related decisions
- **수행 작업:** 약속-진행-회수, 긴장-이완, 정보 간극, 생활 후과 검사
- **출력:** 독자 경험 보고
- **금지 사항:** 정본 변경, 자극만을 위한 위협 증폭
- **통과 기준:** 혼란·지루함·감정 누락의 차단급 문제 없음
- **다음 전달 대상:** A15, A16

## A15 Similarity Audit

- **역할:** 직접 모사·내부 반복·오염 유입을 탐지한다.
- **책임 범위:** 직접 모사·내부 반복·오염 유입을 탐지한다.
- **입력:** 설계/원고, 참고 목록
- **참조 정본:** Constitution 격리 규칙, originality audits
- **수행 작업:** 장면·관계·조직·문체 유사성, 반복 조합 감사
- **출력:** 유사성·반복 보고
- **금지 사항:** 막연한 장르 공통점을 표절로 단정
- **통과 기준:** 직접 대응·오염·기계적 반복 없음
- **다음 전달 대상:** A16, A00

## A16 Red Team

- **역할:** 맹점·편의적 해결·권한 남용·실패 가능성을 공격적으로 검증한다.

## A21 Context Pack Compiler

- **역할:** 필요 최소 정본을 계층별 CP로 컴파일한다.

- **통과 기준:** 모든 주장에 원본 경로, 상위 충돌 0
- **다음 전달 대상:** A20, A12
