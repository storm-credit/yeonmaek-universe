# Context Pack Protocol

## 성격

Context Pack(CP)은 특정 작업에 필요한 정본과 상태를 최소 범위로 묶은 **실행용 파생물**이다. CP는 정본이 아니며 상위 정본을 수정·승격·대체할 수 없다.

모든 CP는 다음을 기록한다.

- CP ID와 생성일
- 대상 계층과 작업 목적
- 원본 파일 경로·버전·승인 상태
- 발췌 범위
- 미해결 충돌과 S0/S1
- 적용 가능한 작법
- 금지 추론
- 만료/재생성 조건

## CP 종류

### Series CP
전체 약속, 최종 상태, 5 Grand Act, 핵심 세계 규칙, 장기 미스터리, 결말 역산을 담는다.

### Grand Act CP
해당 부의 Promise·State Change, 세 Volume Act, 주요 인물·세력·권역, 부 단위 Reward/Loss를 담는다.

### Volume CP
해당 Act의 목표·중간점·저점·재설계, Arc 래퍼, 세 Subact, 필요한 제도·권한·POV를 담는다.

### Arc CP
세 Subact를 관통하는 국소 변화, 관계·정보 흐름, 중심 작법, Anti-Repeat를 담는다.

### Subact CP
국소 문제, 주도 인물, Goal/Opposition/Choice/Cost, 해결 또는 실패, Next Cause, 대응 Episode를 담는다.

### Episode CP
직전 Episode 결과, 대상 Subact, 장면 목표, 등장인물 정보상한, 장소·아이템 상태, 선택·비용, 장 끝 상태를 담는다.

## 생성 절차

1. A00/A01이 작업 범위를 고정한다.
2. A02가 정본 권한과 충돌을 확인한다.
3. A21이 필요한 원본만 수집한다.
4. 장부에서 현재 상태와 다음 확인점을 붙인다.
5. 누락을 S0/S1/경고로 분류한다.
6. 원본 경로가 없는 문장은 제거하거나 `가설`로 표시한다.
7. 대상 작업 종료 또는 상위 정본 변경 시 CP를 폐기·재생성한다.

## 금지

- CP 문장을 근거로 Canon을 수정
- 출처 경로 없는 설정 추가
- 오래된 CP를 최신 정본처럼 사용
- 여러 계층의 CP를 무제한 합쳐 컨텍스트 과밀 생성
- 원고에서 발견한 편의 설정을 CP에 소급 삽입
