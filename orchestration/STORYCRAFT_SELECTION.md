# Storycraft Selection

## 선택 원칙

- Episode 또는 Subact마다 **중심 작법 1개**와 **보조 작법 최대 2개**만 선택한다.
- 작법은 정본과 인과를 구현하는 수단이며 정본을 바꾸지 못한다.
- 같은 조합을 기계적으로 반복하지 않는다.
- 선택 이유, 기대 효과, 실패 징후, Anti-Repeat를 기록한다.

## 작법 목록과 적용 상황

| 작법 | 주 적용 상황 | 실패 징후 |
|---|---|---|
| 결말 역산 | Grand Act·Series 결말의 원인 배치 | 결말 직전 새 규칙 |
| 약속–진행–회수 | 독자 기대와 장기 보상 | 약속만 크고 중간 진행 없음 |
| 시작–결말 대칭 | 상태 변화 가시화 | 표면 이미지 반복만 존재 |
| 국소 완결과 다음 원인 | Arc·Subact 종료 | 사건이 끝나도 다음 단위가 영향 없음 |
| 시도–실패–학습 변주 | 성장·훈련·탐사 | 같은 실패를 이름만 바꿔 반복 |
| 중간점 목표 재정의 | Volume Act 중앙 | 정보 추가만 있고 목표 불변 |
| 목표–방해–선택–비용 | Scene·Episode 기본 인과 | 선택 없는 사건 나열 |
| 장면–반응 | 충격 뒤 처리와 의사결정 | 사건 연속으로 감정·생활 후과 소실 |
| 가치 변화 | 장면 전후 의미 변화 | 위치만 바뀌고 가치 동일 |
| 긴장–이완 파형 | 독자 피로와 회복 조절 | 지속 고조 또는 지속 정체 |
| 정보 간극과 드라마틱 아이러니 | 미스터리·보조 POV | 독자만 속이기 위한 정보 은폐 |
| 공정 단서 | 추리·오독 | 회수 시 처음 등장한 단서 |
| 오답 설계 | 합리적 오판 | 인물이 바보여야만 성립 |
| 복선 식물–회수–재맥락화 | 장기 미스터리 | 식물 뒤 방치 또는 단순 정답 확인 |
| 맥거핀의 소유권·이동·변질 | 아이템 중심 사건 | 물건이 필요할 때 순간이동 |
| 욕망–필요–거짓 믿음 | 인물 아크 | 외부 승리만 있고 내적 수정 없음 |
| 독립 행동 | 조연·기관·세력 | 주인공 부재 시 모두 정지 |
| 관계 상태 변화 | 팀·가족·경쟁 | 감정 대사 후 행동 관계 불변 |
| 보조 POV | 주인공 부재·정보상한 | 같은 사건 반복 서술 |
| 제한자원 선택 | 구조·재난·협상 | 모두 구하는 무비용 해결 |
| 전술적 공간 변화 | 추적·구조·탐사 | 배경이 고정 무대 |
| 정치·협상·법적 절차 | 기관·공개권·책임 | 한 번의 연설로 절차 해소 |
| 생활 후과와 애도 | 위험·손실 뒤 | 다음 장에서 비용 소멸 |
| 문화·종교의 물질적 기능 | 의례·구휼·교육·재판·금기 | 장식적 명칭과 축제만 존재 |

## 조합 규칙

1. 중심 작법이 해결하려는 구조 문제를 한 문장으로 쓴다.
2. 보조 작법은 중심 작법의 약점을 보완해야 한다.
3. 직전 두 단위와 동일한 3종 조합은 금지한다.
4. 같은 중심 작법이 연속될 경우 Opposition·Choice·Cost 중 최소 두 축이 달라야 한다.
5. 작법 때문에 새 설정이 필요하면 먼저 해당 설정 역할로 되돌아간다.
