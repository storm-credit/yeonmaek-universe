# 부제작 7 상세 설정 바이블 — 결정과 공동관리 v0.1

## 1. 한 문장

졸업을 앞둔 이안이 임시 중앙 조율망의 우선 연결권 만료와 여러 지역의 동시 부담 상승 앞에서 권한을 다시 연장하면 가장 빠르게 안정시킬 수 있다는 사실을 알면서도, 마지막 권한을 지역·기관·당사자·감사 기능에 분산하고 자신만 열 수 있던 고정 접근을 해체해 더 느리지만 거부·정정·책임이 가능한 공동관리 체계로 전환한다.

## 2. 시간·생활 기준선

- 시기: 부제작 6 이후 마지막 학교 해
- 나이: 만 18세 전후
- 학적: 졸업·진로 선택 단계
- 이안 역할: 제한 기간 `전환·감사 연결자`
- 학교:
  - 중앙망과 지역망 사이 교육·기록 전환 지원
  - 교육 기능과 연구·보호·허가 기능 분리 논쟁
- 가족:
  - 졸업·진로·주거·일상 선택이 사건과 함께 존재
- 친구:
  - 하람·도겸·유나가 동일 진로나 조직을 선택하지 않음
  - 협력은 우정의 자동 결과가 아니라 역할별 계약과 신뢰

## 3. 중심 질문

> 더 빠른 독점 결정권을 포기한 뒤에도, 주인공은 어떻게 책임을 회피하지 않고 세계에 참여할 수 있는가?

## 4. 시작 상태

- 중앙 조율망은 부제작 6에서 실제 피해를 줄였고 시민·기관 지지를 얻음
- 이안의 우선 연결권은 임시지만 여러 현장의 빠른 조정이 그에게 의존
- 지역·당사자·독립 감사에게 돌림패 조각이 분산됐으나 요청 순서는 이안이 연결
- 숨돌층·수용처·시설·관계 복구가 아직 진행 중
- 제한 공개와 공동 원장 후보가 있지만 법·기관·지역별 상태가 다름
- 졸업 뒤 이안에게 중앙 조정기관의 엘리트 진로가 제안됨

## 5. 최종 사건의 인과

### 임시 중앙망 전환

부제작 6의 긴급 체계를 영구화할지 분산 관리로 이전할지 시험하는 전환 기간이 시작된다.

중앙망은 여러 지역을 같은 상태 시각에 맞춰 안정시켰다. 이 동기화가 풀릴 때 각 지역은 자기 조건으로 돌아가야 한다. 그러나 다음이 동시에 겹친다.

- 서안 통학 회랑의 계절 재검증
- 학교 삼면계단·온실 구역의 구조·생활 전환
- 갈림물목의 지역판 상태 전환
- 수문겹길의 협력 조건 재협상
- 숨돌층 완충로의 수용처·복구 한계

모든 장소가 같은 원인으로 무너지는 것은 아니다. 중앙망에 맞춰 미뤄 둔 서로 다른 결정들이 비슷한 시기에 돌아온다.

## 6. 세 시간 제한

### 시계 A — 우선 연결권 만료

- 만료되면 이안의 제한 기록·경로·유물 요청 우선순위 종료
- 연장하면 즉시 대응 속도 유지
- 자동 연장은 긴급 예외를 상설 권한으로 만듦

### 시계 B — 지역별 상태 창

- 각 장소의 계절·시설·관계 조건이 서로 다른 시간에 바뀜
- 중앙 화면은 하나의 공통 시각으로 단순화하려 함
- 지역은 서로 다른 중지·부분 재개·보호 폐쇄 결정을 요구

### 시계 C — 수용처 복구 한계

- 중앙망을 다시 강하게 사용하면 현재 위험은 줄지만 숨돌층과 기존 수용처 복구가 늦어짐
- 사용을 즉시 중단하면 일부 서비스·교통·교육 활동 축소 필요

졸업식 날짜는 현장 판단 시한이 아니다. 감정적 생활 축으로만 작동한다.

## 7. 최종 선택 4안의 현장 형태

### 안 1 — 중앙권 연장

- 이안의 우선 연결권·돌림패 요청권 연장
- 가장 빠르고 일관된 안정 가능
- 지역 거부·보호 폐쇄·감사 지연

### 안 2 — 즉시 해체

- 중앙망 중단·모든 권한 지역 반환
- 독점 위험 제거
- 전환 준비가 부족해 실제 피해 가능

### 안 3 — 명목 분산·비상 예외 유지

- 평시 분산, 위기 시 이안에게 자동 복귀
- 정치적으로 쉬움
- 사실상 주인공이 최종 열쇠로 남음

### 안 4 — 단계 분산·비상 기능 분해

- 관측·경보·중지·시설·당사자 거부·공개·감사를 서로 다른 주체에 분리
- 자동 복귀 대신 복수 승인과 지역별 중지 기준
- 이안의 마지막 우선권을 `권한 분배·기록 고정·만료 실행`에만 사용

1순위는 안 4다. 안 3은 금지되는 가짜 포기다.

| 중앙 조율 책임자 | 검증된 안전 체계와 단일 책임 유지 | 실제 성과 | 권한 만료를 위험한 정치적 실험으로 봄 |
| 지역 시설·공동체 | 자기 조건·서비스·복구·보상 | 직접 책임 | 다른 지역의 동시 부담을 충분히 보지 못함 |

| 독립 감사 | 위임·부담·공개·수용처 추적 | 권한 남용 방지 | 실시간 지휘권 없음 |
| 국제 조정망 | 최소 경보·구조·호환 유지 | 국경 간 안전 | 지역 원문과 결정권을 최소 코드로 축약할 위험 |

## 9. 인물별 최종 기능

### 이안

- 마지막 권한을 사용해 자신에게 권한을 연장하지 않음
- 돌림패 요청 순서·기록 우선권·단독 경로 접근을 분해
- 이후 관측·중재·기록·감사 역량은 유지
- 졸업 후 복수 진로 중 하나를 선택할 수 있으나 최종 기관장은 아님

### 하람

중앙 표준을 버리지 않는다. 대신 경보·시설·감사 최소 기준을 맡고 지역 결정과 구분한다.

### 도겸

모든 당사자를 대표하지 않는다. 거부·자기명칭·비공개·관계 철회 절차의 설계와 지역 연결에 참여한다.

### 유나

공동 원장이 기관 전용 문서가 되지 않게 시민·피해자·자료 권리 접근을 설계한다. 이안의 개인 기록 관리자가 되지 않는다.

### 지현

아들의 권한 포기를 슬픈 희생으로만 보지 않고 졸업·진로·생활 선택으로 연결한다. 모든 책임을 가족이 떠안지 않는다.

### 세린

학교 학생의 영웅 동원을 끝내고 졸업 후 견습·현실 전문자격·일반 진로를 분리한다.

### 현지·지역 인물

각 지역에서 자기 현장을 직접 결정한다. 최종부에 모두 한국으로 집결하지 않는다.

## 10. 현장 구성 — 네 기능 현장

과밀 방지를 위해 실제 장면 중심은 네 기능 현장으로 제한한다.

### 현장 K1 — 서안 통학 회랑

- 감정적 시작점
- 여울띠 재검증과 사람 통학·보호 폐쇄
- 중앙 연장은 빠른 고정 경로 제공
- 지역 결정은 일부 우회 통학과 다음 계절 재검증을 선택

### 현장 K2 — 학교 삼면계단·온실

- 학교생활·학생·교직원·모서리잠·온기고리 관계
- 세린과 학생들이 멈춤종·대체 동선으로 활동 중지
- 졸업 행사·경기·수업 일부 취소 비용
- 학교가 현장 지휘 본부가 아니라 자기 구역 책임자로 행동

### 현장 D1 — 갈림물목

- 지역판이 중앙 공통 시각을 거부
- 현재 이동 일부를 중지하고 지역 상태 전환을 기다림
- 중앙 화면에는 지연으로 보이지만 지역 기준에서는 안전 선택
- 현지 주체가 최종 결정

### 현장 O1 — 수문겹길

- 국제 최소 경보 유지
- 현지 통역·수문·당사자 대표가 단계 운영 결정
- 한국팀은 연락·기록·학생 책임만 수행
- 문답결 자기명칭·위치 비공개 유지

### 숨돌층

별도 다섯 번째 주인공 현장으로 만들지 않는다. 시설 책임자와 지역팀의 기록·연락 결과로 진행한다.

- 추가 숨돌 채취 거부
- 일부 시설 서비스 축소
- 기존 수용처 복구 우선
- 중앙 성공을 완전히 포기하지 않고 최소 경보 기능 유지

## 11. 수집 회수

### 생물·관계

- 여울띠: 다음 계절 재검증, 동일 개체 확정 금지
- 온기고리: 학생과 영구 동행하지 않음, 활동별 새 협상
- 모서리잠: 학교 시설 공동관리
- 물갈피·뒤집잎: 지역 상태판 유지
- 문답결·빗마디: 현지 자기명칭·원문·비공개
- 소리주머니·마른물결: 공개층·도시 관리
- 숨돌·빛바느질: 채취 제한·복구·보이지 않는 부담

### 유물

- 돌림패: 경보·시설·당사자·감사·지역 조각으로 재분산
- 잔기록판: 공동 원장 감사에 제한 사용
- 멈춤종: 지역별 중지 신호로 사용, 강제 정지 아님
- 비움매듭: 신규 부담 이동보다 기존 수용처 회수·복구 우선
- 반납열쇠: 공동 보관 관계 재확인
- 숨은추: 중앙 총계가 아닌 지역 기준 비교용으로 제한

### 영웅 기록

영웅 목록의 최종 진실을 확정하지 않는다.

- 윤서후: 철수와 과잉동원
- 민서림: 열지 않은 길
- 장리원: 빈칸과 중앙 편집권
- 임해솔: 공개와 비공개 권리
- 백도원: 중앙 성공과 남은 부담
- 세 차례 철회한 대표·판본 사이 통역자: 국제 결정권

현재 인물들이 새 단일 영웅 목록을 만들지 않고 정정·이견·누락 필드를 유지한다.

## 12. 공동 부담 원장

### 공개층

- 사고 사실
- 사람·시설 피해
- 통제·복구·보상 책임
- 권한 위임·만료·감사 상태
- 지역별 공개 연락처와 이의 절차

### 제한층

- 민감 서식·이동 위치
- 미성년·의료·수사 기록
- 당사자 자기명칭·원문·기억·사체 정보
- 보호폐쇄 정확한 좌표

### 운영 원칙

- 한 기관이 작성·수정·감사·공개를 독점하지 않음
- 지역판 원문 유지
- 정정·철회·이견이 기능으로 존재
- 빈칸 이유와 결정 주체를 표시

## 13. 사건 단계

### 1막 — 졸업과 만료

- 학교·가족·친구의 평범한 마지막 해
- 이안에게 중앙 진로 제안
- 각 지역 전환 시험 시작
- 첫 작은 지연과 성공으로 분산 체계 가능성 제시

### 2막 전반 — 다른 속도의 결정

- 지역별 중지·부분 재개·보호 폐쇄가 서로 다른 결과
- 중앙망보다 느리지만 일부 숨은 부담을 먼저 발견
- 중앙 지지자들은 지연 비용을 지적
- 이안은 연결·중재 역할로 계속 중심에 남음

### 중간점 — 중앙 연장이 실제로 더 안전해 보임

- 복수 지역의 상태 변화가 겹치고 연락 지연
- 중앙망 시험 연장이 한 구역의 즉시 위험을 빠르게 안정
- 이안이 우선권을 연장하면 전체 조정이 가능하다는 근거 확립
- 선택이 선악이 아니라 책임·권한 구조가 됨

### 2막 후반 — 분산의 실패와 학습

- 일부 지역 노드는 결정 지연·기록 호환 실패
- 지역끼리도 부담 수용과 공개 범위를 두고 충돌
- 이안 없이 움직이는 연습이 부족했음이 드러남
- 중앙 자동 연장안이 지지를 얻음

### 저점

이안은 자신이 권한을 내려놓는 순간 다른 사람이 다칠 수 있다는 두려움과, 계속 보유하면 모든 관계가 자신을 통과하게 된다는 사실 사이에 놓인다.

### 클라이맥스 1 — 마지막 중앙 사용

이안은 중앙망을 사용하지 않는 순수한 선택을 하지 않는다.

- 현재 인원·시설 위험 경보를 한 번 통합
- 각 현장에 최소 정보·자원·중지 기준 전달
- 돌림패 조각과 기록 접근을 기능별 주체에게 이전
- 자동 연장과 자신에게 돌아오는 비상 예외를 제거
- 권한 만료 실행을 감사 기록으로 고정

### 클라이맥스 2 — 분산 행동

- 서안: 지역·시설·가족이 우회 통학과 보호 폐쇄 결정
- 학교: 학생 철수·행사 취소·시설 보수, 학교는 자기 책임만 수행
- 갈림물목: 지역 상태판에 따라 현재 이동 중지
- 수문겹길: 현지 단계 운영·국제 경보 최소 유지
- 숨돌층: 시설 축소·추가 채취 거부·복구 우선

모든 현장이 완벽히 성공하지 않는다. 지연·비용·불편·일부 손상은 남지만 독점 예외 없이 현재 위기를 끝낸다.

### 결말 — 제도

- 숨은 생태의 존재·피해·책임·권리를 단계적으로 사회 인정
- 위험 위치·미성년·수사·당사자 통제 정보는 제한
- 회랑은 국가·학교·기업 소유가 아닌 공동관리
- 공동 부담 원장과 독립 감사 도입
- 학교의 교육 기능과 연구·보호·허가 기능 분리
- 국제 조정망을 당사자 참여형 경보·검역·구조·중재망으로 개편
- 지역별 다른 관리 체계 유지

### 결말 — 개인

- 이안은 혼자 열던 경로·우선 해독·최종 요청권을 상실
- 가족·친구·학교·생태와의 관계 가능성은 유지
- 졸업·일반 진로·견습·감사·중재 중 선택 가능
- 첫 통학로를 다시 지날 때 예전처럼 혼자 깊이를 열 수 없음
- 필요하면 지역 연락·당사자 승인·공동 절차를 기다려야 함
- 이는 추방이나 감각 상실이 아니라 관계 방식의 변화

## 14. 독립 완결

- 임시 중앙망 만료·전환 문제 해결
- 복수 현장 현재 위험 종료
- 권한 분산과 최소 경보 기능 유지
- 학교·국제망·공동 원장 구조 개편
- 졸업·가족·친구·진로 감정 회수

## 15. 남겨 두는 빈칸

P-17의 정확한 위치·내용·당사자 자기명칭은 공개하지 않는다.

대신 다음은 확정한다.

- 비공개를 결정한 주체가 복수임
- 독립 감사가 존재함
- 정기 재검토와 이의 절차가 있음
- 이안도 자동 접근권을 갖지 않음

이는 후속작 떡밥이 아니라 `알 권리와 비공개의 공존`을 보여 주는 완결 상태다.

## 16. 에필로그 생활 상태

- 학교 졸업
- 친구들은 다른 학교·지역·진로로 갈 수 있음
- 가족 식사·통학·일반 사회의 시간 유지
- 학교는 여전히 사랑받는 장소지만 세계의 중앙 본부가 아님
- 다음 세대 학생은 이안의 영웅 신화를 배우는 대신 공적·비용·이견·누락 당사자를 함께 봄
- 독자용 도감·지도는 완성률이 아니라 정정·보호 폐쇄·관계 상태를 보여 줌

## 17. 하드 가드레일

1. 모든 지역과 인물이 한국 학교에 집결하지 않는다.
2. 최종 악당·봉인·예언·혈통 결전으로 수렴하지 않는다.
3. 중앙 장치를 파괴해 갈등을 해결하지 않는다.
4. 이안이 명목상 포기 후 비상 최종열쇠를 보유하지 않는다.
5. 권한 포기가 책임 회피나 자기희생 미화가 되지 않는다.
6. 학교·기관·공동체도 과거 책임과 특권을 내려놓는다.
7. 모든 비밀·지도·자기명칭을 공개하지 않는다.
8. 공동관리를 갈등 없는 이상사회로 묘사하지 않는다.
9. 지연·비용·불편·보호 폐쇄를 실제 대가로 남긴다.
10. 후속 외전에서 이안의 독점권을 복구하지 않는다.
11. 졸업 뒤 학교 의무복무를 강제하지 않는다.
12. 첫 통학로·가족·유나·학교 관계의 생활 결말을 제도 결말보다 작게 다루지 않는다.
