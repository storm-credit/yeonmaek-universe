# 부제작 4 상세 설정 바이블 — 번역과 국경 v0.1

## 1. 한 문장

금강하구에서 만든 판본 연결 방식 때문에 첫 해외 공동활동에 참여한 이안이, 방콕–차오프라야 합성 도시 수계에서 문답결과 빗마디를 국제 위험 코드로 오분류한 검역 조치와 수문 운영 시한 사이에 놓여, 불완전 번역으로 현장에 기여하되 자신의 접근권이 현지 최종 결정권이 되는 순간에는 물러난다.

## 2. 지역 사용 원칙

- 방콕–차오프라야 도시 수계의 강·운하·도로·수상 이동·배수·주거·기관 기록 기능을 조사
- 실제 운하·수문·주거 취약 지역·민감 시설을 1:1로 사용하지 않음
- 태국 전체나 방콕 문화를 하나의 판타지 체계로 일반화하지 않음
- 불교·정령 신앙·왕실·현존 의례를 생물·유물·마법으로 전용하지 않음
- 실제 홍수·불평등·주거·노동 문제를 심층 생태의 숨은 원인으로 대체하지 않음
- 태국어 원문·자기명칭·현지 기관·인물 이름은 현지 감수 전 provisional

## 3. 시간·생활 기준선

- 시기: 부제작 3 이후, 첫 본격 해외 공동활동
- 나이: 만 15~16세
- 기간 후보: 이동·사전교육·현장·귀환 포함 10~14일
- 한국 학교 책임:
  - 학적·출결·보험·통역·의료·철수
  - 보호자 설명·동의·매일 연락
  - 한국 학생 기록 사용 범위
- 현지 책임:
  - 수문·교통·구조·시설·지역 공개·당사자 관계 최종 결정
- 학생 역할:
  - 기록 대조·불확실성 표시·통역 보조·철수
  - 수문 조작·대피·검역·의료·수사 지휘 금지

## 4. 중심 질문

> 번역되지 않는 기록과 긴급한 안전 사이에서 누가 결정하며, 어떤 불완전함을 남겨야 하는가?

## 5. 시작 상태

- 이안은 단일 지도로 합치는 오류를 배웠고 복수 판본 병존을 지지
- 한국 학교의 호환표는 지역 간 최소 경보·기록 연결에 실제 성과를 냄
- 국제 조정망은 금강하구 사례를 모범으로 보고 한국 학생팀을 초청
- 이안에게 제한 기록 접근 우선권이 주어지며 본인이 예상하지 못한 제도적 권력이 생김

## 6. 중심 사건

### 국제 검역과 수문겹길

현지 여러 기록에서 문답결 배열과 빗마디 변화가 관측된다. 국제 최소 코드 변환 과정에서 다음이 하나의 고위험 항목으로 합쳐진다.

- 빗마디 군체의 압력 상태 변화
- 문답결의 접근 철회 배열
- 민감 이동 위치 비공개 표시
- 현지 시설의 제한 운영 경고

국제 검역팀은 생태 오염·무단 이동 가능성을 이유로 격리와 수문겹길 차단을 제안한다. 차단은 일부 현실 안전을 높이지만 현지 운영 창을 놓치고 부담을 다른 구역에 집중시킬 수 있다.

## 7. 두 시간 제한

### 시계 A — 검역 이송·차단

- 국제 위험 코드가 확정되면 표준 격리 절차가 자동 시작
- 생물·자료·학생 접근 권한이 중앙 검역 체계로 이동
- 현지 이의 신청에는 번역·근거 시간이 필요

### 시계 B — 수문 운영 창

- 수위·기압·도시 이동·시설 점검이 겹치는 제한 운영 시간
- 창을 놓치면 다음 시기까지 시설 부담과 생활 우회가 증가
- 운영을 강행하면 문답결 이동·빗마디 군체 손상 가능

정확한 시간·시설 기술은 현지·시설 감수 전 미정이다.

## 8. 현지 인물 기능

최종 이름·배경은 현지 감수 전 확정하지 않는다.

| 기능 | 욕망 | 독립 행동 | 한국팀과의 관계 |
|---|---|---|---|
| 현지 학생·견습 기록자 | 자기 도시의 기록이 국제 코드에서 사라지지 않게 함 | 원문·생활 기록 공유 범위를 직접 결정 | 이안의 조수 아님, 동등한 기록자 |
| 현지 수문 운영 책임자 | 사람·시설 안전과 운영 창 유지 | 단계 운영·중지·부분 재개 결정 | 한국 기록을 입력으로만 사용 |
| 현지 통역·중재자 | 긴급 구조에 필요한 번역과 번역되지 않을 권리 조정 | 번역 불가·자기명칭·철회 필드 표시 | 이안 접근권을 제한할 수 있음 |
| 지역 생활 연락자 | 주민 이동·노동·통행·공개 피해 최소화 | 대체 동선·정보 공개 범위 협의 | 학교 관광 시선을 견제 |
| 현지 생태·권리 담당 | 문답결·빗마디의 거부·위치·대표 절차 보호 | 격리 이의와 관찰 중지 요구 | 국제 코드와 충돌 |
| 국제 검역 책임자 | 여러 국가에서 통하는 빠른 안전 절차 | 표준 격리·차단 발령 | 악당이 아니라 실제 책임자 |
| 한국 학교 책임자 | 학생 안전·철수·기록 책임 | 접근 범위 축소·귀국 결정 | 현지 현장권한을 대신하지 않음 |

## 9. 기존 인물 변화

### 이안

- 시작: 불확실성을 표시하면 권력 남용을 줄일 수 있음
- 오신념: 자신은 번역자가 아니라 연결자이므로 중립적임
- 중간: 이안의 호환 접근권이 어떤 기록을 먼저 보이게 할지 결정한다는 사실 확인
- 저점: 빠른 코드 수정이 표면 인력 대피에는 성공했지만 문답결의 비공개 표시를 위험 코드로 남김
- 클라이맥스: 자신의 우선 접근·설명 권한을 현지 기록자와 통역자에게 넘기고, 모르는 항목을 삭제하지 않은 최소 경보안만 제출
- 종료: 연결 기술도 국제 권력이며 현지 최종 결정과 분리해야 함을 인정

### 하람

국제 최소 절차의 실제 구조 효용을 지키면서도 자동 격리와 예외 이의 절차를 분리한다.

### 도겸

문답결의 배열을 인간 문장으로 확정하지 않고 행동 조건만 기록한다. 현지 통역자 없이 대표 역할을 하지 않는다.

### 유나·지현

- 유나는 한국에서 공개된 학교 홍보와 현지 보도·학생 기록의 차이를 확인
- 지현은 해외 활동 동의가 국제 기록 접근권까지 포함한 것이 아니라고 이의 제기
- 가족 정보 수준이 되돌아가지 않음

## 10. 수집 배정

### 중심 당사자

- 문답결

### 보조 생태

- 빗마디

### 중심 기록

- 현지 원문·지역 호칭·국제 코드의 다중 판본
- 기록명 `세 차례 철회한 대표`
- 기록명 `판본 사이의 통역자`

### 보조 도구

- 겹눈틀 원리의 국제 적용
- 현지 도구는 문화·기술 감수 전 구체화하지 않음

### 지도

- 수문겹길: 한국판·국제판·현지판 공개 범위 병존

## 11. 합리적 오해

1. 빗마디 수 감소=군체 소멸 또는 오염
2. 문답결 배열 중단=적대·통신 거부
3. 위치 비공개=검역 회피
4. 국제 코드가 더 단순하므로 긴급 상황에서 더 객관적
5. 한국 판본 병기 방식이 현지에서도 중립적

각 오해는 일부 사실을 설명하지만 다른 당사자·권한·관찰 범위를 누락한다.

## 12. 사건 단계

### 1막 — 초대와 효율

- 한국 학교의 호환 기록 방식이 국제 구조 교육에서 인정
- 현지 팀은 이미 여러 판본으로 대응 중
- 학생 교류·도시 생활·언어 차이를 사건 도구가 아닌 생활로 경험
- 한국 모듈이 표면 작업자 안전 통제에 실제 도움

### 2막 전반 — 표준의 성공

- 최소 코드로 여러 기관 연락 속도 개선
- 일부 위험 구역 통제와 인력 대피 성공
- 이안의 접근 우선권 확대
- 국제 검역팀의 격리안이 합리적으로 보임

### 중간점 — 비공개가 위험으로 번역됨

- 문답결 배열의 일부가 ‘이동 위치 공개 거부’일 가능성
- 빗마디 변화는 생태 오염보다 시설·기압·운영 조건의 조합
- 국제 코드가 두 기록을 한 위험종 사건으로 합침

### 2막 후반 — 기다림도 위험

- 완전 번역을 기다리면 수문 운영 창을 놓침
- 자동 격리를 진행하면 이동·서식·지역 운영에 비가역 영향
- 현지 내부도 즉시 운영·부분 운영·격리 지지로 나뉨
- 한국 학생 안전과 철수 시각 접근

### 저점

이안이 만든 수정 코드가 사람 안전에는 성공했지만 현지 당사자의 비공개·대표 범위를 다시 축약한다. 선의의 연결도 누군가의 말을 대신할 수 있음.

### 클라이맥스

- 이안은 자신이 가진 제한 기록 우선권을 현지 기록·통역 책임자에게 이양
- 국제 경보에는 확정된 사람·시설 위험과 미확인 생태 조건만 남김
- 현지 수문 책임자가 단계 운영·중지·대체 동선을 결정
- 문답결은 제시된 복수 경로를 배열 변화·거리 두기·철회로 시험
- 빗마디 군체는 채취하지 않고 현지 관찰로 상태 갱신
- 검역팀은 전면 격리 대신 제한 관찰·재검증으로 전환

### 결말

- 현재 시설·이동 문제는 단계 운영과 지역 관리로 종료
- 문답결 위치·자기명칭은 보호
- 국제 판본 충돌이 공식 사고 기록으로 남음
- 현지 당사자는 국제 협력 조건 일부를 철회·재협상
- 한국 학교의 도감 호환 모듈과 학생 접근권 조사 시작
- 한국 귀환 뒤 강화 통제의 원인이 됨

## 13. 독립 완결

- 격리·운영 딜레마: 현지 단계 운영과 제한 검역으로 해결
- 문답결·빗마디: 포획·강제 번역 없이 현지 관리
- 학생 활동: 철수·귀환·학업 복귀
- 감정: 이안이 중립적 연결자라는 자기상을 버림

## 14. 비가역 전환

- 국제 사고 공식화
- 한국 학교 접근권·기록 모듈 조사
- 현지 협력 조건 변경
- 가족·현실 친구·기관 정보 수준 상승
- 국제 조정망 내부의 중앙화·지역권 논쟁 공개

## 15. 장기 미확인 1개

과거 협정의 누락 서명칸이 문답결과 같은 당사자 형식을 가졌는지 여부. 동일 집단·종이라고 확정하지 않는다.

## 16. 하드 가드레일

1. 한국 학생이 태국 현장 최종 해결자가 되지 않는다.
2. 방콕을 태국 전체로 일반화하지 않는다.
3. 현존 신앙·왕실·의례를 판타지 설정으로 직접 사용하지 않는다.
4. 실제 홍수·주거 취약성의 원인을 생물로 대체하지 않는다.
5. 국제 검역 책임자를 무능·악당으로 단순화하지 않는다.
6. 현지 인물을 통역·안내 역할만 하는 조력자로 만들지 않는다.
7. 문답결의 의미를 이안이 완전 번역하지 않는다.
8. 긴급 구조를 기다림만이 옳다는 교훈으로 만들지 않는다.
9. 구체 태국어·기관·운하·말투는 현지 감수 전 확정하지 않는다.
10. 관광 목록·이국적 음식·사원 묘사가 사건 인과 없이 전면화되지 않는다.
