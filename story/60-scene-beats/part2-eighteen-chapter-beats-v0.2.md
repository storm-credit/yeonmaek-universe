# 제2부 《멈춘 팀이 이기는 날》 18장 씬 비트 v0.2

상태: 원고 아님. 학교 경기·중지권·팀 책임 장면 설계.

## 1장 — 대표 경기 공고
1. 학교가 귀환 규칙을 시험하는 대표 경기를 발표한다.
2. 재원은 우승을, 서후는 사고 없는 완주를 목표로 한다.
3. 나린은 참가가 일상과 가족 약속에 미칠 영향을 계산한다.
4. 팀은 조건부 참가를 결정한다.
- 훅: 경기 규칙에 ‘중지 선언은 실격’ 조항이 있다.

## 2장 — 실격 조항
1. 이솔이 과거 규정 개정 기록을 조사한다.
2. 중지권이 사고 이후 삭제됐음을 발견한다.
3. 오현정은 규정 안에서 학생을 보호할 방법을 찾는다.
4. 서후는 규정 변경 전에도 출전하겠다고 주장한다.
- 오판: 현장에서 잘 판단하면 규정은 중요하지 않다고 본다.
- 훅: 예선 구간이 실제 숨은 길과 연결된다.

## 3장 — 연습장의 다른 바닥
1. 도겸이 연습장 바닥의 공간 겹침을 확인한다.
2. 모아는 경기 장치가 생태 신호를 덮는다고 경고한다.
3. 재원은 기록 단축 가능성을 본다.
4. 팀은 속도와 관찰 역할을 분리한다.
- 훅: 첫 연습에서 중지 신호가 울리지 않는다.

## 4장 — 울리지 않는 신호
1. 서후가 수동으로 경기를 멈춘다.
2. 다른 팀은 기록 방해라며 항의한다.
3. 교사는 장치 오류를 인정하지만 결과를 취소하지 않는다.
4. 재원은 팀 평판 손실을 서후 탓으로 돌린다.
- 비용: 팀 내부 신뢰 하락.
- 훅: 오류가 특정 학생이 지나갈 때만 발생한다.

## 5장 — 특정 학생
1. 나린이 생활 기록과 경기 동선을 비교한다.
2. 오류 대상 학생이 최근 귀가 경로 사고를 겪었음을 찾는다.
3. 이솔은 개인정보 공개 없이 위험 조건을 표현하는 방법을 제안한다.
4. 팀은 개인이 아닌 조건 중심 경고 체계를 만든다.
- 훅: 학교 운영진은 조건 공개도 경기 공정성을 해친다고 본다.

## 6장 — 공정성 회의
1. 학생·교사·운영기관·보호자가 회의한다.
2. 재원은 모든 팀에 같은 규칙이 필요하다고 주장한다.
3. 서후는 같은 규칙이 다른 위험을 만든다고 반박한다.
4. 임시 중지권 시범 적용이 승인된다.
- 훅: 중지 선언 횟수에 제한이 붙는다.

## 7장 — 세 번만 멈출 수 있다
1. 팀이 제한된 중지권을 언제 쓸지 훈련한다.
2. 도겸은 공간 판단, 모아는 생태 판단을 맡는다.
3. 나린은 경기 외 현실 손실을 체크한다.
4. 첫 중지는 성공하지만 불필요했다는 평가를 받는다.
- 감정: 안도 → 판단 불신
- 훅: 실제 위험은 중지권을 두 번 쓴 뒤 나타난다.

## 8장 — 남은 한 번
1. 팀은 마지막 중지권을 아낄지 논쟁한다.
2. 재원은 속도로 위험 구간을 통과하자고 한다.
3. 모아는 생태 거부를 확인한다.
4. 서후는 마지막 중지권을 사용한다.
- 비용: 예선 기록 최하위.
- 훅: 멈춘 덕분에 다른 팀의 장비 결함이 드러난다.

## 9장 — 꼴찌의 증거
1. 장비 결함이 전체 경기장의 문제임이 밝혀진다.
2. 운영진은 예선을 재개하려 한다.
3. 학생들은 중지권 확대를 요구한다.
4. 서후 팀은 우승 기회보다 공동 규칙 개선을 택한다.
- 중간 전환: 경기 승리에서 경기 구조 변경으로 목표 확대.
- 훅: 학교 축제 일정 때문에 재설계 시간이 부족하다.

## 10장 — 축제와 경기
1. 경기와 축제가 같은 동선을 공유한다.
2. 나린이 일반 학생·가족 관람객의 위험을 제기한다.
3. 이솔은 공개 안내와 숨은 경로 보호가 충돌함을 지적한다.
4. 팀은 관람객용 별도 귀환선을 설계한다.
- 훅: 별도 귀환선이 경기 점수 계산에 포함된다.

## 11장 — 점수가 된 안전
1. 운영진이 귀환선 설계를 점수화한다.
2. 재원은 안전마저 승부가 된다고 반발한다.
3. 서후는 점수보다 실제 사용 가능성을 시험하자고 한다.
4. 무작위 사용자 검증이 도입된다.
- 훅: 검증 대상에 서후의 보호자가 포함된다.

## 12장 — 보호자의 검증
1. 윤미정이 학생 설계 경로를 직접 사용한다.
2. 학생 관점에서는 보이지 않던 안내 부족이 드러난다.
3. 나린이 생활 언어로 안내를 다시 쓴다.
4. 서후는 가족을 시험 대상처럼 대했다는 사실을 반성한다.
- 훅: 수정된 안내가 경기 장치와 충돌한다.

## 13장 — 장치와 사람
1. 자동 장치가 예외 안내를 오류로 삭제한다.
2. 도겸은 수동 표식과 자동 장치를 병행하자고 제안한다.
3. 이솔은 삭제 이력을 보존한다.
4. 운영진은 관리 부담을 이유로 반대한다.
- 선택: 효율보다 추적 가능한 이중 체계를 요구한다.
- 훅: 결승 당일 자동 장치가 전체 초기화된다.

## 14장 — 초기화된 결승
1. 팀들은 아무 표식 없는 경기장에 들어선다.
2. 재원은 빠른 선두 확보를 선택한다.
3. 서후 팀은 다른 팀과 역할을 나눈다.
4. 첫 위험 신호가 나타나지만 공식 중지 장치가 없다.
- 훅: 중지 선언을 누가 책임질지 아무도 정하지 못한다.

## 15장 — 실격을 선택한 팀
1. 서후가 공개적으로 경기 중지를 선언한다.
2. 팀 전원이 동의해야 효력이 있다는 조건이 드러난다.
3. 재원이 마지막으로 동의하며 우승 가능성을 포기한다.
4. 경기장은 정지되고 관람객은 별도 귀환선으로 이동한다.
- 비용: 공식 실격.
- 훅: 중지 원인이 실제 사고가 아니라 조작일 가능성이 제기된다.

## 16장 — 조작의 목적
1. 이솔이 초기화 기록을 추적한다.
2. 조작자는 악당이 아니라 중지권의 허점을 증명하려던 선배였음이 드러난다.
3. 선배의 방식이 사람을 위험에 빠뜨렸음을 논쟁한다.
4. 학생들은 목적과 책임을 분리해 평가한다.
- 훅: 운영기관이 사건 은폐를 제안한다.

## 17장 — 기록할 패배
1. 학교는 축제 평판을 위해 축소 보고를 원한다.
2. 나린은 피해 학생의 생활 손실을 기록에 포함하자고 한다.
3. 재원은 실격 기록을 유지하되 판단 근거도 공개하자고 한다.
4. 공동 보고서가 작성된다.
- 감정: 수치 → 책임 있는 자부심
- 훅: 보고서가 다른 지역 학교의 요청을 불러온다.

## 18장 — 멈춘 팀이 남긴 규칙
1. 경기 규정에 학생 중지권·성인 책임 인수·기록 보존 조항이 추가된다.
2. 우승팀보다 서후 팀의 보고서가 교육 자료가 된다.
3. 각 인물은 멈춤을 다른 의미로 받아들인다.
4. 다른 지역에서 같은 규칙을 적용해달라는 교환 탐사 요청이 온다.
- 결말: 멈춤은 패배가 아니라 공동 판단으로 제도화된다.
- 다음 부 훅: 요청 지역은 자신들의 이름과 규칙을 외부에 넘기길 거부한다.
