# 복선·회수·연표 통합 원장 v0.1

상태: P1 후보. 구체 고유명사·연도·나이는 미확정이다.

## 장기 복선 원칙

- 복선은 숨겨진 정답 하나가 아니라 초기의 작은 규칙이 후반의 책임 선택으로 확장되는 구조다.
- 각 복선은 최소한 생활·세계 규칙·관계 중 둘 이상에 영향을 준다.
- 회수는 정보 공개만으로 끝내지 않고 인물의 행동과 제도 변화로 확인한다.

| ID | 초기 제시 | 중간 변형 | 최종 회수 |
|---|---|---|---|
| F-01 | 귀가 길이 사람마다 조금 다름 | 하나의 안전 경로가 타인의 선택을 막음 | 다중 귀환선·지역별 선택권으로 전환 |

| F-03 | 생활 친구가 공개 범위를 묻음 | 온라인 공개가 생태·주민 노출을 부름 | 사실·위치·접근권의 공개층 분리 |
| F-04 | 경기의 중지 신호가 불명예로 취급됨 | 실제 탐사에서 중지 지연이 부담을 다른 지역에 전가 | 중지 판단을 공식 성과와 책임으로 인정 |
| F-05 | 같은 생물이 지역마다 다른 이름을 가짐 | 표준명이 안전을 돕지만 지역 관계를 삭제 | 호환 가능한 여러 이름·판본 유지 |
| F-06 | 빈칸은 미완성으로 평가됨 | 과거 비공개 선택이 은폐와 보호를 동시에 포함 | 빈칸의 이유·기간·이의 절차 기록 |
| F-07 | 주인공이 모두를 집으로 돌려보내려 함 | 귀환 설계가 중앙 의존과 통제로 변함 | 권한 이양·후배 교육·분산 귀환 체계 |
| F-08 | 성인 기관이 서로 다른 장부를 사용 | 사고 때 책임 회피처럼 보이나 실제 보호 대상이 다름 | 공통 최소 필드와 독립 감사 도입 |
| F-09 | 현장 멘토가 기록을 꺼림 | 기록 부재가 권리 보호와 오류 방치를 함께 만듦 | 기록 거부권과 안전 필수 기록의 경계 확립 |
| F-10 | 빈자리새가 사람이 떠난 장소에 남음 | 철거·폐쇄가 생태와 기억을 함께 이동시킴 | 장소를 보존하는 대신 기능·기억·서식처를 나눠 이전 |

## 주인공 성장 연표

정확한 나이와 학년은 미정이며 상대 단계만 사용한다.

1. 시작 전: 평범한 생활과 귀환에 강한 집착.
2. 초기: 이상 관찰, 가족·친구에게 설명할 언어 부족.
3. 학교 진입: 팀 역할과 중지권 학습.
4. 지역 교환: 외부 해결자의 한계와 보조 역할 학습.
5. 상급과정: 공개·기관 책임과 개인 비용 감수.
6. 졸업 전: 중앙 의존을 거부하고 권한 이양.
7. 종료 후: 생활과 작은 탐사를 병행하며 후배의 다른 선택을 인정.

## 시간·이동 규칙

- 홈 생활권 내 이동은 실제 통학·대중교통 시간의 감각을 유지한다.
- 먼 지역 탐사는 학교 일정·숙박·보호자 동의·기관 허가를 요구한다.
- 긴급 상황도 순간이동으로 해결하지 않는다.
- 계절과 학사 일정은 생태 변화·경기·축제·시험과 충돌 여부를 검토한다.
- 한 사건의 복구는 다음 날 완전히 끝나지 않으며 후속 생활 비용을 남긴다.

## 공개 정보 단계

1. 개인 관찰
2. 팀 공유
3. 학교 안전 공유
4. 지역 공동체 협의
5. 기관 간 검증
6. 제한 공개
7. 일반 공개

각 단계 상승에는 이유·동의·비공개 항목·재검토일을 기록한다.

- 인물이 몰랐던 것과 독자에게 숨긴 것을 구분했는가?
- 회수로 누가 이익과 비용을 얻는가?
- 제도 변화가 생활 장면에서 확인되는가?
- 모든 빈칸을 설명해 세계의 여백을 없애지 않았는가?
