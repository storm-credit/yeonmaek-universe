# 7부제 맥거핀·복선·미스터리·결말 회수 원장 v0.2

## 1. 이전 원장 상태

v0.1은 5권 후보 구조를 기준으로 작성됐다. 핵심 기능은 유효하지만 현재 7부제·2/3/2 대형막·P-17 결말과 맞지 않으므로 `deprecated reference`로 남기고 이 문서가 활성 원장이 된다.

## 2. 핵심 맥거핀

### M-01 — 잘못 분류된 도감·분산 부담 기록

표면:
- 오래된 생물 도감과 삭제·정정 항목

실제:
- 생물 이름과 해결법을 주는 마법책이 아니라, 기관 개입 뒤 부담·권한·당사자·기록이 어디로 이동했는지 잇는 불완전 색인

욕망자:
- 하진: 서로 다른 기록을 연결해 피해를 줄이고 싶음
- 학교·기관: 보호·안전·책임 추적
- 지역 기록자: 자기 판본·비공개·갱신권
- 조사·언론: 삭제와 권한 사용의 책임
- 중앙 조율망: 빠른 비교와 경보
- 비인간 당사자: 위치·자기명칭·관계 기록 통제

결말:
- 도감 완성이나 주인공 소유가 아님
- 공동 원장, 판본 병존, 정정·철회·감사 권한 분산

실패 조건:
- 하진만 읽는 선택받은 책
- 약점·해결법 자동 출력
- 페이지 수집이 매 작품 공식이 됨
- 물리적 책 파괴로 증거와 책임이 사라짐

### M-02 — 돌림패·우선 연결권

표면:
- 긴급 위임과 접근 순서를 빠르게 연결하는 도구·권한

실제:
- 각각 최종권한이 아니어도 한 사람을 거치면 결정 순서를 사실상 지배할 수 있음을 보여 주는 권력 장치

결말:
- 관측·경보·중지·시설·거부·공개·감사 기능으로 분해
- 하진 자동 복귀·단독 접근 해체

### M-03 — P-17 보호 기록

표면:
- 삭제 항목·누락 서명·오래된 비공개 기록을 잇는 장기 질문

실제:
- 내용을 공개하면 보호 대상과 위치를 다시 위험에 빠뜨릴 수 있으나, 존재와 권한 사용을 숨기면 기관 책임을 검증할 수 없는 기록

결말:
- 내용 전면 공개가 아님
- 존재 사실, 보호 근거, 접근 이력, 감사 조건, 재검증 기한을 공개하는 `검증 가능한 비공개`
- 후속 떡밥으로 남기지 않음

## 3. 미스터리 질문 사다리

### Q0 — 왜 현실 기록과 현장 경험이 다른가

- 제시: 통학·사진·메모·센서·시설 기록의 순서와 범위 불일치
- 1부제 답: 물리적 시간여행이 아니라 같은 사건이 다른 관찰 범위에 남고 부담이 인접 경로로 이동
- 새 질문: 누가 어떤 목적으로 분류와 접근 범위를 정하는가

### Q1 — 보호는 언제 소유와 관리권이 되는가

- 제시: 모서리잠 보호실, 온기고리 등록, 길문전 안전 데이터
- 2부제 답: 선의의 보호가 반복 호출·등록·홍보·전술 사용으로 바뀔 수 있음
- 새 질문: 하나의 좋은 기준을 다른 지역에도 적용할 수 있는가

### Q2 — 더 좋은 단일 지도는 가능한가

- 제시: 중앙판·생활판·시설판·생태판 충돌
- 3부제 답: 지도들은 정확도 경쟁이 아니라 대상·목적·시기·공개 범위가 다름
- 새 질문: 최소 호환 필드와 원문 병존은 국경을 넘어도 중립적인가

### Q3 — 연결과 번역은 중립적인가

- 제시: 국제 코드가 철회·위치 비공개·시설 경고를 하나의 위험으로 통합
- 4부제 답: 어떤 기록을 먼저 읽고 번역하는지도 권력이며 현지 결정권과 분리해야 함
- 새 질문: 책임을 묻기 위해 어디까지 공개해야 하는가

### Q4 — 전면 공개가 가장 공정한가

- 제시: 환승 영상·삭제 ID·학교 기록·주민 피해
- 5부제 답: 책임·보상·운영은 공개하되 민감 위치·미성년·당사자 원문은 다른 층으로 보호
- 새 질문: 빠른 구조를 위해 권한을 모으면 더 공정하게 운영할 수 있는가

### Q5 — 중앙 조율망은 악인가

- 제시: 분산 기관의 실제 결정 지연과 연쇄 부담
- 6부제 답: 중앙망은 실제로 피해를 줄이며 하진도 성공적으로 운용함. 문제는 수용처·거부·감사·만료를 한 연결 순서에 집중하는 비용
- 새 질문: 성공한 독점 구조를 해체하고도 책임을 회피하지 않을 수 있는가

### Q6 — 주인공이 마지막 연결점이어야 하는가

- 제시: 여러 지역 예외가 하진의 우선 연결을 기다림
- 7부제 답: 자동 복귀·단독 접근을 해체하고 기능별 복수 승인과 지역 중지를 설계
- 종료: 하진은 능력과 책임을 버리지 않지만 최종 열쇠가 되지 않음

### Q7 — P-17은 왜 공개하지 않는가

- 제시: 보호 삭제와 책임 삭제가 같은 형식을 공유
- 최종 답: 내용 공개 자체가 보호 대상을 위험에 빠뜨릴 수 있음. 비공개의 근거와 권한 사용은 감사 가능해야 함
- 종료 방식: 검증 가능한 비공개, 재검증 기한, 복수 감사, 자동 만료

## 4. 대형막별 회수 구조

### 대형막 I — 발견과 소속, 부제작 1~2

시작:
- 하진은 완벽한 기록과 규칙 수행으로 문제를 혼자 줄일 수 있다고 믿음

회수:
- 기록 공유, 철수, 중지, 관계 철회를 받아들임

남기는 부채:
- 삭제 형식과 42번째 길/P-17 연결
- 도감이 생물 목록보다 권한 기록일 가능성

### 대형막 II — 표준 확장과 공개, 부제작 3~5

시작:
- 좋은 절차를 지역·국제·공개 체계로 확장하려 함

회수:
- 판본 병존, 접근 순서의 권력, 층별 공개

비가역 전환:
- 학교와 하진의 기록 접근이 외부 조사·감사 대상이 됨
- 유나가 독립 자료 주체이자 5부제 공동 중심으로 성장

남기는 부채:
- 돌림패 위임 형식과 삭제 권한의 연결
- 중앙 조율망 필요성과 위험

### 대형막 III — 권력 사용과 해체, 부제작 6~7

시작:
- 중앙화가 실제 구조 성공을 제공

회수:
- 하진이 권한을 사용해 성공한 뒤 기능·만료·감사를 분해
- P-17을 전면 폭로하지 않고 검증 가능한 비공개로 종료
- 졸업과 일반 진로를 공적 책임과 분리

종료 부채:
- 현재 사가의 핵심 질문 0
- 공유세계관 확장용 미확인 지역·생태는 새 사가 입력으로만 남기며 본 사가 결말을 빼앗지 않음

## 6. 회수 품질 기준

좋은 회수:
- 초기 장면을 다시 읽었을 때 의미가 달라짐
- 인물의 선택과 비용을 바꿈
- 현재 사건의 물리·관계·제도 결과를 바꿈
- 독자가 필요한 근거를 사전에 볼 수 있었음

나쁜 회수:
- 새 인물이 설명으로 정답을 공개
- 숨겨진 설정을 마지막에 처음 제시
- 상징만 반복하고 행동 결과가 없음
- `다음 사가에서 설명`으로 부채를 미룸
- 맥거핀이 하진의 혈통·힘·왕좌를 증명

## 7. 작품 완료 시 부채 검사

각 부제작 종료 전에 모든 강조 요소를 다음 중 하나로 닫는다.

1. 현재 작품 회수
2. 장기 회수 ID와 담당 부제작 지정
3. 인물·분위기·장소 기능 수행 후 종료
4. 의도적 비공개 + 근거·감사·재검증으로 완결
5. 삭제 또는 강조 하향

`미확인`만 적고 소유자·회수 위치가 없으면 실패다.

## 8. 최종 사가 종료 조건

- Q0~Q7의 현재 사가 답이 독자가 이해 가능한 행동과 결과로 제시됨
- F-001~F-015가 회수 또는 의도적 비공개 완결
- P-17은 후속 떡밥이 아님
- 도감·돌림패·공동 원장은 하진 개인 소유가 아님
- 하진의 책임과 능력은 남지만 자동 복귀·단독 접근은 사라짐
- 첫 통학로·학교·가족·유나·지역·해외 결과가 생활 장면으로 회수됨
