# 인물별 대사·음성 매트릭스 v1.0

## 윤서후
- 문장: 짧고 확인형. 상황을 순서대로 말한다.
- 습관: "잠깐", "돌아갈 길부터", "그럼 누가 남아?"
- 감정이 커질수록 말이 줄고 행동 지시가 구체화된다.
- 금지: 모든 상황을 완벽히 설명하는 천재형 대사.

## 김나린
- 문장: 생활 언어와 현실 질문이 빠르다.
- 습관: 비용·시간·가족 반응을 먼저 묻는다.
- 유머: 비현실적인 상황을 현실 기준으로 재단한다.
- 금지: 비밀을 모르는 평범한 친구 역할에만 머무르기.

## 박도겸
- 문장: 공간·움직임 중심. 말을 하며 몸이 먼저 움직인다.
- 습관: 거리와 통로를 비유로 말한다.
- 갈등 시 빠른 실행을 주장하되 무모함을 자랑하지 않는다.
- 금지: 단순 돌격 담당.

## 최이솔
- 문장: 정확한 단어와 조건을 고른다.
- 습관: "그건 기록과 다르다", "누가 그렇게 분류했지?"
- 감정이 상하면 지나치게 정확해진다.
- 금지: 설명 기계, 사전 같은 대사.

## 한모아
- 문장: 관찰한 행동과 기분을 연결한다.
- 습관: 인간보다 장소·생물의 반응을 먼저 말한다.
- 의견을 강요하기보다 거부 신호를 지적한다.
- 금지: 모든 생물과 대화하는 신비주의자.

## 강재원
- 문장: 결론이 빠르고 비교가 명확하다.
- 습관: 시간·성공 가능성·책임자를 묻는다.
- 성장 후에는 속도뿐 아니라 실패 후 복구 비용을 계산한다.
- 금지: 악역형 비아냥만 반복.

## 오현정
- 문장: 학생의 선택을 존중하되 책임 범위를 명시한다.
- 습관: "할 수 있느냐보다, 멈출 수 있느냐를 보자."
- 설명은 짧고 질문으로 판단을 돌려준다.
- 금지: 무능한 교사 또는 모든 답을 가진 현자.

## 배기준
- 문장: 현장 사례와 실패 경험으로 말한다.
- 습관: 제도 용어보다 실제 장소 이름을 쓴다.
- 자기 경험이 항상 정답은 아님을 점차 인정한다.
- 금지: 수수께끼만 던지는 비밀 멘토.

## 윤미정
- 문장: 귀가 시간·식사·학교 연락 같은 생활 단위로 걱정한다.
- 위기에서도 감정만 폭발하지 않고 확인할 것을 묻는다.
- 서후의 독립을 허용하면서 설명 책임을 요구한다.
- 금지: 주인공을 막기만 하는 보호자.

## 대사 검수표
- 이름을 지우고도 누가 말했는지 구별되는가.
- 같은 정보를 두 인물이 반복하지 않는가.
- 대사가 현재 욕망이나 관계를 바꾸는가.
- 청소년 대사가 성인 보고서처럼 들리지 않는가.
- 침묵·행동으로 처리할 수 있는 설명을 말로 늘이지 않았는가.
