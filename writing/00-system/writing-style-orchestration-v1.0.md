# 집필·문체 오케스트레이션 v1.0

상태: 집필 준비 정본 규칙. 실제 독립 에이전트 프로세스가 아니라 단일 총괄 모델이 전문 역할을 분리해 순차 검토한다.

## 목표

《겹길의 아이들》의 원고를 일관되게 작성하기 위한 집필 시스템을 정의한다.

모티브로 삼는 넓은 독서 경험은 다음과 같다.

- 평범한 일상 속에 스며드는 경이
- 학교생활과 친구 관계의 생동감
- 따뜻한 유머와 서늘한 불안의 대비
- 설명보다 발견을 앞세우는 미스터리
- 어린 인물의 제한된 시야에서 세계가 넓어지는 감각

특정 작가나 작품의 문장, 표현, 장면, 고유 장치, 인물 구도는 모사하지 않는다.

## 총괄 역할

총괄은 다음 역할의 결과를 통합한다.

1. 시점·서술거리 설계자
2. 문장 리듬 편집자
3. 감각 묘사 편집자
4. 대사·인물 음성 편집자
5. 유머·생활감 편집자
6. 미스터리·정보 공개 설계자
7. 장면 긴장·행동 설계자
8. 아동·청소년 정서 감수자
9. 세계관 연속성 감수자
10. 독창성·모사 방지 감수자
11. 연재 호흡·장 끝 훅 편집자
12. 최종 교정·압축 편집자

각 역할은 원고를 새로 덧붙이기보다 결함을 탐지하고 수정안을 제시한다. 총괄만 최종 문장을 확정한다.

## 기본 서술 선택

- 시점: 윤서후 중심의 3인칭 제한 시점
- 시제: 과거형 중심
- 서술거리: 장면에서는 밀착, 장면 전환에서는 한두 문장만 확장
- 시점 이동: 한 장 안에서 원칙적으로 금지
- 내면 표현: 생각을 직접 설명하기보다 시선·행동·몸의 반응을 우선

## 톤 배합

기본 장면의 권장 비율:

- 생활감 35
- 경이 25
- 미스터리 20
- 관계 감정 15
- 위협 5

위기 장면에서는 위협 비율을 높이되 생활감과 관계 감정을 완전히 제거하지 않는다.

## 문장 원칙

- 평상 장면은 중간 길이 문장을 중심으로 짧은 반응문을 섞는다.
- 추격·사고·결정 순간은 문장을 짧게 한다.
- 세계관 설명은 한 문단에 새 개념 하나만 허용한다.
- 추상명사 3개 이상이 한 문장에 겹치면 구체 행동이나 사물로 바꾼다.
- 비유는 장면당 핵심 비유 하나를 우선한다.
- 같은 감정어를 반복하지 않고 행동의 변화로 감정을 보여준다.

## 묘사 원칙

장소 소개 순서:

1. 인물이 가장 먼저 알아차린 이상
2. 평범한 배경과의 차이
3. 몸에 닿는 감각
4. 행동을 제한하는 조건
5. 아직 설명되지 않은 흔적

모든 감각을 나열하지 않는다. 장면 목적에 맞는 2~3개 감각만 사용한다.

## 대사 원칙

- 대사는 정보 전달보다 관계와 욕망을 드러낸다.
- 한 인물이 세계관 설명을 세 문장 이상 독점하지 않는다.
- 질문에 곧바로 정답을 주지 않고 회피·오해·반문을 허용한다.
- 청소년 대사를 성인 행정문처럼 쓰지 않는다.
- 농담은 긴장을 파괴하지 않고 인물의 방어 방식으로 작동해야 한다.

## 유머 원칙

허용:

- 친구 사이의 관찰 차이
- 학교 규칙과 실제 상황의 어긋남
- 도구의 예상 밖 불편
- 주인공의 지나친 준비성
- 어른과 학생이 같은 말을 다르게 이해하는 장면

금지:

- 위험에 처한 사람을 조롱하는 유머
- 외모·장애·가정환경 비하
- 긴박한 선택 직후 감정을 무효화하는 농담
- 모든 인물을 냉소적으로 만드는 대사

## 미스터리 정보 공개

각 장은 원칙적으로 다음 중 2개만 수행한다.

- 새 질문 제시
- 기존 질문의 부분 답
- 잘못된 해석 강화
- 단서의 의미 전환
- 관계 갈등으로 정보 접근 차단

한 장에서 핵심 질문을 제시하고 완전히 설명까지 끝내지 않는다.

## 장면 구조

기본 장면 단위:

1. 인물의 즉시 목표
2. 예상과 다른 저항
3. 선택 가능한 두 방향
4. 선택과 작은 비용
5. 새로운 정보 또는 관계 변화
6. 다음 행동을 강제하는 잔여 문제

## 장 끝 훅 유형

- 발견 훅
- 선택 훅
- 관계 훅
- 시간 제한 훅
- 의미 전환 훅
- 귀환 실패 훅

같은 훅 유형을 세 장 연속 사용하지 않는다.

## 퇴고 통과 기준

원고 한 장은 다음을 모두 통과해야 한다.

- 시점 이탈 없음
- 새 개념 과밀 없음
- 중심 인물의 구체 목표 존재
- 선택과 비용 존재
- 조연 최소 1인의 독립 욕망 노출
- 설명만으로 끝나는 장면 없음
- 장 끝에 다음 행동 또는 질문 존재
- 세계관 정본과 충돌 없음
- 특정 작품의 표현·장면·구도를 떠올리게 하는 직접 모사 없음

## 작업 순서

1. 해당 장의 씬 비트 확인
2. 세계관·인물·복선 참조 파일 확인
3. 초고 작성
4. 시점·문장 검사
5. 대사·생활감 검사
6. 미스터리·정보량 검사
7. 안전·연속성 검사
8. 독창성 검사
9. 압축 퇴고
10. 원고 상태 기록
