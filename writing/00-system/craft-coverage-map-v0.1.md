# 집필 기법 전수 지도 v0.1

상태: P1. 이 문서는 소설 집필 기법 전체를 축으로 나열하고, 각 축이 이 저장소의 어느 정본으로 관리되는지, 빈틈이 무엇인지 추적한다. 새 기법 문서를 만들면 여기에 등록한다.

## 사용법

- 장 집필 전: 해당 장에 걸리는 축의 담당 문서를 확인한다.
- Act 감사 시: `부분`·`없음` 축이 실제 원고에서 문제를 일으켰는지 점검한다.
- 상태: `완비`(전용 규칙 있음) / `부분`(다른 문서에 흩어짐) / `없음`(관리 안 됨).
