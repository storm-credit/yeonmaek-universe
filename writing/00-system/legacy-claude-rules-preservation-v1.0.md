# Legacy CLAUDE Rules Preservation v1.0

목적: 2026-08-08 마이그레이션 전 `CLAUDE.md`의 세부 운영·집필 규칙을 상위 계약에서 분리하되 손실 없이 보존한다. 충돌 시 Canon Constitution이 우선한다.

## 보존된 구조 운영 규칙

- 기존 공식 구조: 시리즈 → 5부 → 15 Act → 45 Subact → 90장 → 장별 씬 비트 → 원고
- 각 부 3 Act, 각 Act 3 Subact, 각 Subact 원칙적으로 2장
- 기존 Sequence는 기능 초안·상위 원장으로 보존
- Subact는 제목, 시작 상태, 주도 인물, 중심 갈등, 핵심 사건, 중간 반전, 선택/결정, 비용, 관계 변화, 복선, 종료 전환, 대응 장을 갖춤
- 이전 Subact의 결과가 다음 Subact의 시작 조건을 바꿈
- 기관 단순 악역화, 학생의 법적 최종 권한, 복선의 장식화 금지
- 제5부 결말은 권한·도구·교육 분산으로 귀결

## 보존된 문체 기준선

- 윤서후 중심 3인칭 제한 시점
- 과거형 중심
- 장 내 시점 이동 원칙적 금지
- 생활감·경이·미스터리·관계 감정·위협의 조화
- 경이는 화려한 명칭보다 평범한 규칙의 어긋남으로 표현
- 설명보다 발견과 오판 우선
- 감정은 몸의 반응·습관 변화·선택으로 표현
- 위험 뒤 생활 비용과 회복 장면 필수

상세 정본은 다음 파일을 우선한다.

- `writing/10-style/voice-and-prose-guide-v1.0.md`
- `writing/20-dialogue/character-voice-matrix-v1.0.md`
- `writing/60-recitation/read-aloud-line-criteria-v0.1.md`

## 보존된 독창성 경계

허용: 일상 속 경이, 학교 공동체와 성장, 따뜻한 유머와 불안의 대비, 제한된 청소년 시야, 발견 중심 미스터리.

금지:
- 특정 작가의 문장·비유·리듬 모사
- 특정 작품의 장면·인물 관계·학교 장치 일대일 대응
- 기숙사·가문·선택받은 혈통·대표 마법 도구의 표면 복제
- 기존 작품 장면의 명칭만 바꾼 재사용

모든 경이와 갈등은 귀환권·접근권·관찰권·기록권·공개권 규칙에서 발생해야 한다.

## 보존된 집필 전 입력

- 해당 부 Act 설계
- 해당 Subact 정식 명세
- 해당 장 설계와 씬 비트
- 직전 장 결과
- 인물 음성 매트릭스
- 관련 세계관·복선 정본
- 장별 최소 분량 정책

현재는 Canon에 따라 신규 원고가 잠겨 있다.

## 보존된 장별 집필·검수 순서

1. Act·Subact·즉시 목표 확인
2. 첫 10% 안 생활 목적 또는 이상 징후
3. 장면별 저항·선택·비용
4. 행동 중 필요한 정보만 공개
5. 관계 또는 세계 이해 변화
6. Subact 반전·비용·종료 전환 기여
7. 다음 행동을 강제하는 훅
8. 전문 역할 검수
9. 압축 퇴고
10. 연속성·복선·표기 확인
11. 상태 기록과 원격 반영

통과 기준:
- 시점 이탈 없음
- 즉시 목표, 선택, 비용 존재
- 조연 독립 욕망 노출
- 새 개념 과밀·설명 전용 장면 없음
- 인물별 말투 구별
- Subact 기능 기여
- 장 끝 행동·질문·관계 변화
- 세계관·연표·거리·학사·권한 충돌 없음
- 직접 모사 위험 없음

## 보존된 자동 진행·이탈 규칙

- 사용자가 이어서 진행·자동 진행·끝까지 진행을 지시하면, 현재 잠금과 완료 게이트 안에서 미완료 항목을 계속 처리한다.
- 기존 순서였던 `정본 확인 → Act 확인 → Subact 확인 → 장·씬 비트 확인 → 집필/문체 작업 → 역할별 검사 → 독창성 검사 → 상태 갱신 → main 반영`은 새 `WORKFLOW_HARNESS.md`의 12단계로 대체한다.
- 원고 잠금 중에는 위 순서의 집필 단계에 진입하지 않고 설정·구조·장부 보완으로 되돌아간다.
- 실패하거나 계획과 달라지면 이유·영향·대체 결정을 `docs/00-project/deviation-log.md`와 Decision Log에 기록한다.
- 완료되지 않은 작업을 완료로 보고하지 않는다.
