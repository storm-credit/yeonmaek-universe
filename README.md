# Yeonmaek Universe

범아시아 동양 판타지 세계관을 **소설 본문보다 먼저 설계**하기 위한 저장소입니다.

## 핵심 목표

- 한국을 첫 관찰점으로 삼되, 처음부터 동아시아·동남아시아·내륙아시아·남아시아·서양 접촉권까지 확장 가능한 구조를 만든다.
- 서양식 마법학교를 동양 장식으로 바꾸지 않고, 지역별 자연관·수련·생태·의례가 서로 다른 방식으로 초자연 현상을 해석하도록 설계한다.
- 국가별 클리셰가 아니라 산맥·강·계절풍·해류·교역로를 따라 형성된 `맥권`을 기본 단위로 검토한다.
- 세계관, 술법, 생물, 기관, 현실 연결 규칙, 대표 경기와 검증 절차를 문서화한다.

## 하지 않는 일

- 소설 원고, 장면, 대사, 회차를 작성하지 않는다.
- 조사되지 않은 문화를 즉석에서 신비화하거나 한 국가를 하나의 마법으로 환원하지 않는다.
- 확정되지 않은 아이디어를 정본으로 취급하지 않는다.

## 저장소 구조

```text
agents/       전문가 에이전트 역할과 종료 조건
docs/         프로젝트 운영, 결정, 조사, 검증 기록
memory/       장기 컨텍스트와 미해결 질문
world/        실제 세계관 설계 모듈
templates/    지역·문화·술법·생물·기관 설계 양식
.github/      조사/설계 이슈와 PR 검토 양식
```

## 표준 작업 순서

`컨텍스트 덤핑 → 작가 인터뷰 → 성공 조건 → 설계안 4개 → 맹점 점검 → 근거 조사 → 전문가 합성 → 반대 검토 → 결정 기록 → 영향도 점검 → 메모리 갱신`

## 정본 상태

- `hypothesis`: 검토 전 가설
- `candidate`: 비교 중인 후보
- `provisional`: 임시 채택
- `canon`: 근거와 영향 검토를 통과한 정본
- `deprecated`: 폐기되었지만 추적을 위해 보존

현재 세계관 내용은 대부분 `hypothesis` 또는 `candidate`입니다.
