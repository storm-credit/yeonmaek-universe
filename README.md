# Yeonmaek Universe

범아시아 동양 판타지의 **세계관 설정집과 장기 이야기 설계도**를 소설 본문보다 먼저 완성하기 위한 저장소입니다.

> 정리 브랜치: `canon/world-bible-blueprint-clean`  
> 원고 보관 브랜치: `archive/full-saga-draft-unapproved`

현재 정리 브랜치에는 세계관·인물·학교·기관·생태·지역·능력 체계와 장기 사가 설계 후보만 유지합니다. 실제 소설 원고와 원고 완료를 전제로 한 문서는 아카이브 브랜치에 보존하며, 이 브랜치에서는 새 원고를 작성하지 않습니다.

## 현재 정확한 상태

- 세계관·C0 내부 설정집: `candidate-complete`
- 한국 학교·가족·도시 홈베이스: 상세 후보 존재
- 생물·유물·회랑·영웅·수집 구조: 상세 후보 존재
- 장기 사가: 7부제 후보 설계 존재
- 상세 분량: 117장·234장면 카드 후보 존재
- 웹연재 분량: 200화 변환 후보 존재
- 실제 원고: 정리 브랜치에서 제외
- final canon·출판 준비: 미완료

7부제·117장·200화는 사용자가 최종 확정한 값이 아니라 검토 가능한 설계 후보입니다.

## 핵심 목표

- 한국을 첫 관찰점으로 삼되 범아시아 확장이 가능한 구조를 만든다.
- 서양식 마법학교를 동양 장식으로 바꾸는 데 그치지 않고, 지역별 자연관·수련·생태·의례와 현대 생활이 초자연 현상을 다르게 해석하게 한다.
- 국가별 클리셰가 아니라 산맥·강·계절풍·해류·교역로와 현대 국가·도시·기관이 중첩되는 구조를 검토한다.
- 결말부터 역산해 시리즈 구조, 맥거핀, 복선, 미스터리, 캐릭터 변화, 학교 반복 루프까지 설계한다.
- 원고 작성 전에 세계관 바이블·시리즈 바이블·복선 원장·지역 조사·정본 관리 체계를 완성한다.

## 현재 핵심 세계 구조 후보

- 범아시아: 생태 회랑/맥권+현대 국가+지역 전승 공동체의 혼합 중첩형
- 현실 연결: 현재 한국과 거의 같은 현실의 서로 다른 깊이
- 비밀 유지: 지각 정상화, 센서 불일치, 사회적 은폐
- 힘 체계: 공통 관측 현상과 지역별 존재론·실천을 분리하는 층위 호환형
- 한국 시작점: 서울·수도권의 도시·산·강·지하 기반시설 혼합형
- 첫 기관: 표면 특성화 학교+연구재단+심층 학궁·보호구역
- 대표 경기: 이동·공간·중지 판단을 결합한 후보 체계
- 생물 분류: 서식·생활사·인지·관계·위험·보존의 다축 프로필형

`맥`, `연맥`, `겹길` 등의 명칭은 작업어이며 최종 제목이나 보편 명칭으로 확정하지 않았습니다.

## 우리가 만드는 설계도

```text
세계관 바이블
├─ 세계 원리·현실 연결·힘·생태
├─ 범아시아 지역·국가 조사
├─ 학교·기관·경기·교육
└─ 지도·연표·용어·도감

작품 바이블
├─ 최종 결말과 역산 인과
├─ 메인 사가와 부제작 구조 후보
├─ 맥거핀·복선·미스터리 원장
├─ 캐릭터 기능·관계 변화
└─ 주제·정보 공개·페이싱
```

## 최우선 운영 규칙

- 소설 원고, 장면 대사, 연재 본문을 작성하지 않는다.
- `진행`, `계속`, `이어서진행`, `자동으로 끝까지`는 설정집·설계도 자동 진행만 뜻한다.
- 원고 작성은 사용자가 작품명과 범위를 특정해 명시적으로 승인한 경우에만 별도 브랜치에서 시작한다.
- 조사되지 않은 문화를 즉석에서 신비화하거나 국가 하나를 마법 하나로 환원하지 않는다.
- 한국을 모든 술법의 원조·최강으로 만들지 않는다.
- 현존 종교의 신성 존재를 조사 없이 생물·몬스터·스킬로 전용하지 않는다.
- `candidate → canon` 승격은 작가 승인과 필수 검토 없이 하지 않는다.
- 기존 PR #1은 원고가 섞인 기록 보존용 Draft이며 자동 Ready·병합하지 않는다.

## 정본 상태

- `hypothesis`: 검토 전 가설
- `candidate`: 비교 중 후보
- `provisional`: 임시 채택
- `canon`: 작가 승인과 필수 검토 통과
- `deprecated`: 폐기되었지만 추적 보존

## 다음 자동 진행 순서

1. 남은 원고 참조와 끊어진 링크 정리
2. 세계관·사가·부제작 source-of-truth 재지정
3. 7부제·117장·200화 후보 적합성 재감사
