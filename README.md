# Yeonmaek Universe

범아시아 동양 판타지 **세계관과 작품 전체를 소설 본문보다 먼저 설계**하기 위한 저장소입니다.

> 현재 단계는 세계관·작품 아키텍처 v0.2입니다. 사용자 명시 사항을 제외하면 대부분 `candidate` 또는 `provisional`이며 아직 작품 정본이 아닙니다.

## 핵심 목표

- 한국을 첫 관찰점으로 삼되 동아시아·동남아시아·내륙아시아·남아시아·서양 접촉권까지 확장 가능한 구조를 만든다.
- 서양식 마법학교를 동양 장식으로 바꾸지 않고 지역별 자연관·수련·생태·의례와 현대 생활이 다른 방식으로 초자연 현상을 해석하게 한다.
- 국가별 클리셰가 아니라 산맥·강·계절풍·해류·교역로와 현대 국가·도시·기관이 중첩되는 구조를 검토한다.
- 결말부터 역산해 권별 구조, 맥거핀, 복선, 미스터리, 캐릭터 변화, 학교 반복 루프까지 설계한다.
- 원고 작성 전에 세계관 바이블·시리즈 바이블·복선 원장·지역 조사·정본 관리 체계를 완성한다.

## 현재 1순위 세계 구조

- 범아시아: 생태 회랑/맥권+현대 국가+지역 전승 공동체의 혼합 중첩형
- 현실 연결: 현재 한국과 거의 같은 현실의 서로 다른 깊이
- 비밀 유지: 지각 정상화, 센서 불일치, 사회적 은폐
- 힘 체계: 공통 관측 현상과 지역별 존재론·실천을 분리하는 층위 호환형
- 한국 시작점: 서울·수도권의 도시·산·강·지하 기반시설 혼합형
- 첫 기관: 표면 특성화 학교+연구재단+심층 학궁·보호구역
- 대표 경기: 맥로 개척전+진문 쟁탈전 결합안 시험 중
- 생물 분류: 서식·생활사·인지·관계·위험·보존의 다축 프로필형

`맥`은 한국권 또는 저장소의 작업어이며 세계 전체의 보편명으로 확정하지 않았습니다.

## 우리가 만드는 설계도

```text
세계관 바이블
├─ 세계 원리·현실 연결·힘·생태
├─ 범아시아 지역·국가 조사
├─ 학교·기관·경기·교육
└─ 지도·연표·용어·도감

작품 바이블
├─ 최종 결말과 역산 인과
├─ 시리즈/권별 구조
├─ 맥거핀·복선·미스터리 원장
├─ 캐릭터 기능·관계 변화
└─ 주제·정보 공개·페이싱
```

## 에이전트 오케스트라

- `AGENTS.md`: 최상위 라우팅과 승인권
- `docs/14-agent-orchestra-v0.2.md`: 왜 어떤 에이전트가 필요한지
- `agents/countries/`: 한국·중국·일본·몽골·동남아·중앙아시아·남아시아 국가별 전문가
- `agents/narrative/`: 결말 역산·맥거핀·복선·미스터리·인과·캐릭터·페이싱 전문가
- `agents/production/`: 정본·용어·연표·지도·도감·출처·독자 이해도 관리자
- `docs/15-narrative-methods-catalog-v0.1.md`: 56개 작품 설계 방법 목록

## 하지 않는 일

- 소설 원고, 장면, 대사, 회차를 작성하지 않는다.
- 조사되지 않은 문화를 즉석에서 신비화하거나 국가 하나를 마법 하나로 환원하지 않는다.
- 한국을 모든 술법의 원조·최강으로 만들지 않는다.
- 현존 종교의 신성 존재를 조사 없이 생물·몬스터·스킬로 전용하지 않는다.
- 공식 문화유산 등재를 창작 사용 허가로 해석하지 않는다.
- 결말과 인과에 기여하지 않는 설정을 무한 확장하지 않는다.

## 표준 작업 순서

`컨텍스트 → 성공 조건 → 에이전트 라우팅 → 4안 → 결말/인과 영향 → 근거 조사 → 통합 → 반대 검토 → 결정 → 영향도 → 메모리`

## 정본 상태

- `hypothesis`: 검토 전 가설
- `candidate`: 비교 중 후보
- `provisional`: 임시 채택
- `canon`: 작가 승인과 필수 검토 통과
- `deprecated`: 폐기되었지만 추적 보존

현재 다음 대형 단계는 **결말 상태 4안 → 시리즈 권수 구조 4안 → 핵심 비밀과 맥거핀 → 복선·회수 원장** 순서입니다. 원고 작성은 별도 집필 단계에서만 시작합니다.
