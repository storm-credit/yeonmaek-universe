# Yeonmaek Universe

범아시아 동양 판타지 세계관을 **소설 본문보다 먼저 설계**하기 위한 저장소입니다.

> 현재 단계는 세계관 아키텍처 v0.1입니다. 아래 내용은 사용자 명시 사항을 제외하면 대부분 `candidate` 또는 `provisional`이며 아직 작품 정본이 아닙니다.

## 핵심 목표

- 한국을 첫 관찰점으로 삼되, 처음부터 동아시아·동남아시아·내륙아시아·남아시아·서양 접촉권까지 확장 가능한 구조를 만든다.
- 서양식 마법학교를 동양 장식으로 바꾸지 않고, 지역별 자연관·수련·생태·의례가 서로 다른 방식으로 초자연 현상을 해석하도록 설계한다.
- 국가별 클리셰가 아니라 산맥·강·계절풍·해류·교역로와 현대 국가·도시·기관이 중첩되는 구조를 검토한다.
- 세계관, 술법, 생물, 기관, 현실 연결 규칙, 대표 경기와 검증 절차를 문서화한다.

## 현재 1순위 구조

- **범아시아 구조:** 생태 회랑/맥권+현대 국가+지역 전승 공동체의 혼합 중첩형
- **현실 연결:** 현재 한국과 거의 같은 현실의 서로 다른 깊이
- **비밀 유지:** 완전 기억 삭제가 아니라 지각 정상화, 센서 불일치, 사회적 은폐
- **힘 체계:** 공통 관측 현상과 지역별 존재론·실천을 분리하는 층위 호환형
- **한국 시작점:** 서울·수도권의 도시·산·강·지하 기반시설 혼합형
- **첫 기관:** 표면 특성화 학교+연구재단+심층 학궁·보호구역
- **대표 경기:** 맥로 개척전+진문 쟁탈전 결합안을 단순화 시험 중
- **생물 분류:** 서식·생활사·인지·인간 관계·위험·보존을 분리한 다축 프로필형
- **시각 앵커:** 도시 수목원 온실+지하 합류전+수위선 문+장각 이동종+계단식 경기장 후보

`맥`은 한국권 또는 저장소의 작업 용어이며 세계 전체가 사용하는 보편명으로 확정하지 않았습니다.

## 하지 않는 일

- 소설 원고, 장면, 대사, 회차를 작성하지 않는다.
- 조사되지 않은 문화를 즉석에서 신비화하거나 한 국가를 하나의 마법으로 환원하지 않는다.
- 한국을 모든 술법의 원조·최강으로 만들지 않는다.
- 현존 종교의 신성 존재를 조사 없이 생물·몬스터로 직접 전용하지 않는다.
- 공식 문화유산 등재를 창작 사용 허가로 해석하지 않는다.
- 확정되지 않은 아이디어를 정본으로 취급하지 않는다.

## 표준 작업 순서

`컨텍스트 덤핑 → 작가 인터뷰 → 성공 조건 → 설계안 4개 → 맹점 점검 → 근거 조사 → 전문가 합성 → 반대 검토 → 결정 기록 → 영향도 점검 → 메모리 갱신`

## 문화 연구 원칙

- 국가 전체가 아니라 구체적인 지역·시대·현상 단위로 조사한다.
- 태국·베트남·미얀마와 대륙부 동남아를 하나의 문화로 취급하지 않는다.
- 중국·일본·한국도 내부 지역과 복수 전통을 분리한다.
- 실제 사실, 기능 추상화, 복합 변형, 완전 창작을 문서에서 구분한다.
- 현존 종교·소수집단·신성 의례는 높은 감수 게이트를 적용한다.
- A등급 공식 자료도 단독 정본 근거가 될 수 없다.

## 정본 상태

- `hypothesis`: 검토 전 가설
- `candidate`: 비교 중인 후보
- `provisional`: 임시 채택
- `canon`: 근거와 영향 검토를 통과한 정본
- `deprecated`: 폐기되었지만 추적을 위해 보존

## 현재 승인 대기

- 청소년 중심 전연령 크로스오버 톤
- 범아시아 혼합 중첩형
- 중첩 현실과 불완전한 비밀 유지
- 서울·수도권 시작점
- 특성화 학교+연구재단 혼합 기관
- 대표 경기의 활성자-봉화 단순화안
- 첫 시각 앵커 조합

승인 전 대량 생물·술법·학교·국가 설정 생성으로 넘어가지 않습니다. 다음 연구 단계는 한국 내부 권역, 태국 파일럿, 베트남 파일럿입니다.
